# P4185R0 - one-time LLM read-back validation

This is a one-time, manual empirical record. It is NOT a CI gate and is inert to
every whisker corpus loader (no `.gt.md` / `.expected.md` / `.facts.jsonl` /
`.anchors.json` suffix match). The enforced gate is the deterministic, LLM-free
`check_facts` run in `tests/test_comprehension_corpus.py` over
`P4185R0.facts.jsonl` against `P4185R0.expected.md`.

## Why this exists

The Lane 3 facts are a deterministic PROXY for "what a downstream LLM must be able to
read from the converted markdown." This document closes the loop that the
deterministic test cannot: it confirms ONCE, empirically, that a real LLM given
only the converted markdown answers the same questions the facts assert. After
this anchor, the deterministic facts stand in for the LLM in CI (determinism,
reproducibility, cost, model-sovereignty: no LLM in the scoring loop).

A round-trip "regenerate similar text" check was deliberately rejected: LLMs
paraphrase, so resemblance measures fidelity, not comprehension. The test is
question answering ("row X, column Y reads what?"), which is read -> understood
-> correct.

## Why this paper matters

P4185R0 is the FIRST corpus member to exercise the `math` fact type (P4182R0 had
no formulas). The four `math` facts are the load-bearing cases here, the analogue
of the two `table` facts for P4182R0, because a faithful-looking reflow can drop
an exponent or a sign and every fidelity metric stays green. The blind reader
recovered all four formulas exactly, anchoring that the deterministic math facts
are a faithful proxy for LLM comprehension of the formulas.

## Method

A fresh, isolated LLM context (a readonly subagent running the gpt-5.5-medium
model) received ONLY the converted markdown (no source HTML, no facts file, no
authoring rationale) plus 9 questions, and answered blind. Answers were compared
to the 9 `checked: verified` facts in `P4185R0.facts.jsonl`.

## Questions (mapped to fact ids)

- Q1 `math-even-power-nonneg` (math): the inline formula for even-power non-negativity. Expected `\(x^{2k} \geq 0\)`.
- Q2 `math-gravitational-pe` (math): gravitational potential energy U. Expected `\(U = -G \cdot m_1 \cdot m_2 / r\)`.
- Q3 `math-reactive-power` (math): reactive power Q in terms of U_rms, I_rms, phase. Expected `\(Q = U_\text{rms} \cdot I_\text{rms} \cdot \sin\varphi\)`.
- Q4 `math-helmholtz` (math): Helmholtz energy A. Expected `\(A = U - T{\cdot}S\)`.
- Q5 `table-anchored-true-zero` (table): Point/Absolute/Delta feature table, "Physical origin" row, "Absolute" column cell. Expected "Anchored at true zero".
- Q6 `table-text-output-point-no` (table): same table, "Text output" row, "Point" column symbol. Expected a cross (✗).
- Q7 `present-temperature-trap` (present): the two-word name for the offset-unit/affine problem. Expected "temperature trap".
- Q8 `absent-audience-label` (absent): whether a literal "Audience:" label leaks into the body vs. only front matter. Expected: only front matter (`audience: SG6 Numerics`); no body label.
- Q9 `section-flow` (order): order of Abstract, Motivation and scope, Non-negative quantities, Absolute quantities, Acknowledgments. Expected that order.

## Runs

One blind run, fresh context, gpt-5.5-medium, reading the committed
`P4185R0.expected.md` directly. Result: 9/9.

Every answer matched the verified facts, including all four math formulas quoted
VERBATIM with their `\( ... \)` delimiters, both table cells, and the exact
section order.

## Conclusion

The converted markdown is LLM-readable for these facts, and the deterministic
facts are a faithful proxy for what the LLM actually recovers. The deterministic
gate may stand in for the LLM in CI.

## Reproduce

Deterministic gate (LLM-free, this is what CI runs):

```
uv run pytest packages/whisker/tests/test_comprehension_corpus.py
```

The blind read-back is manual: hand only `P4185R0.expected.md` plus the 9
questions above to a fresh LLM context and compare its answers to the verified
facts.
