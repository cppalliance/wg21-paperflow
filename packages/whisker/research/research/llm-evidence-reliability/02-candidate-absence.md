# 02 - Candidate-Absence Auditor

**Verdict:** usable-with-conditions (+ a two-sided deterministic contract is architecturally sound and matches olmOCR-bench plus whisker Lane 3, but only after candidate-side matching, sanctioned-reformat exemptions, and tri-state routing are specified; the current PDF judge proves source presence only and mislabels 60% of replay quotes)
**Confidence:** high

## Findings

- [CRITICAL] The PDF judge never verifies candidate absence; it only grounds quotes against the PDF text layer and then asserts absence in the sidecar label. `pdf_judge.py:513-520` calls `ground_spans(spans, pdf_text)` (source-side only); `pdf_judge.py:401-404` emits `"present in PDF text layer, absent from markdown"` for every retained quote with no second pass over `tomd_md`. Page escalation repeats the one-sided pattern: `pdf_judge.py:572-574` grounds against `page_text` only via `ground_page_quotes`. Impact: 12/20 replay quotes (PR #285 0/5, PR #290 0/5, PR #284 2/5) were false-absent per `00-baseline.md:16-19`; evidence precision 8/20 = 40% while verdict recall still improved because deterministic gates caught separate defects.

- [CRITICAL] AbsenceBench and fusion policy both say LLM absence claims are untrustworthy without deterministic candidate verification. `05-web.md` Q1 cites AbsenceBench (models systematically fail surface-form absence even with both documents in context); `fusion.py:174-176` blocks `review -> pass` when `missing_region_count > 0` because the LLM "structurally cannot verify the absence of content." Impact: the PDF lane's missing-content quotes are the same signal class fusion already distrusts; shipping them as grounded evidence without a candidate check contradicts existing safety policy.

- [HIGH] olmOCR-bench `TextPresenceTest` is the portable contract: symmetric PRESENT/ABSENT on the same normalized surface with a length-relative fuzzy threshold. `packages/whisker/research/repos/olmocr/olmocr/bench/tests.py:150-182` normalizes both needle and haystack (`:47-80` strips bold/italic/HTML, collapses whitespace), computes `threshold = 1.0 - max_diffs / len(reference_query)` (`:167-168`), and uses `fuzz.partial_ratio` on the candidate only (`:169`). PRESENT passes when `best_ratio >= threshold`; ABSENT passes when `best_ratio < threshold`. Impact: whisker already ports the page-quote threshold in `ground_page_quotes` (`grounding.py:272-273`, `constants.py:176-181`) but applies it source-side only; the missing piece is the identical check inverted against `tomd_md`.

- [HIGH] Whisker Lane 3 `facts.py` already implements a stricter, higher-precision candidate locate than olmOCR's partial_ratio whole-string test. `facts.py:324-326` `_present_within` uses exact substring first, then `fuzz.partial_ratio_alignment` plus exact edit-distance DP (`:300-321`); `facts.py:441-444` defines ABSENT as `not _present_within`. olmOCR's own tests document partial_ratio false-present risk: `test_tests.py:174-180` `"max"` fails ABSENT against `"maximum"` (substring overlap); `test_tests.py:162-172` shows ABSENT with `max_diffs=2` tolerates two edits but not three. Impact: for quote-level absence, `_present_within` on a contract-normalized markdown surface is the safer candidate oracle than reusing `ground_spans`'s whole-document `partial_ratio` tier (`grounding.py:232-237`, `EVIDENCE_FUZZY_FLOOR=0.90` over full doc).

- [HIGH] Proposed high-precision candidate-absence contract (research artifact; no code in this run). For each LLM missing-content quote `q` after source grounding succeeds:

  1. **Preprocess both sides** with a shared conversion-aware normalizer (extend `normalized_text` or add `candidate_match_surface(md)`): collapse whitespace; strip sanctioned markers (`<!-- tomd:... -->`, binary-payload replacements per `constants.py:95-108`); map YAML front-matter keys to their body equivalents (contract in `pdf_judge.py:129-136`); dehyphenate line-break splits (`pdf_judge.py:96-108` `_dehyphenate` pattern); optionally fold wording-markup interiors to prose (`pdf_judge.py:152-156`).
  2. **Source presence** (retain existing): `ground_spans([q], pdf_text)` or `ground_page_quotes([q], page_text)` must not drop the quote.
  3. **Candidate locate** (new): run `_present_within(norm_q, norm_md, max_diffs)` where `max_diffs = PAGE_QUOTE_MAX_DIFFS` (2) for quotes under 40 normalized chars, else scale as olmOCR: `max_diffs = max(2, round(len(norm_q) * (1 - EVIDENCE_FUZZY_FLOOR)))` capped at `len(norm_q) // 4`.
  4. **Tri-state outcome** per quote: `confirmed_absent` (source grounded, candidate locate fails); `refuted_present` (candidate locate succeeds at exact or within budget); `ambiguous` (candidate locate succeeds only at whole-doc `partial_ratio` with no edit-distance confirmation, or quote shorter than `EVIDENCE_MIN_FUZZY_CHARS` (20, `constants.py:69-73`) without exact/normalized-substring hit).
  5. **Verdict policy**: retain quote in sidecar only for `confirmed_absent`; drop or demote `refuted_present`; route `ambiguous` to abstention (do not count toward missing-content evidence; demote monolith/page verdict to `review` if any deciding quote is ambiguous). If all quotes are `refuted_present`, demote verdict one tier and zero `grounded_evidence` missing-content entries.
  6. **Provenance fields** (sidecar): `source_grounding` (`exact|fuzzy|dropped`), `candidate_status` (`confirmed_absent|refuted_present|ambiguous`), `match_tier`, `max_diffs_used`, `reason_code` (e.g. `front_matter_migration`, `dehyphenation`, `markup_equivalence`, `reordered_present`).

  Model boundary: revise if a labeled holdout shows `_present_within` suppresses genuine sub-resolution defects (e.g. PR #293 `constexpr` token swaps) at the proposed budgets, or if Markdown-aware normalization cannot reach 90%+ evidence precision on the nine-PR replay without NLI.

- [MED] `ground_spans` fuzzy tiers are unsafe as the sole candidate-absence oracle. Whole-document `partial_ratio` (`grounding.py:232-237`) compares the quote against the entire markdown; `EVIDENCE_MIN_FUZZY_CHARS` gates only the ratio tier, not normalized substring (`grounding.py:230-231`). A generic phrase or a substring of a longer present passage can false-clear a genuine absence. Impact: naively calling `ground_spans(quotes, tomd_md)` and treating dropped quotes as "confirmed absent" inverts the logic and inherits false-present risk from the text-lane grounding path.

- [MED] Sanctioned conversion behavior creates predictable false-absent clusters if the candidate check is naive. `pdf_judge.py:129-164` lists YAML front-matter migration, TOC removal, page furniture drop, figure text, dehyphenation, and wording markup; the prompt tells the model not to quote these (`pdf_judge.py:188-192`) but post-hoc verification does not enforce it. Baseline PR #290 (date lines already present, some twice, `00-baseline.md:18`) matches front-matter/body duplication false-absent. Impact: contract step 1 (normalizer + front-matter map) is load-bearing, not optional polish.

- [LOW] Page-scoped escalation inherits the same absence gap. `models.py:104-112` scopes the LLM to confirm a screen flag, not open-ended absence detection; `pdf_judge.py:576` sets `confirmed = page_judgment.content_missing and bool(page_quotes)` where `page_quotes` are source-grounded only. Impact: page-attributed quotes (`pdf_judge.py:592`) need the same candidate-side tri-state before extending `[pN]` attribution to sidecar evidence.

## False-pass hypothesis

PR #285 / PR #290 class: the judge emits missing-content quotes for YAML date lines or body prose that already exists in the converted markdown (`00-baseline.md:17-18`). Current pipeline retains them after source grounding (`pdf_judge.py:519-520`, `401-404`), inflating missing-content evidence and potentially capping a pass at review (`pdf_judge.py:527-538`) on phantom gaps. A reviewer treating sidecar quotes as actionable absence wastes triage on content that is present.

## False-fail hypothesis

PR #293 class: five `constexpr` declarations genuinely absent (`00-baseline.md:19`). If candidate-side matching uses whole-document `partial_ratio` at `EVIDENCE_FUZZY_FLOOR=0.90` without edit-distance confirmation, a partial token overlap elsewhere in a long WG21 paper could mark a quote `refuted_present` and drop all five confirmed misses, demoting a legitimate fail toward pass/review. olmOCR's length-relative threshold (`tests.py:167-168`) plus whisker's `_present_within` DP (`facts.py:300-321`) are the mitigation; flat ratio alone is not.

## What would change my mind

A labeled replay of the nine-PR set (`00-baseline.md:11-12`) applying the proposed contract with per-quote labels, showing evidence precision >= 0.90 with recall on the eight confirmed-absent quotes (PR #284 3/5 + PR #293 5/5) >= 0.875, OR a counterexample where `_present_within` with `PAGE_QUOTE_MAX_DIFFS=2` false-clears a manually verified absent quote from PR #293.
