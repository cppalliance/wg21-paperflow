# 27 - Determinism Auditor

**Verdict:** usable-with-conditions (+ `ground_spans`/`ground_page_quotes` are pure deterministic functions suitable for a two-sided verifier, but the PDF lane still one-side-grounds, LLM quote selection and guard tags inject rerun variance, and `PdfJudgeResult.to_sidecar_dict` omits the sorted provenance contract the text lane already follows)
**Confidence:** high

## Findings

- [CRITICAL] The PDF judge proves source presence only; candidate absence is an LLM claim baked into a deterministic-looking sidecar label. `judge_pdf_extraction` calls `ground_spans(spans, pdf_text)` (`pdf_judge.py:513-520`) and never runs a symmetric check on `tomd_md`, yet `to_sidecar_dict` hardcodes every retained quote as `"present in PDF text layer, absent from markdown"` (`pdf_judge.py:401-404`). Baseline replay measured **8/20 = 40%** candidate-absence precision (`00-baseline.md:14-24`). Impact: a two-sided verifier cannot be replay-stable on evidence disposition until candidate grounding is a separate deterministic pass; today reruns can agree on source grounding while the unverified absence label stays wrong.

- [HIGH] `ground_spans` monotonic exact-occurrence DP is deterministic and fixes repeated-quote collision. `_select_monotonic_matches` (`grounding.py:102-168`) maps model-output-order spans to successive non-overlapping token runs; `test_repeated_quote_maps_to_successive_occurrences` locks the contract (`tests/test_tapetum_llm.py:1273-1288`). Per-span processing preserves model list order (`grounding.py:210-241`). Impact: porting this function unchanged to the candidate side of a two-sided verifier gives stable `present | absent | ambiguous` routing for repeated mentions (olmOCR `TextPresenceTest` pattern, `05-web.md` Q1).

- [HIGH] Fuzzy tiers are deterministic given fixed inputs but asymmetric and whole-document-biased on the monolith path. `ground_spans` uses normalized substring then `rapidfuzz.partial_ratio` against the entire haystack at `EVIDENCE_FUZZY_FLOOR = 0.90` with `EVIDENCE_MIN_FUZZY_CHARS = 20` (`grounding.py:230-237`, `constants.py:67-73`); `ground_page_quotes` uses olmOCR length-relative `1.0 - PAGE_QUOTE_MAX_DIFFS / len(quote)` (`grounding.py:272-274`, `constants.py:176-181`). `facts._best_match` localizes rapidfuzz then exact DP (`facts.py:299-321`), closer to the candidate-absence oracle baseline proposes (`00-baseline.md:61-68`). Impact: a two-sided verifier must not reuse whole-doc `partial_ratio` for candidate presence; threshold choice is stable run-to-run but false-pass geometry differs by tier.

- [HIGH] `ground_page_quotes` has no monotonic DP for repeated quotes on one page. The page escalation loop grounds each quote independently with first-hit substring/fuzzy (`grounding.py:264-277`); duplicate quotes in `missing_content` can both ground to the same page occurrence with no successive-occurrence constraint. Impact: page-escalation evidence lists are deterministic for a fixed LLM output but can over-count repeated mentions; candidate-side page checks should inherit `ground_spans` DP or dedupe by `(quote, start)`.

- [MED] LLM variance breaks semantic sidecar reproducibility even when deterministic post-processing is stable. Each judge call draws a fresh guard tag via `secrets.token_hex(4)` (`pdf_judge.py:491`, `:331`), changing the injected system/user envelope per run. Baseline nine-PR replay had **0 model retries** but **40%** quote precision (`00-baseline.md:11-24`); web evidence shows hosted graders still flip pass/fail at temperature 0 under batching (`05-web.md` Q5 CRAG/FActScore pattern; `research/llm-stack/03-determinism-auditor.md` on vLLM batch invariance). Impact: fingerprint skip (`cli.py:322-352`) keys on inputs, not outputs; two reruns on unchanged inputs can produce different `missing_content` order/content while deterministic demotions (`pdf_judge.py:524-538`, `545-553`) stay stable given the same LLM JSON.

- [MED] PDF sidecar serialization is weaker than the text-lane provenance contract. `TapetumResult.to_dict` sorts `grounded_evidence` by `(quote, start)` and `axis_findings` by axis (`models.py:174-180`); `PdfJudgeResult.to_sidecar_dict` emits `grounded_evidence` in model-filter order with no `status`, `source_start`, `candidate_start`, or tri-state reason code (`pdf_judge.py:401-405`). `page_screen` and `page_escalations` follow deterministic page-index iteration (`pdf_judge.py:298-312`, `560-582`). Impact: a two-sided verifier sidecar needs per-quote sorted provenance (`source: exact|fuzzy|dropped`, `candidate: present|absent|ambiguous`) or inspect diffs will false-alarm on quote-order noise alone.

- [LOW] Unordered-collection hygiene is adequate in deterministic sub-paths. `screen_pages` iterates `enumerate(cleaned_pages)` (`pdf_judge.py:298-312`); `flagged_entries` preserves that list order (`pdf_judge.py:543`, `560`); `textlayer.py:146-150` uses sets only for membership. `match.py` Hungarian assignment on a fixed cost matrix is deterministic for fixed block lists (`match.py:110-116`). Impact: no set-iteration leakage into a two-sided verifier core; D7 risk is sidecar field order and LLM list order, not gate math.

## False-pass hypothesis

PR #285-style replay: the LLM emits five date-line quotes already present in markdown (`00-baseline.md:17-18`). `ground_spans` confirms each quote in `pdf_text` (`pdf_judge.py:519`), no candidate check runs, and the sidecar records all five as source-present/absent-from-markdown (`pdf_judge.py:401-404`). Deterministic machinery reproducibly certifies a false absence on every rerun.

## False-fail hypothesis

A dehyphenated PDF quote `"implementa-" + "tion"` grounds fuzzy on the source page (`grounding.py:272-274`, `pdf_judge.py:100-108`) while the joined word `"implementation"` is an exact candidate hit. Without a candidate `ground_spans` pass and an `ambiguous` band (`00-baseline.md:67-68`, `05-web.md` deduplicated conclusion step 3), a two-sided verifier forced into binary absent would deterministically false-fail legitimate dehyphenation on every rerun.

## What would change my mind

A whisker-local replay on the baseline nine PRs showing `ground_spans(quotes, pdf_text)` plus `ground_spans(quotes, tomd_md)` with explicit `present | absent | ambiguous` labels improves candidate-absence precision above **8/20** with zero new dependencies, AND two back-to-back PDF-lane reruns on three fixed papers produce byte-identical sorted `grounded_evidence` blocks when the LLM JSON is frozen (proving deterministic post-processing alone is sufficient once tri-state provenance is wired).
