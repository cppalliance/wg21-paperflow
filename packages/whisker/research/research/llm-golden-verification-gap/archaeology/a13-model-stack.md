# a13 - Archaeologist: deepseek + llm-stack + llm-batching

**Verdict:** usable-with-conditions — the deepseek/llm-stack/llm-batching corpus is code-anchored, predicts PR #286/#295 misses, and places a real model-capability ceiling (class 3) on fine-grained fidelity tasks, but no tapetum run ever measured recall on golden-PR defect shapes or evaluated multi-sample judging.
**Confidence:** high

## Findings

- [CRITICAL] DeepSeek-V4-Pro structured output is schema-in-prompt + brace-match JSON extraction, not constrained decoding; the 7-field `Adjudication` schema depends on voluntary compliance plus a 2-attempt retry budget. Evidence: `packages/whisker/research/deepseek-v4-pro/SYNTHESIS.md:22-23`; `packages/whisker/research/deepseek-v4-pro/00-baseline.md:178-179`; `packages/whisker/research/deepseek-v4-pro/13-claude-invariant-auditor.md:16-18`. Impact: schema-valid `pass` with empty `evidence_spans` is indistinguishable from a genuine clean read, matching PR #295 (0 generated claims) and the page-13 false-clear pattern in `00-baseline.md`. Answer-class: 3.

- [CRITICAL] The judge model almost never abstains and self-reported confidence is anti-calibrated: 94% hallucination/abstention failure on AA-Omniscience, production mean confidence 0.9586, 0/198 tier-2 escalations, 18/18 suggested fails at >=0.95. Evidence: `packages/whisker/research/deepseek-v4-pro/00-baseline.md:188-190`; `packages/whisker/research/llm-stack/SYNTHESIS.md:15-17`; `00-baseline.md:79-81`. Impact: the [0.35, 0.65] cascade band never fires, so borderline golden defects never get a second read; confident wrong clears are the dominant failure mode. Answer-class: 3.

- [CRITICAL] Measured advisory-lane rerun instability is >=25% verdict-flip rate on identical paper/model/prompt (alliance pod), with no inter-run agreement metric. Evidence: `packages/whisker/src/whisker/CLAUDE.md:554`; `packages/whisker/research/Audit/Auditv1/code-c29-external-delta.md:141-142`. Impact: even a model that sometimes catches a defect cannot support "100% LLM verification"; recall is run-dependent noise on top of capability limits. Answer-class: 3 (primary), 5 (metric).

- [HIGH] Documented ceiling on fine-grained table/cell comparison: zero V4-Pro table benchmarks; lineage proxies show CompTab transposed-table EM 25.00% (DeepSeek-V3) and explicit "pipe tables read as 1D token streams"; cell/row swaps with preserved multiset tokens are the designed PRIMARY blind spot. Evidence: `packages/whisker/research/deepseek-v4-pro/04-table-understanding.md:8-16,24-26`; `packages/whisker/research/tapetum-llm-decision-synthesis.md:29-30`. Impact: directly predicts PR #286 wrapped-`SF` poll-table misses even when pages 8/9 reach the model. Answer-class: 3.

- [HIGH] Serving-level nondeterminism is documented and only partially mitigated: vLLM continuous batching is batch-non-invariant at greedy decode (`MODELS.md:77-78`); DeepSeek-V4-Pro MoE expert routing varies with batch composition (`MODELS.md:69-70`; `packages/whisker/research/llm-batching/16-determinism-auditor.md:8-14`); interference is already active at production `--concurrency 3`, not introduced only at higher N. Mitigations recorded: serial dissect semaphores (D11, not advisory), dedicated pod `min=max=1` + session affinity (`MODELS.md:79-95`), optional `VLLM_BATCH_INVARIANT_LEVEL` (~50% throughput cost, `llm-batching/SYNTHESIS.md:29-32`), client default `--concurrency 1` for regression baselines. Impact: golden-PR reruns can flip axis verdicts without any prompt/routing change. Answer-class: 3.

- [HIGH] Authority-doc thinking/output budgets are parsed but not forwarded to the served model; V4-Pro on vLLM defaults to thinking-off unless `enable_thinking` is set, while `tapetum_llm.md` documents 2048/1024 fast budgets that never reach `AgentBackend.run`. Evidence: `packages/whisker/research/llm-stack/SYNTHESIS.md:18-19`; `packages/whisker/research/llm-batching/16-determinism-auditor.md:18-20`; `packages/whisker/research/llm-batching/05e-web-thinking-control.md:13-14`. Impact: the lane may be running an under-budget, non-thinking adjudication profile unlike the designed cascade; thinking toggle is listed as a larger semantic stability mover than concurrency alone. Answer-class: 2 (wiring), 3 (behavior).

- [MED] Ensemble, self-consistency, and multi-sample judging were surveyed in the ecosystem but never evaluated or deployed for tapetum: SOTA cascade docs mention tier-3 "multi-judge ensemble median" (`whisker-llm-lane4-plan.md:66`), Audit literature notes majority-vote mitigations (`p10-llm-as-judge-eval.md:96`), and code-c29 marks multi-evaluator IAA as post-1.0 advisory enhancement only. Rejection reasons on record: >=25% single-run flip rate, determinism invariant, anti-calibrated confidence, advisory-only architecture, 0/31 converter-QA repos gate on LLM (`code-c29-external-delta.md:158-164,135-142`). Impact: variance reduction via N-of-M was considered theoretically, not tested against golden-PR defects; cannot be assumed to close the recall gap. Answer-class: 5.

- [MED] The pass channel has no post-hoc verification gate: grounding demotion applies only when `suggested_verdict != pass`, so confident passes with all evidence spans dropped survive decide. Evidence: `packages/whisker/research/llm-stack/SYNTHESIS.md:14-15`; `packages/whisker/research/deepseek-v4-pro/SYNTHESIS.md:19`; `00-baseline.md:86-89`. Impact: compounds class 3 (model misses defect) with class 4 (pipeline cannot add recall); zero generated claims on PR #295 short-circuits downstream entirely. Answer-class: 4 (primary), 3 (enabler).

## False-pass hypothesis

PR #286 poll tables: even if pages 8/9 are checked, DeepSeek-V4-Pro reads vertically wrapped header cells as a 1D pipe-table token stream, returns `tables: pass` with confidence >=0.95 and paraphrased or dropped evidence; decide keeps `pass` because demotion is non-pass-only (`adjudicate.py:237-238` per `deepseek-v4-pro/14-tapetum-lane-fit.md:37-43`). Deterministic gate stays green; human-verified `SF`→`S` truncation is invisible.

## False-fail hypothesis

A shippable WG21 paper whose sole whisker hard flag is cosmetic `heading_monotone` (H2→H4). DeepSeek labels `structure` axis `fail`/`major` despite the tapetum rubric capping such jumps at `review`/`minor` (`deepseek-v4-pro/06-heading-structure.md:18-19,28-30`). Advisory surfaces a structural fail on a rescue candidate, wasting reviewer attention without catching a real golden defect.

## What would change my mind

A labeled rerun on the PR #286/#295 defect classes (table wrapped-cell transcription, HTML secno stripping) after P0 routing/packet fixes, on a dedicated batch-invariant pod (`VLLM_BATCH_INVARIANT`), reporting: (1) >=85% recall on those two defect shapes with thinking budgets wired as documented, (2) <=5% verdict flip across 3 identical reruns per paper, and (3) zero confident passes where all evidence spans were dropped — would upgrade class 3 from "documented ceiling" to "residual edge cases only."
