# r04 - Repo miner: docling

**Verdict:** usable-with-conditions (+ Docling's committed multi-artifact golden grid verification is the strongest portable pattern for whisker's P0 table-cell compare and guard discipline, but Docling has no LLM verification stage and would not close PR #286/#295 recall on its own)
**Confidence:** high

## Findings

- [CRITICAL] Docling regression QA is **deterministic golden replay**, not LLM verification: `verify_conversion_result_v2` gates on `ConversionStatus.SUCCESS`, page-cell counts, full `DoclingDocument` JSON walk, markdown, and doctags (`tests/verify_utils.py:355-439`); table items use `verify_table_v2` per-cell text plus `column_header`/`row_header`/`row_section` flags (`134-171`, `307-313`). No LLM/VLM judge participates in CI. Impact: mirrors baseline class **5** — Docling proves countable defects belong in deterministic tripwires; whisker's tapetum_llm recall loss (`00-baseline.md:50-51`, `74`, `84-85`) is not fixable by copying Docling's eval stack wholesale. Answer-class: **5**, **4**.

- [CRITICAL] TableFormer cell text is assembled by **geometry overlap**, not post-hoc LLM audit — directly relevant to PR #286 wrapped headers. Evidence: V2 `_match_text` joins all PDF/OCR text cells with `intersection_over_self(bbox) > 0.3` (`table_structure_model_v2.py:174-185`); fallback `get_text_in_rect` concatenates overlapping `textline_cells` when `overlap_frac > 0.5` (`docling_parse_backend.py:147-173`); V1 path passes word-level tokens into `multi_table_predict(..., do_matching=self.do_cell_matching)` (`table_structure_model.py:228-259`). `verify_table_v2` then asserts exact per-grid-cell strings (`verify_utils.py:145-155`). Whisker side: **no table-cell comparison anywhere** (`00-baseline.md:54-55`); `PageUnit.has_tables` never read by `route_pdf_units`. Impact: PR #286 `SF`→`S` is a **deterministic compare + routing gap**, not an LLM-capability gap; portable fix is Docling-style grid diff on poll-table cells, not more judging. Answer-class: **1**, **2**.

- [HIGH] **No per-table-cell confidence** in Docling's verification or (fully) in runtime scores. Evidence: `verify_table_v2` checks text and role booleans only — no confidence field (`verify_utils.py:134-171`); page `layout_score`/`ocr_score` average **layout-cluster** and OCR-cell confidences (`layout_model.py:233-238`); `parse_score` is a 10th-percentile heuristic over page text cells (`page_preprocessing_model.py:75-88`); docs state `table_score` is *(not yet implemented)* (`docs/concepts/confidence_scores.md:42`) and page writers never set `table_score` (only NaN aggregation at `standard_pdf_pipeline.py:1079-1082`). Impact: Docling does not gate on per-cell table confidence; whisker should not expect an LLM lane to infer wrapped-cell truncation from aggregate scores. Answer-class: **2**, **5**.

- [HIGH] HTML backend **preserves full heading descendant text**; heading-number logic is PDF-pipeline-only and assigns **levels**, not export normalization. Evidence: `_handle_heading` calls `_extract_text_and_hyperlink_recursively` then `add_heading(..., text=text_clean, orig=annotated_text.text, ...)` with no secno/chrome stripping (`html_backend.py:2123-2184`); `HeadingHierarchyModel` runs only in PDF/image pipelines and `_parse_marker` reads numbering for **level** inference, not text mutation (`heading_hierarchy_model.py:108-130`, `427-470`; `pipeline_options.py:1549-1601`). HTML e2e goldens use headings like `## Background` with **no** bikeshed `span.secno` fixtures in `tests/data/html/sources/` (rg finds no `secno`); `test_e2e_html_conversions` compares exported MD to committed groundtruth (`test_backend_html.py:443-471`). Whisker mirror: `html_outline.py:66-81` false-equivalence on `1. Abstract` (`00-baseline.md:62-64`). Impact: secno stripping is a **contract-encoding gap** absent from both Docling HTML tests and whisker LLM prompts. Answer-class: **1**.

- [HIGH] Golden discipline is **multi-artifact, CI-locked, double-reviewed** — portable to whisker guard, not tapetum_llm. Evidence: `814` files under `tests/data/` (measured); regen via `DOCLING_GEN_TEST_DATA=1 uv run pytest` (`CONTRIBUTING.md:76-82`); CI asserts flag off (`test_data_gen_flag.py:5-9`); Mergify requires **two reviewers** when `tests/data/**` changes (`.github/mergify.yml:16-24`); serialize-then-compare with `COORD_PREC=2`, fuzzy text NED `<0.4`, strict/fuzzy bbox ratios (`verify_utils.py:23-27`, `99-112`, `51-52`). Whisker analogues: `guard.py` scalar-only baselines (`packages/whisker/research/redteam/docling.md:13-19`); `--update` without CI lockout. Impact: Docling would catch a wrapped-cell regression at **first** `verify_table_v2` failure; whisker deterministic lane passed PR #286 (`00-baseline.md:45`). Answer-class: **1**, **5**.

- [MED] Agent-skill `docling-evaluate.py` is **heuristic triage** (chars/page, replacement chars, duplicate blocks, table count), explicitly suggesting `--pipeline vlm` retries — not golden recall. Evidence: `evaluate()` emits warn/fail on density and duplication (`scripts/docling-evaluate.py:133-215`); README positions it as convert→evaluate→refine for assistants (`docs/examples/agent_skill/docling-document-intelligence/README.md:3-6`). VLM/`ExtractionVlmPipeline` exists (`document_extractor.py:42`, `pipeline/vlm_pipeline.py:83+`) but is a **separate conversion producer**, not a verifier of committed goldens. Impact: same advisory role as whisker tapetum_llm; supports baseline **0 of 31 repos gate on LLM** (`00-baseline.md:82`). Answer-class: **5**, **3**.

- [MED] `do_cell_matching=True` (default in e2e PDF tests, `test_e2e_conversion.py:39`) can **break** when PDF cells span columns; option documents the tradeoff (`pipeline_options.py:150-155`). Portable whisker table-cell compare must use source geometry (PyMuPDF x=77.25/100.5 proof in `00-baseline.md:42-44`) with explicit merge rules, not blind trust in PDF cell boundaries. Answer-class: **1**, **2**.

- [LOW] External `docling-eval` modality benchmarks (TEDS per axis, cited in Audit p27) are **not present** in this clone; only in-repo goldens + agent heuristic script. Impact: per-modality eval is a separate satellite; whisker should map axes to its own TEDS/NID/MHS gates, not import docling-eval verbatim. Answer-class: **5**.

## False-pass hypothesis

PR #286 poll tables: Docling extraction with `do_cell_matching=True` and `_match_text` space-join could still mis-assign a wrapped `S`/`F` pair if PDF cells are split across columns (`pipeline_options.py:152-153`); `verify_table_v2` would **only** fail if a committed golden already encodes `SF` — absent from whisker's scalar guard, the run passes like PR #286 deterministic `pass` (`00-baseline.md:45`). Confidence `table_score` stays NaN (`confidence_scores.md:42`), so no score trips it.

## False-fail hypothesis

Strict `verify_text` line equality in non-fuzzy mode (`verify_utils.py:100-108`) flags benign cross-platform whitespace in markdown/table exports while humans accept; whisker adding Docling-style exact grid compare without fuzzy mode or NED tolerance (`fuzzy_threshold=0.4`, `110-112`) could reject candidates that pass human golden review on formatting-only deltas.

## What would change my mind

A whisker prototype running Docling-style **per-cell grid diff** on PR #286 pages 8-9 (source PyMuPDF geometry → expected header cell text) plus bikeshed **secno-stripped heading normalization** before outline compare on PR #295, integrated into deterministic gates (not tapetum_llm), showing measured recall on those two golden PRs without increasing LLM unit budget.
