# r12 - Repo miner: firecrawl + Dolphin + markitdown + pandoc

**Verdict:** usable-with-conditions — all four repos gate conversion quality with deterministic anchors, goldens, or structure checks; LLM appears only for extraction/generation, never as a recall-complete verifier against committed goldens.
**Confidence:** high

## Findings

- [CRITICAL] **Firecrawl's post-extraction LLM validation loop is commented out; runtime QA is schema-shape compliance, not source-grounded defect detection.** `extraction-service.ts:943-984` contains a disabled `generateCompletions` block labeled "Deduplicate and validate final result against schema" that would re-LLM-merge duplicates; it never runs. Active path ends at `generateObject` + `mixSchemaObjects` (`extraction-service.ts:930-934`). `ajv.compile(multiEntitySchema)` at `:467` discards the validator (compile-only sanity check). Impact: mirrors whisker's verification asymmetry (`00-baseline.md:84-85`): internal JSON consistency, zero recall for defects the model never claims. Answer-class: 4.

- [CRITICAL] **Firecrawl separates two QA lanes: deterministic scrape anchors vs fuzzy LLM-extract e2e — only the former catches conversion regressions.** Scrape path asserts `toContain`/`not.toContain` on markdown plus metadata axes (`scrapeURL.test.ts:55-71`, `94-95`). Extract e2e instead counts substring hits in returned fields (`e2e_extract/index.test.ts:35-45`: `gotItRight > 1` over author names; `:83`: `>= 2` founders) with no diff against source HTML/PDF. One extract case has assertions fully commented out (`index.test.ts:174-176`). Impact: confirms class-5 pattern (`00-baseline.md:82`): mature stacks use LLM extract for triage, deterministic anchors for regression; "100% LLM golden verification" is not their operating model. Answer-class: 5.

- [HIGH] **Firecrawl schema enforcement is request-time + provider structured-output, not golden-contract encoding.** API boundary validates schema compilability via Ajv (`types.ts:196-207`) and OpenAI-compat transforms (`:206-208`). Generation uses `generateObject` with `strictJsonSchema: true` and `jsonSchema(schema)` (`llmExtract.ts:730-737`). Retries swap models on quota/`NoObjectGeneratedError` (`llmExtract.ts:837-850`, `singleAnswer.ts:62`). Impact: same ceiling as whisker `UnitCheck.verdict_matches_defects` (`00-baseline.md:86-89`): forces well-formed claims, cannot force inspection of secno-stripped headings or wrapped table cells absent from schema/prompt. Answer-class: 1.

- [HIGH] **Dolphin's layout-anchor decomposition (structure first, content second) is portable to verification routing but ships with no eval loop.** Stage 1: `model.chat("Parse the reading order...")` → bbox/label list (`demo_page.py:185-190`). Deterministic gate: `check_bbox_overlap(..., iou_threshold=0.1, overlap_box_ratio=0.25)` collapses to `distorted_page` when >25% boxes overlap (`utils.py:489-533`, `demo_page.py:206-209`). Stage 2: modality-stratified crops with distinct prompts for `tab`/`equ`/`code`/text (`demo_page.py:251-282`). No in-repo tests, no golden diff, no source compare. Impact: maps directly to whisker P0 hypotheses — deterministic table-page/unit routing via `PageUnit.has_tables` (`00-baseline.md:54-55`) plus per-anchor content judge — but Dolphin proves structure-first routing alone does not close PR #286/#295 without encoded contract rules. Answer-class: 2.

- [HIGH] **Pandoc scales heading/table correctness via 1,078 committed command-test fixtures + QuickCheck table invariants, not LLM judges.** Command tests embed expected stdout after `^D` in each `.md` fixture (`Command.hs:13-31`, `:137-141`). Reader/writer goldens use byte-exact `goldenTest` after normalization (`Old.hs:380-403`: `expected == actual`). Table helper module adds 50-run QuickCheck properties on column spans/row structure (`AnnotatedTable.hs:134-142`, `148-151`). Impact: field-proven recall path for countable defects is exact committed output + structural properties; whisker tapetum_llm cannot substitute without a golden micro-corpus beneath advisory LLM. Answer-class: 5.

- [MED] **markitdown uses in-tree `FileTestVector` anchors (18 fixtures) with heading/table substring checks and structural table validators, not property tests or LLM verification.** Vectors declare `must_include`/`must_not_include` per file (`_test_vectors.py:6-13`); docx vector asserts `"# Abstract"`, `"# Introduction"` (`:25-26`) — heading level via markdown prefix, not bikeshed secno stripping. PDF table suite adds `validate_table_structure` (uniform column counts, `:74-94`), header/cell substring presence, and monotonic section-order asserts (`test_pdf_tables.py:220-257`). Parametrized over all vectors (`test_module_vectors.py:27-68`). Impact: portable as whisker facts-file anchors for WG21 papers; would still miss PR #295 unless contract explicitly encodes stripped secno (`00-baseline.md:59-64`). Answer-class: 1.

- [MED] **Dolphin `demo_layout.py` stops after bbox assignment with empty text — structure-only path is explicit, not an accident.** Layout stage writes `"text": ""` for every element (`demo_layout.py:185-191`); content parsing lives only in `demo_page.py:process_elements`. Impact: strongest portable pattern is "verify/diff structure deterministically, defer content to per-anchor LLM" — but verification requires a second deterministic compare (source geometry, golden outline, table grid), which Dolphin never implements. Answer-class: 2.

- [LOW] **Concrete whisker ports (ranked).** (1) Firecrawl scrape `toContain`/`not.toContain` + metadata axes → per-PID facts beneath tapetum_llm (`scrapeURL.test.ts:55-71`). (2) Dolphin two-stage router → table-page priority in `source_router.py:149-233` using existing `PageUnit.has_tables` (`00-baseline.md:54`). (3) markitdown `validate_table_structure` + ordered section positions → deterministic table-cell/header gate for poll tables (`test_pdf_tables.py:74-94`, `:220-257`). (4) Pandoc command-test micro-corpus → hard layer under metric slack (`Command.hs:13-31`). Answer-class: 2.

## False-pass hypothesis

Firecrawl extract e2e accepts PCI-DSS boolean `true` when any compliant-looking page is scraped (`e2e_extract/index.test.ts:145`) without comparing extracted fields to source text; whisker tapetum_llm would similarly false-clear PR #295 headings because `html_outline.py:66-81` equates `1. Abstract` source and candidate strings while the human contract requires secno stripping.

## False-fail hypothesis

Pandoc command test `5474-tables.md` expects exact OpenDocument XML cell text (`5474-tables.md:15-62`); a semantically correct table with benign whitespace or caption renumbering fails CI until `--accept` refresh (`Old.hs:402-403`), analogous to whisker guard firing on formatting-only NID churn without Dolphin-style `truncate_repeated_tail` normalization.

## What would change my mind

Finding an active (uncommented) firecrawl or Dolphin code path that, at QA time, diffs LLM-extracted table cells or heading strings against PDF text-layer coordinates or HTML source DOM — not merely validates JSON schema shape or bbox labels — in these four clones.
