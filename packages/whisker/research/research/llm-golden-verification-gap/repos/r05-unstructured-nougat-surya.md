## False-pass hypothesis

PR #286 wrapped poll-header `SF`→`S`: whisker's source-aware LLM lane routes pages 8/9 but checks other units under `MAX_UNIT_CHECKS=5` and has no table-cell compare (`00-baseline.md:41-55`). An **unstructured-style** deterministic stack (table-structure strategy + `cct-%missing` on extracted table text) or **Nougat-style** table-stratum set-F1 (`metrics.py:39-43`) would be **more likely** to flag missing `F` than the current LLM lane, but still would not encode wrapped-cell geometry without an explicit contract — so a false-pass remains plausible on metrics alone if table text lands in the wrong extraction channel.

## False-fail hypothesis

Unstructured's **zero-tolerance** metrics tree diff (`check-diff-evaluation-metrics.sh:56-73`): a benign 0.001 Levenshtein wiggle on an otherwise correct WG21 paper fails CI unless an operator runs `OVERWRITE_FIXTURES=true` on a pinned Docker refresh workflow — a deterministic false-fail whisker's slack-based guard (`constants.py:94`) is designed to avoid.
