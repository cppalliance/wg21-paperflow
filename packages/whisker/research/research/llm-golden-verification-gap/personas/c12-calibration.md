# c12 - Calibration statistician

**Verdict:** usable-with-conditions (every LLM-lane confidence/threshold is either a literature placeholder or a single-paper flip-check; none was fitted on labeled golden-PR outcomes, and the 9-paper dev-replay cannot support any recall or "100% verification" claim)
**Confidence:** high

## Findings

- [CRITICAL] **Self-reported confidence carries zero discriminative signal but still gates three code paths.** The model emits `confidence` in schema (`models.py:180,218,313`); it branches escalation at `[CONFIDENCE_AMBIGUOUS_LO, CONFIDENCE_AMBIGUOUS_HI]` = [0.35, 0.65] (`adjudicate.py:272-273`, `constants.py:27-28`), demotes sub-floor verdicts at `CONFIDENCE_DECISION_FLOOR` = 0.50 (`adjudicate.py:342-343`, `pdf_judge.py:706-707`), and enables fusion `llm_clear_soft_review` when `conf >= 0.50` (`fusion.py:462,482`). Production: **96/96** clear firings at conf >= 0.95 including PR #282 false-clear at **1.00** (`00-baseline.md:80-81`, `research/llm-qa-integration/SYNTHESIS.md:38-39`); **0/381** sidecars below 0.50; histogram min 0.85, p05=p25=0.95 over 198 sidecars (`packages/whisker/research/llm-stack/21-cascade-calibration-statistician.md:8-10`). Impact: confidence is decorative for clears and dead for escalation; treating it as calibrated uncertainty is actively misleading. Answer-class: **3**, **5**.

- [CRITICAL] **No tapetum_llm threshold was ever fitted on labeled outcomes; constants.py explicitly says so.** Comments mark cascade band, candidate filter, and recall floors as **PROVISIONAL, pending mini-eval** (`constants.py:16-21,89-91,167-176,211-213`). Git history: thresholds landed in `3bc6348` (Lane-4 scaffolding) and `c59139c` (source-aware v6); no subsequent commit adds a calibration artifact or fitted edges. `whisker calibrate` exists for deterministic unigram edges only (`whisker/CLAUDE.md:324-329`); Audit v1 notes tapetum mini-eval **never run** (`packages/whisker/research/Audit/Auditv1/CODE-AUDIT-RESULT.md:273`). Impact: every numeric cutoff is an unmeasured operating point; PR #286/#295 misses are statistically unsurprising, not outliers. Answer-class: **5**.

- [CRITICAL] **Dev-replay sample size forbids "100% verification" or even ">=95% recall" claims.** Corpus: **9** papers, **13** defect groups across **7** defective papers (`packages/whisker/corpus/dev-replay/labels.json`); two 2026-07-22 incident blockers show **0/2** recall on human-verified defects (PR #286 poll cells, PR #295 secno headings, `00-baseline.md:41-75`). Even a hypothetical **13/13** perfect run yields Wilson 95% lower bound on recall **0.451**; paper-level **7/7** yields lower bound **0.313**; rule-of-three upper miss bound after 13 consecutive detections is still **23%**. To reach Wilson lower >= **0.95** on defect-level recall with zero observed misses requires **~2000** labeled defect instances (computed: n=1500 -> 0.948, n=2000 -> 0.955). Impact: the current corpus supports exploratory debugging only, not verification SLOs. Answer-class: **5**.

- [HIGH] **The ambiguous-band cascade trigger is empirically empty; derived signals partially replaced it but pass-channel remains single-tier.** Band [0.35, 0.65] never fired: **0/198** escalations (`00-baseline.md:78-79`, `constants.py:23-26`). Code now also escalates on `axis_conflict` and `ungrounded_evidence` (`adjudicate.py:252-275`, `constants.py:32-40`), but a confident consistent `pass` with empty evidence bypasses all three (`adjudicate.py:327-332`, `tapetum_llm.md:199`). Impact: the lane's false-pass blind spot (token-preserving corruption) has no second look when the model rubber-stamps pass at 0.95+. Answer-class: **3**, **4**.

- [HIGH] **Only one recall floor was offline-calibrated; the HTML section floor that fired on PR #295 was not.** `PAGE_RECALL_FLOOR` = 0.90 was set from p0957r8 page-13 recall **0.8810** vs 107 control pages worst **0.9129** (`constants.py:167-176`, `research/per-page-judging/SYNTHESIS.md:18-21`). `SECTION_RECALL_FLOOR` = 0.90 is a copy with no separate HTML flip-check (`constants.py:211-213`). Runtime: PR #295 `section:6` recall **0.0437** routed correctly but signal was polluted by `<script>`/`<style>` in `_SectionExtractor` (`00-baseline.md:67-73`); threshold did not fail, routing did. `PDF_JUDGE_RECALL_FLOOR` = 0.85 and `PDF_JUDGE_NID_FLOOR` = 0.80 demote monolith passes only (`pdf_judge.py:708-718`); document-wide averages hide localized loss (`00-baseline.md:46-49`). Impact: recall thresholds detect coarse absence, not contract-level defects (secno, wrapped cells). Answer-class: **1**, **2**.

- [HIGH] **`MAX_UNIT_CHECKS` = 5 and lexical scheduling were chosen by analogy, not measurement.** Same cap pattern as `MAX_PAGE_ESCALATIONS` = 5 (`constants.py:185-191,223-226`); commit `c59139c` ("fail-closed source-aware golden QA") with no labeled budget study. `unit_judge.py:225-241` sorts by hardcoded `severity_rank` then **lexical** `unit_id`, displacing PR #286 pages 8/9 while checking page:13 (`00-baseline.md:46-49`). Per-page synthesis expects 0-2 flagged pages (`constants.py:185-187`); no dev-replay replay proves 5 is sufficient for 9-paper golden PRs. Impact: budget starvation is a tuning guess that failed on the latest incident. Answer-class: **2**.

- [MED] **Grounding fuzzy thresholds are precision-only and whole-document shaped.** `EVIDENCE_FUZZY_FLOOR` = 0.90 with `EVIDENCE_MIN_FUZZY_CHARS` = 20 (`constants.py:67-73`, `grounding.py:317-331`); page quotes use length-relative `PAGE_QUOTE_MAX_DIFFS` = 2 (`grounding.py:612`, `constants.py:199-204`, olmocr-bench pattern). Origin: reject langextract 0.75 LCS tier (`grounding.py:19-21`); no labeled ROC on WG21 quotes. Production: **9/197** sidecars dropped a span (`00-baseline.md:84-89`); zero recall power on ungenerated claims. Impact: grounding subtracts false positives, cannot raise recall on PR #286/#295 (0 generated claims). Answer-class: **4**.

- [MED] **Severity vocabularies are inconsistent and none were calibrated against human labels.** Router emits `low|medium|high|critical` (`source_router.py:45,184-226`); unit scheduler ranks `critical=0..low=3` (`unit_judge.py:225-229`); fusion caps on `high|critical` only (`fusion.py:62,201`); axis fold uses `SEVERITY_MAJOR` = `"major"` (`constants.py:52`, `adjudicate.py:309-314`, `models.py:160`). Dev-replay labels mix `high|critical|medium|low` (`labels.json`). No mapping study or inter-rater calibration ties these to merge decisions. Impact: severity-driven scheduling and fusion caps optimize an unvalidated ordinal scale. Answer-class: **2**, **5**.

## False-pass hypothesis

Clean-pass HTML golden PR with bikeshed `span.secno` headings: `html_outline.py:66-81` false-equates source and candidate outline; metadata/outline `pass`, zero defect claims, fusion `review` only via coverage cap (`00-baseline.md:62-75`). Self-reported confidence **0.98** on PR #286 PDF run (`00-baseline.md:46`) with **0** accepted defect groups. Fusion `llm_clear_soft_review` path never fires (det not soft-only), but the inspect line still shows high confidence as if it were evidence (`inspect_report.py:105`). Operator reads conf >= 0.95 + empty defects as calibrated "checked clean."

## False-fail hypothesis

Deterministic `SECTION_RECALL_FLOOR` = 0.90 flags a section whose recall is **0.88** due to sanctioned front-matter or bikeshed chrome in the candidate text window (same class as PR #295 `section:0` false "candidate missing" signal, `00-baseline.md:68-69`): unit check fires, cap exhausts at `MAX_UNIT_CHECKS` = 5, fusion `source_aware_review_cap` blocks clear despite human merge intent. Threshold was calibrated on PDF page tokens, not HTML section extractors with script pollution.

## What would change my mind

A committed tapetum mini-eval artifact (>= **30** golden-PR papers, human-verified defect-group labels including secno and table-cell classes, held-out test split) showing: (1) refitted recall/budget constants with recorded TPR/FPR at chosen operating points, (2) post-hoc calibration (Platt or isotonic) on **derived** features (grounded-span ratio, axis conflict, unchecked-unit fraction) achieving Spearman rho >= **0.4** with human agreement while self-reported confidence stays rho <= **0.1**, and (3) defect-level recall **>= 0.80** on fuzzy-residue classes with Wilson lower > **0.60** on the holdout. Until that exists, drop confidence from all branching decisions and treat every constant in `constants.py` as hypothesis, not verification policy.
