# c11 - Model capability skeptic

**Verdict:** usable-with-conditions (class 3 is proven as a hard ceiling on 100% LLM golden verification, but on the recorded PR #286/#295 zero-recall runs classes 1 and 2 explain where recall was lost; capability limits dominate attainability, not the specific miss mechanism)
**Confidence:** high

## Findings

- [CRITICAL] **Page-13 unit false-clear proves the model misses defects on a correctly selected unit.** On the 2026-07-21 P1068R11 historical replay, page 13 was routed, checked, and returned `pass` at confidence `1.0` with reasoning focused on headings/URLs while malformed inline-code delimiter debris on the same page was ignored (`PR286-LLM-FALSE-CLEAR.md:531-546`, `:613-621`; `unit_judge.py:568-606` sends full `candidate_md` plus routing `signal_detail`). `UnitCheck.verdict_matches_defects` accepts pass-with-empty-defects (`models.py:315-320`, `00-baseline.md:86-89`). Impact: better routing alone cannot fix this miss class; the unit model looked at the wrong signal and still false-cleared. Answer-class: 3.

- [CRITICAL] **Page-13 false claim on the 2026-07-22 current replay shows hallucination under high confidence, refuted only by precision-stage grounding.** Current PR #286 run: one generated page-13 heading defect contradicting metadata/outline `pass`; evidence disposition `ambiguous=1`, accepted defect groups `0` (`00-baseline.md:50-51`, `PR286-LLM-FALSE-CLEAR.md:141-142`). The model did not name the real table blocker; it invented a heading-number loss that two-sided verification killed. Impact: even when the model generates claims, they can be wrong at conf `0.98` while true defects stay unclaimed. Answer-class: 3.

- [CRITICAL] **Measured verdict instability: >=25% per-PID flip rate on identical inputs despite greedy sampling.** Evidence: `whisker/CLAUDE.md:554-556` documents "Identical reruns on the alliance pod: >= 25% verdict-flip rate (same paper/model/prompt)"; measurement setup is two back-to-back c=32 runs on the same 20-PID borderline set producing `15 pass / 5 review` vs `10 pass / 10 review` (`llm-batching/20-sweep-results.md:31-40`), a 5/20 = 25% lower bound on pass↔review flips with fail count constant. Client pins are already maximal: `MODELS.md:28-31` (`temperature=0.0`, `top_p=1.0`, `seed=0`); `llm-qa-integration/23-ci-reproducibility.md:10` attributes residual variance to server-side MoE/batch non-invariance, not missing client pins. Impact: recall is run-dependent noise on borderline papers; "100% LLM verification" is not a stable metric even with perfect packets. Answer-class: 3 (primary), 5 (goal).

- [HIGH] **Self-reported confidence is anti-calibrated and never triggers the designed uncertainty band.** `whisker/CLAUDE.md:556-557`: "96/96 clear firings at >= 0.95 confidence, including a false-clear at 1.00 (PR #282 p4020r0)"; corroborated on 381 production sidecars: 0/381 below `CONFIDENCE_DECISION_FLOOR` (0.50), all 96 `llm_clear_soft_review` firings in `[0.95, 1.0]` (`llm-qa-integration/opus-B-llm-calibration.md:41-42`, `tapetum-golden-review-findings-2026-07-14.md:86-89`); escalation band `[0.35, 0.65]` hit `0/198` (`constants.py:23-28`, `tapetum-golden-review-findings-2026-07-14.md:87-88`). Impact: operators cannot use confidence to distinguish true clears from false clears; tier-2 cascade never fires on uncertainty. Answer-class: 3.

- [HIGH] **Unit-check packet shape is a needle-in-haystack task at scales our research already flagged as unreliable.** Each `_check_one_unit` call injects one bounded source page/section plus the **full** candidate markdown (`unit_judge.py:581-588`, `UNIT_CHECK_SYSTEM_PROMPT:94-97`); there is no page-local candidate slice. Budget constants: `MAX_PAPER_MD_CHARS = 500_000` for H2 chunking of monolith adjudication (`constants.py:54-60`, `chunking.py:129-164`); unit checks are **not** chunked and always attach whole `candidate_md`. Typical scale: source unit ~50+ content tokens minimum (`PAGE_MIN_TOKENS = 50`, `constants.py:183`) up to low thousands per page; a 15-page paper candidate is on the order of tens of thousands of characters (~5-15k tokens at `SERVICES.toml` `chars_per_token = 4.0` for `alliance-pod/deepseek-v4-pro`). Prior corpora: per-page judging found "asymmetric haystack: small page source vs full markdown each call" recreates attention failure (`per-page-judging/19-false-pass-hunter.md:10-11`); p0957r8 had document `content_recall=0.9806` while page-13 content was absent (`tapetum-golden-review-findings-2026-07-14.md:24-25`); DeepSeek-V4 long-context stress tests report MRCR 8-needle `0.82 @ 256K` falling to `0.59 @ 1M` (`deepseek-v4-pro/00-baseline.md:192-195`). Impact: the model is asked to find unit-local defects (wrapped table cells, inline-code debris) in a full-document haystack while the routing signal anchors attention to `heading_drift`; research predicts within-page and subtle structural misses at this scale. Answer-class: 3.

- [HIGH] **Temperature is already zero; residual variance is infra-limited, not fixable by prompt tuning alone.** `MODELS.md:28`: `temperature = 0.0` (greedy argmax); D5 forbids per-call override (`CLAUDE.md` determinism pins). `MODELS.md:77-78`: hosted vLLM-class servers flip tokens when batch composition changes; Fireworks does not expose batch-invariant kernels. The 25% flip rate persisted with `temperature=0.0` and `seed=0` on identical reruns (`llm-qa-integration/23-ci-reproducibility.md:10-14`). Impact: "pin sampling harder" is exhausted; capability/stability ceiling is server-side, matching open-weight sovereignty constraints (`whisker/CLAUDE.md:558-561`). Answer-class: 3.

- [HIGH] **Counter-case: PR #286 and PR #295 blockers never reached a fair unit inspection — classes 1/2 dominate the recorded recall loss.** PR #286 (current head): human-verified poll-table `SF`→`S` defect on pages 8-9; both pages routed but displaced by `MAX_UNIT_CHECKS = 5` under severity-then-lexical sort (`00-baseline.md:46-49`, `constants.py:223`, `PR286-LLM-FALSE-CLEAR.md:146-147`). PR #295: four `span.secno` H2 labels; metadata/outline `pass` because `html_outline.py:66-81` collects unfiltered heading text so source and candidate outlines match (`00-baseline.md:62-64`, `PR286-LLM-FALSE-CLEAR.md:196-201`); checked units were `section:1` and `section:6`, not the heading-label sections; `section:0` routed with no source packet (`00-baseline.md:72-74`). Generated defect claims: 0 on PR #295; table blocker never unit-checked on PR #286 current run. Impact: for these two reviews, recall ~0 is primarily encoding/routing starvation, not demonstrated model failure on the target units. Answer-class: 1, 2.

- [MED] **Structured output is voluntary JSON, not constrained decoding — schema compliance does not imply inspection completeness.** `deepseek-v4-pro/00-baseline.md:178-179`: VllmThinkingBackend uses schema-in-prompt + brace-match extraction; `deepseek-v4-pro/00-baseline.md:188-190`: AA-Omniscience ~94% hallucination/abstention failure (model rarely abstains). Historical PR #286 had one schema-invalid unit result retried successfully (`PR286-LLM-FALSE-CLEAR.md:505-506`, `:621`) — retry recovered JSON, not judgment. Impact: valid `pass`/empty-defects outputs can mask skipped defect classes even when prompts name `punctuation_loss` and `code_loss` (`unit_judge.py:102-106`). Answer-class: 3.

## False-pass hypothesis

P1068R11 page 13 after P0 routing fixes: numeric page scheduling selects page 13 for a `heading_drift` signal; unit check receives ~1-2k-token source page plus full ~10k-token candidate containing literal backtick debris around `std::ranges::generate_random`. Model returns `pass`, confidence `0.98-1.0`, empty defects, reasoning cites heading fidelity (`PR286-LLM-FALSE-CLEAR.md:613-619` pattern). Evidence verification has zero claims to refute (`PR286-LLM-FALSE-CLEAR.md:625-634`). Fusion caps at `review` for coverage, not detection.

## False-fail hypothesis

After deterministic secno stripping (class-1 fix), PR #295 metadata/outline compares normalized outlines and passes; a unit check on a high-recall section polluted by `<script>` text (`section:6`, recall `0.0437`, `00-baseline.md:70-71`) could emit a false `constexpr`/content-omission claim at confidence >= 0.95 that survives source grounding but is refuted as candidate-present — precision control fires, but operator sees high-confidence noise unrelated to the golden contract.

## What would change my mind

A controlled replay on PR #286/#295 head bytes **after** P0 routing, outline normalization, and table-cell packets are implemented: pages 8-9 and the four secno headings are unit-checked with localized candidate slices, three identical reruns per paper on a batch-invariant pod, reporting (1) >=85% recall on those defect shapes, (2) <=5% verdict flip across reruns, and (3) zero `pass` at confidence >= 0.95 where the checked defect class was named in the routing signal but omitted from defects — would demote class 3 from "dominant ceiling" to "residual edge cases" for golden-PR verification.
