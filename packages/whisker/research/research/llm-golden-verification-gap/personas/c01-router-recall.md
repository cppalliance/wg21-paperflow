# c01 - Router recall attacker

**Verdict:** usable-with-conditions (The router’s four PDF and three HTML signal types are exhaustively mapped and every human-verified golden defect class in the incident record lacks a matching emitter; quantification is 0/10 class-visible, but budget starvation and contract-encoding gaps downstream still share blame.)
**Confidence:** high

## Findings

- [CRITICAL] The PDF router exposes exactly four signal types and never reads table presence. Evidence: `route_pdf_units` emits only `token_delta` (`source_router.py:166-189`), `low_recall` (`source_router.py:191-204`), `missing_captions` (`source_router.py:206-216`), and `heading_drift` (`source_router.py:218-231`); `PageUnit.has_tables` is computed at `textlayer.py:256-272` and assigned at `textlayer.py:272`, but no field on `PageUnit` besides `text`, `caption_lines`, `heading_candidates`, and `content_tokens` is consulted in the router loop (`source_router.py:191-231`). Impact: the PR #286 blocker (six poll-table headers `|SF|` transcribed as `|S|`, baseline pages 8-9) has zero table-cell signal; pages 8/9 were routed for unrelated reasons and displaced by `MAX_UNIT_CHECKS=5` (baseline runtime). Answer-class: 2.

- [CRITICAL] `low_recall` and `token_delta` are word-multiset blind to the dominant incident defect classes. Evidence: `content_recall` counts reference word-token multiset overlap (`metrics.py:376-393` via `content_tokens`); poll-header corruption swaps cell boundaries while preserving tokens `S`, `F`, `N`, `A`, `SA` (baseline PR #286); punctuation-only normative loss (`N>.`, improvement-bugs §5 page 7) and inline-code delimiter debris (pages 12-13) likewise keep word recall near 1.0 (baseline page-13 recall `0.9974`; improvement-bugs §3.3). Impact: neither whole-page nor section recall fires for token-preserving structural corruption. Answer-class: 2.

- [HIGH] HTML routing has three signal types and also ignores `SectionUnit.has_tables`, inline semantics, and list structure. Evidence: `route_html_units` emits `heading_drift` (`source_router.py:248-274`), `low_recall` (`source_router.py:288-300`), and `missing_code` (`source_router.py:302-314`); `SectionUnit.has_tables` / `has_images` are set in `_SectionExtractor` (`html_outline.py:147-150`, `html_outline.py:120-121`) but never read in `source_router.py:276-314`; `missing_code` compares only `<pre>` block counts (`html_outline.py:145-146`) against fenced-block counts in `_parse_markdown_sections` (`source_router.py:103-135`), not inline `` ` `` rendering, `` `constexpr`contexts ``, or consumed grave accents (improvement-bugs PR #295 extended fidelity §Validation method). Impact: four extended PR #295 fidelity groups have no router hook. Answer-class: 2.

- [HIGH] `heading_drift` cannot enforce the golden secno-stripping contract on HTML because upstream outline text already includes `span.secno`. Evidence: `_HeadingExtractor.handle_data` appends all descendant text (`html_outline.py:79-81`); `route_html_units` compares `_text_key(source_title)` to candidate section titles (`source_router.py:253-274`); baseline PR #295 records metadata/outline `pass` with empty heading_drift while four H2s retain `1.`–`4.` labels. Impact: the structure-only blocker produces no heading_drift signal even though the signal type exists. Answer-class: 1 (contract not encoded before compare) with class-2 starvation when noisy signals displace real units.

- [HIGH] Five `PageUnit` / `SectionUnit` structural flags are extracted then discarded by the router. Evidence: never read in `source_router.py`: `PageUnit.has_images` (`textlayer.py:214-217`, `271`), `PageUnit.has_tables` (`textlayer.py:272`), `PageUnit.code_token_count` (`textlayer.py:252-274`); `SectionUnit.has_images` (`html_outline.py:121`), `SectionUnit.has_tables` (`html_outline.py:120`). Impact: image-reference loss, table-heavy pages, and code-dense pages cannot generate targeted signals despite extraction cost already paid. Answer-class: 2.

- [MED] List cardinality, blockquote nesting, and subordinate-heading flattening are outside every router code path. Evidence: `_parse_markdown_sections` tracks only ATX/setext headings and fenced/`<pre>` code counts (`source_router.py:70-142`); PDF `heading_drift` tests set membership of large-font lines in candidate heading keys (`source_router.py:218-221`), not loss of list markers or heading tier; no `<ol>`/`<li>`/`<blockquote>` handling in `source_router.py`. Impact: improvement-bugs historical PR #286 classes (ordered-list collapse 2+3→1+1, three flattened subordinate headings, improvement-bugs §5 pages 9-10) emit no signal; page 10 was not routed at all in that replay. Answer-class: 2.

- [MED] HTML section text packets admit `<script>`/`<style>` payload, polluting `low_recall` and displacing real checks. Evidence: `_SectionExtractor.handle_data` appends all character data with no tag filter (`html_outline.py:168-172`); `_BLOCK_TAGS` lists block containers but not `script`/`style` (`html_outline.py:34-38`); baseline PR #295 routed `section:6` recall `0.0437` from script pollution while secno-heading sections went unchecked. Impact: one of three HTML signal types generates false-high-severity noise; class-2 budget starvation. Answer-class: 2.

- [LOW] Incident-record quantification: 0/10 unique defect classes are router-visible by signal semantics. Evidence: classes drawn from baseline PR #286/PR #295 (table cell, secno labels, inline-code adjacency/delimiters, markdown delimiter consumption, cite/br semantics, raw HTML tokens, formatting quality) plus improvement-bugs historical PR #286 (punctuation-only, list cardinality, subordinate-heading flatten, inline-code debris) union to ten classes; none maps to a dedicated `signal_type` or to a firing instance of an existing type for the verified defect (secno: signal type exists but baseline empty heading_drift; table: pages routed incidentally without table signal). Impact: recall is lost before `unit_judge` for 100% of class-tagged blockers in the verified record; downstream verification asymmetry (answer-class 4) is moot when no unit targets the defect. Answer-class: 2 (primary), 5 (100% LLM verification of these classes is the wrong metric without new deterministic signals).
