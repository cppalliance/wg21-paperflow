# c17 - Corpus strategist

**Verdict:** usable-with-conditions (a recall-measurable corpus is architecturally clear — labeled positives per golden-contract class, sidecar replay against `defect_groups`, optional golden mutation — but the current inventory has zero positives on the two 2026-07-22 miss-classes, stale labels on both incident papers, and holdout polarity inverted for recall; ~19–60 labeled positives per class are needed to distinguish 60% from 95% recall, vs 0–4 today on most classes)
**Confidence:** high

## Findings

- [CRITICAL] **Ideal recall corpus shape.** A corpus that can *measure* source-aware LLM lane recall must provide, per golden-contract defect class: (1) locked `(source, candidate)` pairs where the candidate violates the structural contract in a human-verified way, (2) a machine-readable label with class, location, and instance count, (3) an evaluation hook that replays saved sidecars and scores **accepted defect groups / verified instances** against those labels (not `expected_llm_verdict` alone — that field is schema-validated but never compared to live LLM output in pytest, `test_dev_replay_acceptance.py:19`). Holdout anchors (`holdout/README.md:24-41`) measure **precision** of quote grounding (`present_in_candidate` on source substrings), not recall on defects the model never claims. Impact: without class-balanced labeled positives and a recall pytest, recall ~0 on PR #286/#295 is invisible to CI. Answer-class: **5**.

- [CRITICAL] **Current inventory vs ideal: distance summary.** **Papers:** DR 9 golden-PR replays; holdout 3 (disjoint except quarantined `p0533r9`, `manifest.json:31-33`); GF 12 sources / 15 snapshots / 4 blessed ideals (`baselines.json` ratchets 4 axes, not defect labels). **Labels stale on both incidents:** `p3953r0` empty `defect_groups`, `expected_llm_verdict: pass` (`labels.json:183-190`) vs baseline 4 secno headings (`00-baseline.md:59-65`); `p1068r11` lists `heading_hierarchy` + `html_entities` only, not 6 wrapped poll-table cells (`labels.json:82-106` vs `00-baseline.md:41-44`). **Defect types in DR (10 strings):** `toc_leak`×4, `heading_hierarchy`, `html_entities`, `table_corruption`, `table_flattened`, `front_matter_error`, `page_content_omission`, `heading_level_drift`, `qualifier_omission`, `punctuation_omission` — none named `secno_retained` or `table_cell_wrap`. **Holdout:** 48 anchors, 46 `present_in_candidate`, 2 `candidate_not_found` (`holdout/README.md:48-50`); 7 strata covered but zero recall-oriented defect labels. **Gap to measurable corpus:** 6 of 9 contract classes have Total < 19; 2 classes (L1, C1) have Total 0; the two PR #286/#295 miss-classes have no DR label at all. Impact: claiming any recall percentage on secno or wrapped-cell classes is undefined. Answer-class: **1**, **5**.

(4) `golden-hook:` in `test_comprehension_corpus.py:39-43` documents planned construct-isolated `<case>.in.html`/`.out.md` pairs — **not implemented**. **Missing for LLM recall:** no mutator for secno injection (`## 1. Impact: mutation can fill zero-positive classes cheaply once tied to sidecar replay; today it only validates deterministic Lane 3 and readback sensitivity. Answer-class: **5** (+ **1** for contract rules absent from prompts).

- [HIGH] **Sample size per class: 60% vs 95% recall.** Treat each labeled positive as one Bernoulli trial (detected = 1). Two-proportion power (p₁=0.60, p₂=0.95, α=0.05 two-sided, power=0.80): **n ≈ 19** independent positives per class (computed via standard sample-size formula, `(z_α/2 + z_β)² × (p₁(1−p₁)+p₂(1−p₂)) / (p₁−p₂)²`). Intuition: at n=19, expected hits 11 vs 18 — separable; at n=4 (current TOC class), 60% and 95% both allow 3–4 hits by chance. **Certifying** recall ≥ 0.95 with 95% confidence (Clopper–Pearson, zero misses): **n ≈ 59** per class. **Current corpus:** only `qualifier_omission` (151 instances, content-out-of-scope) exceeds 19; contract-relevant classes peak at 8 (T2 with incident). Impact: the present corpus can show catastrophic misses but cannot statistically distinguish "fixed to 60%" from "target 95%" on any structural class. Answer-class: **5**.

- [MED] **What to build (minimal measurable corpus).** (1) **Relabel** `p1068r11` + `p3953r0` to baseline truth (`00-baseline.md`). (2) **Add mutator catalog** mapping each contract class → deterministic edit on `ideals/*.md` or PR candidate + expected `defect_group.type` (extend DR v1 schema or parallel `mutations.jsonl`). (3) **Recall pytest:** for each labeled `(pid, group)`, assert sidecar has matching accepted group or `verified_count` ≥ `affected_count` (pattern sketched in `a15-corpora-labels.md:34`). (4) **Scale to ≥19 synthetic + organic positives per class** across PDF/HTML, using GF sources (12) and DR PR heads as seeds; holdout stays locked for precision only. (5) Keep Lane 3 canaries separate — they do not substitute for tapetum recall (`corpus/README.md:35-37`). Impact: closes the measurement gap without conflating grounding precision (holdout) with defect recall. Answer-class: **5**.

- [LOW] **Golden fixture pairs are regression substrate, not evaluation labels.** `packages/tomd/tests/fixtures/golden/` provides source→snapshot byte locks (`test_pdf_golden` / `test_html_golden`) and source→ideal structural gates (`test_golden_gate.py`, 4 blessed rows in `baselines.json`). They supply **inputs** for DR/holdout but carry **no** per-defect recall annotations; overlap: all 9 DR papers have sources under `golden/sources/`. Impact: fixtures are necessary but insufficient — bless/ideal workflow (`README.md:121-146`) produces correct candidates, while recall measurement needs *incorrect* candidates with known defect class. Answer-class: **5**.

## False-pass hypothesis

Leave DR labels unchanged: `p3953r0` stays `expected_llm_verdict: pass` with empty `defect_groups` (`labels.json:183-190`). Dev-replay schema tests pass (`test_dev_replay_schema.py:96-102`), holdout stays green on 46/48 presence anchors, and operators report "corpus coverage: 9/9 golden PRs labeled." Live lane still 0/4 on secno headings (`00-baseline.md:62-74`). Corpus metrics look complete while recall on the highest-signal HTML defect class remains unmeasured.

## False-fail hypothesis

Generate 19 synthetic secno mutants from `ideals/p4020r0.md` by prefixing every H2 with `N.` without updating source HTML: a naive "fail if heading matches `\d+\.`" rule fires on clean papers whose titles legitimately start with digits, marking 19/19 false misses and reporting 0% recall. Mutators must pair candidate edits with source-side `span.secno` evidence (`a17-golden-contract.md:69-71`), not text-only regex.

## What would change my mind

Ship corrected DR labels for both incident papers, a mutator-backed recall pytest with ≥19 labeled positives each for H2 (secno) and T2 (wrapped/table-cell), and one CI run showing sidecar replay recall ≥0.80 on those classes with Wilson 95% CI lower bound strictly above 0.60 — would flip verdict to **usable** as a corpus that actually measures the lane.
