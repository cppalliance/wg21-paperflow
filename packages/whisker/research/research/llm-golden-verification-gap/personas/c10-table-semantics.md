**Verdict:** usable-with-conditions (The full table story is mappable and the P0 column-cluster cell compare is the right deterministic tripwire for PR #286, but neither lane today compares header cell strings and the planned fix still faces colspan, borderless, and rotation edge cases.)
**Confidence:** high

## Findings

- [CRITICAL] The deterministic hard gate has exactly one table-related structural check and zero cell-semantics checks. Evidence: `run_gates` runs `_gate_no_empty_table` only (`gates.py:191-206`, `209-218`), which rejects a GFM separator with a pipe header but no data row; `_decide` hard-fails on gates plus `unigram_coverage < 0.85` only (`score.py:177-185`, `152-160`). No pipe count, header text, column alignment, or per-cell diff anywhere in `gates.py`, `score.py`, or the QA path wired into verdict. Impact: poll tables with intact `|S|F|N|A|SA|` pipes pass all six gates while violating the human wrapped-cell contract (`00-baseline.md:41-44`). Answer-class: 1.

- [CRITICAL] Whisker QA metrics count and parse tables but never compare cell content to source or ideal. Evidence: `compute_metrics` sets `table_count` via mistune AST (`qa.py:332`), `table_parse_errors` when row column counts disagree within one table (`qa.py:287-301`, `359`), and `lossy_table_count` from `tomd:lossy-table` markers (`qa.py:346-349`); `_score` never subtracts for `table_parse_errors` and only appends `lossy_table_count` to issues without a penalty (`qa.py:380-381`, `365-423`). `WhiskerResult` stores `table_parse_errors` and `lossy_table_count` (`score.py:72-73`, `314-315`) but `_decide` ignores them. Impact: P1068R11 observed QA `100` with six consistent five-column poll tables (`PR286-LLM-FALSE-CLEAR.md:465-478`) because every row has five pipes and no lossy marker, not because cells match source. Answer-class: 1.

- [CRITICAL] Baseline claim confirmed: no table-cell comparison exists anywhere in `tapetum_llm`. Evidence: `rg -i table` across `packages/whisker/src/whisker/tapetum_llm/` hits prompt taxonomy (`unit_judge.py:104`, `tapetum_llm.md:169-180`), `PageUnit.has_tables` / `SectionUnit.has_tables` assignment (`textlayer.py:272`, `html_outline.py:120-148`), and evidence-verification ambiguity for table-axis quotes (`grounding.py:359-364`, `558-577`); `route_pdf_units` never reads `has_tables` (`source_router.py:149-233` vs `textlayer.py:160-272`); `route_html_units` has no table-cell path (`source_router.py:236-316`, baseline `00-baseline.md:54-55`). Impact: the LLM lane cannot emit a grounded table-cell defect it was never asked to compute; recall is zero by construction. Answer-class: 1 + 2.

- [HIGH] Holistic table metrics (TEDS, GriTS-Con, ideal panel) cannot see localized header truncation on an otherwise valid grid. Evidence: `teds` is APTED tree-edit over HTML table DOM (`metrics.py:449-555`, `bench.py:112-125`); `grits_con` is order-matched cell F1, advisory-only, never gated (`bench.py:142-167`, `CLAUDE.md:387-388`); `golden_compare._table_axis` scores `(table_rows, table_cols)` tuples only (`golden_compare.py:279-284`). Lane 3 `facts._check_table` does per-cell neighbor checks (`facts.py:374-414`) but requires authored `checked: verified` facts; dev-replay labels for `p1068r11` list heading/entity issues only, not poll-header cells (`labels.json:82-106`, `a15-corpora-labels.md`). Impact: P1068R11 had no discoverable canonical ideal (`PR286-LLM-FALSE-CLEAR.md:570`); markitdown advisory TEDS `0.1294` did not flag (`PR286-LLM-FALSE-CLEAR.md:480`); token multiset `unigram_coverage` `0.9807` stayed above fail edge because `S`, `F`, `N`, `A`, `SA` all remain in the document. Answer-class: 1 + 5.

- [HIGH] P1068R11 passed deterministic QA 100 for predictable, documented reasons—not a scoring bug. Evidence: all six gates green including `no_empty_table` (`PR286-LLM-FALSE-CLEAR.md:471-478`); `table_parse_errors=0` because every poll row has five columns (`qa.py:287-301`); QA score penalties apply to uncertain regions, mojibake, heading skips, unfenced code—not cell text (`qa.py:375-421`); `lossy_table_count` only listed in issues, not scored down (`qa.py:380-381`). Six instances differ only in first header cell `SF`→`S` while pipe topology stays `|S|F|N|A|SA|` vs source `|SF|F|N|A|SA|` (`00-baseline.md:41-44`, `PR286-LLM-FALSE-CLEAR.md:76-78`). Impact: token-preserving table-header corruption is an explicit blind spot of the operational gate, predicted by persona prototypes 19/23 (`a09-persona-prototype.md`). Answer-class: 1.

- [HIGH] The P0 planned fix (source-aware table-cell compare with PDF column-cluster packets and wrapped-cell merging) would catch `SF`→`S` if geometry matches the baseline record. Evidence: P0 spec requires PDF packets from text position and column boundaries that distinguish vertically wrapped `SF` from a separate `S` cell (`PR286-LLM-FALSE-CLEAR.md:240-249`); baseline geometry: column x = `72.5, 95.5, 110.5, 127.5, 144.5, 167.5`; wrapped `S`+`F` share x=`77.25` inside the first column band, while second-column `F` sits at x=`100.5` (`00-baseline.md:42-44`, `PR286-LLM-FALSE-CLEAR.md:65-69`). Reasoning: cluster spans with x≈77.25 into column-1 → merged string `SF`; parse candidate pipe-table cell `(0,0)` → `S`; deterministic mismatch on six tables. Impact: this belongs on the deterministic/source-router path, not on LLM rediscovery; fixes recall without requiring `MAX_UNIT_CHECKS` to reach pages 8/9. Answer-class: 1 (encode contract) + 5 (LLM is wrong primary owner).

- [MED] Hardest edge cases for column-cluster + wrapped-cell merging threaten false passes and false fails. Evidence: `tables.py` / golden-hook docs flatten rowspan/colspan to first slot (`CLAUDE.md:846-847`); tomd `table.py` orphan absorption handles wrapped first lines on ruled layouts but borderless Tony/SPEC grids rely on x-gap heuristics (`tomd/CLAUDE.md:208`); PyMuPDF `get_text("text", sort=True)` is reading-order flat text with no rotation metadata in LLM packets (`textlayer.py:197`, `c04-pdf-textlayer.md`). Edge cases: (1) **Borderless tables**—ragged x clusters may split one logical column into two bands or merge adjacent narrow columns; (2) **Col-span**—merged header cells duplicate text in first slot only, so column-cluster boundaries derived from body rows mis-assign header glyphs; (3) **Rotated text**—sidebar or landscape headers land outside y-band column profiles; (4) **Multi-row headers**—WG21 feature-test tables stack two header rows; naive "row 0 only" compare misses wrong sub-header cell or treats sub-header lines as wrapped orphans. Impact: P1068R11 single-row poll headers are the easy case; generalizing without span-aware grids (docling `verify_table_v2` cited in `CLAUDE.md:846-847`) risks both missed `SF`→`S` on complex ballots and false fails on faithful merge flattening. Answer-class: 1 + 5.

- [LOW] LLM table rubric and defect taxonomy describe qualitative failure modes but supply no executable compare. Evidence: `tapetum_llm.md:169-180` lists merged-cell loss and column association breaks; `unit_judge.py:104` names `table_corruption` ("table structure broken"), not wrong cell text; `grounding._table_tokens_are_present` only marks table-axis quotes ambiguous when quote tokens ⊆ candidate table tokens (`grounding.py:359-364`), a precision guard with zero recall power when no claim is generated (`00-baseline.md:84-85`). Impact: even after pages 8/9 are checked, the model receives flat page strings without column delimiters and a contract that sanctions line-break differences (`pdf_judge.py:186-188`, `c04-pdf-textlayer.md`); table semantics cannot be verified at 100% by prompt alone. Answer-class: 3 + 4 + 5.

## False-pass hypothesis

P1068R11 PR-head candidate with six poll tables using `|S|F|N|A|SA|`: deterministic whisker returns `pass`, QA `100`, all gates green, `table_parse_errors=0`, `unigram_coverage≈0.98` (`PR286-LLM-FALSE-CLEAR.md:459-478`); source-aware LLM routes pages 8/9 for `heading_drift` but checks pages 1/13/2/3/4 under `MAX_UNIT_CHECKS=5` (`00-baseline.md:46-49`), emits zero defect groups, and fusion caps at coverage `review`—leaving the verified six-instance `SF`→`S` blocker invisible in both lanes.

## False-fail hypothesis

Faithful poll table where tomd repeats a colspan header across pipe columns (sanctioned denormalization per `tapetum_llm.md:173-174`): a naive column-cluster compare that expects one glyph cluster per pipe column without merge-aware rules could flag `table_cell` mismatch against PDF geometry even though the golden contract allows repeated header values; similarly, GriTS-Con/TEDS against a weak markitdown oracle already reports near-zero on clean papers (`CLAUDE.md:530-532`) and must not be promoted to hard gate without calibration.

## What would change my mind

An implemented P0 table-cell module (column-cluster packets + wrapped-cell merge) replayed on baseline P1068R11 bytes that emits a deterministic `table_cell` mismatch on all six poll-header instances (source merged `SF` at x=`77.25` vs candidate `S`) with zero false flags on the locked holdout table stratum papers, plus sidecar proof that the signal fires before unit scheduling—not merely that `has_tables` was logged.
