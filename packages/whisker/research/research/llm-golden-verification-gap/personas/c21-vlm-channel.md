# c21 - VLM second-channel advocate

**Verdict:** usable-with-conditions — the dormant rasterize→transcribe→diff stack is the right independent channel for PDF geometry-lossy defects (poll wrapped headers, figure text), but only if wired with table-page scoping and per-page diff; whole-document `text_nid` alone will false-clear PR #286-class blockers, and VLM does nothing for PR #295 HTML secno defects.
**Confidence:** medium

## Findings

- [CRITICAL] The VLM stack already implements the full second-converter pipeline the vlm-pdf-qa synthesis recommended: rasterize PDF pages → per-page VLM transcription from pixels alone → deterministic diff vs tomd markdown → tapetum-compatible sidecar. Evidence: `vlm_pipeline.py:39-93` (`vlm_adjudicate_paper`: `rasterize_pdf` → `transcribe_pages` → `diff_vlm_vs_tomd`); `vision.py:55-99` (PyMuPDF PNG, `TARGET_PIXELS=2_073_600`, `MAX_PAGES=50`); `transcribe.py:100-141` (serial per-page `run_vision_task`, fidelity fail-closed); `vlm_diff.py:124-200` (`text_nid`, `content_recall`, optional `mhs`, thresholds at `:50-59`). Impact: ~793 LOC of tested prior art exists; recall loss on PR #286 is not "no VLM design" but "never invoked." Answer-class: **5** (goal deferred pending infra) and **2** (production lane chose text-layer judge instead).

- [CRITICAL] Production `whisker-tapetum-llm` never calls the VLM pipeline; PDF papers route exclusively to the PyMuPDF text-layer judge. Evidence: `cli.py:1034-1035,1111-1118` (`use_pdf_judge = kind == "pdf"` → `judge_pdf_extraction(...)`); grep confirms zero imports/calls of `vlm_adjudicate_paper` in `cli.py`; `code-c24-vlm-boundary.md:38-39`. `_persist_lane_result` accepts `VlmDiffResult.to_sidecar_dict()` (`cli.py:598-606`) but only the text/pdf-judge path reaches it today. Impact: baseline PR #286 pages 8–9 were eligible for text-layer units, starved by `MAX_UNIT_CHECKS=5` (`00-baseline.md:46-49`); a wired VLM lane would not inherit that unit cap but was never an runtime option. Answer-class: **2**.

- [HIGH] Audit `*.readback*.md` artifacts are **markdown comprehension readback**, not VLM pixel readback, and cannot be cited as VLM fidelity evidence. Evidence: `readback.py:8-14` (blind Q&A: fact-derived questions + converted markdown only, no images); `readback_cli.py:8-12` (`whisker-readback` console script, separate from VLM modules). Impact: P4182R0 8/8 and N5040 6/6 table passes (`p4182r0.readback.md:87-107`, `n5040.readback.md:46-82`) prove the text pod can recover table facts from **clean** markdown, not that olmOCR-class pixel transcription would catch PR #286's `SF`→`S` swap. Answer-class: **5**.

- [HIGH] Readback on poll-table corpus paper P0876R23 **does** surface the SF-class defect on markdown, but also shows model misread (`F` not `SF`) even when markdown may be correct — the same failure mode as free-form judging, not proof VLM diff would fire. Evidence: `p0876r23.readback.md:63-72` (`table-poll-stlouis` **FAIL**: expected `heading: SF`, pod answered `heading: F`, latency 1077ms); corrupt run keeps the same fail and adds `table-poll-sofia` fail (`p0876r23.readback-corrupt.md:71-78`). Baseline PR #286 blocker: wrapped poll header `SF` transcribed as `S` (`00-baseline.md:41-44`). Impact: a second LLM channel reading **candidate markdown** can miss or mis-name wrapped headers; VLM's value proposition is reading **source pixels** where baseline says the cell is "VISUALLY unambiguous," then diffing independently — but readback does not test that path. Answer-class: **3** (model capability on table headings) and **1** (golden wrapped-cell contract absent from lane).

- [HIGH] Per-PR VLM cost for table-bearing pages only on the PR #286 incident is operationally negligible vs today's text lane. Evidence: baseline routed 9 pages, 2 with tables (pages 8–9, `00-baseline.md:46-48`); VLM transcribe is one serial call per page (`transcribe.py:117-130`, `vision_task.py:55-57`); cost research mid-estimate **~12 s/page** (`research/vlm-pdf-qa/33-cost-latency-analyst.md:10-12`), raster **~33 ms/page** (`33-cost-latency-analyst.md:18`). Arithmetic: **2 × 12 s ≈ 24 s** marginal GPU time per golden-PR review vs **~30 s/paper** single text-layer adjudication (`33-cost-latency-analyst.md:8-9`); alliance pod billed per uptime hour, not per token (`whisker/CLAUDE.md` tapetum availability section). Impact: table-page-only VLM is affordable for dev-replay PR checks; full-corpus blind serial VLM remains blocked (~21 h for 6266 pages, `33-cost-latency-analyst.md:10`). Answer-class: **2** (scope sampling fixes budget) and **5**.

- [HIGH] VLM-transcription → deterministic diff is materially more stable than free-form source-aware judging for geometry-lossy defects. Evidence: `vlm_diff.py:15-17` ("fully deterministic (no LLM, no randomness)"); verdict from pure metrics (`text_nid`, `content_recall`, `:140-144`) not model self-assessed defect lists; contrasts with baseline **≥25% verdict-flip rate** and **0 accepted defect groups** on PR #286 after evidence verification (`00-baseline.md:50-55,78-85`). `transcribe.py:52-68` instructs faithful OCR ("do not paraphrase", "do not hallucinate"); structured `PageTranscription` schema (D6) vs open-ended `UnitCheck` claims that die in `grounding.py` when never generated. Impact: hallucination moves to the transcription step (bounded by finetuned converter vs zero-shot judge per `vlm-pdf-qa/SYNTHESIS.md:8-9`); the **compare** step is reproducible. Residual risk: whole-document diff dilutes six `SF`→`S` tokens (`vlm_diff.py:91-93` concatenates all pages; thresholds `NID_PASS=0.85`, `RECALL_PASS=0.90`). Answer-class: **4** (verification asymmetry sidestepped for diff path) and **3** (transcription still LLM).

Answer-class: **1**.

- [LOW] `has_tables` is computed at extraction time but unused for routing or VLM page selection — wiring gap shared with text lane. Evidence: `textlayer.py:86-95,221-224` (`PageUnit.has_tables`); `source_router.py` never reads `has_tables` (baseline `00-baseline.md:53-54`; grep empty). Impact: table-page-only VLM for golden-PR replay should key off `has_tables` or deterministic lossy-table flags, not whole-document rasterization. Answer-class: **2**.

## False-pass hypothesis

P1068R11 with VLM wired but **whole-document** `diff_vlm_vs_tomd`: olmOCR transcribes poll headers as `SF` from pages 8–9 pixels, tomd candidate has `S`; six header tokens drown in thousands of agreeing tokens, `text_nid ≥ 0.85` and `verdict=pass` (`vlm_diff.py:136-137,207-208`), fusion sees det=pass + tapetum=pass → same golden-PR blocker ships that text-layer missed.

## False-fail hypothesis

Faithful P1068R11 conversion where VLM mis-transcribes a math glyph on page 13 while pages 8–9 are correct: whole-document `text_nid` drops into ambiguous band → `verdict=review` (`vlm_diff.py:211-212`), advisory noise without naming the real wrapped-cell defect (wrong axis, same as det `ref_nid` advisory false alarms).

## What would change my mind

A live run of `vlm_adjudicate_paper("P1068R11", …)` against PR #286 head bytes with a vision-capable pod, persisting per-page transcriptions for pages 8–9 showing `SF` in VLM text and `S` in tomd, plus either (a) a **per-page** or table-grid diff returning `fail`/`review` with axis notes citing those pages, or (b) demonstrated failure of whole-document diff despite localized defect — would flip toward **usable** (wire table-scoped VLM) or **garbage** (drop VLM for this class), respectively.
