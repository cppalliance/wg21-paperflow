# c03 - HTML outline attacker

**Verdict:** usable-with-conditions (+ the HTML outline path is a precise root-cause map for PR #295's metadata/outline false pass, but it cannot enforce golden-contract heading normalization without new deterministic preprocessing; treat its `pass` as structural agreement on raw descendant text, not golden fidelity)
**Confidence:** high

## Findings

- [CRITICAL] PR #295 metadata/outline `pass` with empty `heading_drift` is mechanically explained by all-descendant-text collection: bikeshed `<h2><span class="secno">1.</span> Abstract</h2>` yields source outline `h2: 1. Abstract` via `handle_data` appending every in-heading text node (`html_outline.py:79-81`, `154-157`), and the PR-head candidate snapshot carries the same labels (`packages/tomd/tests/fixtures/golden/snapshots/p3953r0.md:12-57`: `## 1. Abstract` … `## 4. Impact on existing code`). `_candidate_structure_packet` emits matching `h2: 1. Abstract` (`unit_judge.py:127-130`); the LLM compares identical outlines and reports no drift (baseline `00-baseline.md:62-64`, `174-175`: 0 generated defect groups, structure-only recall 0/4 headings). Impact: the mandatory metadata check is blind to the human-verified blocker because source ground truth includes the chrome the golden contract forbids. Answer-class: 1.

- [CRITICAL] There is no normalization layer between HTML extraction and outline comparison that encodes the golden secno-stripping rule. `extract_heading_outline` only collapses whitespace (`html_outline.py:73`, `155`); `format_outline` truncates display to 120 chars (`html_outline.py:202-206`); `adjudicate.py` passes raw `(tag, text)` tuples straight into `run_metadata_outline_check` (`adjudicate.py:485`, `566-567`). `route_html_units` matches titles via `_text_key` = `normalized_text(...).casefold()` (`source_router.py:57-58`, `253-274`), which folds alnum but does not strip `span.secno`, `header-section-number`, or bikeshed classes. Impact: every comparison stage equates "candidate retained secno" with "faithful conversion." Answer-class: 1.

- [HIGH] `METADATA_CHECK_SYSTEM_PROMPT` never states the secno / structural section-label stripping rule. Full prompt text (`unit_judge.py:78-91`): *"You are a metadata and outline validator. Compare the source metadata and source heading outline with the candidate Markdown front matter and heading outline. Judge field values, missing sections, and heading-level drift. Cosmetic source formatting is not a defect. Ignore source table-of-contents entries, page numbers, running headers, and running footers as sanctioned source chrome; the candidate is expected to omit that chrome while preserving the corresponding body headings."* It sanctions TOC/page furniture only, not bikeshed `span.secno` or pandoc `header-section-number` in body headings. The inline unit contract (`unit_judge.py:67-76`) likewise omits secno policy. Impact: even a capable model is asked to rediscover a rule documented only in human golden skills (`tomd` `_render_heading` keeps secno in output: `render.py:648-661`, `_HEADING_SKIP_CLASSES` = `{self-link}` only). Answer-class: 1.

- [HIGH] Heading-comparison failure modes from raw descendant-text extraction (all class 1 unless noted):
  1. **secno false pass** — source and candidate both include `1. Abstract`; golden wants `Abstract`.
  2. **secno false fail** — candidate correctly strips prefix but source outline still includes `1.` → spurious `missing_sections` / `heading_drift`.
  3. **`<br>` concatenation** — `HTMLParser` collects adjacent text nodes with no `<br>` separator (`html_outline.py:66-81`); P3953 `<h1>…P3953R0<br>Rename…</h1>` becomes `P3953R0Rename std::runtime_format`, producing baseline routing false positive `section:0` "candidate missing" (`00-baseline.md:68-73`).
  4. **aria-hidden / decorative spans** — no attribute filter; hidden numbering text is collected same as visible secno.
  5. **TOC / link-wrapped headings** — anchor + `toc-section-number` inner text is collected wholesale; p4228r0 TOC uses `toc-section-number` in `<li><a>` (`p4228r0.html:521-560`), body headings append empty `self-link` anchors (no text) but numbered spans remain (`p4228r0.html:563-566`).
  6. **pandoc `header-section-number`** — p4228r0 body headings emit `N Title` in outline; golden may require strip while router title-key match hides level-only defects.
  7. **bikeshed chrome headings (`no-num`, `no-ref`)** — not filtered by class; P3953 profile `<h2 class="no-num">` (`test_html_extract.py:207-209`) enters outline and triggers `section:1` "candidate missing" when date moves to YAML (`00-baseline.md:70-71`).
  8. **Router level-only drift** — `heading_drift` signals fire only on title-key miss or level mismatch (`source_router.py:261-274`), never on "same text, wrong chrome policy."
  9. **Shared defect symmetry** — when tomd output and golden ideal share the same secno bug, deterministic `_text_key` match yields no router signal (PR #295: 0/4 headings recalled). Answer-class: 1 (items 1-8), 4 (item 9: zero claims → verification idle).

- [MED] Golden fixture sources under `packages/tomd/tests/fixtures/golden/sources/*.html` contain no bikeshed `secno`, `no-num`, or `no-toc` strings (rg 2026-07-22: 0 matches). Chrome patterns live elsewhere: pandoc/respec **`header-section-number`** on every p4228r0 body heading (`p4228r0.html:563+`, CSS line 207); bikeshed **`secno` / `no-num` / `<br>` title** only in unit-test HTML (`test_html_extract.py:206-209`, `test_html_render.py:326-347`), not in committed source fixtures; P3953 has snapshot only (`snapshots/p3953r0.md`), no `sources/p3953r0.html`. **Misjudgment forecast:** p4020r0 (plain `<h1>`/`<h2>`, no numbering chrome) — low false-pass risk from outline path; p4228r0 — high risk of number-in-title false pass or strip-policy false fail; cwg1 — legacy `<H4>` with inline `1.` prefix (not span.secno) still couples numbering to title text (`cwg1.html:32-35`). Impact: the regression corpus does not exercise the bikeshed defect class that burned PR #295. Answer-class: 1.

- [MED] `_SectionExtractor` shares the same title extraction as the outline (`html_outline.py:169-170`, `154-157`) and feeds `route_html_units` section packets (`adjudicate.py:470-494`, `source_router.py:276-300`). Section titles inherit every outline failure mode; baseline `section:6` low-recall signal was polluted by unfiltered `<script>`/`<style>` in section body text (`00-baseline.md:71-72`, `_SectionExtractor` collects all `handle_data` without skipping script/style: `html_outline.py:168-172`). Impact: routing noise displaces real units under `MAX_UNIT_CHECKS = 5` while secno headings never route. Answer-class: 2.

- [LOW] Triage injects the same raw outline via `format_outline(extract_heading_outline(...))` (`adjudicate.py:561-568`) with no contract-normalized expected shape, so the monolith triage step inherits the same blind spot as the mandatory metadata call. Impact: redundant false confidence on HTML papers. Answer-class: 1.

## False-pass hypothesis

P3953R0 (PR #295): four bikeshed H2s retain `1.`–`4.` secno prefixes in both source HTML outline extraction and candidate markdown; metadata/outline returns `pass`, empty `heading_drift`, 0 unit defect claims, while human golden contract requires `## Abstract` (no structural label). Verified baseline numbers: structure-only recall 0/4 headings, 0/1 groups (`00-baseline.md:74-75`, `189-190`).

## False-fail hypothesis

p4228r0 after deterministic secno/`header-section-number` stripping in candidate but not in `extract_heading_outline`: source outline `h1: 2 Introduction` vs candidate `h1: Introduction` → spurious `missing_sections` or `heading_drift` even when conversion matches golden ideal. Conversely, naive level-only diff on p4228r0 References subtree (`h2` → `h3` nesting) reproduces the documented PR #295 false-positive trap if secno normalization is added without source-anchored level rules (`research/golden-qa-gap/opus-C-mc5-llm.md:312-318`, cited in archaeology a01).

## What would change my mind

A whisker-side `normalize_source_heading(text, html_context)` that strips bikeshed `secno` and pandoc `header-section-number` before both `run_metadata_outline_check` and `route_html_units`, plus a dev-replay rerun on P3953R0 showing non-empty `heading_drift` or accepted defect groups for all four secno-polluted H2s without new false fails on p4228r0 References nesting.
