# c07 - Schema validator attacker

**Verdict:** usable-with-conditions (Every pydantic validator in the LLM output path enforces internal field consistency only; downstream demotion and fusion caps catch some vacuous passes, but schema cannot force examination of the right content and retries optimize for valid empty-defect shapes, not defect discovery.)
**Confidence:** high

## Findings

- [CRITICAL] All five `@model_validator` / `@field_validator` hooks in `models.py` are internal-consistency gates; none bind output to source/candidate bytes. Evidence: `IdealDiscrepancy.text_must_not_be_blank` rejects whitespace only (`models.py:102-108`); `IdealVerification.verdict_matches_discrepancies` ties `agree` to empty `discrepancies` (`models.py:120-127`); `PageJudgment.missing_flag_matches_quotes` ties `content_missing` to non-empty `missing_content` (`models.py:220-228`); `MetadataOutlineCheck.pass_requires_no_mismatch` rejects pass only when explicit bool/list mismatch fields are set (`models.py:283-295`); `UnitCheck.verdict_matches_defects` ties `pass` to empty `defects` (`models.py:315-320`). Impact: baseline PR #295 metadata/outline `pass` with empty `heading_drift` while human-verified secno labels remain is schema-valid; the validator cannot see that source outline preprocessing omitted the contract (`00-baseline.md` PR #295). Answer-class: 1.

- [CRITICAL] Six LLM `output_type` models have zero cross-field validators and admit vacuous clean shapes. Evidence: `Adjudication` (`models.py:166-188`) — no validator linking `verdict`, `axis_findings`, `evidence_spans`, or `worst_axis`; decide step explicitly sanctions pass with empty evidence (`adjudicate.py:325-326`). `AxisFinding` (`models.py:155-163`) — axis verdict independent of any quote. `EvidenceSpan` (`models.py:138-152`) — no substring requirement (grounding is post-schema in `grounding.py`). `DefectFinding` (`models.py:231-259`) — `source_quote` not validated against the unit packet. `PdfJudgment` in `pdf_judge.py:267-284` — no validator linking `verdict` to `missing_content`; `_fold_monolith_verdict` preserves model pass when `missing_content` is empty (`pdf_judge.py:369-370`). Impact: a model can emit `pass` + empty defect/missing lists without ever naming the human-verified blockers; baseline PR #286 `accepted defect groups: 0` and PR #295 `generated defect claims: 0` are compatible with every schema. Answer-class: 4.

- [HIGH] Enumerated vacuous-pass paths (schema accepts clean verdict with no evidentiary obligation). Evidence: (1) `UnitCheck`: `verdict=="pass"` iff `defects==[]` (`models.py:315-320`); (2) `IdealVerification`: `verdict=="agree"` iff `discrepancies==[]` (`models.py:120-127`); (3) `MetadataOutlineCheck`: `verdict=="pass"` when all match flags true and drift lists empty — no per-heading secno audit (`models.py:283-295`); (4) `PageJudgment`: `content_missing==false` with empty quotes (`models.py:220-228`); (5) `Adjudication`: any `verdict` with empty `axis_findings` and empty `evidence_spans` (`models.py:166-188`, `adjudicate.py:313-316`); (6) `PdfJudgment`: `verdict=="pass"` with `missing_content==[]` (`pdf_judge.py:267-284`, `369-370`); (7) `DefectFinding` list empty inside otherwise-valid `UnitCheck`; (8) `TapetumResult.unit_coverage` defaults `coverage_complete: true` when no unit judge ran (`adjudicate.py:418-423`); (9) `parse_ideal_verification` returns `None` on any validation error, erasing ideal disagreements from fusion (`models.py:130-135`). Impact: each path is a legitimate "verified clean" shape that requires no proof the model inspected the defect locus; retries can converge on (1)/(3)/(5)/(6) faster than emitting grounded defects. Answer-class: 4.

- [HIGH] Retry loops repair schema contradictions, not recall. Evidence: whisker judge calls use `run_judge_task` → `AgentBackend.run` → `ModelBackend.run` with pydantic `output_type` (`judge_task.py:68-74`, `agents.py:161-171`); alliance-pod path sets `Agent(..., retries=3)` (`model_backends.py:455-460`); raw JSON path retries on `ValidationError` only (`model_backends.py:374-395`). Zero `ModelRetry` or `output_validator` hooks exist in `tapetum_llm/models.py` or whisker validators. For `UnitCheck`, a retry from `pass`+nonempty-defects can resolve to `pass`+empty-defects (schema-valid vacuous pass) as easily as to `review`+defects — nothing in the validator pushes toward finding defects, only toward consistent field tuples. Impact: D10 retry budget is a formatting repair loop, not a recall amplifier; aligns with baseline "schema validators force internal consistency only" (`00-baseline.md:86-88`). Answer-class: 4.

- [HIGH] Minimal schema additions that would force accountability (still insufficient alone for 100% recall). Evidence: current gaps above. Proposed minimal deltas: (a) per routed signal, require `UnitCheck.signals_addressed: list[Literal[...]]` with `@model_validator` `set(signals_addressed) == set(risk_signal_types_for_unit)` passed in prompt metadata; (b) for each `MetadataOutlineCheck` pass, require `heading_pairs_checked: list[{source,candidate}]` with `@field_validator` each pair present in injected outline strings; (c) for `Adjudication`/`PdfJudgment` pass, require `evidence_spans`/`missing_content` min_length≥1 OR explicit `clean_after_checklist: list[FidelityAxis]` with all axes listed; (d) `DefectFinding` add `source_quote_grounded: bool` set by post-validator calling `ground_spans` or reject at schema time via `@field_validator` substring check against unit packet (external, not just internal). Impact: would block silent pass-without-citation and make "did not look" auditable; would not fix routing starvation or contract-encoding gaps without deterministic preprocessing (classes 1–2). Answer-class: 4.

- [MED] `TapetumResult` records routed-but-unchecked units; pipeline demotion prevents `suggested_verdict==pass`, fusion caps at review — but metadata can still schema-pass independently. Evidence: `TapetumResult.unit_coverage` persists `coverage_complete`, `checked_unit_ids`, `unchecked_unit_ids`, `failed_unit_ids` (`models.py:354-358`, `393`); `run_unit_checks` marks cap-displaced and no-packet units unchecked (`unit_judge.py:239-252`, `305-308`); sets aggregate `verdict="review"` when incomplete (`unit_judge.py:319-323`); `adjudicate.py:362-364` and `pdf_judge.py:881-882` demote monolith pass→review; `fusion._source_aware_requires_review` fires on `coverage_complete is not True` or nonempty `unchecked_unit_ids` (`fusion.py:192-196`, rule `source_aware_review_cap` at `constants.py:137`). Baseline PR #286: pages 8/9 routed but unchecked, fusion `review` via coverage cap not detection; PR #295: `section:0` in `unchecked_unit_ids`, metadata `pass`. Impact: sidecar is honest about coverage gaps; schema-valid metadata pass + incomplete unit coverage is a normal false-clear shape; no field records "defect class never routed" (e.g. table cells, baseline PR #286). Answer-class: 2.

- [MED] `MetadataOutlineCheck` one-way mismatch guard cannot catch false agreement. Evidence: validator only rejects `verdict=="pass"` when `title_matches`, `document_number_matches`, `date_matches` are false or drift lists nonempty (`models.py:286-294`); it does not require nonempty `heading_drift` when headings differ under human contract; it allows `verdict=="review"` or `"fail"` with empty drift lists (no symmetric constraint). Impact: false agreement (source outline equals wrongly normalized candidate outline) passes schema and matches PR #295 runtime. Answer-class: 1.

- [LOW] `IdealVerification` mirrors the same vacuous-agree pattern as `UnitCheck` and is orthogonal to source-aware recall. Evidence: `agree` iff empty discrepancies (`models.py:120-127`); fusion only caps pass→review on `ideal_verdict=="review"` (`fusion.py:406-417`), never promotes. Impact: ideal lane can agree vacuously while source-aware unit lane misses; separate concern from golden-PR blockers unless ideal exists. Answer-class: 5.

## False-pass hypothesis

PR #295 P3953R0: `MetadataOutlineCheck` returns `verdict="pass"`, `heading_drift=[]`, all match flags true — schema-valid (`models.py:283-295`) because bikeshed outline extraction makes `1. Abstract` match on both sides (`00-baseline.md` PR #295); concurrent `unit_coverage.unchecked_unit_ids` includes `section:0` but metadata pass is unconstrained by coverage; fusion ends `review` via `source_aware_review_cap`, not because schema forced defect enumeration.

## False-fail hypothesis

PR #286 page-13 unit check: model emits `UnitCheck` with nonempty `defects` (false heading-drift) and `verdict!="pass"` — schema accepts; `verdict_matches_defects` would reject only the inconsistent combo `pass`+defects (`models.py:315-320`); downstream evidence marks claim `ambiguous=1` (baseline), defect groups stay 0 — schema never required the model to retract, but verification demoted impact without a schema retry toward vacuous pass.

## What would change my mind

A whisker-local `@model_validator` on `UnitCheck` that rejects `pass` unless `reasoning` cites at least one verbatim substring from the injected SOURCE TEXT block (validated against the unit packet bytes), deployed on a replay of PR #286 pages 8–9 with table signals routed and checked, producing a schema rejection (retry or hard fail) when the model returns the current empty-defect pass — proving external validators can break vacuous pass without deterministic table compare in the router.
