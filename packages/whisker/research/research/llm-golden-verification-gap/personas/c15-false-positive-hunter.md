**Confidence:** high

## Findings

- [CRITICAL] YAML front-matter mapping fires false HTML `heading_drift` ("candidate missing") for legitimate title promotion. P0 **HTML packets** (missing-packet diagnostic) + P0 **heading normalization** (map h1 to front-matter title key) address this; **scheduling** does not. Answer-class: 1.

- [HIGH] `<script>`/`<style>` payload in section text creates false `low_recall` that steals budget from real sections. Evidence: `_SectionExtractor.handle_data` appends all character data with no tag filter (`html_outline.py:168-172`); `script`/`style` absent from `_BLOCK_TAGS` (`html_outline.py:34-38`); `route_html_units` compares polluted `unit.text` to candidate section via `content_recall` (`source_router.py:288-300`, `metrics.py:376-393`); baseline PR #295 `section:6` recall `0.0437` (`00-baseline.md:71-72`).
