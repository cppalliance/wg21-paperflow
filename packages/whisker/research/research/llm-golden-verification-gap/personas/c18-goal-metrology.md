# c18 - Goal metrologist

**Verdict:** usable-with-conditions ("100% LLM verification" is not a well-formed SLO; the lane is contractually advisory, single-shot recall is bounded below 100% by measured flip rate and subtract-only verification, and both 2026-07-22 incident blockers were deterministically decidable, so the honest target splits mechanical encodings from LLM triage on fuzzy residue with per-class metrics)
**Confidence:** high

## Findings

- [CRITICAL] **Interpretation 1 — per-PR defect-group recall (100% of human-verified groups named in accepted LLM output):** requires every merge-blocking `defect_group` to survive routing, unit check, claim generation, and two-sided evidence verification. Attainability: **failed on both incidents and not achievable single-shot.** PR #286: **0/1** accepted defect groups (pages 8/9 routed, unchecked under `MAX_UNIT_CHECKS=5`, `00-baseline.md:46-55`); PR #295: **0/4** secno headings, **0** generated claims (`00-baseline.md:62-74`). Even with routing fixed, **>= 25% verdict-flip rate** on identical reruns (`whisker/CLAUDE.md:553-554`) implies P(miss) > 0 per invocation; zero generated claims make evidence verification vacuously inert (`00-baseline.md:84-89`, `grounding.py` precision-only). Impact: one LLM run cannot certify golden completeness. Answer-class: **5**.

- [CRITICAL] **Interpretation 2 — per defect-class recall (100% within each taxonomy bucket on labeled corpus):** requires recall = 1.0 per class on dev-replay (9 papers) plus holdout (48 anchors, 3 papers). Attainability: **unmeasurable today; ceiling below 100% even with labels.** Dev-replay omits both incident classes: p1068r11 labels `heading_hierarchy`/`html_entities` but not six wrapped poll-table cells; p3953r0 is labeled clean with `expected_llm_verdict: pass` and empty `defect_groups` (`a15-corpora-labels.md:8-10`). Holdout anchors test source-quote **presence** (46/48 `present_in_candidate`), not recall on ungenerated claims (`a15-corpora-labels.md:20-21`). External ceiling: DeltaBench macro-F1 **40.76%**, recall **57.19%** on fine-grained error detection (`w1-judge-recall-ceiling.md:29`). Impact: "100% per class" is rhetoric until taxonomy and positives exist for secno and wrapped-cell classes. Answer-class: **5**.

- [HIGH] **Interpretation 3 — zero false clears (100% specificity: no LLM `pass`/empty defects when human blocks merge):** requires LLM lane never emits clear-with-zero-defects on golden-PR blockers. Attainability: **violated.** PR #282 p4020r0 false-clear at confidence **1.00** (`00-baseline.md:80-81`, `whisker/CLAUDE.md:556-558`); **96/96** clear firings at conf >= 0.95 anti-calibrated. PR #286/295: fusion `review` via `source_aware_review_cap` with **0** accepted groups (`00-baseline.md:50-52,74-75`) — programmatically conservative but operator-indistinguishable from "checked and clean" when inspect omits unchecked unit IDs. Impact: specificity SLO on LLM `pass` conflicts with measured calibration. Answer-class: **3**, **5**.

- [HIGH] **Interpretation 4 — verdict agreement (100% LLM fused verdict matches human merge/review/block):** requires exact trichotomy match across golden-PR replay. Attainability: **not achievable.** Flip rate alone caps rerun agreement at ~**75%** upper bound without aggregation (`w1-judge-recall-ceiling.md:17-18`; `tapetum_llm.md:31`). PR #286: det `pass`, LLM `review` (coverage-only), human **block** on table defect — trichotomy mismatch before flips. Lane contract: advisory, "never part of `whisker --gate`" (`tapetum_llm.md:3-9`, `whisker/CLAUDE.md:534-540`); **0/31** surveyed conversion-QA repos gate on LLM signals (`whisker/CLAUDE.md:550-552`). Impact: verdict agreement is the wrong metric for a lane designed not to decide merge. Answer-class: **5**.

- [HIGH] **Interpretation 5 — LLM-only verification (100% without expanding deterministic encodings):** requires the existing tapetum_llm stack alone to catch all contract violations, with deterministic lane unchanged. Attainability: **contradicted by design and incidents.** Both blockers are **deterministically decidable** but not encoded: PR #286 wrapped `SF` cells provable by PyMuPDF column x geometry (`00-baseline.md:41-44`, `PR286-LLM-FALSE-CLEAR.md:65-78`); PR #295 secno labels detectable via DOM `span.secno` strip before compare (`html_outline.py:66-81`, `render.py:648-661`, `a17-golden-contract.md:10`). Table row/cell swaps are prompt-assigned to the LLM ("you are the catch", `tapetum_llm.md:175`) while research assigned them to deterministic fact-mining (`a02-llm-qa-integration.md:14-15`). Impact: pursuing LLM-only 100% repeats work the geometry/DOM path already owns. Answer-class: **5** (+ **1** contract-encoding gap).

- [HIGH] **Interpretation 6 — per-run exhaustive coverage (100% of contract-relevant units routed AND checked, single invocation):** requires `checked_unit_ids` to cover every unit bearing a human-verified defect. Attainability: **failed mechanically, independent of model.** PR #286: pages 8/9 routed, displaced by `MAX_UNIT_CHECKS=5` and lexical sort (`constants.py:223`, `unit_judge.py:225-241`, `00-baseline.md:46-49`); PR #295: `section:0` routed, no source packet, silently unchecked (`00-baseline.md:67-73`). `PageUnit.has_tables` exists but `route_pdf_units` never reads it (`textlayer.py:86-98`, `source_router.py:149-233`, `00-baseline.md:54-55`). Impact: "100% verification" cannot mean "looked everywhere" until budget/scheduling and signal taxonomy are fixed; even then flip rate blocks single-run certainty. Answer-class: **2**, **5**.

- [MED] **Reframe — raise deterministic coverage; LLM handles fuzzy residue only:** of 34 atomic golden-contract rules (`a17-golden-contract.md:22-63`), **13 (38%)** reach neither deterministic code nor LLM prompts; the two incident blockers (#6 secno strip, #23 wrapped table cells) sit in that set but are **mechanically encodable** (DOM class + regex; PDF cell geometry compare). **Deterministic SLO candidate (100% recall required):** rules with structural/string predicates — FM key order (#1-2), TOC leak (#9-12), list marker/depth (#15,17), code fence presence (#18-19), table dimensions (#21-22), secno strip (#6), wrapped cell text (#23), bikeshed chrome exclusion (#14), blank-line cap (#27), bullet marker (#33), pandoc ghosts (#34), page furniture (#10-11), heading nest cap (#8), dehyphenation (#28), ins/del token presence (#24). **Fuzzy residue (LLM triage, measured recall, not 100% gate):** structure-only scope / no wording paraphrase (#30); preserve source typos vs intentional fix (#29); wrong heading level when order stays monotone (`pr-golden-review.md:17`); rendered-Markdown semantics — delimiter consumption (`constexpr`contexts), `<br>` flattening, `<cite>` emphasis loss (PR #295 extended fidelity, `PR286-LLM-FALSE-CLEAR.md:105-109`); qualitative table failure beyond cell text (merged cells, column swaps without geometry); wording deliverable appropriateness; image alt semantic fidelity; reference-entry count parity without DOM inventory (#14 partial); ideal hand-corrected vs seed (#31, process). Impact: the right goal is not "LLM finds secno" but "deterministic gate fails secno; LLM ranks the ~10-15 judgment rules." Answer-class: **5**.

- [MED] **Measurable replacement goal (recommended SLO):** **(G1)** **100% recall on mechanically-checkable defect classes** enforced by `whisker --gate fail` on corrected dev-replay (secno strip, PDF table-cell geometry, existing gates) — not LLM; **(G2)** **>= 0.80 defect-group recall** on labeled fuzzy-residue groups after routing fixes, measured by sidecar replay pytest (ceiling informed by DeltaBench ~57%, not 1.0); **(G3)** **100% coverage reporting**: every run lists `unchecked_unit_ids` for routed-but-skipped units (pages 8/9, section:0) and never presents metadata/outline `pass` as heading verification; **(G4)** **false-clear rate <= 5%** on labeled blockers under **3-run majority** (flip budget: 25% rate → p(miss)^3 ≈ 1.6% at independence, still not zero); **(G5)** **verdict stability tracked**: N>=3 reruns per labeled paper, report flip rate and claim-set Jaccard. Prerequisites: corrected labels for p1068r11/p3953r0 (`a15-corpora-labels.md:8-10`), holdout schema extension or parallel recall holdout for polarity-aware defects, **>= 30** labeled golden-PR papers with >= 2 positives per class (`a02-llm-qa-integration.md:18`). Impact: operators get a testable contract aligned with advisory architecture and ecosystem norm (0/31 LLM gates). Answer-class: **5**.

- [LOW] **Compounding probability — "100%" is a product, not one knob:** P(recall) ≈ P(route) × P(check|routed) × P(claim|checked) × P(verify|claim). PR #286: P(check|routed)=0 for pages 8/9; PR #295: P(claim|checked)=0 after outline false-equivalence; when P(claim)=0, P(verify)=1 vacuously but recall=0 (`00-baseline.md:84-89`). Impact: goal metrology must decompose SLO by pipeline stage, not aggregate into one LLM percentage. Answer-class: **2**, **4**.

## What would change my mind

Corrected dev-replay (>= 30 papers, secno + table-cell labels), deterministic gates at 100% recall on mechanically-checkable classes, plus instrumented LLM replay showing **single-shot fuzzy-residue recall >= 0.95** AND **verdict flip rate <= 5%** on three reruns per paper with CI pytest — would refute the 25%-flip bound for this lane and make Interpretation 2 worth revisiting. No such artifact exists; until then, the split SLO in finding 7 is the honest ceiling.
