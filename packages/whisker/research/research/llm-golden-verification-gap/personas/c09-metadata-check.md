# c09 - Metadata/front-matter check attacker

**Verdict:** usable-with-conditions (The metadata/outline adjudication path encodes part of the tomd contract in prompts but the deterministic comparison layer ignores H1→YAML mapping, secno stripping, and inline HTML normalization, producing a PR #295 false pass on the real blocker plus 2/3 false routing signals.)
**Confidence:** high

## Findings

- [CRITICAL] The mandatory metadata/outline check does not encode the golden rule that source H1 title maps to YAML front matter, not a body H1. Evidence: `tapetum_llm.md:136-137` states "body starts at H2; the front-matter title is the implicit H1"; `METADATA_CHECK_SYSTEM_PROMPT` (`unit_judge.py:78-91`) says only "Title-block metadata is converted into YAML front matter" and compares "source heading outline" to "candidate Markdown front matter and heading outline" without stating that source `h1` must be absent from candidate ATX headings; `_candidate_structure_packet` (`unit_judge.py:123-131`) lists every ATX heading in the file with no H-level shift. Impact: PR #295 `section:0` routed `'P3953R0Rename std::runtime_format': source h1, candidate missing` (baseline) while the title correctly lives in YAML; the metadata call still returned `pass` with empty `heading_drift` (baseline). Answer-class: 1.

- [CRITICAL] Secno stripping and bikeshed chrome normalization exist only in the human golden contract, never in the metadata or routing comparison layer. Evidence: `_HeadingExtractor.handle_data` (`html_outline.py:79-81`) concatenates all descendant text including `span.secno`; `route_html_units` compares `_text_key(source_title)` to candidate section titles at the same numeric level (`source_router.py:253-274`); baseline PR #295 records four H2s retaining `1.`–`4.` labels as the human-verified blocker while metadata/outline `pass` with empty `heading_drift`. Impact: the structure-only recall loss is invisible to the path whose job is outline fidelity; the LLM is asked to rediscover a rule preprocessing never applies. Answer-class: 1.

- [HIGH] `adjudicate._run_html_unit_checks` assembles source metadata from raw HTML outline text without contract normalization before the LLM call. Evidence: `adjudicate.py:475-489` builds `metadata_parts` from `source_outline[:3]` formatted as `{tag}: {text}` plus `section_units[0].text[:4000]`; that outline is produced by `extract_heading_outline` (`html_outline.py:84-91`) with no secno/br/chrome stripping; the same raw outline feeds `route_html_units` (`adjudicate.py:494`). Impact: polluted source packets and false `heading_drift` signals propagate from the same unnormalized extractor; fixing only the LLM prompt cannot repair deterministic false positives upstream. Answer-class: 1.

- [HIGH] Inline HTML normalization before comparison is incomplete: `<br>` and nested inline elements concatenate without separators; entity handling differs between extractors. Evidence: `_HeadingExtractor` collects text via `handle_data` only and never inserts a separator on `<br>` (`html_outline.py:66-77`); title text is joined with `" ".join("".join(self._text_buf).split())` (`html_outline.py:73`), collapsing `<br>` to zero-width glue (baseline: `P3953R0Rename std::runtime_format`); `_SectionExtractor` uses `convert_charrefs=True` (`html_outline.py:98`) while heading titles use the default parser path; router title keys use `normalized_text(...).casefold()` via `_text_key` (`source_router.py:57-58`, `metrics.py:342-344`), which alphanumerically folds content but does not repair br-glue or strip secno spans. Impact: false "candidate missing" on section:0 and weak title matching against YAML; operators cannot trust outline signals as structural ground truth. Answer-class: 1.

- [HIGH] PR #295 routing false-positive rate was 2/3 on heading_drift alone, consuming 2 of 2 executed unit checks on non-defects while the secno blocker was never routed. Evidence: baseline lists three routed signals—`section:0` and `section:1` both false "candidate missing" (YAML-mapped title and bikeshed `no-num no-toc no-ref` chrome), `section:6` recall `0.0437` polluted by `<script>`/`<style>` in `_SectionExtractor` (`html_outline.py:168-172`, no tag filter); checked units `section:1` and `section:6`, unchecked `section:0` (no source packet, `unit_judge.py:248-252`); generated defect groups 0/1 structure-only FN (baseline). Impact: under `MAX_UNIT_CHECKS=5` (`constants.py:223`) the cap was not hit here, but 100% of checks targeted false or polluted units; on PR #286 the same budget pattern displaced pages 8/9 (baseline). False routing erodes trust in `source_aware_review_cap` fusion, which caps to `review` for coverage gaps—not because a real defect was found. Answer-class: 2.

- [MED] Golden markdown structural conventions vs what the comparison layer knows. Evidence: contract docs—`tapetum_llm.md:136-141`, `tomd/CLAUDE.md:150-177`, image sidecar `![alt](path)` (`tomd/CLAUDE.md:69`). Layer knowledge: YAML block extraction and three boolean field checks via `MetadataOutlineCheck` (`models.py:262-281`); ATX heading list with literal levels (`unit_judge.py:127-130`); TOC title skip set `{contents, tableofcontents}` only (`source_router.py:36-37`, `145-147`); front-matter strip before section parse (`source_router.py:61-67`); intent case-fold guard in evidence verification only (`grounding.py:372-395`). Not encoded: secno/`span.header-section-number` stripping, H1→YAML level shift, YAML key-order validation, reply-to list shape, image sidecar path conventions, wording ins/del markers, prose reflow policy, fenced-code fidelity beyond `<pre>` count. Impact: metadata/outline adjudication covers a narrow slice of the golden contract and false-clears the PR #295 structure blocker. Answer-class: 1.

- [MED] Monolith triage prompts know the H2-first contract; the metadata unit prompt and deterministic router do not inherit it consistently. Evidence: `_build_triage_message` injects `format_outline(extract_heading_outline(...))` for HTML (`adjudicate.py:561-568`) under the system prompt block quoting `tapetum_llm.md:136-137`; chunk notes explicitly say "Do not flag missing front matter" (`adjudicate.py:554-558`); `METADATA_CHECK_SYSTEM_PROMPT` lacks the H2-first and implicit-H1 sentences (`unit_judge.py:78-91`). Impact: split-brain contract—whole-document triage is told the rule, mandatory outline adjudication and routing are not deterministically aligned; model trust in `metadata_outline_check.pass` is unwarranted when preprocessing already false-matched secno labels. Answer-class: 1.

- [LOW] Schema validators enforce internal consistency, not contract coverage. Evidence: `MetadataOutlineCheck.pass_requires_no_mismatch` (`models.py:283-295`) rejects pass paired with explicit mismatch fields but accepts pass with empty `heading_drift` when source and candidate outlines were equated pre-normalization; `UnitCheck.verdict_matches_defects` (baseline `models.py:315-320`) allows pass-with-empty-defects. Impact: sidecar records a clean metadata gate that contradicts human golden review; anti-calibrated confidence (PR #295 source-aware conf `1.0`, baseline) compounds operator distrust. Answer-class: 4.

## False-pass hypothesis

P3953R0 HTML: `extract_heading_outline` includes `span.secno` text in both source and candidate heading lists (`html_outline.py:79-81`); `run_metadata_outline_check` compares those raw outlines (`unit_judge.py:134-159`); source `h2: 1. Abstract` matches candidate `h2: 1. Abstract`, so `heading_drift` stays empty and the validator permits `verdict=pass` (`models.py:283-295`) even though the golden contract requires `## Abstract` without the structural label.

## False-fail hypothesis

P3953R0 HTML: source bikeshed `<h1>` with `<br>` concatenates to `P3953R0Rename std::runtime_format` (`html_outline.py:66-77`); `route_html_units` requires a candidate ATX section at the same level (`source_router.py:260-274`); title correctly moved to YAML leaves no body `h1`, emitting `heading_drift` detail `candidate missing` for `section:0` (baseline); `section:1` subtitle/chrome section similarly flags missing (`baseline` three routing false positives).

## What would change my mind

A replay at baseline PR #295 hashes where deterministic preprocessing strips `span.secno` and maps source `h1` to YAML `title:` before both `run_metadata_outline_check` and `route_html_units`, with sidecar proof of non-empty `heading_drift` (or `fail`) on the four secno H2s and zero `heading_drift` signals on YAML-mapped title/subtitle sections.
