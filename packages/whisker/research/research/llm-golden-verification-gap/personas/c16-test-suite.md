# c16 - Test suite auditor

**Verdict:** usable-with-conditions (The 36-file / 885-test suite is a strong precision and plumbing harness for the source-aware lane, but it contains zero CI-hermetic assertions that a human-verified golden-PR defect is detected end-to-end, so green CI cannot falsify the PR #286 / PR #295 recall failures documented in `00-baseline.md`.)
**Confidence:** high

## Findings

- [CRITICAL] Zero end-to-end "known defect detected" assertions exist across all 36 test files. Evidence: audited `packages/whisker/tests/` (885 `def test_*` functions, ~1,852 `assert` statements); the closest hermetic cases are (a) `test_dev_replay_acceptance.py:99-114` router token-delta on `p0533r9` (deterministic `route_pdf_units`, not LLM), (b) `test_source_aware_integration.py:377-421` `test_defect_groups_demote_pass` where `_StubAgent` is programmed to return a `UnitCheck` with a pre-authored `DefectFinding`, and (c) `test_pdf_judge.py:638-659` `TestGoldenQuoteReplay` which calls `classify_candidate_evidence` on inline quote/candidate strings (grounding disposition only, no lane run). Impact: the suite can pass while accepted defect groups stay 0/1 on PR #286 and structure recall stays 0/4 on PR #295 (`00-baseline.md` runtime facts). Answer-class: 5.

- [CRITICAL] LLM responses are universally stubbed or patched in CI; default stubs encode optimistic pass-with-no-defects. Evidence: `_StubAgent.run` in `test_pdf_judge.py:684-705` and `test_source_aware_integration.py:80-97` returns `MetadataOutlineCheck(verdict="pass", heading_drift=[])` and `UnitCheck(verdict="pass", defects=[])` for every unit call; `_PagedStubAgent` in `test_pdf_judge.py:1246-1262` identical; `test_source_aware_integration.py:359-365` injects a `low_recall` signal then stub returns empty defects (mirrors PR #286 page-13 false-clear pattern in `00-baseline.md` §PR286); `test_unit_judge.py:127-142` `_UnitAgent` returns test-authored `UnitCheck` objects (tests verify refutation of injected claims, never that the model discovers a defect). Impact: mocks assume recall is solved upstream; the two incidents prove it is not. Answer-class: 4.

- [HIGH] Dev-replay acceptance explicitly excludes LLM verdict recall and does not exercise PR #286 / PR #295 blocker fixtures. Evidence: module docstring `test_dev_replay_acceptance.py:8-19` states "hermetic, no LLM" and "LLM verdict accuracy is measured separately in runtime replays"; only one corpus-backed router test (`test_router_observes_full_151_token_delta`, `p0533r9`); `corpus/dev-replay/labels.json:183-190` lists `p3953r0` as `human_verdict: merge`, `defect_groups: []`, `expected_llm_verdict: pass` while `00-baseline.md` documents the secno-heading blocker on PR #295; `p1068r11` labels (`labels.json:82-105`) omit the six poll-table `SF`→`S` wrapped-cell defects. Impact: the labeled replay corpus cannot gate the two most recent golden misses. Answer-class: 1.

- [HIGH] No test fixture encodes wrapped PDF poll-table cells or bikeshed `span.secno` heading chrome. Evidence: `rg -i 'secno|wrapped.?cell|poll.?table'` over `packages/whisker/tests/` hits only unrelated "wrapped" strings (`test_tapetum_llm.py:1328` prompt docstring, `test_pdf_judge.py:58` PyMuPDF box helper); `test_html_outline.py:17-49` uses bare `<h2>Abstract</h2>` only; `test_source_router.py:168-178` `test_route_html_heading_drift` compares `### Design` vs `<h2>Design</h2>` (ATX level drift), not secno label stripping; table coverage in `test_facts.py:546-561` and `test_comprehension_corpus.py:83` exercises deterministic comprehension facts on generic HTML `<table>`, not vertically wrapped PDF header cells. Impact: the two baseline blockers have no regression anchor in the test suite. Answer-class: 1.

- [MED] Assertion budget is overwhelmingly mechanics, precision, and fusion plumbing, not adversarial recall. Evidence: LLM-lane files (~14 of 36) contribute ~1,295 of ~1,852 asserts (static count 2026-07-22); breakdown: `test_tapetum_llm.py` 273 asserts / 67 mock hits (cascade, chunking, CLI), `test_fusion.py` 188 (synthetic sidecar dicts including `FUSION_RULE_SOURCE_AWARE_REVIEW_CAP` at `test_fusion.py:460`, `482`, `608`), `test_pdf_judge.py` 191 (textlayer/recall screen/grounding, stubbed judge), `test_unit_judge.py` 97 (17 `_UnitAgent` tests, mostly refuting false positives). Defect-related asserts that assume the model already claimed the defect: ~35 (`defect_groups`, `verified_count`, `has_verified_defects`) vs ~0 that assert discovery from real golden-PR bytes. Impact: precision controls are well tested; recall is not a tested property. Answer-class: 4.

- [MED] The only behavioral LLM eval is opt-in, synthetic, and not in CI. Evidence: `test_tapetum_llm_eval.py:33-36` skipped unless `WHISKER_LLM_EVAL=1`; fixtures are fabricated `P9901R0`–`P9908R0` broken markdown (`test_tapetum_llm_eval.py:70-262`), not PR #286/#295 candidate/source pairs; asserts `suggested_verdict != "pass"` and expected axis flagged, not named golden-contract defects. Impact: even manual eval does not cover the incident defect classes. Answer-class: 5.

- [LOW] Grounding is tested without a dedicated `test_grounding.py`; coverage is split and downstream-only. Evidence: `grounding.classify_candidate_evidence` in `test_dev_replay_schema.py:58-74`, `test_pdf_judge.py:638-659`, holdout anchor dispositions (`test_dev_replay_schema.py:192-200`); no test asserts grounding creates a claim the model omitted (`00-baseline.md` §Evidence verification: "zero RECALL power"). Impact: consistent with answer-class 4 but reinforces that tests validate subtraction, not discovery. Answer-class: 4.

- [LOW] Deterministic lane tests (22 files, ~557 asserts) do not compensate for LLM recall gaps on the two incidents. Evidence: `test_score_pinning.py:46` includes `p1068r11` golden markdown self-score only; `test_gates.py`, `test_metrics.py`, `test_facts.py` gate structure/facts on committed snapshots; PR #286 deterministic verdict `pass`, QA 100 and PR #295 det `pass` per `00-baseline.md`. Impact: a fully green whisker CI is compatible with 0/1 LLM true-positive groups. Answer-class: 5.

## False-pass hypothesis

Run `whisker-tapetum-llm` on PR #295 head candidate `f4988f05cf5a...` against source `2aa5d2dda5b7...`: metadata/outline returns `pass` with empty `heading_drift`, zero generated defect claims, fusion caps at `review` via `source_aware_review_cap` only (`00-baseline.md` PR #295 facts). The full CI hermetic suite passes because no test replays those bytes or asserts the four `span.secno` headings are named in `defect_groups`.

## False-fail hypothesis

`test_unit_judge.py:174-204` `test_refuted_defect_does_not_demote_pass`: when `_UnitAgent` returns a `qualifier_omission` claim but the quote is present in the candidate, `run_unit_checks` returns `verdict=="pass"` and `defect_groups==[]`. A future fix that over-tightens evidence refutation could demote legitimate constexpr-delta findings from real `p0533r9`-class papers; the suite would flag that regression, but only for mock-injected claims, not for live model silence.
