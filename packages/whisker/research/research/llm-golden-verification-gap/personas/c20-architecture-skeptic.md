# c20 - Architecture skeptic: routed-unit-checking shape

**Verdict:** usable-with-conditions (Routed-unit open discovery is the wrong primary recall architecture for golden-PR verification; both 2026-07-22 blockers are deterministically decidable, readback/transcription alternatives failed their own corrupt controls, and the honest shape is deterministic structural diff plus mutation tripwires with the LLM relegated to triage of pre-computed deltas.)
**Confidence:** high

## Findings

- [CRITICAL] **Current shape (signals → top-5 route → LLM discovery → verify → fuse)** assigns recall to an LLM that must invent defect claims from sparse packets, then applies subtract-only verification that cannot recover zero-generation misses. Evidence: `unit_judge.py:93-117` instructs open-ended "Report specific defects"; `grounding.py:8-12` drops ungrounded quotes but never generates claims; baseline PR #286 **0/1** accepted groups with pages 8/9 routed but unchecked under `MAX_UNIT_CHECKS=5` (`00-baseline.md:46-55`, `unit_judge.py:225-240`); PR #295 **0** generated claims with metadata/outline `pass` (`00-baseline.md:62-74`). Impact: architecture makes recall a product P(route)×P(claim)×P(verify|claim); when P(claim)=0, the lane is structurally blind regardless of model quality. Answer-class: **4**, **5**.

- [CRITICAL] **Shape (d) mutation tripwire (no LLM: cell/heading/list invariants)** would catch both incident blockers with full determinism and minimal cost. Evidence: PR #286 wrapped `SF`→`S` is provable by PyMuPDF column geometry (`00-baseline.md:41-44`); PR #295 secno labels are a DOM-strip rule before compare (`html_outline.py:66-81`, baseline `00-baseline.md:59-64`); Lane 3 already implements the pattern in `facts.py:374-393` (`table` neighbor checks with optional `table_heading`) and CI canaries prove teeth (`test_comprehension_corpus.py` per `code-c04-fail-not-partial.md:419`); `PageUnit.has_tables` exists but `route_pdf_units` never reads it (`textlayer.py:86-98`, `source_router.py:191-231`, `00-baseline.md:54-55`). Impact: the P0 table-cell compare and heading-normalization fixes are not "patches to the LLM lane" but the correct primary recall layer; 0 LLM calls, flip-rate immune. Answer-class: **1**, **5**. Incidents: **PR #286** (six poll headers), **PR #295** (four H2 secno labels).

- [HIGH] **Shape (a) exhaustive deterministic diff → LLM triage of diff hunks** inverts the discovery burden correctly and matches ecosystem practice (0/31 repos gate on LLM; baseline class 5). Evidence: current router emits only four PDF / three HTML coarse signals (`source_router.py:149-314`, `c01-router-recall.md:8-12`); no exhaustive source-vs-candidate structural diff exists in tapetum_llm; `tapetum_llm.md:175` explicitly assigns row/cell swap detection to the judge ("you are the catch") while admitting the deterministic token gate is blind — an architectural admission that diff should be deterministic, LLM optional. Recall mechanism: deterministic diff emits every hunk (table grid, normalized headings, token deltas); LLM classifies severity/defect-type only on bounded hunks. Cost: O(pages+sections) Python, plus LLM only on non-empty diff set (typically ≪ whole-document monolith). Determinism: diff fully deterministic; triage retains ≥25% flip rate (`00-baseline.md:78-79`) but cannot miss a hunk the diff surfaced. Incidents: **PR #286** if diff includes PDF text-layer cell grid vs pipe-table headers; **PR #295** if diff applies secno strip to source outline before heading compare. Answer-class: **5**.

- [HIGH] **Shape (b) readback / transcription comparison** is the wrong primary channel for golden verification: it failed adversarial controls and reproduces the same table misread on clean markdown. Evidence: `readback.py:371-387` corrupts by reversing pipe cells and flipping operators; Auditv1 corrupt fixtures — P4182R0 **8/8 passed** in CORRUPT mode (`p4182r0.readback-corrupt.md:5`), P4234R0 **6/6 passed** (`p4234r0.readback-corrupt.md:5`), N5040 **4/6** (`n5040.readback-corrupt.md:5`); P0876R23 NORMAL **7/8** with table-poll-stlouis FAIL on heading `SF` read as `F` (`p0876r23.readback.md:63-72`) — the same failure class as PR #286 baseline; dormant VLM path `vlm_pipeline.py:46-50` (rasterize→transcribe→diff) uses whole-document `text_nid`/`content_recall` (`vlm_diff.py:50-59`), not cell-level grid compare, and is unwired (`vlm_pipeline.py:14-15`, `code-c24-vlm-boundary.md:52`). Cost: one LLM call per fact (readback) or per page (transcribe) — far above five unit checks, with no CI path. Determinism: non-deterministic; corrupt control proves insensitivity. Incidents: **PR #286** MISS (model misreads wrapped headers on clean md too); **PR #295** MISS (no secno-specific transcription question). Answer-class: **3**, **5**.

- [HIGH] **Shape (c) checklist-per-unit (K fixed yes/no questions per packet)** improves on open discovery but duplicates Lane 3 without fixing contract encoding unless questions are deterministic. Evidence: readback already generates type-specific questions from verified facts (`readback.py:337-338`, `whisker/CLAUDE.md:702-708`); a tapetum checklist would need golden-contract questions ("Are poll column headers exactly SF/F/N/A/SA?", "Do H2 headings omit bikeshed secno numerals?") — i.e., re-encode rules from human skill docs (`00-baseline.md:93-95`, class 1). Recall mechanism: bounded K answers per checked unit; misses if K omits a class or unit is budget-starved (same `MAX_UNIT_CHECKS=5` ceiling, `constants.py:223`). Cost: K×selected_units LLM calls; K must be authored per stratum. Determinism: better calibration than open discovery, still ≥25% flip on free-text answers. Incidents: **PR #286** CATCH only if K includes table-header parity derived from source geometry; **PR #295** CATCH only if K includes secno-strip rule — at which point the checklist is a slower duplicate of shape (d). Answer-class: **1**, **3**.

- [MED] **Keeping the current routed-unit shape with P0 fixes alone** leaves recall hostage to router taxonomy and five-unit budget forever. Evidence: even after table-cell signals and heading normalization land, `unit_judge.py:239-240` still caps at five units; PR #286 routed nine units with pages 8/9 displaced (`00-baseline.md:46-49`); noisy `heading_drift` signals consume budget (`PR286-LLM-FALSE-CLEAR.md:433`); fusion `review` from `source_aware_review_cap` is coverage-only, not detection (`00-baseline.md:52-55,74-75`). Impact: fixes are necessary but insufficient architecture — discovery-first routing cannot reach "looked everywhere" without unbounded LLM cost. Answer-class: **2**, **5**.

- [MED] **Shape comparison summary (recall / cost / determinism / incidents):**

  | Shape | Recall mechanism | Cost | Determinism | PR #286 | PR #295 |
  |---|---|---|---|---|---|
  | Current routed-unit | LLM discovers from ≤5 flagged packets | ~5 unit calls + monolith | LLM flip ≥25% | MISS | MISS |
  | (a) Diff-first + LLM triage | Deterministic diff finds all deltas; LLM classifies hunks | Diff cheap; LLM ∝ #hunks | Diff deterministic | CATCH (with cell-grid diff) | CATCH (with secno-normalized diff) |
  | (b) Readback / transcribe | LLM Q&A or page transcription vs candidate | High (per fact/page) | Non-deterministic; corrupt controls fail | MISS | MISS |
  | (c) Checklist-per-unit | K fixed questions per packet | K×units (≤5) | Partial | CATCH if K encodes table rule | CATCH if K encodes secno rule |
  | (d) Mutation tripwire | No LLM; grid/heading/list invariants | Lowest | Fully deterministic | CATCH (P0 table-cell compare) | CATCH (P0 secno strip) |

  Impact: shapes (d) and (a) are complementary, not competing — (d) gates, (a) triages residue. Answer-class: **5**.

- [LOW] **The monolith + unit-check complement story** (`tapetum_llm.md:117`) is sound for advisory whole-document drift but misapplied as golden-PR completeness verification. Evidence: monolith catches global reorder (`tapetum_llm.md:117`); unit checks catch localized omissions when routed (`unit_judge.py:93-100`); neither performs exhaustive contract enforcement, and PR #295 shows metadata/outline monolith false-clears when preprocessing erases the contract delta (`00-baseline.md:62-64`). Impact: keep monolith for fuzzy global axes; do not expect it to substitute for deterministic golden-contract encodings. Answer-class: **5**.

## False-pass hypothesis

Operator treats fusion `review` (conf 0.98, PR #286) or metadata/outline `pass` (PR #295) as evidence the LLM lane exercised golden-contract rules: routed-unit architecture checked the wrong five units, generated zero verified defect groups, and coverage cap only demoted pass→review (`00-baseline.md:50-55,74-75`) — indistinguishable from "verified clean" without sidecar `unchecked_unit_ids` inspection.

## False-fail hypothesis

After reshaping to diff-first + deterministic tripwires: a faithful conversion whose source PDF text layer legitimately splits a poll header across lines (`SF` at x=77.25 + `F` at x=100.5 per baseline geometry) but whose candidate pipe table correctly renders `|SF|` triggers a naive cell-string diff false alarm — unless compare uses the same geometry-aware merge rule as the golden contract, not raw text-layer token concatenation.

## What would change my mind

A replay at baseline PR hashes where the **current** routed-unit architecture (no new deterministic tripwires) achieves ≥1 accepted defect group on both blockers in a single run with `checked_unit_ids` covering pages 8/9 and secno-bearing sections — sidecar proof, not prompt tweaks alone. No such run exists in the record.
