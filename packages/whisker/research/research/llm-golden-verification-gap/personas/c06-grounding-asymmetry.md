# c06 - Grounding asymmetry attacker

**Verdict:** usable-with-conditions (Evidence verification is provably subtractive-only and compounds recall loss at every gate, but the dominant recall failure on PR #286/#295 is still zero claim generation upstream; verification asymmetry explains why even a lucky true claim would rarely survive, not why the lane names zero real defects.)
**Confidence:** high

## Findings

- [CRITICAL] No code path creates a defect claim: the lane can only filter model output. Evidence: `UnitCheck.defects` is LLM `output_type` only (`models.py:307-310`); `verify_unit_evidence` enriches existing defects (`unit_judge.py:493-565`) and never inserts rows; `verified_defects` is built only from dispositions already on model defects (`unit_judge.py:279-289`); `_aggregate_defects` groups that list only (`unit_judge.py:365-413`); `fusion._accepted_unit_defects` / `_accepted_flat_dispositions` read sidecar dispositions (`fusion.py:227-245`) and `_source_aware_requires_review` escalates on accepted groups (`fusion.py:198-214`) but never mints them. Impact: baseline PR #295 `generated defect claims: 0` and PR #286 `accepted defect groups: 0` with `ambiguous=1` are recall failures at generation/routing first; verification cannot recover invisible defects. Answer-class: 4.

- [CRITICAL] Accepted defect groups require a conjunction stricter than "verified missing": `source_status == GROUND_EXACT` AND `candidate_status == candidate_not_found`. Evidence: admission filter at `unit_judge.py:285-288`; `_is_accepted_disposition` in `fusion.py:219-224`; `_aggregate_defects` only ingests pre-filtered `verified_defects` (`unit_judge.py:291`). Fuzzy source grounding downgrades to `GROUND_FUZZY` when `semantic_parity_holds` fails on the source slice (`unit_judge.py:535-539`, `grounding.py:310-321`). Impact: true defects with punctuation/operator drift (improvement-bugs normative `N>.` loss, table `SF`→`S`) face elevated abstention before acceptance. Answer-class: 4.

- [HIGH] Full claim lifecycle and kill gates (model → accepted group), all subtractive. Evidence chain: (1) LLM emits `DefectFinding` inside `UnitCheck` (`models.py:231-260`, `_check_one_unit` `unit_judge.py:568-606`); (2) schema gate `verdict_matches_defects` rejects pass-with-defects / fail-without (`models.py:315-320`, enforced by `run_judge_task` → `agent.run` with `output_type`); (3) `verify_unit_evidence`: drop if `len(quote) < 5` → `source_ungrounded` (`unit_judge.py:515-521`); (4) `ground_spans` on source unit — drop if no exact/substring/fuzzy≥`EVIDENCE_FUZZY_FLOOR` (0.90) and `len(norm_quote) >= EVIDENCE_MIN_FUZZY_CHARS` (20) (`grounding.py:248-335`, `constants.py:67-73`); (5) source exact demotion if post-alignment normalization or `semantic_parity_holds` fails (`grounding.py:309-321`, `unit_judge.py:535-539`); (6) `classify_candidate_evidence`: `present_in_candidate` refutes; `ambiguous` on fuzzy candidate grounding, casefolded substring overlap (`grounding.py:521-531`), sanctioned TOC/front-matter/table/math surfaces (`grounding.py:545-581`); only `candidate_not_found` survives (`grounding.py:51-52`, `419-585`); (7) `_aggregate_defects` + `verify_defect_counts` — keyword groups with `verified_delta == 0` and exact-location flag are stripped (`unit_judge.py:297-304`, `455-459`); (8) fusion accepts only `_is_accepted_disposition` groups (`fusion.py:219-214`). No step adds a claim. Impact: lane recall ≤ P(generate) × ∏P(pass gate). Answer-class: 4.

- [HIGH] Compounding recall estimate from named thresholds. Evidence: let p = P(model emits a true defect on the right unit); then P(accepted) ≈ p × q_schema × q_len × q_src × q_exact × q_absent × q_fusion, where q_schema ≈ 0.95+ (finite pydantic retries via `judge_task.py:68-74`), q_len = P(quote≥5 chars) ≈ 0.99 for non-trivial quotes, q_src = P(source grounds) — exact/substring always; fuzzy needs partial_ratio≥0.90 on whole document if len≥20 (`constants.py:67-73`), q_exact = P(`semantic_parity_holds` on source interval) — drops toward ~0.7-0.9 when operators/punctuation differ (tests `test_unit_judge.py:269-310`), q_absent = P(`candidate_not_found` not `ambiguous`/`present`) — abstention is the default for near-miss surfaces per `grounding.py:425-428`, q_fusion = 1 given accepted disposition. Example: p=0.3, q_exact=0.8, q_absent=0.6 → P(accepted)≈0.14; with baseline p≈0 on true table/secno defects, product is ≈0 regardless. Impact: verification is a precision funnel, not a recall amplifier. Answer-class: 4.

- [HIGH] PR #286 `ambiguous=1`: the sole generated claim was a false page-13 heading-number allegation; ambiguous abstention was the correct precision outcome. Evidence: baseline runtime — one page-13 heading claim, `ambiguous=1`, `accepted defect groups: 0`, metadata/outline `pass`; improvement-bugs current revalidation: model claimed stripped `X.`/`XI.`/`XII.` labels were missing, contradicting conversion contract (`unit_judge.py:67-76`, improvement-bugs §Observed results PR #286). Kill mechanism: `verify_unit_evidence` → `classify_candidate_evidence`; when source quote grounds but candidate match is fuzzy or casefolded-surface overlapping heading prose without exact refutation, status is `ambiguous` (`grounding.py:521-542`, mirrored in tests `test_unit_judge.py:237-267`, `test_pdf_judge.py:777-789`). A `candidate_not_found` outcome would have falsely accepted a sanctioned label-strip defect. Impact: the one claim that reached verification was noise; verification correctly withheld a false positive but contributed zero true-defect recall (0/1 TP groups, baseline). Answer-class: 4 (primary), 3 (model hallucinated the claim). Answer-class: 4.

- [MED] Verdict-vs-signal cross-check exists lane-locally and only demotes pass→review; it never creates defects or reads the deterministic whisker sidecar. Evidence: PDF judge computes its own `text_nid`/`content_recall` and demotes model pass when recall < `PDF_JUDGE_RECALL_FLOOR` (0.85) or nid < `PDF_JUDGE_NID_FLOOR` (0.80) (`pdf_judge.py:622-623`, `708-718`, `constants.py:164-165`); per-page `screen_pages` flags recall < `PAGE_RECALL_FLOOR` (0.90) (`pdf_judge.py:311-335`, `constants.py:177`); page cap `MAX_PAGE_ESCALATIONS=5` caps pass without LLM (`pdf_judge.py:726-738`); unit incomplete coverage forces review (`unit_judge.py:305-323`, `pdf_judge.py:881-886`); fusion `llm_escalate_major` requires LLM axis `fail`+`major`, not whisker hard flags (`fusion.py:499-512`). PR #286: recall 0.9940, nid 0.9587, screen 0/15 flagged (baseline) — no demotion despite six poll-table errors. Impact: no "model pass + severe deterministic whisker fail → synthesize defect" path; lane-local metrics missed token-preserving table corruption. Answer-class: 4.

- [MED] Zero generated claims short-circuits the entire verification stack with a misleadingly quiet sidecar. Evidence: when all unit checks return empty `defects`, `verify_unit_evidence` is a no-op loop (`unit_judge.py:507-512`), `verified_defects` stays empty (`unit_judge.py:279-289`), `defect_groups` stays empty, yet `evidence_summary` all zeros and fusion `source_aware_review_cap` still fires on incomplete coverage (`fusion.py:183-196`, baseline PR #286 unchecked pages 5,6,8,9; PR #295 zero claims). Impact: operators cannot distinguish "verified clean" from "never claimed"; baseline explicitly warns this (`00-baseline.md` PR #295, improvement-bugs §What the two-paper validation proves item 2). Answer-class: 4.

- [LOW] Post-aggregation count verification can subtract groups but never add them. Evidence: `verify_defect_counts` only enriches `qualifier_omission` keyword groups (`unit_judge.py:416-472`); filter removes groups with `count_status=="verified"` and `verified_delta==0` when exact-location verified (`unit_judge.py:297-304`). Mechanical counts require `_COUNTABLE_KEYWORDS` (`unit_judge.py:350-354`). Table-cell or heading defects have `count_status=unverified` and cannot be mechanically discovered here. Impact: extra precision gate on keyword omissions only. Answer-class: 4.

## False-pass hypothesis

P1068R11 current-head: deterministic `pass` (baseline); whole-document PDF judge `pass` with recall 0.9940 above `PDF_JUDGE_RECALL_FLOOR=0.85`; zero unit-generated claims on pages 8-9 (displaced by `MAX_UNIT_CHECKS=5`); if the model ever emitted a true `|SF|` table quote with fuzzy operator parity, `classify_candidate_evidence` would likely abstain `ambiguous` rather than emit `candidate_not_found`, and fusion would still not cap on refuted/ambiguous claims (`fusion.py:26-27`).

## False-fail hypothesis

P1068R11 page-13 unit run: model emits false `heading_drift` claiming stripped Roman labels are missing; `classify_candidate_evidence` returns `ambiguous=1` (`baseline`), defect group count stays 0 (`unit_judge.py:265-267`), so verification abstains rather than publishing a false `candidate_not_found` defect — a correct precision outcome that nonetheless reads as "LLM found something, verification killed it" instead of a true-defect miss.

## What would change my mind

A replay at baseline PR #286 hashes where a human-injected or model-generated true table-cell claim (`|SF|` source quote, absent from candidate) flows through `verify_unit_evidence` and lands in `defect_groups` with `evidence_disposition.source_status=exact` and `candidate_status=candidate_not_found`, proving the acceptance conjunction is reachable for the verified blocker class — not merely that ambiguous correctly kills false heading claims.
