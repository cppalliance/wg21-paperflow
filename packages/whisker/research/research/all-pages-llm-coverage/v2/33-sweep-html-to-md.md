**C1 CONFIRMED** for all four repos at pinned SHAs.

- **html-to-markdown-go:** Deterministic HTML→MD converter (Go). One charter-floor hit is a code comment about invoking an option func (`cli/html2markdown/cmd/cmd_convert.go:24`). No LLM/VLM client, no HTTP to model APIs, no verification loop.

MCP `get_prompt` renders static user messages instructing an *external* MCP client to call deterministic `convert_html` / `extract_metadata` tools (`catalog.rs:94-125`); it does not call any model and does not judge existing conversion output against source.
- **html2text:** Pure Python HTML→text/MD; 0 floor hits.
- **markdownify:** Pure Python HTML→MD; 0 floor hits.

No production path in any repo implements per-page/chunk/unit LLM verification of already-produced conversion output (tapetum_llm-style judging).
