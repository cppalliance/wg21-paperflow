# 22 - False-Pass-Hunter-AllPages

**Verdict:** usable-with-conditions — forcing one scoped LLM unit check per physical page fixes the coverage-audit gap (operator can see every `page:N` was invoked) but does not close the five false-pass classes below; an "all pages checked, 0 findings" sidecar still overstates trust unless deterministic adjuncts (order gap, drift, anti-rubber-stamp, heading-level map, image/VLM boundary) ride alongside and fusion never treats LLM-only pass as stronger than whisker.
**Confidence:** high

## Findings

- [CRITICAL] **Cross-page reordering still false-passes when every page's tokens appear somewhere in the markdown.** Evidence: scoped page escalation explicitly disclaims order (`pdf_judge.py:238-241`: "Content from this page counts as present if it appears ANYWHERE in the markdown, in any order; document-wide reordering is a separate check you are not performing here"); unit checks inject full candidate markdown per page (`unit_judge.py:93-98`) with no positional anchor. Deterministic nets exist but do not gate the PDF LLM lane: shingle `coverage` and shingle `drift` are reported only, never verdict flags (`score.py:155-157`); `reading_order_ned` is advisory (`match.py:279-285`); `COV_UNIGRAM_GAP_TRIGGER` fires fleet triage only (`adjudicate.py:138-141`), not `judge_pdf_extraction`; olmOCR-style `FACT_ORDER` checks exist (`facts.py:448-465`) and `anchors.py` ordered chains (`anchors.py:150-169`) but require per-paper specs, not wired into `--all-pages`. Impact: a 33/33 all-pages pass stack still ships P3844R4-class scramble (`unigram_coverage≈0.98`, `coverage≈0.52` per persona 19).

- [CRITICAL] **Rubber-stamping over n near-identical prompts: nothing rejects uniform `(pass, high confidence, no defects)` × N.** Evidence: monolith pass with empty `missing_content` skips grounding entirely (`pdf_judge.py:369-370`); HTML lane explicitly sanctions empty-evidence pass (`adjudicate.py:329-330`); unit verdict is `pass` when `defect_groups` empty and coverage complete (`unit_judge.py:390-394`); fusion removed self-reported confidence from the clear path but has no cross-page variance or minority-veto gate (`fusion.py:465-507`). Web: LLM validators TPR >96% but TNR typically <25% (`05-web.md` Q4, arXiv 2510.11822). Prior production sidecars: confidence min 0.90, 18/18 fails at ≥0.95 (`19-false-pass-hunter.md:20`). Impact: `--all-pages` multiplies cost without multiplying discrimination; operator sees "15/15 pages checked" and infers depth the judge did not apply.

- [HIGH] **Duplicated content is rewarded by presence-only per-page checks.** Evidence: document `content_recall` is multiset recall (extra candidate tokens do not penalize, `metrics.py` via persona 19); per-page unit question is faithful preservation of THIS unit, not "exactly once." Deterministic nets: `unigram_drift` is soft-only above `DRIFT_SOFT_EDGE=0.10` (`score.py:193-194`, `constants.py:40-41`); olmOCR-style repeated n-gram scan lives in auto-baseline facts (`facts.py:674-688`, `constants.py:195-197`) but is not invoked from `pdf_judge.py`; `no_toc_leak` catches TOC-style duplicate headings only (`gates.py:143-154`), not body prose duplication. Impact: converter loop inserting page 7 twice passes all page-7..page-7 checks and document-level unigram recall.

- [HIGH] **Heading-LEVEL errors when order stays correct (PR #282 class) survive all-pages LLM checks.** Evidence: pr-golden-review load-bearing step: deterministic + LLM both miss wrong heading levels when the staircase stays monotone (`pr-golden-review.md:17-18`, PR #282 `### References` vs source `<h2>`). Deterministic: `heading_monotone` hard-fails only level jumps (`gates.py:105-110`), not uniform off-by-one depth; PDF router `heading_drift` signals missing large-font lines as headings, not level mismatch (`source_router.py:236-255`); HTML router compares levels deterministically (`source_router.py:298-312`) but PDF lane does not. LLM: metadata/outline check is one LLM call comparing outlines (`unit_judge.py:78-91`), same agreeableness risk; unit defect type `heading_drift` exists (`unit_judge.py:103`) but only fires if the model reports it. Impact: golden PR with one wrong level passes whisker gates + all-pages LLM with 0 findings.

- [HIGH] **Defects invisible in the text layer (image-only figure text) are policy-sanctioned, not caught.** Evidence: conversion contract tells judges imaged figure text is never missing (`unit_judge.py:73`, `pdf_judge.py:171-172`); tomd skips raster content by design (baseline Q1 docling VLM is extraction coverage, not our verification path). Deterministic nets: whole-PDF `MIN_TEXTLAYER_CHARS=200` fails only near-empty text layers (`textlayer.py:56-58`, `148-154`); `PageUnit.has_images` is extracted (`textlayer.py:214-259`) but `route_pdf_units` never routes on it (`source_router.py:209-265`); `FACT_IMAGE_REF` / readback lane (`facts.py:478-486`, `readback.py`) is separate from tapetum PDF judge. Impact: figure caption in text layer passes; diagram labels visible only in bitmap pass silently; all-pages text checks give false completeness.

- [MED] **"All pages checked, 0 findings" creates unearned operator confidence even with planned fail-closed coverage.** Evidence: planned `--all-pages` forces every `page:N` as required unit + `coverage_complete` audit against `page_count` (`00-baseline.md:44`); fusion already caps non-fail merge at `review` when `unit_coverage.coverage_complete` is false (`fusion.py:191-195`). But when coverage is complete and every unit returns pass with empty defects, nothing cross-checks whisker `coverage` vs `unigram_coverage` gap, drift, or uniform confidence (`pdf_judge.py:884-889` only demotes on unit `review`, not on suspicious unanimity). Impact: sidecar reads like exhaustive verification; fusion `agree` path keeps deterministic pass even when LLM added no discriminating signal (`fusion.py:525-527`).

- [MED] **Within-page sub-unit loss (one table row) can still satisfice a page-level pass.** Evidence: capped quotes (`pdf_judge.py:212-225`, `MAX_MISSING_QUOTES`); unit checks aggregate defects but pass when model reports none (`unit_judge.py:390-394`). Deterministic: table-neighbor probes exist for authored facts (`facts.py:466-467`) and table_presence routes pages with tables (`source_router.py:257-263`), but all-pages mode checking every page does not add mechanical cell-neighbor verification unless the LLM emits `table_corruption` / `cell_content_wrong` (`unit_judge.py:104-105`). Impact: "page 13 checked" masks partial table loss that olmOCR `TableTest` would catch deterministically.

## False-pass hypothesis

**15-page golden PDF, sections 4–6 swapped in markdown:** Every page's text-layer tokens appear verbatim somewhere in the 25k-token markdown. `--all-pages` runs 15 serial `UNIT_CHECK` calls (plus monolith + metadata outline); each receives ~800-token page source + full markdown; all return `pass`, empty defect groups, confidence 0.97–0.99 (rubber-stamp pattern). Sidecar: `unit_coverage.coverage_complete=true`, `checked_unit_ids=["page:1",…,"page:15"]`, `defect_groups=[]`. Whisker deterministic sidecar still shows `unigram_coverage=0.98`, `coverage=0.52` (order scramble). Tapetum verdict `pass`; fusion `agree` if whisker also pass. olmOCR `TextOrderTest` or 2–3 `FACT_ORDER` facts would fail; whisker already computes the gap signal but does not demote the LLM lane.

## False-fail hypothesis

**Wording paper with sanctioned `<ins>`/`<del>` on 12/40 pages:** Per-page unit prompt lists wording markup as deliverable (`unit_judge.py:75`). Model flags `entity_artifact` or `punctuation_loss` on many pages at `review`. Worst-unit aggregation yields document `review` despite faithful conversion (inverse of rubber-stamp). Mitigation already partial: severity-aware fold in HTML lane (`chunking.py` per persona 19); PDF path should not treat non-major per-page `review` as document fail when defects are refuted by grounding.

## What would change my mind

A held-out replay of P3844R4 (reorder) + PR #282 ideal (heading level) + one image-only-figure golden through implemented `--all-pages` with ablation: (A) LLM-only all-pages, (B) + deterministic order-gap demotion (`unigram_coverage - coverage > COV_UNIGRAM_GAP_TRIGGER`), (C) + anti-uniform-pass gate, (D) + deterministic heading-level map (HTML-router logic on PDF font sizes). If B–D catch all three without false-failing a clean wording paper, downgrade CRITICAL findings to MED and verdict to usable.
