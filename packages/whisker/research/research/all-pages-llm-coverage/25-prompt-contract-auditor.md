# 25 - Prompt contract auditor

**Verdict:** usable-with-conditions — the planned `--all-pages` loop can reuse `_check_one_unit` and `UnitCheck` as the per-page call shape, but today's `UNIT_CHECK_SYSTEM_PROMPT` plus `signal_detail`-only user framing is a routed-risk contract, not a neutral full-audit contract; it omits six escalation-bound sanctions and has no anti-rubber-stamp mechanism beyond post-hoc grounding.
**Confidence:** high

## Findings

- [CRITICAL] **All-pages pages with no router signal have no prompt contract today.** `_check_one_unit` always receives `signal_detail` built from routed signals (`unit_judge.py:331`), and `UNIT_CHECK_SYSTEM_PROMPT` assumes item 3 is a "RISK SIGNAL: why this unit was flagged" (`unit_judge.py:98`). `run_unit_checks` returns `None` when `risk_signals` is empty (`unit_judge.py:287-288`), so a clean page never reaches the LLM. **Required neutral full-audit instruction** (user-message `Risk signal:` slot or equivalent system addendum) must state: (1) `No deterministic risk signal; mandatory full-coverage page audit (all-pages review mode).` (2) audit scope = content-bearing text on THIS page vs the full candidate markdown, with **global presence**: text counts as preserved if it appears anywhere in the markdown in any order (`pdf_judge.py:238-241`). (3) inherit the full `_CONVERSION_CONTRACT` block (`pdf_judge.py:153-189`), not the abbreviated `_UNIT_CONVERSION_CONTRACT` (`unit_judge.py:67-76`). (4) binding quote discipline: never report page furniture, TOC lines, or title-block fields already represented in YAML as defects; leaked TOC only in reasoning (`pdf_judge.py:251-253`). (5) verdict rule: `pass` only when `defects` is empty after applying sanctions; do not invent defects from sanctioned conversion behavior. (6) if nothing content-bearing is missing, return `pass` with explicit one-line reasoning naming what was checked (page N prose/tables/code), not a generic affirmation. Evidence: `unit_judge.py:93-120,331,660-681`; planned required units in `00-baseline.md:44`. Impact: without this replacement text, all-pages either skips clean pages or reuses a misleading "risk" frame that biases the model toward defect search without escalation-grade false-fail guards.

- [CRITICAL] **Unit prompt misses the page-escalation cross-page presence rule; cross-page reflow guarantees false `content_omission`.** Escalation: "Content from this page counts as present if it appears ANYWHERE in the markdown, in any order" (`pdf_judge.py:238-241`). Unit check: "faithfully preserves the source content for THIS UNIT ONLY" (`unit_judge.py:99-100`) with `source_quote must be verbatim from the SOURCE TEXT` (`unit_judge.py:118-119`). Post-hoc `classify_candidate_evidence` searches full `candidate_md` (`unit_judge.py:632-633`), but the model is primed for unit-local absence first. Impact: dangling page tails at join sites (tomd cross-page reflow) produce `content_omission` defects that can survive to `verified_defects` when the tail is exact in source and not located verbatim in md (`unit_judge.py:356-360`).

- [HIGH] **Six escalation sanctions absent from `_UNIT_CONVERSION_CONTRACT`; each guarantees false findings on clean papers when the model quotes the sanctioned surface.** (a) **YAML key explicitness** — escalation: named keys and "If those values appear in the YAML block, they are NOT missing" (`pdf_judge.py:156-160`); unit: generic "title-block metadata → YAML" (`unit_judge.py:70`). False finding: page-1 `content_omission` / `qualifier_omission` on `document:`, `reply-to:`, or title-block lines. (b) **Leaked-TOC inverse with signatures** — escalation: Contents heading, heading+page-number duplicate (`pdf_judge.py:161-168`); unit: only "TOC DELIBERATELY REMOVED" (`unit_judge.py:71`) plus defect type `toc_leak` without inverse examples (`unit_judge.py:109`). False finding: spurious `toc_leak` or spurious pass when body still contains TOC chrome. (c) **HTML comment sanction** — escalation: `<!-- tomd:... -->` / `<!-- tapetum:... -->` (`pdf_judge.py:174-175`); unit: absent. False finding: `entity_artifact` on sanctioned disclosure comments. (d) **Wording-color caveat** — escalation: markup is deliverable; cannot verify colors; suspicious placement caps at review, never fail on placement alone (`pdf_judge.py:176-185`); unit: one-line "wording markup is the deliverable" (`unit_judge.py:75`). False finding: `content_omission` / `code_loss` on `<ins>/<del>` blocks the model treats as corruption. (e) **Quote prohibitions for furniture/TOC/front matter** — escalation: "Never quote page furniture, the TOC, or title-block lines that map to the YAML front matter" (`pdf_judge.py:251-253`); unit: no equivalent in output discipline (`unit_judge.py:117-119`). False finding: model obeys weaker contract, quotes `"Document Number: P1068R11"`; grounding marks `CANDIDATE_AMBIGUOUS` (`grounding.py:545-547`), unit verdict forced to `review` via `evidence_uncertain` (`unit_judge.py:381-394`) even with zero verified defects. (f) **Figure-text scope** — both sanction imaged figure text (`unit_judge.py:73`, `pdf_judge.py:171-173`), but escalation binds "diagram, chart, or scanned block" and pairs with quote prohibitions; unit lacks "do not quote in-diagram axis labels as missing prose." False finding: `content_omission` on vector-figure interior text that is correctly imaged.

- [HIGH] **Prompt-injection posture is equivalent to the pipeline envelope, and structured output bounds the response shape.** Page text and candidate markdown pass through `inject_untrusted` with per-call random tag and `guard_instruction(tag)` appended to system prompt (`unit_judge.py:671-680`; `pipeline/tools.py:49-62`). No separate `wrap_source` symbol exists; `inject_untrusted` is the live primitive (same mechanism noted in prior audits). Output is constrained to `UnitCheck` via `run_judge_task` → `AgentBackend.run` with pydantic `output_type` (`unit_judge.py:683-687`; `judge_task.py:68-73`; `models.py:298-320`): `defects` max 5, `verdict`/`defects` consistency validator, `confidence` bounded [0,1], `DefectFinding.affected_count >= 1`. Impact: delimiter forgery is mitigated and free-text verdict parsing is avoided; injection can still steer verdict fields inside the envelope (soft instruction-following), matching agreeableness-bias prior art (`05-web.md:33`).

- [MED] **Anti-rubber-stamp: nothing prevents uniform pass across n near-identical prompts.** Each all-pages call repeats the same `UNIT_CHECK_SYSTEM_PROMPT`, the same full `candidate_md` (`unit_judge.py:679-680`), and the same `UnitCheck` schema; only `unit_id`, `source_text`, and `signal_detail` differ. No per-page challenge token, no deterministic pre-check gating the LLM on clean pages, no ensemble/minority veto (`05-web.md:33`), and unit-level `confidence` is recorded but not used to demote rubber-stamp passes (`unit_judge.py:694-695`; contrast monolith demotion at `pdf_judge.py:709-722`). Mechanical refutation applies only after the model emits defects (`verify_unit_evidence`, `unit_judge.py:585-657`); a uniform `pass` with empty `defects` on every page exits unchanged (`models.py:316-319`, `unit_judge.py:390-394`). Impact: localized real defects on one page can be missed while all other pages rubber-stamp, especially with full markdown in every call (attention dilution; cf. `05-web.md:32` scoped judging vs whole-document QA).

- [MED] **User-message field `Risk signal:` will carry incoherent text if all-pages reuses routed detail strings on zero-signal pages.** Today `"; ".join(signal.detail for signal in unit_signals)` (`unit_judge.py:331`) assumes at least one `RiskSignal`. Injecting synthetic required units without replacing this field leaves the prompt's item 3 ("why this unit was flagged") semantically false. Impact: models may ignore the risk frame or over-search for phantom flags; the neutral instruction in finding 1 must replace, not append to, routed `signal_detail`.

- [LOW] **Abbreviated conversion contract is duplicated, not shared, creating drift risk.** `_UNIT_CONVERSION_CONTRACT` (`unit_judge.py:67-76`) is an inline copy explicitly decoupled from `pdf_judge._CONVERSION_CONTRACT` (`unit_judge.py:65-66`, `pdf_judge.py:153-189`). All-pages plan must unify on one contract source or the page-escalation fixes will regress on the next edit to only one copy.

The model rubber-stamps `pass`/empty defects on page 13 while neighboring pages' prose in the shared candidate satisfies skimming; no pre-LLM per-page recall gate applies to required zero-signal pages, and uniform passes are not demoted (`unit_judge.py:390-394`, `models.py:316-319`).
