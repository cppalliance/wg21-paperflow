# 32 - steelman-all-pages

**Verdict:** usable-with-conditions — `--all-pages` review mode is justified for golden-PR validation (one paper, hourly pod, permanent fixture cost) but must stay opt-in, budget-scaled, and paired with human fidelity diff because it still cannot catch cross-page reorder, images, or LLM false-pass bias.
**Confidence:** high

## Findings

- [CRITICAL] A golden ideal is permanent ground truth: an error frozen into `ideals/<pid>.md` or `baselines.json` penalizes every future converter that reads the source correctly. Evidence: `.cursor/commands/pr-golden-review.md:7` ("An error frozen into a golden becomes a permanent false regression signal -- every future converter that reads the source correctly gets penalized for being right"); `pr-golden-review.md:39` (baseline scores measure tomd-vs-ideal and "a defect in the ideal contaminates the baseline"). Impact: the marginal cost of 10–40 serial unit calls on a review pod is trivial next to decades of false regression signal; fleet cost/noise objections from `research/per-page-judging/SYNTHESIS.md:31-33` do not survive the review-mode re-weigh in `00-baseline.md:36-37` (n=10–40, human triages flags, pod billed hourly).

- [CRITICAL] The deterministic per-page recall screen measures multiset token PRESENCE only, not structure, order, or emphasis on that page. Evidence: `packages/whisker/src/whisker/metrics.py:376-393` (`content_recall` = fraction of reference word occurrences found in candidate; "Extra or duplicated candidate words are NOT penalized"); `pdf_judge.py:311-331` (screen uses `content_recall(tomd_md, page)` per page). Concrete defect class: wrong heading *level* with correct text (PR #282: `### References` vs source `<h2>`) — `pr-golden-review.md:17` states both deterministic gates and the LLM lane miss this "when order stays correct and the staircase stays monotone"; recall stays high because every token is present. Impact: a page can show recall ≥0.90 while local structure is mangled; only a scoped LLM page check (or human Step 2 heading map) can surface it.

- [CRITICAL] Routed unit checks have a structural blind spot: signal types are a closed list and unrouted pages get zero LLM scrutiny. Evidence: `source_router.py:200-260` (only `token_delta`, `low_recall`, `missing_captions`, `heading_drift`, `table_presence`); `unit_judge.py:287-288` (`if not risk_signals: return None`); `00-baseline.md:22-23` ("a page with NO signal is never checked even in exhaustive mode"). Impact: semantic-preservation defects outside those five classes on a quiet page (token-preserving table cell swap, wrong numeric value, code garble with preserved lexemes — `21-steelman-monolith.md:10`) are invisible to the current cap; `--all-pages` forcing every `page:N` as a required unit (`00-baseline.md:44`) closes this gap by design.

- [HIGH] Today's implementation silently under-delivers the review workflow the operator expects. Evidence: `00-baseline.md:19` (P1068R11 live run: 5 of 15 pages individually checked); `cli.py:1120-1127` (PDF branch calls `judge_pdf_extraction` with no `exhaustive` pass-through); `pdf_judge.py:843-850` (`run_unit_checks` called without `exhaustive=`); `constants.py:223` (`MAX_UNIT_CHECKS = 5`). Impact: `--inspect` on a golden PR advertises source-aware unit checks but PDFs hit a fleet cap; the planned `--all-pages` flag with fail-closed `page_count` audit (`00-baseline.md:44`) restores honesty.

- [HIGH] Human golden review reads every page; partial LLM coverage undermines workflow parity. Evidence: `pr-golden-review.md:41-47` (Step 2 fidelity diff: heading map for every source heading, completeness of every section/list/code block/reference entry); `pr-golden-review.md:72` (LLM pass invalid when flagged units unchecked — but unrouted pages are never flagged); runtime 5/15 on P1068R11 (`00-baseline.md:19`). Impact: the operator manually diffs all pages then sees an LLM assistant certify 5/15; `--all-pages` aligns machine coverage with the command's stated completeness bar.

- [HIGH] External precedent supports exhaustive element-level judging when human correlation matters, scoped to hard units not whole-doc sampling. Evidence: `05-web.md` Q4 — pdf-parse-bench ([arXiv 2603.18652](https://arxiv.org/abs/2603.18652)): LLM judge applied exhaustively to every matched TABLE pair (451 tables, 100 PDFs) because rule metrics correlated poorly with humans (TEDS r=0.68 vs judge r=0.93 after 1,500+ human ratings); ParseBench ([run-llama/ParseBench](https://github.com/run-llama/ParseBench)) scores every page exhaustively with 169K+ rule tests. Impact: `--all-pages` unit checks mirror the pdf-parse-bench pattern (full coverage of semantic units, not fleet sampling) at golden-review scale where human agreement is the goal.

- [MED] Review-mode economics absorb serial wall-clock that fleet mode rejects. Evidence: `unit_judge.py:283-285` (exhaustive mode comment: "pod is billed hourly, not per token"); `cli.py:146-151` (timeout budget sized for `MAX_UNIT_CHECKS=5`, must be rescoped for all-pages — `00-baseline.md:24-25`); D11 serial discipline (`00-baseline.md:25`). Impact: 15–40 serial calls ≈ 2–15 min on an hourly pod is acceptable for a one-shot golden gate; it is not acceptable for 189-paper corpus runs — mode separation is correct.

## False-pass hypothesis

A 12-page prose-heavy golden where every page's tokens appear in the markdown but one page's emphasized list is flattened to inline text (bullets → comma-separated sentence). Per-page `content_recall` stays ≥0.90 (`metrics.py:376-393`), no router signal fires if captions/headings/tables are absent (`source_router.py:224-263`), and the monolith may pass with high confidence because global token multiset is intact (`21-steelman-monolith.md:14-15` — monolith wins global checks). Only an all-pages unit check comparing that page's layout/emphasis to the candidate would catch it.

## False-fail hypothesis

A 3-page admin paper where page 2 is a near-blank continuation page (<50 tokens, skipped by `PAGE_MIN_TOKENS`, `constants.py:183`) forced into all-pages checking may produce spurious "missing content" flags for furniture the conversion contract deliberately strips (header/footer sanction, `research/per-page-judging/SYNTHESIS.md:35-37`). Mitigation: inherit full conversion contract in page-scoped prompts (SYNTHESIS adopted design) and record sanctioned clears in sidecar rather than failing the golden.

## What would change my mind

A labeled holdout of ≥30 golden-PR reviews showing `--all-pages` LLM unit checks catch zero defects beyond monolith + metadata/outline + human Step 2 fidelity diff, while generating >10% document-level false-review rate after human triage — would flip the verdict to "not justified" despite permanence arguments, because the incremental signal would not repay operator time and would inherit LLM-as-judge TNR collapse (`05-web.md` Q4, [arXiv 2510.11822](https://arxiv.org/html/2510.11822v2): TNR typically <25%).

## Honest limits (--all-pages does NOT buy)

- **Cross-page order:** Per-page unit checks cannot verify section N on page 5 precedes section N+1 on page 6; the monolith must remain for global reorder detection (`21-steelman-monolith.md:14-15`, `research/per-page-judging/SYNTHESIS.md:40-41`).
- **Images:** Image content is out of scope for tomd and golden review today (`pr-golden-review.md:111`: "We skip images for now"); all-pages does not add figure raster validation.
- **TNR / agreeableness bias:** Exhaustive LLM judging inflates pass rates on incorrect outputs unless calibrated with minority-veto or human-labeled sets (`05-web.md` Q4, Agreeableness bias card); all-pages increases exposure to false passes, not just false fails — human Step 2 fidelity diff remains load-bearing (`pr-golden-review.md:17`).
