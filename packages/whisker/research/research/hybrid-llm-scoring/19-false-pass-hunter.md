# 19 - False-Pass-Hunter

**Verdict:** usable-with-conditions — a merged det+LLM gate is viable only under worst-of (or display-only) fusion with deterministic hard-fail veto and LLM-absent fallback to det; weighted or confidence-majority merge would ship 64+ review papers the lanes already flag as risky, including extreme order-scramble cases.
**Confidence:** high

## Findings

- [CRITICAL] **Confidence-weighted or LLM-majority merge upgrades 101 whisker `review` papers to `pass` at median confidence 0.98, including 64 with substantive det soft signals (gap >0.08, drift >0.15, or misaligned regions).** Evidence: reproduced cross-tab of 194 paired sidecars in `data/whisker/`; sample **P3844R4** — det `review`, `unigram_coverage=0.979`, `coverage=0.507` (47.1pp gap), `unigram_drift=0.331`, `qa_score=65`, 20 misaligned regions, 6 uncertain markers; tapetum `suggested_verdict=pass`, `confidence=0.95`, `primary_concern`: "No significant conversion defects found." Gap semantics: large `unigram_coverage - coverage` means words present but reading order scrambled (`constants.py:28-30`). Impact: any merge rule that lets high-confidence LLM `pass` override det `review` ships scrambled or QA-degraded conversions (goal 3).

- [CRITICAL] **Worst-of / det-veto survives table-garble and broken-requirements cases that det-only `review` would miss if LLM is ignored, but weighted merge false-passes them when LLM is trusted.** Evidence: **P2583R0** — det `review` (`unigram_coverage=0.950`, 4 misaligned regions); tapetum `fail`, `confidence=0.95`, `tables` axis `fail`/`major` ("production libraries comparison table … severely garbled"). **P4003R0** — det `review` (62 misaligned regions, 1 uncertain marker); tapetum `fail`, `confidence=0.95`, `tables` axis `fail`/`major` (io_runnable requirements column extracted as prose). Baseline example **P4003R0** (`00-baseline.md:50`). Impact: matrix/worst-of with `merged = max(det, llm)` catches these; det-only or LLM-absent merge false-passes; naive average false-passes when LLM is absent and det stays `review`.

- [HIGH] **LLM overrules legitimate hard gates only on heading-monotone RESCUE population (9/9 fail→review), not fail→pass — but a merge that maps `review`+high confidence to `pass` would false-pass relative to the CI gate.** Evidence: **N5035** — det `fail`, sole hard flag `gate:heading_monotone:heading level jumps H1 -> H3` (`gates.py:105-109`), `unigram_coverage=0.953`; tapetum `review`, `confidence=0.95`, structure axis `review`/`minor` ("cosmetic … RESCUE case"). **P3941R2** — det `fail`, `unigram_coverage=0.999`, sole hard flag `H2 -> H4`; tapetum `review`, `confidence=0.98`. `worst_axis_verdict` folds non-major structure fails to `review`, not `pass` (`chunking.py:106-123`). Impact: weighted merge treating `review`≈`pass` when `confidence≥0.95` would ship 9 papers `whisker --gate` currently blocks; worst-of keeps det `fail`; display-only keeps gate unchanged (C1).

- [HIGH] **Four unigram hard-fail papers have no tapetum sidecar; optimistic merge defaults false-pass.** Evidence: **P3978R0** `unigram_coverage=0.811` < `UNIGRAM_COVERAGE_FAIL_EDGE=0.85` (`constants.py:37`, `score.py:156-160`); **P4012R0** `0.839`; **P4167R0** `0.839`; **P4231R0** `0.843` — all det `fail`, hard flag `unigram coverage … < 0.85 (content missing)`, no `*.whisker.tapetum.json`. Baseline: 6 tapetum errors leave no LLM verdict (`00-baseline.md:51`). Impact: merge rules "LLM absent → pass" or "LLM absent → optimistic" ship genuinely missing content; surviving rule: `LLM absent → det verdict` (worst-of degenerates to det-only).

- [HIGH] **Chunked adjudication can dilute corruption: tier-2 escalation is disabled for chunked papers and aggregation can pass from a clean early chunk.** Evidence: **P4215R0** — det `review`, `ref_nid=0.100`; tapetum `pass`, `confidence=0.98`, `reasoning`: "[aggregated over 2 chunks] … chunk 1 of 2 … ends mid-section … No conversion defects." Tier-2 skip at `adjudicate.py:247-248`; `aggregate_adjudications` folds max-severity per axis with `min` confidence (`chunking.py:226-259`). **P3045R8** — chunked 2 parts, det `review` (6 misaligned regions), tapetum `pass` `0.95`. Partial-read demotion exists only inside the LLM lane (`adjudicate.py:287-291`), not in a hypothetical merge. Impact: weighted or LLM-majority merge on chunked papers inherits dilution; worst-of still needs `state.partial → merged review` when chunking marks partial.

- [MED] **Confidence is anti-calibrated for false-pass risk: 0.95–0.98 confidence on wrong `pass` upgrades.** Evidence: **P4178R0** — det `review`, `unigram_coverage=0.952`, `coverage=0.837` (11.5pp gap, order-scramble proxy per `23-false-negative-hunter.md:28`); tapetum `pass`, `confidence=0.98`. **P3568R2** — det `review`, `unigram_drift=0.371`, 135 misaligned regions; tapetum `pass`, `confidence=0.98`. Production note: 0/198 sidecars have confidence inside `[CONFIDENCE_AMBIGUOUS_LO, CONFIDENCE_AMBIGUOUS_HI]` (`constants.py:27-28`, `11-false-positive-hunter.md:10`). Impact: any fusion weighting `confidence` as trust multiplier maximizes false passes; surviving rule: never promote on confidence alone (`CONFIDENCE_DECISION_FLOOR` only demotes, `adjudicate.py:279-285`).

- [MED] **Stale tapetum sidecar merge is architecturally possible though absent in the 2026-07-06 batch (0 `whisker_verdict` mismatches).** Evidence: `_persist_result` writes `<pid>.whisker.tapetum.json` independently of whisker reruns (`cli.py:207-217`); `TapetumResult` records `whisker_verdict` at adjudication time (`adjudicate.py:307-310`). Reconverted det `fail` + unre-run tapetum still showing `suggested_verdict=pass` from an earlier det `pass` would false-pass under file-pair merge without version coupling. Impact: merged artifact needs `schema_version` + source sidecar hash or mtime guard; surviving rule: reject merge when `tapetum.whisker_verdict ≠ whisker.verdict` or tapetum missing/error.

- [LOW] **PRIMARY pass-tier gap papers (3/9) never adjudicated; det-only merge leaves known blind spot, but LLM-majority merge cannot fix what was never run.** Evidence: **P4019R0** det `pass`, gap `0.061`, no tapetum; **P4143R0** gap `0.057`; **P4212R0** gap `0.060` — all below `COV_UNIGRAM_GAP_TRIGGER=0.15` (`constants.py:82`), so not PRIMARY candidates (`adjudicate.py:101-113`). Impact: merge does not create false passes here today (det already `pass`), but documents that fusion cannot tighten pass-tier without rerunning selector thresholds.

## False-pass hypothesis

**P3844R4 under weighted merge:** det `review` with `coverage=0.507` vs `unigram_coverage=0.979`, `qa_score=65`, 20 regions, 6 uncertain markers; tapetum `pass` at `confidence=0.95`. A merge rule `merged = pass if llm.pass and llm.confidence ≥ 0.90` (or numeric average favoring LLM) emits `pass` and ships a conversion with ~49% shingle coverage and sub-threshold QA — broken reading order and degraded structure that det `review` and separate lanes still surface. **Surviving rule:** `merged = fail if det.fail`; `merged = review if det.review or llm.fail or llm.review`; `merged = pass` only if both `pass` (worst-of strict), or display-only with no gate action (C1).

## False-fail hypothesis

**P3941R2 under worst-of without RESCUE carve-out:** det `fail` (heading_monotone H2→H4, `unigram_coverage=0.999`), tapetum `review`/`minor`. Strict worst-of yields `fail` and blocks a shippable wording paper the tapetum lane correctly rescues. A merge matrix that maps heading-only det hard-fail + tapetum `review`/`minor` → merged `review` (not `fail`) avoids the false fail without opening the P3844R4 false-pass hole.

## What would change my mind

A labeled holdout (≥30 papers) where blind humans mark the 64 substantive `review→pass` tapetum upgrades (gap/drift/region-positive): if ≥80% are human-`pass`, then confidence-weighted promotion is calibrated and worst-of is overly conservative; if ≤30% human-`pass`, worst-of (or det-veto matrix) is mandatory for goal 3.

## Fusion-family conclusion

| Family | False-pass risk | Notes |
|--------|-----------------|-------|
| **Weighted / average** | Highest | 101 `review→pass` upgrades at 0.95–0.98 confidence; P3844R4, P3568R2, P4178R0 ship scrambled content. |
| **Matrix (det-veto)** | Low if rules are: det hard-fail → merged fail; det review → merged review minimum; llm fail → merged fail; both pass → pass; heading-only fail + llm review/minor → merged review. | Needs explicit RESCUE row; still safer than weighting. |
| **Worst-of (strict)** | Lowest actionable false-pass | `merged_pass ⇔ det.pass ∧ llm.pass`; det `fail`/`review` never promoted by LLM alone; LLM absent → det only. |
| **Display-only** | Zero gate false-pass | Satisfies C1: merged value is reported, `whisker --gate` stays det-only. Recommended until labeled holdout validates promotion rules. |

**Recommendation:** adopt **worst-of** (or **display-only** for CI) as the merged verdict; never let `confidence` or LLM-only `pass` override det `review`/`fail`; require tapetum `whisker_verdict` freshness before fusion; inherit chunk `partial → review` cap from `adjudicate.py:287-291`.
