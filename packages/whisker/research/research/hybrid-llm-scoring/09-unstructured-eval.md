# 09 - unstructured-eval

**Verdict:** usable-with-conditions — Unstructured’s eval framework is a strong deterministic per-doc + aggregate persistence pattern with strata kept separate, but it has zero LLM scoring and no hybrid fusion mechanics for tapetum.
**Confidence:** high

## Findings
- [CRITICAL] Quality CI gates **three independent eval strategies** (text-extraction, element-type, table-structure) as **separate committed TSV trees** with **no single merged overall score**; each strategy diff-gates alone via `diff -ru`. Evidence: `test_unstructured_ingest/evaluation-metrics.sh:15-24`, `test_unstructured_ingest/check-diff-evaluation-metrics.sh:56-73`. Impact: directly supports goals 2–3 lane visibility and C1 (tapetum stays advisory; merged composite must not replace deterministic verdict on record).
- [HIGH] Every calculator exports a **dual-artifact pair**: per-document TSV (`all-docs-*.tsv`) plus aggregate TSV (`aggregate-*.tsv`) written together on `calculate(export_dir=...)`. Evidence: `unstructured/metrics/evaluate.py:153-155`, `357-362`, `477-482`, `241-246`; `_write_to_file` at `unstructured/metrics/utils.py:101-122`. Impact: portable template for extending `<pid>.whisker.json` with nested `deterministic` + `tapetum` + optional `merged` blocks while keeping per-paper and corpus rollup sidecars (`report.json` pattern in 00-baseline:22).
- [HIGH] Text extraction uses **dual axes per document row**: `cct-accuracy` (weighted Levenshtein complement) and `cct-%missing` (multiset bag-of-words missing fraction); aggregate rolls each axis separately with mean/stdev/count. Evidence: `unstructured/metrics/evaluate.py:409-445`, `434-435`; `unstructured/metrics/text_extraction.py:57-117`, `160-203`; `AGG_HEADERS` at `evaluate.py:53-60`. Impact: maps cleanly to whisker `nid/teds/mhs` plus `unigram_coverage`/`percent_missing` in one sidecar row; a merged score should preserve both lanes, not collapse to one axis (goal 3).
- [HIGH] **No model-based quality scoring** in the eval path: repo-wide search finds no LLM/judge/OpenAI/Anthropic usage; all metrics are deterministic string/set/structure math. Evidence: `unstructured/metrics/text_extraction.py`, `element_type.py:43-93`, `table/table_eval.py:63-81` (difflib `SequenceMatcher.ratio`, not TEDS); zero LLM hits in `packages/whisker/research/repos/unstructured/`. Impact: goal 1 (keep LLM scoring) must continue via tapetum_llm; Unstructured offers no fusion recipe—only the reporting shell.
- [MED] **Optional strata separation** without merging: `get_mean_grouping(group_by="doctype"|"connector")` writes additional TSVs (`all-{doctype|connector}-agg-{cct|element-type}.tsv`) alongside corpus-wide aggregates; Nougat-style stratum means stay separate. Evidence: `unstructured/metrics/evaluate.py:510-596`, `379-381`, `472-474`. Impact: whisker `report.md` leaderboard can add connector/doctype sections without blending into one gate score.
- [MED] Table-structure eval is a **9-metric custom bundle** (detection recall/precision/F1, table-level SequenceMatcher, element col/row index and content acc, weighted aggregate)—**not TEDS**. Evidence: `unstructured/metrics/evaluate.py:207-238`, `282-327`; `unstructured/metrics/table/table_eval.py:40-81`, `98-120`. Impact: whisker should keep in-repo TEDS (00-baseline:15-16); do not adopt Unstructured table math as primary axis.
- [MED] **Partition strategy selection (hi_res vs fast) is deterministic routing, not scored**: `AUTO` picks `HI_RES` when tables/images needed, else `FAST` if text extractable, else `OCR_ONLY`; dependency fallbacks only. Evidence: `unstructured/partition/strategies.py:37-109`, `94-109`; `PartitionStrategy` at `unstructured/partition/utils/constants.py:17-21`; `unstructured/partition/auto.py:88-91`. Performance benchmark hard-codes hi_res for PDF/image and fast otherwise (`scripts/performance/benchmark_partition.py:38-52`) with rolling-median runtime gate (`scripts/performance/compare_benchmark.py:237-238`)—quality-neutral. Impact: no portable “route then score” hybrid; whisker tapetum cascade remains the LLM routing layer.
- [LOW] **Score persistence format is TSV-only** (tab-separated, sorted by connector/filename); CI compares entire directory trees byte-exact; refresh requires `OVERWRITE_FIXTURES=true` outside normal CI. Evidence: `unstructured/metrics/utils.py:101-122`, `116-117`; `check-diff-evaluation-metrics.sh:14`, `46-55`; pinned corpus `test_unstructured_ingest/metrics/metrics-json-manifest.txt:1-18`. Impact: whisker JSON sidecars are richer, but the **exact-diff + explicit refresh ritual** is adoptable for guard/baseline governance (goal 2 persistence contract).

## False-pass hypothesis
A merged det+LLM pass that averages high `cct-accuracy`/whisker `nid` with tapetum pass while **`cct-%missing`/`unigram_coverage` spikes** (paragraph dropped but remaining blocks align): Unstructured gates both axes per row (`evaluate.py:434-435`); a single merged float could false-pass if the missing-content axis is omitted from the composite.

## False-fail hypothesis
Adopting Unstructured’s **zero-tolerance `diff -ru` TSV gate** on whisker bench floats would false-fail benign 0.001 metric drift that today passes guard slack (00-baseline notes Nougat/Unstructured exact snapshots vs whisker `guard.py` slack). Separately, six tapetum JSON errors (00-baseline:51) would block any merge that requires a complete LLM lane sidecar.

## What would change my mind
Discovery of an LLM judge or deterministic+LLM score-fusion module under `unstructured/metrics/` or an ingest eval CLI that combines model verdicts with Levenshtein/%missing—none exists in the cloned repo after targeted search for `evaluate`, `metrics`, `accuracy`, `aggregate`, `strategy`, and LLM-related strings.
