# 12 - False-Negative-Hunter

**Verdict:** usable-with-conditions   The lane can surface table and wording defects when the model quotes them, but three structural blind spots (chunk-blind section order, evidence-free pass, dead tier-2) let token-preserving semantic corruption sail through as `pass`, and the 73/197 production pass rate has no labeled precision estimate.
**Confidence:** high

## Findings
- [CRITICAL] A `pass` verdict requires zero grounded evidence by contract and code. Evidence: `tapetum_llm.md:99` ("If the conversion is faithful, say `pass` with high confidence and empty evidence"); `adjudicate.py:237-238` (demotion to `review` runs only when `suggested_verdict != VERDICT_PASS and not grounded`). Impact: every one of the 73 production `pass` sidecars (`00-baseline.md:45`) is an unverified negative — the lane asserts fidelity without a single machine-checkable proof span. A confident hallucinated pass is indistinguishable from a genuine one in the sidecar schema.
- [CRITICAL] Cross-chunk H2 section reordering is invisible to the cascade. Evidence: `chunking.py:57-92` splits on H2 and packs greedily; `adjudicate.py:187-192` triages each chunk in isolation; `tapetum_llm.md:93-95` instructs the model not to flag missing sections or mid-sentence stops at chunk boundaries; `chunking.py:178-184` folds per-chunk axis findings by worst per axis, never comparing section order across chunks. Impact: swapping two adjacent H2 sections across a chunk boundary (the dominant defect class named at `tapetum_llm.md:55`) leaves each chunk locally coherent — both chunks return `structure: pass`, aggregation returns `pass`, and no code path ever sees the global permutation.
- [HIGH] The two-tier cascade provides no second look in production or for chunked papers. Evidence: `escalated=true` in 0 / 197 sidecars (`00-baseline.md:46`); `adjudicate.py:206-208` gates tier-2 on confidence inside `[CONFIDENCE_AMBIGUOUS_LO, CONFIDENCE_AMBIGUOUS_HI]` (`constants.py:22-23`, i.e. 0.35–0.65); `tapetum_llm.md:17-19` maps both `fast` and `deep` to the same `alliance-pod` service; `adjudicate.py:203-204` skips tier-2 entirely when `state.chunked`. Impact: a single triage call at confidence 0.95 (the observed CJK-glue artifact band, `00-baseline.md:48`) is the final word — no deeper read, no different model, and oversize papers (~6 in corpus per `constants.py:42-43`) never get tier-2 at all.
- [HIGH] Table row swaps can pass at high confidence with no escalation and no evidence. Evidence: `tapetum_llm.md:72-76` names "Row or cell swap" as the tables-axis defect the deterministic gate misses; `tapetum_llm.md:72` acknowledges LLMs read pipe tables as a 1D token stream; `adjudicate.py:99-100` forwards pass-tier papers with `lossy_table_count > 0` to the lane (exactly the population most likely to carry row swaps); production distribution 73 `pass` / 106 `review` / 18 `fail` (`00-baseline.md:45`) with zero escalations. Impact: a straw-poll table whose SF/F/N/A/SA columns are internally consistent but whose rows are permuted reads as a valid table in one pass; the model returns `tables: pass`, `confidence: 0.95`, `evidence_spans: []`, and the decide step accepts it.
- [MED] Single-pass reads up to 500k chars cannot reliably verify global section order even without chunking. Evidence: `constants.py:44` (`MAX_PAPER_MD_CHARS = 500_000`); `tapetum_llm.md:55` ("Permuted sections are the dominant defect the deterministic gate misses, so scrutinize order"); no step injects a section-index manifest or pairwise order constraints — the model must hold the entire heading sequence in working memory across ~125k tokens (`00-baseline.md` long-context notes). Impact: within-chunk permutations and subtle duplications in papers under the char budget are judged by one serial LLM scan with no deterministic order check (contrast whisker Lane 3 `facts.py` `order` assertions in `whisker/CLAUDE.md`).
- [MED] Evidence grounding normalizes away the very punctuation table/math axes protect. Evidence: `grounding.py:39-44` runs both haystack and quote through `normalized_text` (OmniDocBench `clean_string`, keeps alnum+CJK only per `00-baseline.md:76` RQ3); `tapetum_llm.md:51-54` lists `stable_names` brackets, `math` superscripts, and pipe-table delimiters as fidelity axes. Impact: grounding verifies quote *presence*, not quote *correctness* — a span quoting the right words in the wrong table cell still grounds; normalization erases `|`, `^`, `_` that would distinguish a corrupted cell from a faithful one, so grounding cannot rescue a table-swap false-pass even if the model accidentally quotes both rows.
- [LOW] The lane is advisory-only and never blocks shipment. Evidence: `tapetum_llm.md:3-4` ("Advisory only: never part of `whisker --gate`"); `00-baseline.md:18` (always exits 0). Impact: false-negative passes are silent — they do not change the whisker verdict on record, so the 73 production passes inflate perceived coverage without a downstream gate to catch errors the lane missed.

## False-pass hypothesis
**(a) Cross-chunk section swap.** A 600k-char WG21 paper is split into 2 chunks at an H2 boundary (`chunking.py:84-91`). Sections `## Motivation` and `## Design` are transposed in the markdown so Motivation appears after Design globally, but each section sits entirely within one chunk. Chunk 1 sees Design (reads coherently); chunk 2 sees Motivation (reads coherently). Both chunks return `structure: pass, severity: none, confidence: 0.92`; `aggregate_adjudications` (`chunking.py:186-187`) folds to overall `pass`; tier-2 is skipped (`adjudicate.py:203-204`); decide accepts with empty evidence (`adjudicate.py:237-238`).

**(b) Table row swap at confidence 0.95.** A pass-tier paper with `lossy_table_count=1` (`adjudicate.py:99`) contains a 5-row straw-poll pipe table where rows 3 and 4 are swapped — every cell value is present (whisker `unigram_coverage` stays high) but row labels no longer match poll outcomes. The triage model reads the table as a token stream, returns `tables: pass, severity: none, confidence: 0.95, evidence_spans: []`. Confidence 0.95 is outside `[0.35, 0.65]` so tier-2 never runs (`adjudicate.py:206-208`; corroborated by `escalated=0` / 197, `00-baseline.md:46`). Decide emits `suggested_verdict: pass`.

**(c) Fabricated pass with empty evidence.** A corrupted pass-tier candidate (e.g. two xrefs with swapped revision letters, `[P1234R5]` rendered as `[P1234R4]`) receives a triage response: `verdict: pass, confidence: 0.85, evidence_spans: [], axis_findings: [{axis: "xrefs", verdict: "pass", severity: "none"}]`. The model never inspected the xref list. Decide grounds zero spans, but the demotion guard at `adjudicate.py:237-238` fires only for non-pass verdicts, so `suggested_verdict` remains `pass`. The sidecar records confidence 0.85 and an empty `grounded_evidence` list — indistinguishable from a genuine clean conversion.

## False-fail hypothesis
A faithful conversion whose only whisker hard flag is `heading_monotone` (H2 followed by H4) reaches the lane via the RESCUE population (`adjudicate.py:90-92`, `tapetum_llm.md:66-68`). The model labels `structure: fail, severity: minor`; `worst_axis_verdict` (`chunking.py:45-48`) folds the non-major fail to `review`; decide preserves `review`. This is working-as-designed rescue, not a false-fail — the lane correctly avoids upgrading cosmetic structure noise to `fail`.

## What would change my mind
A labeled holdout of the 73 production `pass` sidecars — even 20 papers with human-verified `facts.jsonl`-style assertions (table cell neighbors, section order chains) — showing >= 90% precision (<= 2 false passes) would downgrade the CRITICAL findings to MED and flip the verdict to `usable`.
