# 17 - Steelman

**Verdict:** usable-with-conditions — the stack is architecturally serious (injection defense, fail-not-partial, determinism pins, post-hoc grounding, retry policy that matches published failure modes); conditions are operational gaps (per-step budget non-wiring, cascade never escalating in production), not a wrong foundation.
**Confidence:** high

## Findings
- [HIGH] The raw-JSON retry loop splits truncation from malformation instead of treating every parse failure alike. On `finish_reason == "length"` it grows `max_tokens` and re-issues the original request without appending the truncated assistant turn (`model_backends.py:388-404`); on genuine malformation it appends the bad output plus a corrective nudge (`model_backends.py:405-417`). That directly avoids the context-contamination failure mode documented for naive retry loops (arXiv 2605.08563v1 in `05-web.md` Q5) and is exercised by dedicated tests (`packages/pipeline/tests/test_truncation_retry.py:8-11`). Impact: self-hosted DeepSeek-class token injection (confirmed in 200-paper transcripts, `00-baseline.md:48`) is mitigated by a policy that knows *why* JSON broke, not just that it broke — stronger than parse-or-drop pipelines that discard the attempt with no diagnosis.
- [HIGH] Fail-not-partial fidelity is enforced end-to-end, and the lane is explicitly advisory-never-gates. A partial read cannot masquerade as a clean pass (`adjudicate.py:242-246`); ungrounded non-pass verdicts and sub-floor confidence demote to review, never upgrade (`adjudicate.py:234-240`). The CLI contract is exit 0 always, never touches `whisker --gate`, never overwrites whisker verdicts (`cli.py:11-14`). Impact: the stack buys a second opinion without polluting the deterministic CI gate — the right separation for a lane whose job is to steer human review, not auto-ship.
- [HIGH] Prompt-injection defense exists as a first-class framework contract, not an afterthought. Untrusted text is wrapped with per-run randomized guard tags, forged delimiters are escaped before wrapping, and the framework floor instructs the model to treat delimited content as data (`tools.py:38-62`, `runner.py:119-126`, `runner.py:205`). The scoped `read_paper` tool caps lines and re-wraps every chunk (`tools.py:65-100`). Impact: WG21 paper markdown is adversarial by nature; most extraction/adjudication stacks ingest it raw. Having *any* delimiter + escape + instruction stack is rare and aligns with CLAUDE.md's stated invariant (`00-baseline.md:15` cites `tools.py` as the defense layer).
- [HIGH] Serial execution is a deliberate determinism purchase, not accidental slowness. Framework sub-task fan-out defaults to `_TASK_CONCURRENCY = 1` (`tasks.py:30-38`); tapetum declares `concurrency: 1` in its authority doc (`tapetum_llm.md:23`); the 200-paper batch loop awaits one `adjudicate_paper` at a time (`cli.py:277-288`). MODELS.md documents why: concurrent requests invite MoE routing variance and cross-request batch interference at the inference layer (`MODELS.md:63-69`). vLLM's own Batch Invariance docs confirm that `temperature=0` and `seed` alone do not guarantee stable tokens under continuous batching; `VLLM_BATCH_INVARIANT=1` is required for batch-size/order invariance (`05-web.md` Q4, https://docs.vllm.ai/en/stable/features/batch_invariance/). Impact: on a single shared `alliance-pod`, serial buys semantic reproducibility cheaply; bounded paper-level concurrency (hook already sketched at `runner.py:133-162`, `00-baseline.md:70`) may cost determinism before it buys proportional throughput.
- [MED] The D-rule determinism regime is codified and mechanically enforced, not aspirational. Every vLLM raw-JSON call pins `temperature=0.0`, `top_p=1.0`, `seed=0` (`model_backends.py:321-323`); tool parallelization is disabled at the backend layer (`model_backends.py:462` per `00-baseline.md:56`); structured output is mandatory via pydantic `output_type` with a finite attempt budget (`_RAW_JSON_MAX_ATTEMPTS = 3`, `model_backends.py:76-85`). The `Adjudication` schema carries seven fields, above the >=5-field stability floor measured in MODELS.md (`models.py:13-16`, `00-baseline.md:65`). Test harness: 177 pipeline + 325 whisker test functions (`00-baseline.md:40`), task-reported 187 + 670 pytest passes. Impact: a redesign proposal must beat a working, tested contract — not a README wish list.
- [MED] Evidence grounding is an active post-hoc verifier, not decorative schema fluff. Every LLM-quoted span is checked against normalized markdown via exact substring or `rapidfuzz.partial_ratio >= 0.90` (`grounding.py:24-56`, `constants.py:50` via baseline RQ3); empty quotes drop (`grounding.py:45-47`). Production run: 9/197 sidecars dropped at least one ungrounded span (`00-baseline.md:47`). Impact: the lane refuses to let the model cite evidence it did not actually read — a credibility floor most LLM QA tools skip entirely.
- [MED] The authority-doc pattern makes prompts reviewable and keeps pipeline structure out of Python string literals. `prompt.py:8-22` declares the markdown file as the upstream authority for services, system prompt, config, and per-step metadata; `tapetum_llm.md` holds the cascade, slot map, and full system prompt (`tapetum_llm.md:1-29`). Impact: prompt changes are diffable in git and parse-checked at load time — operational hygiene that scales when models and axes evolve.
- [LOW] Batch UX treats 200-paper runs as a first-class operator surface. `_BarAwareHandler` blanks and redraws the progress bar so logs never collide with the bar (`cli.py:76-95`); `_RetryCountFilter` rolls known self-correcting retry warnings into a footer count instead of one line per paper (`cli.py:50-73`, `cli.py:55-58`). Impact: long serial runs remain diagnosable without drowning the operator — small but real evidence the lane was built for production batch review, not one-off demos.

## False-pass hypothesis
A token-preserving table-cell swap or math exponent collapse that leaves quoted evidence fuzzy-matchable at `EVIDENCE_FUZZY_FLOOR = 0.90` against normalized markdown could still ground and pass if the model quotes a generic substring (`00-baseline.md:76` RQ3 seed) — grounding catches fabrication, not semantic corruption the quote happens to resemble.

## False-fail hypothesis
A faithful conversion with cosmetic heading-level drift can land in review via severity-aware demotion or the 106/197 review plurality (`00-baseline.md:45`) — conservative by design (`adjudicate.py:234-240`), but humans may over-weight advisory review on papers whisker already passed.

## What would change my mind
An A/B on the shared pod showing paper-level `--concurrency N>1` (via `cli.py` fan-out, not global semaphore flips) produces identical verdict/confidence distributions on a fixed paper set while cutting wall-clock proportionally — that would flip serial from virtue to optional tradeoff; absent that evidence, serial remains the rational default under batch-invariance constraints (`05-web.md` Q4).
