## The single most load-bearing logic finding (with file:line)

**The pass channel has no verification gate at all, and it is the exact blind spot the lane exists to close.** Two confirmed facts compose into one hole: (1) grounding demotion fires only for non-pass verdicts, `adjudicate.py:237-238`, and the system prompt tells the model to emit `pass` with empty evidence, `tapetum_llm.md:99`; (2) the second-tier look is dead, `escalated=0/197` gated at `adjudicate.py:206-208`. So a `pass` is a single unaudited triage call: no grounded quote is required, no deep re-read ever happens, and `to_dict` (`models.py:106-124`) records an empty `grounded_evidence` list indistinguishable from a genuine clean conversion. The lane was built for the false-pass case (token-preserving corruption that survives `unigram_coverage`); that is precisely the path with zero gate. Load-bearing anchor: `adjudicate.py:237-238`.

## Net assessment (3-6 sentences)

The gate and folding LOGIC is individually sound and deterministic where it can be: severity-aware worst-axis fold, min-confidence chunk aggregation, sorted persistence, the truncation/malformation retry split, and the D11-safe ordered-concurrency primitive all verify cleanly at their cited lines. The failure is calibration and coverage, not code correctness: the confidence band `[0.35, 0.65]` never intersects the model's self-reported confidence (0/197 escalations), so the "two-tier cascade" is single-tier documentation debt, and the one gate that would catch the lane's raison d'etre (false passes) does not run on pass verdicts. Grounding is genuinely active (9/197 dropped a span) but verifies alphanumeric-skeleton presence against the whole document at a 0.90 fuzzy floor, which cannot falsify a confident pass and can clear generic boilerplate. Error handling silently preserves stale pass sidecars on a failed rerun and never discloses partial reads in the persisted schema. The freshness revert matters materially: every "attempt 3" finding (persona 20's central thesis, plus baseline anchors) is now refuted because the budget is 2 with no `_RAW_JSON_MAX_ATTEMPTS`. Verdict: usable-with-conditions as an advisory lane, but the cascade should be treated as inert and the pass channel as unverified until the band is refit and a pass-side evidence requirement (or a real second-model tier) is added.
