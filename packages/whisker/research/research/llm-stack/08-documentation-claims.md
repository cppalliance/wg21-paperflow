# 08 - Documentation-Claims

**Verdict:** usable-with-conditions (+ the lane runs and grounding/decide logic match most authority-doc semantics, but the authority doc, framework docstrings, whisker CLAUDE.md, and MODELS.md structured-output section materially misdescribe per-step budgets, thinking, cascade economics, and the VllmThinkingBackend call path)
**Confidence:** high

## Findings
- [CRITICAL] Per-step `**max-output:**` and `**thinking-budget:**` in the authority doc are parsed but never applied at runtime. Evidence: declared for Triage at `tapetum_llm.md:117-118` (2048 / 1024) and Adjudicate at `tapetum_llm.md:137-139` (4096 / 4096); parsed into `StepPrompt` at `prompt.py:389-390`; `AgentBackend.run` docstring promises runner forwarding at `agents.py:127-133`; `run_agent` omits both kwargs at `runner.py:266-272`; tapetum binds every slot to flat `max_tokens=4096` with no `thinking_budget` at `adjudicate.py:388-395`. Impact: thinking is never enabled (`model_backends.py:305-309` only sets `thinking_token_budget` when `thinking_budget is not None`); triage runs at 4096 not 2048; any operator tuning the authority doc gets zero effect and debug transcripts misrepresent the intended cascade.
- [HIGH] The framework docstring is an active false claim, not stale commentary. Evidence: `agents.py:127-133` states "Per-step overrides come from `StepMeta.max_output_tokens` via the runner" and the same for `thinking_budget`; `run_agent` never reads `spec.step.max_output_tokens` or `spec.step.thinking_budget` (`runner.py:266-272`). Impact: new pipeline authors copying dissect/agora patterns will assume authority-doc budgets wire through; tapetum is the counterexample proving they do not.
- [HIGH] The "two-tier cascade" is documented as distinct fast/deep models with cost savings, but both tiers resolve to the same service and production never escalated. Evidence: `tapetum_llm.md:3` ("cheap fast model" … "deep model"); escalation gate described at `tapetum_llm.md:133` and `tapetum_llm.md:147`; both slots map to `alliance-pod` at `tapetum_llm.md:17-18`; gate logic at `adjudicate.py:206-208`; runtime `escalated=true` in 0 / 197 sidecars (`00-baseline.md:46`). Impact: documentation promises a cheaper first pass plus a larger-model second opinion; observed behavior is single-pass deepseek-v4-pro on the same pod with confidence always outside `[0.35, 0.65]`, so the cascade narrative overstates delivered architecture and cost model.
- [HIGH] Tier 2 escalation for chunked oversized papers is silently disabled but not disclosed in the authority doc. Evidence: `tapetum_llm.md:147` ("Runs only when the Tier 1 confidence falls inside the ambiguous band"); `adjudicate.py:200-204` returns early when `state.chunked` with comment "Tier2 escalation for chunked papers is a later upgrade"; chunking sets `state.chunked = True` at `adjudicate.py:184`. Impact: the largest papers (the 413-risk population the chunking path exists to serve) can never reach Step 2 regardless of confidence; operators reading only `tapetum_llm.md` believe the full cascade applies.
- [HIGH] `MODELS.md` "Structured outputs" section contradicts the backend tapetum actually uses. Evidence: `MODELS.md:129` ("Every step that calls an LLM uses pydantic-ai with `output_type=<PydanticModel>`. The schema is injected automatically"); `VllmThinkingBackend.run` calls `AsyncOpenAI.chat.completions.create` directly, injects schema via `_schema_instruction` in the system prompt, and validates with `json.loads` + `output_type.model_validate` at `model_backends.py:294-375` (no pydantic-ai `Agent`). Impact: the governing doc misstates the structured-output strategy for the self-hosted path; retire-when rows for schema-in-prompt and raw-JSON retry (`MODELS.md:119-121`) apply to tapetum but the top-level structured-output claim does not.
- [MED] Decide-step grounding is documented as "verbatim, normalized whitespace" but implementation applies the OmniDocBench text normalizer (LaTeX fold, alnum+CJK strip). Evidence: `tapetum_llm.md:154` ("verbatim, normalized whitespace, fuzzy floor"); `ground_spans` calls `normalized_text` on both quote and full markdown at `grounding.py:39-51`; `normalized_text` is `clean_string(textblock2unicode(text))` at `metrics.py:338-340`. Impact: docs understate normalization aggressiveness; quotes containing `^`, `_`, or LaTeX can ground after folding even when not substring-present in raw markdown, weakening the "verbatim" contract operators expect.
- [MED] whisker `CLAUDE.md` overclaims tapetum LLM calls are "deterministic" while `MODELS.md` documents hosted vLLM batch non-invariance. Evidence: `packages/whisker/src/whisker/CLAUDE.md:405-406` ("every call is serial and deterministic"); `MODELS.md:77` ("Hosted inference is best-effort reproducible, not bit-exact" … batch size changes can flip tokens). Impact: downstream readers treat advisory sidecars as rerun-stable; serial client execution is true, cross-run identity is not guaranteed and is not documented at the lane level.

## False-pass hypothesis
Authority doc promises thinking-budget 1024/4096 and a deep second pass for ambiguous calls (`tapetum_llm.md:118-119`, `:137-139`, `:147`), but thinking is off and tier2 never ran in production (`adjudicate.py:388-395`, `00-baseline.md:46`). A borderline conversion that a reasoning-enabled deep tier would flag can receive a confident single-pass `pass`, especially when grounding accepts a fuzzy-normalized generic quote (`grounding.py:51`, `tapetum_llm.md:154`).

## False-fail hypothesis
Triage forced to 4096 max-output instead of the documented 2048 (`tapetum_llm.md:117` vs `adjudicate.py:391`) increases exposure to truncation/retry paths on long papers; a truncation retry with accumulated error context (`model_backends.py:388-417`) can produce harsher axis findings than the documented smaller triage budget would, inflating the 106/197 review rate without a true conversion defect.

## What would change my mind
A single PR that forwards `spec.step.max_output_tokens` and `spec.step.thinking_budget` from `run_agent` to `AgentBackend.run`, with debug transcripts showing Triage at 2048/thinking 1024 and Adjudicate at 4096/thinking 4096, plus authority-doc updates either splitting `fast`/`deep` to distinct services or rewriting the cascade section to match same-service economics and the chunked tier2 skip.
