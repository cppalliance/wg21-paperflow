# llm-stack - Research Synthesis

**Verdict band:** usable-with-conditions   **Confidence:** high
**Decision (self-target):** harden

The architecture is sound; the operating points are not. Every hard invariant the lane
depends on (advisory isolation, fail-not-partial, injection defense, sampling pins,
truncation-aware retry) is implemented and verified at file:line. What is wrong is
calibration, coverage, and disclosure, none of which is foundational, and every remedy
lands whisker-local, infrastructure, or is parked as out-of-scope-pipeline. That is the
definition of harden, not redesign, and no persona of 22 returned `garbage`.

## Summary
- **Advisory isolation caps the blast radius of every other defect.** The CLI never gates, never overwrites the whisker verdict, and always exits 0 (`cli.py:11-14`, `_EXIT_OK = 0` at `cli.py:37`). A miscalibrated or false-negative sidecar cannot pollute the deterministic CI gate. This is why the correct decision is harden, not redesign: the contract already contains the damage.
- **The pass channel has NO verification gate, and that is exactly the false-pass blind spot the lane exists to close.** Grounding demotion runs only for non-pass verdicts (`adjudicate.py:237-238`), the system prompt tells faithful conversions to emit `pass` with empty evidence (`tapetum_llm.md:99`), and the second-tier re-read is dead (escalated `0/198`). So a `pass` is a single unaudited triage call with no grounded span, schema-indistinguishable from a genuine clean conversion. All 74 production passes carry no machine-checkable proof (Meta-B load-bearing finding).
- **The "two-tier cascade" ran single-tier in production.** `escalated=true` in `0/198` sidecars; the ambiguous band `[0.35, 0.65]` (`constants.py:22-23`, gate `adjudicate.py:206-208`) never intersects DeepSeek's self-reported confidence (min 0.85, max 1.00, mean **0.9586**), and even a fired escalation is a no-op model swap because `fast`/`deep`/`default` all resolve to `alliance-pod` (`tapetum_llm.md:17-19`). Chunked papers skip tier-2 entirely (`adjudicate.py:200-204`). Calibration + documentation debt, not broken correctness (Meta-A/B/E).
- **Self-reported confidence is anti-calibrated and is the wrong escalation trigger.** Every suggested `fail` carries confidence >= 0.95 (18/18, mean **0.9539**) while per-axis verdicts disagree on **123/198** papers (Meta-A, reproduced exact). The fix is to escalate on a derived uncertainty signal (axis disagreement, ungrounded-drop count, retry occurrence), not to tune the scalar band.
- **Per-step `max-output`/`thinking-budget` are parsed but never forwarded**, so triage runs at the construction-time `max_tokens=4096` with thinking OFF instead of the documented 2048/1024. `run_agent` passes only `tools/label/debug_log/request_limit` (`runner.py:266-272`); the fields exist on `StepPrompt` and the `agents.py:127-133` docstring falsely promises runner forwarding. The framework fix is out-of-scope (pipeline read-only), but the observable symptom is remediable whisker-locally in `adjudicate.py:388-396` (Meta-C linchpin, Meta-E balancing correction).
- **The 9/200 raw-JSON CJK-injection hard-failure class is LIVE again.** The retry budget was reverted to `max_attempts = min(2, request_limit)` (`model_backends.py:300`; `_RAW_JSON_MAX_ATTEMPTS` deleted, third-attempt test gone), so every persona-20 "budget-3 justified" claim is mooted and the failure class returns on a fresh run. Root cause is a vLLM MLA FP8 decode bug (#41985); the accepted fix is an infrastructure pod upgrade (#42287 + #41199), not a pipeline edit (Meta-A/C/D/E).
- **Corpus numbers to trust:** 198 `*.tapetum.json` / 74 pass / 106 review / 18 fail; baseline's 197/73 is stale (Meta-A, reproduced to the digit). Asterisk: the 198 count reflects a superseded budget-3 run; under the reverted budget-2 code the expected yield is ~191 with the 9-failure class re-entered.

## Hardening plan (whisker-local, ranked by leverage)
1. **Fix the cascade at the trigger, not the band.** In `_custom_adjudicate` (`adjudicate.py:195-212`) gate escalation on a derived uncertainty signal (per-axis disagreement, `ungrounded_dropped > 0`, malformation-retry occurrence) instead of the anti-calibrated scalar `confidence`. Refit `CONFIDENCE_AMBIGUOUS_LO/HI` (`constants.py:22-23`) only after a labeled mini-eval exists. Highest honesty leverage.
2. **Give `pass` a verification requirement (or an honest annotation).** Either require a corroborating grounded span on PRIMARY (whisker-pass-channel) candidates, or annotate every pass in the sidecar as "unverified (no grounded span)". Gate the stricter form on a labeled mini-eval so it does not manufacture review noise. Target: `adjudicate.py:237-238`, `models.py:106-124`.
3. **Port the langextract monotonic exact-occurrence grounding DP into `grounding.py`** (candidate hardening item, ~150 LOC, no new dependency). Re-implement `_select_monotonic_matches` so repeated evidence phrases map to successive non-overlapping positions in model-output order (langextract `resolver.py:1113-1243`) instead of the current occurrence-blind first-substring hit (`grounding.py:49`), and upgrade the return shape to `(quote, char_interval, AlignmentStatus)` so `--inspect` can say "exact at chars X-Y" instead of a bare kept/dropped count (`grounding.py:56`). **Keep our `EVIDENCE_FUZZY_FLOOR = 0.90` `partial_ratio` (`constants.py:50`) as the fuzzy tier; do NOT port langextract's looser 0.75/0.333 LCS gate** (its own oracle test codifies a wrong gapped span as correct). Add a min-quote-length gate (short quotes must satisfy substring, not fuzzy) and the post-alignment guard: reject any exact span whose `markdown[char_interval]` != quote after normalization. Attribution obligation only (Apache-2.0 port, add a `THIRD_PARTY_NOTICES` entry).
4. **Deliver the documented per-step budgets/thinking whisker-locally.** In the agent-construction dict (`adjudicate.py:388-396`) pass per-slot `max_tokens`/`thinking_budget`: `fast` -> 2048/1024, `deep` -> 4096/4096, matching `tapetum_llm.md`. `AgentBackend.run` resolves `None` to construction defaults, so this achieves the authority-doc intent with zero pipeline edit. Requires `alliance-pod` to be `thinking_capable`; if not, keep thinking off and document it.
5. **Close the disclosure/idempotency gaps.** On adjudication failure write an error/tombstone sidecar (`failed: true`, exception class) or delete the stale one; add `partial`/`chunked` to `TapetumResult.to_dict` (`models.py:106-124`); extend partial demotion beyond pass-only (`adjudicate.py:245-246`) so a partial-read fail/review is flagged. Target: `cli.py`, `models.py`, `adjudicate.py`.
6. **Strengthen PRIMARY selection + add a deterministic order check.** Make `select_candidates`/`_has_pass_risk_signals` (`adjudicate.py:82-109`) actually forward the `cov_unigram_gap` permuted-section proxy, and inject an H2 section-index manifest so cross-chunk reordering is detectable (`chunking.py`, `adjudicate.py:187-192`).
7. **Correct the authority docs** (`tapetum_llm.md`, `whisker/CLAUDE.md`): rewrite the cascade section to same-service reality (or the new split), disclose the chunked-tier2 skip, soften "verbatim" grounding to reflect OmniDocBench normalization, and soften "every call is deterministic" to serial-but-not-bit-exact.
8. **Optional decide-step fold** (structure-only-minor -> pass), and **wrap tier1 fields before the tier2 prompt** (`adjudicate.py:342-348`) alongside the cascade fix. Both gated / deferred: the fold needs a labeled holdout (>= 80% human-shippable), the wrap is inert until tier2 fires.
9. **Add whisker-side regression tests:** CLI batch-loop firewall + retry-noise filter, cascade boundary values (0.34/0.35/0.65/0.66), and confident-pass-with-all-spans-dropped (the pass-channel hole). (Persona 07 whisker-side only; the `test_runner.py` gap is out-of-scope.)

Note: `--concurrency N` (default 1, `asyncio.Semaphore`-bounded `gather` with input-order merge) is **already implemented** in `cli.py` per the concurrency-architect (persona 18) design and the D11-safe CLI paper-level hook. No further concurrency work is needed; only pair it with batch-invariant infra below if rerun-comparable distributions are required.

## Flip conditions
- **Up to `usable`:** a labeled mini-eval shows the pass channel's true false-pass rate is acceptably low after item 2, AND the cascade is either honestly documented as single-tier or repointed to a real second model (infra) — i.e. the lane demonstrably does the one job it exists for.
- **Down to `garbage`:** if a labeled corpus shows the advisory lane's `pass` verdicts miss token-preserving corruption at a rate that would mislead reviewers even as advice (the false-pass mission fails outright), OR if the pass-channel hole is shown to actively launder real defects rather than merely fail to catch them. Neither is evidenced today; the advisory isolation contract keeps the current floor at usable-with-conditions.
- **Confidence stays `high`** as long as the pinned state holds: Meta-A reproduced the load-bearing calibration/distribution metrics to the digit (0/198 escalations, mean 0.9586, 18/18 fails >= 0.95), Meta-D found 0 fabricated anchors, and every CRITICAL is code-anchored, not inferred. Confidence would drop only if a fresh budget-2 rerun materially changed the verdict distribution the plan is built on.
