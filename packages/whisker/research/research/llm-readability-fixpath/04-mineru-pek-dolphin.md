## Findings

- [CRITICAL] **No repo validates LLM consumability; all three gate structural fidelity only.** MinerU publishes OmniDocBench End-to-End Overall (edit distance, TEDS, CDM) in docs/README with no in-repo scorer (`docs/en/quick_start/index.md:99`, `README.md:88-105`; prior scan MinerU.md §4). PDF-Extract-Kit eval docs are literal `XXX` placeholders (`docs/en/evaluation/pdf_extract.rst:5`, `README.md:84-86`). Dolphin cites six OmniDocBench axes in `README.md:58-106` but ships no Python scorer module. Impact: none of them answer 00-baseline Q1/Q2; whisker Lane 3 (`facts.py`, `readback.py`) remains the only in-monorepo comprehension gate.

- [HIGH] **MinerU is the only repo with discrete in-repo assertions — but they are aggregate-ish, JSON-only, and n=1.** `tests/unittest/test_e2e.py:152-220` walks `content_list.json` per block type: image caption `fuzz.ratio > 90` (`:161-168`), table caption + `validate_html(table_body)` + substring hit-rate over 11 literals (`:171-201`, pass if `correct_count > 0.9 * len(targets)` txt/ocr or `> 0.7` vlm), equation token presence (`:205-209`), text `fuzz.ratio > 90` (`:211-218`), modality diversity `len(type_set) >= 4` (`:157,220`). Markdown output is written but **never asserted** (`:119-128`). Impact: localized recovery on one fixture, not comprehension over emitted markdown; still closer to olmOCR presence tests than PDF-Extract-Kit/Dolphin (which have zero asserts).

- [HIGH] **Single dropped table row: our `facts.py` wins over all three repos.** MinerU table QA is a **fraction of anchor substrings** in `table_body` HTML (`test_e2e.py:181-201`): one missing row cell can pass if ≥90% of 11 literals still hit. OmniDocBench TEDS (external to all three repos; we port it verbatim in `metrics.py:394-551`) scores whole-table tree edit distance — a row swap with preserved grid shape can score high while a specific cell value is wrong. Our table facts locate a **target cell and verify directional neighbors** (`facts.py:373-406`, `_check_neighbors` at `:359-370`): a dropped row fails when the anchor cell or any asserted neighbor (`up`/`down`/`left`/`right`/`heading`) is absent or wrong, with `table_heading` disambiguation (`:376-380`) and all-occurrence search (`:386-404`). Impact: for "row 3 column 2 reads X and cell below reads Y", only whisker Lane 3 catches it deterministically without LLM scoring.

- [HIGH] **No blind LLM readback or LLM-as-judge in any target repo.** Repo-wide search in prior scans: no `readback`, `comprehension`, `judge`, or Q&A eval modules in MinerU (`tests/` only), PDF-Extract-Kit (no tests, `.gitignore:8` ignores `test*`), or Dolphin (~32 files, no `tests/`). MinerU README positions output for "LLM · RAG · Agent workflows" (`README.md:49`) but does not verify downstream recovery. Our `readback.py` generates questions **without embedding answer lexemes** (`readback.py:106-177`, table blindness fix at `:138-157`), scores answers deterministically per fact type (`_evaluate_answer` at `:180-205`), and ships adversarial `--corrupt` control reversing table rows and flipping operators (`_corrupt_markdown` at `:297-313`, prefix at `:71-74`). Impact: we alone have a methodology control (corrupt mode) proving questions test comprehension, not pattern matching.

- [MED] **Table grid: TEDS lives in our `metrics.py`, not theirs; Dolphin HTML strip is the only portable normalization gap.** Whisker already ports PubTabNet/OmniDocBench TEDS verbatim (`metrics.py:394-551`) with `_normalize_table_html` (`:519-537`: `th→td`, strip `thead`/`tbody`/`tfoot`, wrap `<html><body>`). Lane 3 table **comprehension** uses a separate stdlib grid parser in `tables.py:80-135` (`parse_html_tables`, `parse_pipe_tables`) feeding neighbor checks in `facts.py:341-406` — no external repo offers a stronger cell-neighbor assertion layer. Dolphin's pre-score chain strips `<table>` attributes to canonical `<table>` before external TEDS (`utils/markdown_utils.py:14-16,271-280`) and applies `truncate_repeated_tail(threshold=20, keep=1)` on text blocks (`:52-79,320-321`); overlap with our `_normalize_table_html` is partial (we do not strip arbitrary table attrs or truncate VLM repetition tails in the text axis). MinerU uses `validate_html(table_body)` as a well-formedness gate only (`test_e2e.py:171-201`), not grid comparison. PDF-Extract-Kit demo **drops** table blocks in markdown emit (`project/pdf2markdown/scripts/pdf2markdown.py:320-321`). Impact: nothing to replace `tables.py`; optional bench-side adoption of Dolphin tail truncation reduces false NID regressions (`00-baseline.md` live-run context).

- [MED] **Corpus authoring: external OmniDocBench consumption only; our `corpus_tools.py` is ahead on stratified fact authoring.** MinerU: one fixture PDF (`tests/unittest/pdfs/test.pdf`), runtime output to `tests/unittest/output/` with inline hardcoded strings, no OmniDocBench dataset builder or committed goldens (prior scan MinerU.md §2). - [LOW] **PDF-Extract-Kit is the negative control confirming our guard design.** Zero tests, zero eval code, demo silently omits figures/tables (`pdf2markdown.py:320-321`), README defers PDF→Markdown QA to MinerU (`README.md:34-36,144-145`). Impact: anti-pattern for modality-presence gating (whisker A2 vacuous-green and facts conjunctive guard already address this per 00-baseline).

## False-pass hypothesis

**Theirs:** MinerU passes table QA when 10/11 anchor substrings appear in `table_body` but row 3 column 2 is swapped with row 4 (`test_e2e.py:194-199` hit-rate gate). External TEDS can stay ≥0.95 when structure is preserved but one cell's text is wrong. PDF-Extract-Kit demo emits table-free markdown with no failing gate (`pdf2markdown.py:320-321`).

**Ours:** A table fact asserting only `cell` + `right` neighbor passes if the target cell and its right neighbor are correct but **down** neighbor (next row, same column) was dropped — unless a separate fact asserts the `down` direction. Mitigation: author multiple neighbor directions per critical row (comprehension corpus already does this for N5040 per 00-baseline).

## False-fail hypothesis

**Theirs:** MinerU txt/ocr table gate requires `correct_count > 0.9 * len(target_str_list)` (`test_e2e.py:198-199`); benign HTML whitespace drift in one anchor fails an otherwise faithful extraction. Dolphin `truncate_repeated_tail` could collapse legitimate repeated list markers if ported naïvely (`markdown_utils.py:52-79`).

**Ours:** `math` facts using structural `_math_surface` (`facts.py:237-254`) may fail when the formula is present but rendered as display math `\[...\]` vs inline `$...$` — mitigated by `_fold_display_math_delims` (`:213-234`, live-run driven per 00-baseline). Table facts with wrong `table_heading` filter skip the correct table (`facts.py:388-390`) causing false fail on duplicate cell values across tables.

## Adoption candidate

**`truncate_repeated_tail(s, threshold=20, keep=1)` from Dolphin `utils/markdown_utils.py:52-79`**, wired at `:320-321` inside `MarkdownConverter.convert` when `post_process=True`. License: Dolphin (ByteDance) — verify upstream license at adopt time (typically permissive; **not** MinerU). **Do not port MinerU `test_e2e.py` asserts wholesale — MinerU is AGPL-3.0** (`packages/tomd/improvements.md:83,655`; OpenDataLab stack). Highest leverage: deterministic VLM repetition collapse before Lane 2 NID/TEDS scoring, reducing false regressions without touching comprehension facts. Secondary (pattern only, not code port): MinerU `len(type_set) >= 4` modality-presence gate (`test_e2e.py:220`) as an `auto_baseline_checks` extension — logic is trivial, AGPL applies if copying source verbatim.

## What would change my mind

Finding an in-repo OmniDocBench runner or LLM-as-judge eval script in any of the three clones (e.g. `eval/`, `benchmark/run_omnidoc.py`, or a TEDS module importing `apted`) with committed gold pairs and per-cell assertions — would upgrade MinerU/Dolphin from "publish-only structural metrics" to reproducible structural QA and might surface a table-grid technique stronger than our `tables.py` neighbor model.
