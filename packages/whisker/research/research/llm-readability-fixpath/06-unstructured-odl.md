# 06 - unstructured+opendataloader

**Verdict:** usable-with-conditions — all three repos are strong Lane 2 structural-regression references (text recall, TEDS/NID/MHS, table-detection F1, pinned corpora) but ship zero comprehension assertions or blind LLM readback; whisker's Lane 3 stack (`facts.py`, `readback.py`, `corpus_tools.py`) is strictly ahead for LLM-readability verification.
**Confidence:** high

## Findings

- [CRITICAL] **No repo verifies comprehension via discrete human-verified facts.** Unstructured gates three deterministic metric families (`TextExtractionMetricsCalculator`, `ElementTypeMetricsCalculator`, `TableStructureMetricsCalculator` at `evaluate.py:342-507`); opendataloader-bench gates scalar NID/TEDS/MHS means (`evaluator.py:94-125`, `run.py:53-117`). Neither has `present`/`absent`/`order`/`table`-neighbor/`math`/`code`/`xref` assertions, `checked: verified` provenance, or vacuous-green gates. Impact: our `facts.py` Lane 3 is the only verified comprehension path among these four codebases (00-baseline: 37 gated verified facts, 5-paper corpus).

- [HIGH] **Unstructured per-element assertions are corpus-level structural proxies, not comprehension facts.** Text axis: `cct-accuracy` (Levenshtein, weights `(2,1,1)` at `text_extraction.py:57-60`) plus `cct-%missing` bag-of-words recall (`text_extraction.py:160-203`, rows at `evaluate.py:434-435`); we already ported the complement as `content_recall` (`metrics.py:372-389`). Element-type axis: `(type, category_depth)` frequency match (`element_type.py:18-93`, `evaluate.py:489-494`) — no whisker markdown analog. Table axis: nine metrics including `table_detection_recall/precision/f1`, `element_col_level_index_acc`, `element_row_level_content_acc` (`table_eval.py:43-60`, `evaluate.py:227-238`). Impact: unstructured beats us on layout-taxonomy and table-detection bundle scoring; we beat it on targeted cell-neighbor and math/code/xref/image-ref facts.

- [HIGH] **Zero blind LLM readback in any target repo.** Repo-wide search for `LLM`, `comprehension`, `question`, `QA`, `judge`, `readback` in all three clones: no matches. opendataloader-pdf Level 2 is substring needles only (`ci-verify.py:163-200`, e.g. `must_contain=["|"]` for table smoke). opendataloader-bench cites MDEval/QA papers as related work only (`README.md:228-230`), not implemented. Impact: `readback.py` (`_generate_question:106-177`, `_evaluate_answer:180-205`, `_corrupt_markdown:297-313`, 37/37 live readback in 00-baseline) is unique; these repos cannot validate that an LLM recovers facts from converted markdown.

- [MED] **Table grid comparison: three different algorithms, different jobs.** Unstructured `table_eval`: table ID via concatenated-text `difflib.get_close_matches` (`table_alignment.py:27-48`), cell pairing by fuzzy content match then `(row,col)` index-tuple accuracy (`table_alignment.py:106-161`), row/col token-order via `compare_contents_as_df` (`table_alignment.py:95-100`) — not TEDS/APTED. opendataloader-bench: PubTabNet APTED tree edit on HTML table DOM with Levenshtein cell content (`evaluator_table.py:222-247`; whisker `metrics.py:392-399` ports same TEDS for Lane 2 bench). whisker `tables.py` + `facts.py`: stdlib pipe/HTML grid parse (`tables.py:44-135`), exact normalized cell locate with all-occurrence + `table_heading` disambiguation (`facts.py:373-394`), directional neighbor check with optional edit budget (`facts.py:348-370`). Impact: TEDS is stronger for holistic table-tree fidelity; our neighbor model is stronger for "what is right of cell X?" comprehension; unstructured fuzzy content-match is weaker than exact-normalized on duplicate cell values but adds corpus-level detection F1 and index-shift metrics we lack in guard.

- [MED] **Corpus authoring: fixed structural benchmark vs stratified comprehension scaffold.** Unstructured: 18-doc manifest (`metrics-json-manifest.txt:1-18`), S3 gold JSON, committed TSV trees with zero-tolerance `diff -ru` (`check-diff-evaluation-metrics.sh:46-73`). opendataloader-bench: 200 PDFs via Git LFS (`README.md:110-120`, `194`), hand-labeled `ground-truth/markdown/` paired by `doc_id`, rich `ground-truth/reference.json` element annotations (`reference.json:1-30`, Table category at `evaluator_table_detection.py:67-71`), corpus-mean regression via `thresholds.json` + `regression_tolerance: 0.02` (`run.py:69-86`). whisker `corpus_tools.py`: heuristic strata (`classify_paper:70-94`), zero-coverage stratified pick (`stratify_candidates:97-139`), draft `.facts.jsonl` skeletons (`draft_facts_scaffold:145+`). Impact: odl-bench wins at scale fixed structural GT; we win at growing a comprehension corpus with human blessing workflow; neither replaces the other.

- [LOW] **opendataloader-pdf CI is smoke + needles, not comprehension.** Three-level taxonomy (`ci-verify.py:3-4`): exit/file smoke, `assert_content` needles (`163-200`), byte-identical option compare (`273-319`); `STRIKETHROUGH_KNOWN_ISSUE` skip with audit trail (`46,1128-1129`). External bench via `scripts/bench.sh` cloning opendataloader-bench. Impact: portable as whisker CLI smoke patterns, not Lane 3 substitutes.

## False-pass hypothesis

Unstructured: a conversion that preserves bag-of-words and Levenshtein similarity but permutes table cell positions could pass `cct-accuracy` + low `cct-%missing` while failing `element_col_level_index_acc` only if table-structure eval runs (default CI ingest loop runs text-extraction + element-type only per prior scan `test-ingest-src.sh:81-89`; table-structure is implemented but not in that loop). opendataloader-bench: high corpus `teds_mean` with a single swapped neighbor cell in one paper passes `check_regression` because per-document scores in `documents` are not gated (`run.py:66-86`). **Ours:** token-preserving semantic corruption (table cell swap, exponent drop) can pass Lane 2 `content_recall`/TEDS while failing Lane 3 facts — the reason readback exists.

## False-fail hypothesis

Unstructured: wild byte-length ratio assigns sentinel `accuracy = 0.01` (`evaluate.py:417-421`), failing docs that are structurally fine but reflowed to very different length. opendataloader-bench: null TEDS when GT lacks tables excludes doc from mean (`evaluator_table.py:234-235`) — no false fail, but masks modality gaps. **Ours:** `readback.py` ORDER evaluation requires strict increasing normalized positions (`readback.py:191-199`); an LLM that lists items correctly but paraphrases surface text could false-fail; deterministic `facts.py` order checks share the same fuzzy-window behavior via `_position_within`.

## Adoption candidate

**`opendataloader-bench-tmp/src/evaluator_table_detection.py:evaluate_table_detection_batch`** (Apache-2.0) — binary table-presence precision/recall/F1 from `reference.json` Table elements vs markdown pipe-table separator detection (`evaluator_table_detection.py:43-51,54-71`); already wired into odl CI regression (`run.py:226-237`, `thresholds.json:5`). whisker guard has no `table_detection_f1` axis today (grep: zero hits in `packages/whisker/src/whisker/`). Highest incremental Lane 2 value not already ported (note: `content_recall` already adopts unstructured `cct-%missing` at `metrics.py:372-375`; TEDS already ported at `metrics.py:392-399`).

## What would change my mind

A committed comprehension benchmark in any of these repos — fact JSONL fixtures with human verification, or an in-repo LLM blind-QA harness with leak-safe question generation and adversarial controls — that catches table-neighbor or math failures our 37-fact corpus misses, with published pass rates on WG21-scale markdown.
