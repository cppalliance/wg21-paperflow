# 10 - langextract

**Verdict:** usable-with-conditions — langextract's three-tier char-interval aligner is the strongest open-source grounding reference we surveyed, but whisker's fix-path implementation already ports its safe core (monotonic exact DP, post-alignment guard, graded span return) and adds comprehension readback plus A1 demotion that langextract lacks; langextract wins only on localized token-reorder fuzzy (LCS Tier 3), which its own oracle test shows is unsafe to adopt wholesale.
**Confidence:** high

## Findings

- [CRITICAL] **Three-tier aligner vs our `grounding.py` + A1 demotion.** langextract runs monotonic exact DP → difflib `MATCH_LESSER` → LCS fuzzy (0.75 coverage + 1/3 density) (`resolver.py:948-959`, `:962-1019`, `:1027-1065`, gates `:1377-1404`, constants `:57-58`). Whisker already re-implements Tier 1 DP (`grounding.py:101-167`, attribution `THIRD_PARTY_NOTICES.md:5-9`), adds a post-alignment guard langextract lacks (`grounding.py:220-227`), returns `(status, start, end)` for exact spans (`grounding.py:51-59`, `:323-326` in adjudicate), and keeps document-level `partial_ratio ≥ 0.90` with a min-length gate for fuzzy (`grounding.py:231-236`, `constants.py:67-73`) instead of LCS. **Paraphrase:** langextract Tier 3 accepts token-reordered subsequence matches (`resolver_test.py:1585-1597`, `"problems heart"` → `MATCH_FUZZY`) but rejects partial overlap below 0.75 (`resolver_test.py:1601-1619`); whisker fuzzy has no localized span and can accept scattered document-level paraphrase via `partial_ratio` (`grounding.py:231-236`, persona 17 steelman). Tier 3 also **invents wrong localized spans** at the density floor (`fuzzy_alignment_cases_test.py:213-222`, `_accept_lcs_match` `:1403-1404`). Net: langextract is not uniformly more robust; it trades our coarse-but-spanless fuzzy for a tighter local matcher that can mis-ground. Impact: do not import LCS; keep A1 demotion as the verdict layer langextract has no analogue for.

- [HIGH] **Ungrounded extraction policy: flag-and-keep vs drop-and-demote.** langextract leaves failed alignments in the output with `char_interval=None` and `alignment_status=None` (`core/data.py:74-76`, `:87-88`; difflib reject resets `:1016-1019`; LCS miss returns `None` `:773-774`). README instructs consumers to filter (`README.md:94-95`); `benchmarks/benchmark.py:222-260` counts grounded vs ungrounded but never fails the run. Parse/schema failures on a chunk return `[]` when `suppress_parse_errors=True` (`extraction.py:365`, `resolver.py:309-321`). Whisker **drops** ungrounded quotes (`grounding.py:237-238`), surfaces `ungrounded_dropped` (`adjudicate.py:277`, `:338`), and **demotes** a confident pass whose cited evidence was entirely dropped to `review` (`adjudicate.py:295-304`, baseline `00-baseline.md:13-15`); empty-evidence passes are untouched (`adjudicate.py:297-298`). Impact: langextract is fail-soft (silent chunk loss, consumer-side filter); our lane is fail-safe for verdict trustworthiness.

- [HIGH] **No answer-evaluation analog beats `_evaluate_answer`.** Grep over langextract finds no scoring of LLM answers against expected values. Closest is operational telemetry: `benchmarks/benchmark.py:222-260` measures grounding rate (non-null `char_interval`), not comprehension. Whisker `readback.py` generates leak-resistant questions per fact type (`readback.py:106-177`), evaluates deterministically (`readback.py:180-205`: yes/no prefixes, `_present_within` for math, order positions, table neighbor cells), and includes adversarial `--corrupt` (`readback.py:267-268`, `:297-313`; baseline `00-baseline.md:30-36`, 37/37 live corpus). Impact: langextract offers nothing portable for blind readback; our harness is strictly ahead for Lane 3 validation.

- [MED] **Chunking: sentence/token windows + multi-pass merge vs H2 serial fold.** langextract `ChunkIterator` packs sentences up to `max_char_buffer` (default 1000, `extraction.py:53`, `chunking.py:343-383`), batches chunks with `batch_length`/`max_workers` for parallel LLM calls (`extraction.py:57-58`, `chunking.py:265-279`), supports `extraction_passes>1` merged first-pass-wins on char overlap (`annotation.py:46-84`, README `:156-158`), optional `context_window_chars` overlap (`extraction.py:65`). Whisker splits on H2 fence-aware section boundaries (`chunking.py:129-194`), processes chunks **serially** (D11, `adjudicate.py:203-221`), aggregates worst-axis/min-confidence/union evidence (`chunking.py:226-292`), marks `partial` on hard-split sections and blocks clean pass (`chunking.py:148-150`, `adjudicate.py:308-312`), and skips tier-2 escalation on chunked papers (`adjudicate.py:255-259`). Portable improvements: (1) optional `context_window_chars`-style overlap when grounding cross-section evidence quotes; (2) offline `prompt_validation.py:56-60`, `:180-218` lint for few-shot examples through the same aligner (no CI analogue today). Do **not** port parallel multi-pass merge into tapetum (D11, determinism).

- [MED] **Monotonic DP overlap exclusion can false-fail nested quotes langextract keeps ungrounded but whisker keeps.** langextract DP skips overlapping shorter extractions when a longer winner aligns first (`resolver_test.py:1024-1057`, `:944-997`). Whisker exact tier assigns successive non-overlapping occurrences per span list order but fuzzy substring keeps all non-overlapping quotes independently (`grounding.py:229-230`). Impact: langextract is stricter on overlapping entity strings; our policy is more permissive at the evidence-quote level.

- [LOW] **Graded `AlignmentStatus` persistence parity already landed.** langextract enum (`core/data.py:43-47`); whisker emits `status: exact|fuzzy` plus char offsets in `grounded_evidence` (`adjudicate.py:323-326`, `grounding.py:45-46`). Inspect locatability gap from the Jul-06 scan is closed for exact tier; fuzzy still lacks intervals by design.

## False-pass hypothesis

Model cites `"metformin hydrochloride tablet"` against a gapped clinical source; langextract LCS returns `MATCH_FUZZY` with a nine-token `char_interval` whose substring is mostly unrelated noise (`fuzzy_alignment_cases_test.py:213-222`, `resolver.py:1403-1404`). A consumer filtering on `char_interval is not None` (README `:94-95`) treats that as verified provenance. Whisker blocks this for exact tier via the post-alignment guard (`grounding.py:220-227`) but fuzzy tier still accepts without a localized span via document-level `partial_ratio` (`grounding.py:231-236`); A1 demotion (`adjudicate.py:295-304`) only fires when **all** cited evidence drops, not when fuzzy accepts a paraphrased quote.

## False-fail hypothesis

Model outputs overlapping evidence quotes `"Naprosyn"` and `"arthritis"` from one sentence; langextract monotonic DP aligns `"arthritis"` first and leaves `"Naprosyn"` at `char_interval=None` (`resolver_test.py:1024-1057`). Whisker keeps both via normalized substring (`grounding.py:229-230`). A merge rule penalizing tapetum when langextract-style overlap exclusion drops a nested valid quote would falsely demote an otherwise grounded pass (A1 would not fire if any quote survives).

## Adoption candidate

**`_normalize_token` plural stem** — `packages/whisker/research/repos/langextract/langextract/resolver.py:1275-1281` (Apache-2.0, Copyright Google LLC). ~7 LOC: strip trailing `s` when `len>3` and not `ss`, applied before exact token matching. Closes inflection false-drops (`"tables"` vs `"table"`) that may miss exact tier and rely on fuzzy ratio (`grounding.py:229-236`). Monotonic DP is **already ported** (`grounding.py:14-21`, `THIRD_PARTY_NOTICES.md`); this is the highest-leverage remaining snippet. Do not adopt LCS Tier 3, library dependency, or `suppress_parse_errors=True` defaults.

## What would change my mind

A langextract release merging PR #480 CJK char-substring fallback with a mandatory post-alignment span-text guard on **all** tiers (matching whisker `grounding.py:220-227`), plus published wrong-span rate `<1%` on a WG21-representative corpus — would flip Tier 3 from "reject" to "re-evaluate for localized paraphrase recovery" while keeping our A1 demotion and readback harness as the verdict layer langextract will never provide.
