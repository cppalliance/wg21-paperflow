# M17 — --det-skip must not be default

CLAIM: --det-skip is advisory opt-in only (~250–350 s); unsafe as a fleet default for quality-stability.
EVIDENCE FILE: 24-det-skip-llm.md; ADR-010-no-default-det-skip.md
IMPLICATION FOR PLAN: Keep flag opt-in; do not bank det-skip seconds in package tables.
STATUS: reject
