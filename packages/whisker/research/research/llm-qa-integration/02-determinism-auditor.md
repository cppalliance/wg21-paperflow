# 02 - Determinism-Auditor

**Verdict:** usable (+ the mechanical gate path is run-to-run stable; LLM variance is quarantined to the advisory lane, matching the 31-repo pattern that zero projects use an LLM signal as a CI/accept gate)
**Confidence:** high

## Findings

- [HIGH] Whisker deterministic gates and verdict fusion are structurally replay-stable: `run_gates` executes six gates in a fixed list order (`packages/whisker/src/whisker/gates.py:209-218`), `_decide` only hard-fails on gate failures and `unigram_coverage` below a named constant (`score.py:177-185`, `constants.py:37-38`), and sidecar serialization sorts flag lists (`score.py:129-130`). Sets in `gates.py` (`keys` at `:63`, `seen_plain` at `:156`) are membership-only; they do not drive iteration order into verdict text. Impact: re-running `whisker` on unchanged markdown reproduces verdicts; the architecture's "deterministic decides" claim holds for the CI gate.

- [HIGH] Bench aggregation and guard regression are deterministic but float-sensitive at the threshold boundary: per-paper `overall` is a fixed-order mean of eligible axes (`bench.py:200-205`), corpus means sum in list order (`bench.py:240-246`), rows and `below_floor` are sorted by pid (`bench.py:211`, `:247-254`), and guard diffs sort axes (`guard.py:345`, `:358`). `constants.py:118-119` documents exact metric reproduction on unchanged code. Impact: no RNG or unordered-set leakage into gating; the only "variance" is IEEE-754 edge cases at slack boundaries (`GUARD_AXIS_SLACK = 0.02`, `constants.py:121`), not run-to-run drift.

- [HIGH] Reference repos isolate LLM nondeterminism from mechanical gates, same as whisker. Marker CI blocks only on deterministic corpus means (heuristic >= 90, TEDS >= 0.7); LLM judge scores are advisory and skipped on failure (`00-baseline.md:26`, `05-web.md / Q5 / Marker CI gates heuristic only`). MinerU E2E gates use fixed `fuzz.ratio > 90` and substring hit-rates, not LLM scores (`00-baseline.md:27`; `research/llm-readability-fixpath/04-mineru-pek-dolphin.md` cites `test_e2e.py:163-220`). opendataloader `check_regression` gates corpus means only, ignoring per-document scores (`00-baseline.md:38`; `research/llm-readability/repo-scan/opendataloader-pdf.md`). Impact: ecosystem evidence supports deterministic-first gating; LLM-in-path (marker table rewrite retry on LLM score < 4, `00-baseline.md:26`) affects conversion retries, not accept/reject of scored output.

- [HIGH] 05-web temperature-reproducibility findings align with our tapetum client pins but do not make the advisory lane bit-stable. Production graders at default temp 1.0 show up to ~50% pass/fail flip across 20 identical runs; temp=0 reduces but does not eliminate disagreement (`05-web.md / Q2 / Necessary but Not Sufficient: Temperature Control and Reproducibility`). Whisker inherits D2 sampling pins via `AgentBackend` (`packages/pipeline/src/pipeline/model_backends.py:310-312`: `temperature=0.0`, `top_p=1.0`, `seed=0`); `readback.py:306` and `vision_task.py:161-163` pin explicitly. `tapetum_llm.md:29` documents that hosted vLLM under continuous batching is not bit-stable even at temp 0. Impact: reruns can diverge in advisory verdict/confidence; this cannot flip `whisker --gate` because fusion never hard-fails and tapetum is opt-in (`fusion.py:148-170`, `tapetum_llm.md:3`).

- [MED] Marker and MinerU show where nondeterminism-adjacent fuzz enters gating paths without an LLM judge: heuristic corpus means and `rapidfuzz` ratio cutoffs are deterministic functions of output but hand-set (`research/llm-readability/repo-scan/marker.md` on `verify_scores.py:9-13`; MinerU `fuzz.ratio > 90` at `test_e2e.py:211-218`). Marker additionally drops failed benchmark samples before averaging (`research/hybrid-llm-scoring/02-marker-hybrid.md` cites `overall.py:72-77`), injecting selection bias into the gate statistic. Impact: gates are repeatable run-to-run but threshold-sensitive and can false-pass localized regressions hidden in corpus means; whisker's per-paper guard (`GUARD_AXIS_SLACK`, `guard.py`) is stricter on that axis.

- [MED] Tapetum's PDF lane mixes deterministic demotion with LLM escalation before any human sees output, but still does not gate CI. `screen_pages` flags pages when lane-local `content_recall < PAGE_RECALL_FLOOR` (`pdf_judge.py:287-310`, `constants.py:154`); judge `pass` is demoted on recall/nid floors (`pdf_judge.py:527-538`); over-cap flagged pages cap at `review` without LLM calls (`pdf_judge.py:545-553`). These steps are pure functions of text; only the judge call is stochastic. Impact: deterministic sub-gates reduce false-pass from LLM overconfidence on PDF lane, but LLM variance remains in `suggested_verdict` and fusion's advisory `combined_verdict`.

- [LOW] Minor unsorted iterations in the advisory path do not affect deterministic CI. `textlayer.py:158` builds a set from `line_counts.items()` (insertion-ordered Counter, membership-only). `adjudicate.py:500` iterates `models.items()` in service-map order (stable for fixed `tapetum_llm.md`). `content_recall` sums over `ref.items()` (`metrics.py:388`) in Counter insertion order (token first-seen order in reference, deterministic for fixed input). Impact: no finding against gate determinism; D7 discipline is explicit in `score.py:129-130` and `whisker/CLAUDE.md` determinism invariant.

- [LOW] Reference clones under `packages/whisker/research/repos/` were empty in this audit run; all reference-repo claims rely on `00-baseline.md` matrix anchors and prior deep-reads flagged for persona 25 re-verification (`00-baseline.md:98-103`). Impact: file:line citations for marker/MinerU/opendataloader are baseline-sourced, not re-read from live clones in this session.

## False-pass hypothesis

A paper with `unigram_coverage` just above `UNIGRAM_COVERAGE_FAIL_EDGE` (0.85, `constants.py:37`) and token-preserving table-cell corruption passes the deterministic hard gate every rerun identically, while the advisory LLM lane may flip between pass and review on pod variance (`tapetum_llm.md:29`, `05-web.md / Q2`). If an operator treats `fuse_verdicts` `combined_verdict` as ship authority (`fusion.py:200-207` can clear soft review to pass), LLM run-to-run flips become a false-pass vector even though `whisker --gate` stays stable.

## False-fail hypothesis

A clean paper with `heading_monotone` gate failure and `unigram_coverage >= 0.95` hard-fails deterministically on every rerun (`score.py:177-179`, `gates.py:96-112`); the LLM rescue path only affects fusion (`fusion.py:151-160`), not the recorded whisker verdict. No run-to-run false-fail from nondeterminism in the gate itself; false-fail here is a threshold/design issue (cosmetic heading skip), not variance.

## What would change my mind

Live re-read of the 31 clones confirming an repo that mechanically gates CI/accept on an LLM quality score (not conversion-path retry, not advisory benchmark column), OR a whisker deterministic gate test showing verdict flip on identical markdown across two back-to-back runs with no code/threshold change.
