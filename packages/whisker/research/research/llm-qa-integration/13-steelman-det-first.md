# 13 - Steelman-Det-First

**Verdict:** usable-with-conditions (+ the det-first + advisory-LLM split matches how every serious doc-AI repo and benchmark actually gates quality, and the 2026-07-16 PR replay shows deterministic gates carry human agreement while the LLM lane adds localization and queue ergonomics, not verdict authority)
**Confidence:** high

## Findings

- [CRITICAL] **0/31 repos using an LLM quality signal as a mechanical accept gate is convergence on engineering necessity, not herd behavior.** Evidence: `00-baseline.md:43-55` (uniform division: LLM converts or mines facts; CI/accept gates are deterministic, human-verified, or heuristic); olmOCR-Bench explicitly rejects LLM-as-judge for 7,010 binary tests (`05-web.md / Q1 / olmOCR-Bench`); ParseBench: "does not use LLM-as-judge - all evaluation is deterministic and rule-based" (`05-web.md / Q1 / ParseBench`); AllenAI rationale that programmatically checkable correctness belongs in unit tests, not soft metrics (`05-web.md / Q5 / olmOCR-Bench README`). Impact: whisker's product constraints (model sovereignty: repo `CLAUDE.md:64-70`; defensible findings requiring reproducible verdicts: repo `CLAUDE.md:72-74`; whisker `CLAUDE.md:34-35` "no LLM in the gate") **forbid** cloud-LLM gating even if the ecosystem did it. The ecosystem independently arrived at the same split we are required to hold.

- [CRITICAL] **Fresh PR-rerun evidence (2026-07-16): human agreement moved 4/9 to 8/9 after `no_toc_leak` + TOC prompt rule; every new hard fail came from the deterministic gate.** Evidence: `00-baseline.md:61-63`. Impact: on the golden-ideal review cohort, the marginal **unique** detection win was det-side; the LLM confirmed and localized but did not flip verdict authority. This is the strongest empirical argument that gates decide and the lane advises.

- [HIGH] **TOC-leak (MC2) closed by ~40 LOC of fence-aware regex where two LLM prompt generations failed silently.** Evidence: `_gate_no_toc_leak` at `gates.py:143-185` (TOC-label regex `:132-134`, page-suffixed duplicate-heading pairwise match `:155-184`, wired at `run_gates` `:218`); PR #290 p1122r3 and PR #293 p0533r9 passed all pre-fix gates and scored green (`golden-qa-gap/00-baseline.md:36-38`); PDF judge and text-lane structure axis both false-cleared p1122r3 at pass/0.98 before the explicit TOC defect rule (`whisker/CLAUDE.md:505-511`, `tapetum_llm.md:62`). Impact: a narrow, testable mechanical invariant (`test_gates.py:99-160`) outperformed prompt-only QA on the exact miss-class; this is the template for det-first fixes (adapt/extend gates, not promote LLM to gate).

- [HIGH] **The advisory lane's load-bearing value is localization and explanation, not catching what det missed.** Evidence: p0957r8 page-13 escalation produced five grounded `[p13]` quotes (Figure captions, table header, sample row) after `screen_pages` flagged recall 0.881 (`packages/whisker/research/tapetum-golden-review-findings-2026-07-14.md:200-209`; `grounding.py:244-254` page-scoped quote grounding); PR #293 LLM independently surfaced 31 dropped `constexpr` on the `code` axis at conf 0.95 while det missed (`golden-qa-gap/00-baseline.md:66`, `10-persona-findings.md:141`); axis findings + `ground_spans` DP-to-fuzzy pipeline (`grounding.py:171-241`, same pattern as langextract `00-baseline.md:59`). Impact: operators get **where** and **what** (quotes, axis labels); fusion never hard-fails from LLM (`fusion.py:17-24`, `:148-170` whisker_fail_locked) and CI remains det-only (`whisker/CLAUDE.md:34-35`).

- [HIGH] **Industry and maintainer rationale aligns with whisker's asymmetric fusion matrix, not with LLM-integrated gating.** Evidence: cascade pattern "deterministic gates catch 30-60% at sub-ms cost" (`05-web.md / Q4 / Deterministic vs LLM-Judge Evals 2026`); DistilledPatterns "the model proposes, deterministic checks decide" (`05-web.md / Q4 / Deterministic Guardrails`); Marker CI gates heuristic >= 90 only, LLM scorer skipped on failure (`00-baseline.md:26`, `05-web.md / Q5 / Marker CI gates`); TheoryDelta Feb 2026: judge gates are probabilistic, flaky CI, recommended deterministic assertions first (`05-web.md / Q1 / What Happens When LLM-Judge CI Gates`). Impact: whisker's `fuse_verdicts` (`fusion.py:124-252`) implements the recommended cascade: det decides, LLM can rescue heading-only fails to **review** (`:151-160`), clear soft review under guardrails (`:192-207`), escalate pass to review on major axis fail (`:204-215`), never override det hard fail except heading-monotone rescue capped at review.

- [MED] **Deterministic sub-gates inside the advisory lane reduce false-pass without violating "no LLM in the gate."** Evidence: `screen_pages` lane-local per-page recall floor (`pdf_judge.py:287-310`, `constants.py:154`); fusion blocks `llm_clear_soft_review` when `missing_region_count > 0` (`fusion.py:177-190`, closed p0957r8 false-pass upgrade in `tapetum-golden-review-findings-2026-07-14.md:16-31`); PDF judge recall/nid demotion floors (`pdf_judge.py:527-538`). Impact: even inside tapetum, mechanical checks decide escalation and demotion; the LLM confirms scoped flags, matching olmOCR's "LLM mines, human verifies, bench gates on verified facts" precedent (`00-baseline.md:53-55`).

- [MED] **Honest ceiling: det-first hits structural limits the LLM lane also does not reliably close.** Evidence: selection gap (clean-pass token-preserving corruption never reaches LLM under `--review-all`, `whisker/CLAUDE.md:490-492`); heading-level blind spot despite HTML outline injection (PR #282 pass/1.00 vs human request-changes, `00-baseline.md:82`, `tapetum-golden-review-findings-2026-07-14.md:60-82`); MC1 front-matter truth still key-presence only (`gates.py:60-75`, `golden-qa-gap/00-baseline.md:27-34`); MC3 photocopy-golden and MC4 sub-resolution defects invisible to aggregate metrics (`golden-qa-gap/00-baseline.md:44-58`); LLM confidence anti-calibrated (min 0.90, 0/198 cascade escalations, `tapetum-golden-review-findings-2026-07-14.md:86-89`). Impact: det-first is sound **as architecture**; remaining gaps need more deterministic facts/gates (olmOCR pattern), not promoting LLM to CI gate.

## False-pass hypothesis

A clean-pass paper with token-preserving semantic corruption (table cell transposition, math relation flip) that survives `unigram_coverage` and all structural gates: the `--review-all` candidate filter never selects it (`whisker/CLAUDE.md:490-492`), so tapetum never runs unless the operator does a full corpus pass. Det false-passes; LLM is not structurally guaranteed to catch it either (monolithic prompt shallow-scan documented for p0957r8, `tapetum-golden-review-findings-2026-07-14.md:7-14`).

## False-fail hypothesis

Nine heading-monotone-only deterministic fails (RESCUE population, e.g. H1->H3 cosmetic jump with unigram >= 0.95) remain **fail** on the CI gate record even when fusion downgrades combined to **review** via `llm_rescue_heading` (`fusion.py:151-160`; population documented in `research/hybrid-llm-scoring/20-false-fail-hunter.md`). Operators treating det fail as ship-block without reading fusion advisory still queue false fails.

## What would change my mind

A labeled holdout of >=30 WG21 golden-ideal reviews where an **LLM-integrated gate** (LLM verdict or LLM-judge score as mechanical CI blocker on converted output) achieves >=90% precision vs human gold **and** <=5% run-to-run pass/fail flip rate under pinned open-weight models (replicating the TheoryDelta/deepeval failure mode in `05-web.md / Q1`), **without** sacrificing model-sovereignty or determinism invariants. Until that exists, the 31-repo + 05-web evidence says det-first is the only adoptable production architecture; the advisory lane stays optional ergonomics.
