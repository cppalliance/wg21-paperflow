# 20 - LLM-as-Judge-Scholar

**Verdict:** usable-with-conditions (+ marker's serious LLM-judge craft is worth borrowing into our advisory lane, but only as prompt/grounding upgrades; the ecosystem confirms gates must stay deterministic)
**Confidence:** high

## Findings

- [HIGH] Image-grounded, per-axis rubric judging is the highest-value marker technique we lack. Marker `LLMScorer` renders page 0 to a PIL image and sends `[img, markdown]` to Gemini with explicit overall/text/formatting axes plus element-conditional sub-scores (tables, equations, section_headers, lists, images; 0 = N/A) before emitting JSON (`packages/whisker/research/repos/marker-v1.10.2/benchmarks/overall/scorers/llm.py:15-51,87-134`). Our PDF lane compares raw text layer to markdown only (`packages/whisker/src/whisker/tapetum_llm/pdf_judge.py:171-177,493-497`), explicitly trading away vision (`pdf_judge.py:15-18`). Impact: adopts marker's strongest judge signal for the advisory lane without moving LLM into gates; directly targets the documented heading-level blind spot (`00-baseline.md:82-83`) and layout/table formatting errors the text layer cannot see. Implementation path already exists: `vision.py` rasterization + `vision_task.py` temp-0 pins (D5-compatible).

- [HIGH] Marker encodes the same "deterministic decides, LLM advises" discipline we already ship. Benchmark harness catches scorer exceptions and continues (`marker/benchmarks/overall/overall.py:58-63`); CI gates only heuristic mean >= 90, never LLM (`marker/benchmarks/verify_scores.py:12-13`; `05-web.md / Q5 / Marker CI gates heuristic only`). Our fusion treats tapetum absent/error/confidence-0-stub as `whisker_only` (`packages/whisker/src/whisker/tapetum_llm/fusion.py:17-18,86-94,133-142`). Impact: ecosystem + marker are not counter-evidence to our architecture; they are independent confirmation (`00-baseline.md:43-55`).

- [HIGH] Rubric-first with describe-then-score is compatible with our determinism stack and partially already adopted. Marker forces `image_description`, `markdown_description`, `comparison` strings before integer scores (`llm.py:87-91,127-134`). We already put `reasoning` first in `Adjudication` so the model deliberates before verdict (`packages/whisker/src/whisker/tapetum_llm/models.py:87-88`) and carry a binding conversion contract in PDF prompts (`pdf_judge.py:129-165`). Impact: extend marker's element-conditional scoring rubric (especially section_headers, tables, equations) into page-scoped escalations (`pdf_judge.py:206-239,315-347`) without changing fusion authority.

- [MED] Marker Elo pairwise judging does NOT implement the 05-web Q2 position-swap mitigation and is the wrong paradigm for our QA shape. `Comparer` fixes version A before version B in the prompt (`elo.py:32-40,116-131`); `random.shuffle(method_lst)` only permutes which converter pairs run (`elo.py:194-195`), not A/B order within one judgment. `05-web.md / Q2 / Judging the Judges` names position swapping as the load-bearing debias technique. Impact: do not port Elo ranking into tapetum (we judge one candidate, not leaderboard pairs). If we ever add oracle-vs-tomd pairwise escalation, position swap (run both orderings, require agreement) is determinism-compatible at the cost of 2x serial calls (D11 allows serial per-paper escalation).

- [MED] Multi-sample averaging is structurally forbidden under our determinism contract. `05-web.md / Q2 / An Empirical Study of LLM-as-a-Judge` reports that greedy decoding gives zero variance but lower human correlation than multi-sample averaging. Repo-wide D5 forbids per-call temperature override (`CLAUDE.md` Determinism section). Marker already pins `temperature: 0` (`llm.py:148`, `elo.py:149`), matching our lane. Impact: reject multi-epoch judge averaging for tapetum unless we explicitly downgrade the determinism claim for the advisory lane; prefer rubric depth + image grounding + mechanical quote grounding (`grounding.py:171-241`) instead.

- [MED] Failure-tolerance is same discipline at the system boundary, stricter inside our lane. Marker skip-on-fail drops a scorer row and keeps the benchmark run (`overall.py:61-63`). Our CLI catches per-paper adjudication exceptions, counts `error`, and continues the batch (`cli.py:865-892`); fusion ignores errored sidecars (`fusion.py:90-91`). Inside the PDF lane, judge failure raises `PdfLaneError` (no partial verdict, `pdf_judge.py:449,510-511`), stricter than marker's row skip but still non-gating because fusion never hard-fails from LLM (`fusion.py:22-23`). Impact: optional soften to marker-style stub sidecar (`models.py:157-160`, `adjudicate.py:534-545`) on transient API errors only; do not relax quote grounding or deterministic gate authority.

- [LOW] Marker judges only page 0 in `LLMScorer` (`llm.py:101-105`); we already have a stronger per-page deterministic screen + scoped escalation for flagged pages (`pdf_judge.py:287-310,540-592`, `constants.py:144-168`). Impact: borrow marker's image+rubric prompt per escalated page, not their single-page benchmark shortcut; keeps our per-page-judging synthesis (`research/per-page-judging/SYNTHESIS.md` cited in `pdf_judge.py:149-169`).

## False-pass hypothesis

PDF-text judge passes a paper where heading levels are wrong but all words are present: the text layer carries no `#`/`##` markup, so the judge cannot see the HTML-lane heading defect that humans flag (`00-baseline.md:82-83`; `pdf_judge.py:171-177` compares unstructured text). A marker-style page-image rubric with an explicit `section_headers` axis (`llm.py:42-43,70-72`) would surface it in the advisory lane without gating.

## False-fail hypothesis

PDF-text judge reviews or fails on "missing" content that is visible in the rendered page but garbled in the embedded text layer. Marker explicitly warns that markdown may reflect bad OCR gibberish (`llm.py:22-23`). Our judge treats the text layer as evidentiary ground truth for quotes (`pdf_judge.py:188-190,513-520`), so OCR noise can manufacture grounded-looking false misses. Image-grounded judging (marker pattern) or demoting text-layer quotes when recall screen is clean would reduce this.

## What would change my mind

An A/B on the 9-paper human-verdict replay (`00-baseline.md:61-63`): same model, temp=0, serial calls, text-layer judge vs page-image rubric judge (marker `llm.py` pattern on `screen_pages` flagged pages only). If image-grounded advisory verdicts move human agreement materially above 8/9 without increasing false-pass rate on the deterministic gate's 4 hard fails, the top finding promotes from "worth borrowing" to "required upgrade."
