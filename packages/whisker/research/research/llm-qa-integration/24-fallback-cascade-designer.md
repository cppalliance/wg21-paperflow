# 24 - Fallback-Cascade-Designer

**Verdict:** usable-with-conditions — deterministic-gates-decide + advisory LLM remains sound; the adoptable upgrade is a **marker-then-gate** cascade (nougat-style per-page failure visibility wired to a new whisker hard gate), not olmocr/docling partial-success shipping.
**Confidence:** medium (reference-repo `file:line` anchors come from 00-baseline and prior deep-reads; local clones under `packages/whisker/research/repos/` were empty at research time — meta-review persona 25 should re-verify)

## Findings

- [CRITICAL] **Reference repos keep failed units visible instead of dropping them, but none use that visibility as a document accept gate.** olmOCR escalates temperature across page retries then substitutes `pdftotext` with `is_fallback=True`; the pipeline never hard-fails a single page silently (`00-baseline.md:28`, cited `pipeline.py:329-332`). Nougat writes `[MISSING_PAGE_FAIL:n]`, `[MISSING_PAGE_EMPTY:n]`, or `[MISSING_PAGE_POST]` into the `.mmd` artifact and concatenates all pages (`research/per-page-judging/15-nougat-surya-analyst.md`, `predict.py:178-202`). Docling promotes VLM `LENGTH` / `CONTENT_FILTERED` / missing response to `ConversionStatus.PARTIAL_SUCCESS` and still exports assembled output (`research/llm-qa-integration/06-error-handling-robustness.md:35`, `vlm_pipeline.py:245-274`). Impact: the industry pattern is **provenance-preserving degradation**; whisker should borrow visibility + deterministic reaction, not partial export.

- [CRITICAL] **Our fidelity contract is document-level fail, which is compatible with page-level diagnosis markers.** Repo `CLAUDE.md:123-127`: "If full fidelity cannot be achieved, stop. Fail the paper … Never produce a partial result mistakable for a complete one." That forbids shipping a *complete-looking* broken paper (docling `PARTIAL_SUCCESS` yield), not forbidding in-band markers that force a downstream hard fail. A nougat-style `<!-- tomd:page-failed:page=13 reason=… -->` plus a whisker gate that hard-fails on any such marker gives **page WHERE + document-level honesty** — the middle ground the operator asked for.

- [HIGH] **tomd already has a rich uncertainty/disclosure layer, but no per-page extraction-failure marker and no path that fails one page while emitting the rest.** Per-page dual-path comparison marks low-similarity pages as `SectionKind.UNCERTAIN` (`structure.py:283-328`, promotion/demotion at `:411-420`); emit prefixes `<!-- tomd:uncertain:L{start}-L{end} -->` (`emit.py:1489-1498`). Separate disclosure markers: `tomd:vector-extraction-uncertain` (`vector_images.py:451`, `emit.py:1526-1527`), `tomd:glyph-placeholders` (`glyphs.py:94`), `tomd:lossy-table` (`render.py:15`), `tomd:images-truncated` (`images.py:91-95`). Document-level only exits: `SkipReason` enum (`types.py:25-31`) → empty markdown + `RuntimeError` at convert (`api.py:482-486`, `pipeline.py:1297-1364`). **No `tomd:page-failed` or nougat `[MISSING_PAGE_*]` equivalent exists today.**

- [HIGH] **Whisker currently treats tomd uncertainty as soft review, explicitly not conversion defect — so promoting `tomd:uncertain` to hard fail would be wrong.** `_decide` adds `{uncertain_count} uncertain marker(s)` to soft flags only (`score.py:197-198`); structural gates are the sole hard tier (`gates.py:209-218`). tapetum_llm system doc lists `tomd:uncertain`, glyph placeholders, and vector uncertainty as **sanctioned output** (`tapetum_llm.md:93-97`, `whisker/CLAUDE.md:549-550`). Impact: a new marker kind (`page-failed`) must be semantically distinct from `uncertain` (exhausted recovery, not dual-path disagreement); only the former gets a hard gate.

- [HIGH] **Minimal adoptable cascade for OUR pipeline (conversion → QA, no LLM in the gate).** Layer 0: `tomd` default convert (`run_pipeline`, `api.py:339-366`). Layer 1: existing six hard gates (`gates.py:209-218`). Layer 2 (**new**): `_gate_no_page_failures` — regex on `tomd:page-failed:` → hard fail with page list in `GateResult.detail` (mirrors nougat in-band marker + deterministic gate; fusion locked on det fail, `fusion.py:148-169`). Layer 3: existing content hard gate (`unigram_coverage < 0.85`, `score.py:181-185`, `constants.py:37-38`). Layer 4 (**optional, bounded**): deterministic re-convert on specific gate failures with a fixed parameter schedule (`ml_tables` → `extract_vector`, `pipeline.py:1380-1387`; orchestration gap noted in `16-retry-loop-architect.md:16`) — retry targets **conversion**, not LLM re-judge; reject olmocr temp escalation and pdftotext substitution (D5, `16-retry-loop-architect.md:14`). Layer 5: advisory tapetum_llm unchanged (`00-baseline.md:70-72`, `05-web.md / Q4 / Deterministic vs LLM-Judge Evals`). **Cost:** ~60–100 LOC tomd (emit marker when per-page promotion exhausts and both paths empty or similarity stays below threshold after stages 3–4 in `compare_extractions`), ~40 LOC whisker gate + tests; **zero LLM tokens**; possible ↑ fail rate on papers that today pass with silent best-effort uncertain regions (policy trade, not architecture contradiction).

- [MED] **tomd's `uncertain` regions are already page-scoped internally but emitted as line-range comments, not page-failure tokens.** `compare_extractions` groups by `page_num` (`structure.py:294-302`); pairwise and bulk promotion rescue adjacent/document pools (`structure.py:362-407`, `PDF_ARCH.md` stages 3–4). Remaining UNCERTAIN sections carry MuPDF best-effort text into markdown (`emit.py:1489-1498`) and generate reconcile prompts (`emit.py:1581-1592`). Impact: today's "partial extraction failure" surfaces as **review-band QA + prompts file**, not fail — the gap is missing a closed reason enum (`dual_path_exhausted`, `unreadable_page`, `image_raster_failed`) when promotion cannot rescue.

- [MED] **olmocr's doc-level fallback-rate cap (0.004) is yield engineering, not a QA pattern to import wholesale.** One fallback page in a 33-page WG21 paper exceeds the threshold and discards the document (`research/per-page-judging/18-aggregation-statistician.md:28`); yet each fallback page still ships pdftotext substitution marked `is_valid=True` (`pipeline.py:372-375` per prior research). Impact: adopt olmocr's **never silent** lesson and retry budget; reject silent weaker-engine substitution as pass (`06-error-handling-robustness.md:61`).

- [LOW] **05-web cascade literature aligns with our lane split, not with LLM-gated accept.** Industry cards recommend deterministic gates first (30–60% failures at sub-ms cost), LLM judges for semantic remainder (`05-web.md / Q4 / Deterministic vs LLM-Judge Evals`, `DistilledPatterns` "model proposes, checks decide"). Impact: adding a deterministic page-failure gate strengthens the existing architecture; wiring LLM confidence to accept would contradict both our invariants and ecosystem evidence (`00-baseline.md:43-44`).

## False-pass hypothesis

A 33-page WG21 paper where page 13's dual paths disagree after all promotion stages; tomd emits `<!-- tomd:uncertain:L…-L… -->` with MuPDF guess text, no `page-failed` marker. Whisker passes (uncertain is soft only, `score.py:197-198`); unigram coverage stays high because surrounding pages dominate. A table on page 13 is wrong but token-preserving — same class as MC1 selection gap (`whisker/CLAUDE.md:490-492`). **Without the proposed marker+gate**, the cascade false-passes; **with it** (if page 13 met exhausted-recovery criteria), det gate fails with `page=13` in detail.

## False-fail hypothesis

A clean paper with intentional dual-path disagreement on one paragraph (tomd's designed honesty, `tomd/CLAUDE.md:129`). If `_gate_no_page_failures` mistakenly keyed off `tomd:uncertain` instead of a distinct `tomd:page-failed`, every honestly flagged region would hard-fail the document — false fail. Guard: separate marker namespace; keep `uncertain` soft per `tapetum_llm.md:93-97`. Secondary risk: nougat-style false `[MISSING_PAGE_EMPTY]` on cover pages (`15-nougat-surya-analyst.md:26-30`) — our gate should only fire on closed `SkipReason`-grade page failures (empty both paths, unreadable page text), not on low-similarity prose that promotion already accepted.

## What would change my mind

Instrumented pilot on ≥10 papers with known per-page defects: implement `tomd:page-failed:page=N` for pages where `compare_extractions` leaves UNCERTAIN with `min(m_len,s_len) >= MIN_UNCERTAIN_WORDS` AND post-promotion similarity still below threshold, wire `_gate_no_page_failures`, and show ≥80% of injected single-page drops hard-fail with correct page in gate detail while ≥95% of golden corpus papers without genuine page loss still pass — without elevating sanctioned `tomd:uncertain` regions to fail.
