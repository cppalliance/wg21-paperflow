# 07 - Adversary-Evasion

**Verdict:** usable-with-conditions — deterministic gates + advisory LLM matches the 31-repo pattern (00-baseline.md §2: zero repos gate accept on LLM scores), but both our stack and the reference CI gates admit concrete false-pass exploits; named upgrades (TOC gate variants, selection-gap closure, anchorless-fact hygiene) are adoptable without reversing architecture.
**Confidence:** high

## Findings

- [CRITICAL] **TOC-leak gate misses five verified bypass shapes.** `_PAGE_SUFFIX_RE` only pairs headings when the suffixed form ends with a single whitespace plus `\d{1,4}` (`gates.py:136-176`); runtime verification (2026-07-16) shows **pass** for: dot-leader page refs (`## 1. Introduction ....... 3` alongside `## 1. Introduction`), roman-numeral suffixes (`## 1. Introduction iii`), parenthesized page numbers (`(3)`), reworded TOC entries (`## Overview 5` vs body `## 1. Introduction`), and plain-text TOC lines with no `Contents` label (non-heading `I. History ..... 3`). Only tab-separated digits trip the pairwise matcher. Impact: MC2 is closed for the PR #290/#293 fingerprint (00-baseline.md:62-63) but not for common PDF TOC typography; a leaked TOC can still hard-pass all six gates.

- [CRITICAL] **Token-preserving semantic corruption passes the hard gate and often never reaches the LLM.** `_decide` hard-fails only on structural gates or `unigram_coverage < 0.85` (`score.py:177-185`, `constants.py:37-38`); reordering sections, swapping table cells, or flipping `>=` to `<=` preserves the token multiset. `select_candidates` under `--review-all` only escalates pass-tier papers with lossy-table/mojibake/cov-gap signals (`adjudicate.py:98-125`), not clean-pass corruption — the documented "selection gap" (`whisker/CLAUDE.md:490-492`, 00-baseline.md:83). Default full-run adjudicates all papers but fusion cannot hard-fail (`fusion.py:228-240`: det=pass + LLM major fail → merged **review** only). Impact: the architecture's worst false-pass class (MC3/MC4 semantic damage with green metrics) survives CI if operators treat det pass as ship.

- [HIGH] **Anchorless Lane-3 table facts admit decoy-table false-pass.** When `table_heading` is absent, `_check_table` passes if **ANY** occurrence satisfies neighbor checks (`facts.py:381-423`); `test_canary_decoy_table_all_occurrences` proves a decoy table with `alpha→99` passes while the genuine `alpha→42` table exists (`test_facts.py:496-498`). Fail-closed ALL-semantics applies only with `table_heading` (`facts.py:377-380`). Impact: comprehension CI is exploitable on any paper whose facts omit `table_heading`; golden-grid (CLAUDE.md golden-hook) is the structural fix.

- [HIGH] **Advisory LLM lane confirms det fails but cannot block clean-pass exploits and still false-clears review in edge cases.** 2026-07-16 PR replay: all four new hard fails came from det, LLM confirmed (00-baseline.md:62-63). Conversely, p0957r8 monolithic judge returned pass/0.98 with page-13 content absent (`tapetum-golden-review-findings-2026-07-14.md:7-14`); fusion `llm_clear_soft_review` was blocked after fix when `missing_region_count > 0` (`fusion.py:177-190`, `test_fusion.py:383-388`), but det=pass + LLM pass on token-preserving corruption still yields merged pass. Empty-evidence pass at high confidence remains sanctioned (`tapetum-golden-review-findings-2026-07-14.md:90-92`). Impact: LLM adds localization, not a second mechanical gate.

- [HIGH] **Marker `heuristic >= 90` CI gate is evaded by reorder, duplication, and uncovered blocks.** CI blocks only on deterministic means heuristic ≥ 90 and TEDS ≥ 0.7, not LLM scorer (`00-baseline.md:26`, `05-web.md / Q1 / Marker CI gates heuristic only`). In-path LLM rewrites blocks but document output never aborts (`12-marker-analyst.md:12-13`, `:22-24`): failed units keep OCR output, `"No corrections needed"` preserves wrong tables (`llm_table.py:207-209` per 12-marker-analyst). Per-page presence checks reward duplicated prose (`19-false-pass-hunter.md:14`: content_recall ignores extras). Skip heuristics exclude oversized tables (>175 rows), images when `extract_images=True`, etc. (`12-marker-analyst.md:16`). Impact: a conversion that preserves most block text in wrong reading order or duplicates a page-7 paragraph can score ≥90 while permuting Table 2 headers (p0957r8-class defect, 12-marker-analyst.md:24-25).

- [HIGH] **olmOCR fact tests pass with fact-anchored text present but garbled elsewhere.** Bench gates on committed JSONL facts per `(pdf, page)` (`00-baseline.md:28`, `10-olmocr-bench-analyst.md:8-10`); ~7k tests over 1,400 pages ⇒ sparse coverage. `TextPresenceTest` uses fuzzy `partial_ratio` with length-relative threshold (`tests.py:168-173` per 10-olmocr-bench-analyst); `max_diffs > 0` matches decoy boilerplate in the wrong section (`10-olmocr-bench-analyst.md:26-27`). `TableTest` floor `max(0.5, 1.0 - max_diffs/len(cell))` accepts near-miss cells (`tests.py:395-396,442` per 10-olmocr-bench-analyst). `checked: verified` is stored but **not enforced at score time** (`10-olmocr-bench-analyst.md:18`). Pipeline never hard-fails a page — temp escalation → pdftotext fallback (`00-baseline.md:28`, `pipeline.py:329-332`). Impact: all verified facts green while un-tested pages carry scrambled prose or wrong table topology; same class as our unigram pass + missing facts.

- [MED] **Promoting LLM to mechanical gate closes almost none of the above and opens new ones.** Would catch some semantic/table defects IF every paper were judged with grounded evidence, but: (a) prompt injection — converted markdown is untrusted; adjudicate/pdf_judge wrap via `inject_untrusted` (`pdf_judge.py:492-496`, `adjudicate.py:418-449`) mitigates delimiter forgery, not rubric-bleed or instruction-following failures (`tapetum-golden-review-findings-2026-07-14.md:39-51`); (b) non-determinism — 05-web Q2 cites up to ~50% pass/fail flip at temp 1.0, residual bias at temp 0 (`05-web.md / Q2 / Temperature Control`); (c) position/self-preference bias (`05-web.md / Q2 / Position Bias`, `Self-Preference`); (d) overconfidence (`05-web.md / Q2 / Overconfidence`); (e) selection gap and fusion asymmetry mean a mechanical LLM gate would either run on all papers (flaky CI, 05-web Q1 TheoryDelta) or inherit the same blind spot. Ecosystem unanimous pattern: deterministic first, judge advisory (`05-web.md / Q4 / Deterministic Guardrails`). Impact: LLM-as-gate trades auditability for variance; does not subsume fact-based or structural gates.

- [LOW] **HTML heading-level corruption passes det + text-lane LLM.** Structure axis treats heading-level jumps as cosmetic (`tapetum-golden-review-findings-2026-07-14.md:60-74`, PR #282 pass/1.00 vs human request-changes in 00-baseline.md:82). Deterministic `heading_monotone` only catches skipped levels, not wrong level on a known section (`gates.py:96-112`). Impact: false-pass on HTML lane until source-outline diff (golden-qa-gap T3.3) lands.

## False-pass hypothesis

**Ours:** A WG21 PDF whose TOC leaks as `## 1. Scope ....... 5` (dot leaders) plus body `## 1. Scope`, with table column 2 swapped (`8`↔`80`) in one poll table. All six gates pass (TOC bypass verified above; `heading_monotone` intact; tables non-empty). `unigram_coverage` ≥ 0.95 (token-preserving). `--review-all` never selects the paper (`adjudicate.py:98-100`). Default tapetum run may escalate to review if LLM catches the table axis, but `whisker --gate pass` exits 0 on det pass and fusion cannot hard-fail (`fusion.py:228-240`).

**Marker equivalent:** Reorder text blocks so heuristic block-match NID stays ≥90 while permuting a table header row; LLM table processor returns `"No corrections needed"` on a cropped row batch that omits the header (`12-marker-analyst.md:24-25`). CI `verify_scores.py` heuristic gate passes (`00-baseline.md:26`).

**olmOCR equivalent:** Page 13 retains anchor strings covered by verified `TextPresenceTest` facts; adjacent paragraphs on the same page swap two proposal numbers. Fact pass-rate stays 100%; un-tested regions stay garbled (`10-olmocr-bench-analyst.md:26-27`).

## False-fail hypothesis

**Ours:** Faithful multi-column reflow: all words present, reading order reshuffled. Legacy shingle `coverage` would review-flood; current gate uses order-invariant `unigram_coverage` (`score.py:149-158`, `constants.py:21-38`) so reflow passes — **no false-fail** on this class post-scoring-v2. Remaining false-fail: cosmetic `heading_monotone` on papers where oracle emits H4 under H2 (`fusion.py:149-160` rescues to merged review, not pass).

**Marker:** Equation LLM rewrite rejected when corrected HTML `<30%` of OCR length despite valid condensing (`12-marker-analyst.md:28-29`); deterministic original kept — not a CI fail, but a missed fix.

**olmOCR:** `max_diffs=0` presence fact fails on smart-quote or hyphenation normalization mismatch despite semantically correct conversion (`10-olmocr-bench-analyst.md:30-31`).

## What would change my mind

A labeled adversary corpus (≥20 papers) where each exploit variant above is run through whisker det+tapetum+marker bench+olmOCR fact suite, reporting per-architecture false-pass rate with file:line anchors for any **new** bypass — if deterministic gates + sparse verified facts beat LLM-gated CI on false-pass rate **and** false-fail rate, verdict flips to **usable** without conditions.
