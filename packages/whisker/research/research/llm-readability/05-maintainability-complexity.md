# 05 - Maintainability-Complexity

**Verdict:** usable-with-conditions — the three-lane split and tapetum one-way import are sound, but copy-pasted table/fence parsers and lane-specific normalizers will drift as the comprehension corpus grows beyond 2 papers.
**Confidence:** high

## Findings

- [HIGH] Pipe-table detection is duplicated between Lane 2 and Lane 3 with divergent cell normalization. Evidence: `facts.py:261-295` (`_parse_pipe_tables`, comment "Mirrors the bench table detector") vs `bench.py:98-131` (`_extract_md_tables`); shared regex at `facts.py:73-74` and `bench.py:55-56`, but `facts.py:184-186` lowercases and collapses whitespace in `_norm_cell` while `bench.py:89-95` only `.strip()`s cells. Impact: a table-parser fix or GFM edge-case change applied in one lane silently leaves the other scoring different tables; Lane 2 TEDS and Lane 3 neighbor facts can disagree on the same markdown without any test catching the split (corpus: 2 papers, `00-baseline.md` line 77).
- [HIGH] `_TABLE_SEP_RE` and fence-skipping logic are replicated in four modules with no shared helper. Evidence: `bench.py:55-56`, `facts.py:73-74`, `gates.py:132`, `match.py:53` (fence only); `gates.py:32` uses a *different* `_FENCE_RE` capture pattern than the other three. Impact: the setext/HR false-positive guard documented at `gates.py:138-141` can be fixed in gates while bench/facts table extraction still mis-detects tables, producing contradictory pass/fail across lanes on the same file.
- [HIGH] Three lanes apply three incompatible normalization policies with no single policy module. Evidence: Lane 1 `normalize_for_exact_lane` (`golden.py:79-90`, line endings + trailing space only); Lane 2 `normalized_text` = `clean_string(textblock2unicode(...))` (`metrics.py:338-339`, strips markdown/LaTeX to alnum+CJK); Lane 3 `_math_surface` keeps `^ _ =` (`facts.py:173-181`) and `_norm_cell` for tables (`facts.py:184-186`); tapetum grounding reuses `normalized_text` (`grounding.py:39-44`). olmOCR-bench uses a single NFC/hyphen/quote normalization across all assertion classes (`05-web.md` Q1, https://github.com/allenai/olmocr/tree/main/olmocr/bench). Impact: threshold constants in `constants.py:37-38` encode content-recall semantics tied to `unigram_coverage`, but comprehension facts and golden diffs measure different surfaces; extending fact types (code/xref gap noted at `00-baseline.md` line 80-83) forces authors to guess which normalizer applies.
- [MED] `__main__.py` is an 804-line god-module owning every CLI subcommand, persistence, and exit-code contract. Evidence: module docstring lists six commands (`__main__.py:10-19`); file bundles score, bench, guard, golden, facts, calibrate, and menu dispatch. Impact: any lane change touches the same file as unrelated lanes; the library/CLI split invariant (`CLAUDE.md` "Library returns data; CLI persists") is correct in principle but the CLI surface resists incremental refactors as CI subcommands accumulate.
- [MED] `metrics.py` imports a private helper from `gates.py`, inverting expected layering. Evidence: `metrics.py:43` (`from whisker.gates import _split_front_matter`); helper defined at `gates.py:37-48`. Impact: heading-tree parsing (`mhs`) is coupled to gate internals; extracting front-matter splitting for reuse (e.g. shared with a future table module) requires editing both layers and risks import cycles if gates ever needs a metric.
- [MED] `table_parse_errors` and `lossy_table_count` are populated on `WhiskerResult` but never read in `_decide`. Evidence: fields stored at `score.py:67-68`, `249-250`; `_decide` hard/soft logic at `score.py:152-184` omits them; `tapetum_llm/constants.py:61-64` documents them as signals consumed only by the advisory candidate selector. Impact: core scoring and tapetum lane encode overlapping table-risk semantics in two places; a developer tuning table QA in tomd may assume whisker gates on these fields and ship a false sense of safety (`00-baseline.md` line 85-88: thresholds provisional, not fitted).
- [MED] PROVISIONAL threshold constants carry long rationale comments but no committed calibration artifact replaces them in the scoring path. Evidence: `constants.py:11-15`, `37-38` ("PROVISIONAL, pre-calibration"); `00-baseline.md` line 85-88; `whisker calibrate` exists (`__main__.py:841-844`) but baseline states edges are "not yet fitted on our own labeled corpus." Impact: rationale and live constants can drift apart across edits; reviewers cannot tell whether a comment still matches the number without re-running calibrate on labeled data.
- [LOW] `tapetum_llm/cli.py` reverse-imports from the core CLI god-module, weakening the documented one-way isolation. Evidence: `tapetum_llm/cli.py:30` (`from whisker.__main__ import _render_progress`); isolation invariant at `tapetum_llm/__init__.py:25-26` and `CLAUDE.md` line 409. Impact: refactoring `__main__.py` progress rendering breaks the optional advisory install; the dependency arrow points advisory→CLI instead of advisory→`report.py` or a tiny shared util.

## False-pass hypothesis

A maintainer patches `_TABLE_SEP_RE` in `gates.py:132` to stop setext underlines from tripping `no_empty_table`, but leaves the identical regex at `facts.py:73` and `bench.py:55` unchanged. A paper with a `---` thematic break above a pipe table now passes structural gates while `_parse_pipe_tables` still splits the table incorrectly; Lane 3 table facts miss the scrambled cell but `unigram_coverage` stays above 0.85 (`constants.py:37`), so the default whisker verdict remains pass.

## False-fail hypothesis

A corpus author adds a `present` fact whose anchor text includes markdown punctuation (e.g. `` `[` `` or `` `]` `` in a stable-name tag). Lane 3 evaluates via `normalized_text` (`facts.py:343`), which strips brackets through `clean_string` (`metrics.py:115-119`), so the fact fails even though the raw markdown contains the string and Lane 1 golden diff is unchanged.

## What would change my mind

A single shared `tables.py` (or equivalent) extracted from bench/facts/gates with one parametrized pytest matrix covering fence skip, separator detection, and cell-normalization modes, plus a committed calibrate output replacing the PROVISIONAL edges in `constants.py` with measured TPR/FPR — demonstrating that table semantics and threshold rationale stay aligned under change.
