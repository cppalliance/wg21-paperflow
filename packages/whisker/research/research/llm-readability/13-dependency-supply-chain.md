# 13 - Dependency-Supply-Chain

**Verdict:** usable-with-conditions — `uv.lock` pins exact versions for reproducible installs, but Lane 3 verdict-critical libraries (`rapidfuzz` alignment, `pylatexenc` folding) sit outside guard `tool_versions`, use loose pyproject floors, and lack regression tests on the alignment path that gates fuzzy facts.
**Confidence:** medium

## Findings
- [HIGH] **`rapidfuzz.partial_ratio_alignment` can silently flip Lane 3 fuzzy facts, and patch drift is allowed.** Evidence: `_best_match` uses `fuzz.partial_ratio_alignment` to locate the window, then a custom substring DP for the pass/fail decision (`facts.py:214-236`); pyproject floor `rapidfuzz>=3.14.5,<4` (`packages/whisker/pyproject.toml:17`); lock resolves `3.14.5` (`uv.lock:3355-3356`). `test_edit_distance_parity.py` freezes only `Levenshtein.distance`, not alignment (`packages/whisker/tests/test_edit_distance_parity.py:8-14`). Impact: a rapidfuzz patch that shifts `dest_start`/`dest_end` can change which window the DP sees and flip `present`/`absent`/`order`/`math` at the `max_diffs` boundary without any CI signal.
- [HIGH] **Guard baselines stamp `tomd`/`whisker` only; transitive scorer deps that feed comprehension are explicitly excluded.** Evidence: `_TOOL_VERSION_PACKAGES = ("tomd", "whisker")` with comment that transitive deps "rarely change markdown output and are deliberately not snapshotted" (`guard.py:67-73`); `collect_tool_versions()` gates on those two names only (`guard.py:76-88`). Impact: a lock refresh that bumps `rapidfuzz` or `pylatexenc` leaves guard green while Lane 3 verdict semantics drift, violating the determinism invariant in root `CLAUDE.md` for the comprehension gate.
- [MED] **`pylatexenc` is floor-pinned at 2.x with a 2021 lock snapshot; 3.x alpha introduces parser API breaks.** Evidence: `pylatexenc>=2.10` (`packages/whisker/pyproject.toml:16`); lock `2.10` upload 2021-04-06 (`uv.lock:3138-3140`); math facts fold via `textblock2unicode` in `_math_surface` (`facts.py:173-181`, `metrics.py:129-138`). pylatexenc 3 docs warn APIs "might still change" and deprecate macro parsing paths the 2.x `LatexNodes2Text` stack relies on (https://pylatexenc.readthedocs.io/en/latest/new-in-pylatexenc-3/). Web card: Unicode/LaTeX substitution degrades downstream math QA vs human judgment (https://arxiv.org/html/2512.09874v2, `05-web.md` Q5). Impact: even a 2.x patch that changes unicode folding can flip `math` facts and `present` checks that run through `normalized_text`, with no upper bound preventing accidental 3.x once it ships stable.
- [MED] **CI syncs from ranges, not a frozen lockfile.** Evidence: `.github/workflows/tests.yml:31` runs `uv sync --all-packages --group dev` without `--frozen`. pyproject allows wide floors on `numpy>=1.26`, `scipy>=1.11`, `lxml>=5.0.0`, `markitdown[pdf]>=0.1.6` (`packages/whisker/pyproject.toml:9-19`); lock currently resolves `numpy 2.4.6`, `scipy 1.17.1`, `lxml 6.1.0` (`uv.lock:1666-1667`, `2118-2119`, `3758-3759`). Impact: a maintainer `uv lock --upgrade` on main can land new resolver output without pyproject edits; comprehension CI may pass on different library builds than the SHA recorded in `00-baseline.md` item 9.
- [MED] **`apted` is maintenance-frozen since 2017 but load-bearing for Lane 2 TEDS/MHS.** Evidence: lock `apted 1.0.3` upload 2017-11-08 (`uv.lock:227-232`); used via `APTED` in `metrics.py:36-37` for table tree edit distance and heading hierarchy. PyPI shows no releases after 1.0.3 (https://pypi.org/project/apted/). Impact: no security or bugfix channel for a niche algorithm package; drift risk is low for Lane 3 (comprehension does not call apted) but high for bench/guard numeric rows that share the whisker install.
- [MED] **`grits-metric` and its `pylcs` transitive are niche, advisory-only, but unpinned above floor.** Evidence: `grits-metric>=0.6.0` (`packages/whisker/pyproject.toml:10`); lock `0.6.0` dated 2026-04-15 (`uv.lock:1157-1167`); pulls `pylcs 0.1.1` (`uv.lock:3144-3145`); used only for advisory `grits_con` in `bench.py:180-203`. Impact: does not gate Lane 3 comprehension (`00-baseline.md` item 32-33), but an unpinned upgrade could shift bench/advisory numbers and trigger unnecessary human review load.
- [LOW] **`mistune` pinning discipline is sound and aligned with tomd.** Evidence: `mistune~=3.2.0` in both whisker and tomd (`packages/whisker/pyproject.toml:13`, `packages/tomd/pyproject.toml:11`); lock `3.2.0` (`uv.lock:1962-1963`); shared AST renderer for MHS (`metrics.py:556-558`). Impact: major-version AST drift is blocked; MHS/heading scores stay comparable to tomd QA definitions.
- [LOW] **`markitdown` oracle has a deep transitive tree but does not gate comprehension.** Evidence: `markitdown[pdf]>=0.1.6` (`packages/whisker/pyproject.toml:12`); lock `0.1.6` with deps including `magika` → `onnxruntime` (`uv.lock:1823-1843`, `1762-1775`); oracle path is advisory per lane model (`00-baseline.md` item 35-37). Impact: markitdown drift can shift `ref_nid` review flags, not Lane 3 fact pass/fail, but expands supply-chain surface (ML runtime) for an optional signal.

## False-pass hypothesis
A rapidfuzz patch narrows `partial_ratio_alignment`'s reported window so `_substring_edit_distance` runs on a subspan that excludes a corrupted boundary character; a `present` fact with `max_diffs=2` passes even though the full phrase in the markdown is three edits away (`facts.py:229-235`, `test_present_fuzzy_within_budget_passes` in `packages/whisker/tests/test_facts.py:51-56` exercises the happy path only).

## False-fail hypothesis
A `pylatexenc` 2.x patch changes how `\text{...}` or superscripts fold to unicode; `_math_surface` lowercases the folded string (`facts.py:181`) and a verified P4185R0 math fact (4 math facts per `00-baseline.md` item 55-57) fails on byte-identical markdown because the normalized surface no longer matches the human-verified gold string.

## What would change my mind
CI running `uv sync --frozen` on every matrix job, plus guard `tool_versions` (or an equivalent lock hash) stamping `rapidfuzz` and `pylatexenc` at exact resolved versions, together with frozen golden vectors for `partial_ratio_alignment` window + `_best_match` outcomes in `test_facts.py`.
