# 03 - Determinism-Auditor

**Verdict:** usable-with-conditions (+ Lane 3 facts/gates/score/metrics/match are pure and ordering-stable; tapetum_llm advisory reruns are not reproducible under MoE serving and has one decide-path gap that lets an ungrounded pass stand)
**Confidence:** high

## Findings
- [CRITICAL] The tapetum_llm lane is explicitly non-deterministic across runs even with serial execution and sampling pins. Evidence: `packages/whisker/tests/test_tapetum_llm_eval.py:12` ("NOT a CI gate: the LLM is non-deterministic"); `packages/whisker/research/deepseek-v4-pro/00-baseline.md:237` (MoE batch-routing variance vs D1-D11); `packages/whisker/research/deepseek-v4-pro/SYNTHESIS.md` item 6 (49B/1.6T MoE expert routes can flip under shared-pod batch composition). Impact: advisory verdicts on the same paper can change run-to-run; they must never gate CI and cannot be treated as reproducible QA.
- [HIGH] Decide step does not demote a suggested `pass` when every evidence span fails grounding, so a confident but ungrounded pass survives unchanged. Evidence: `packages/whisker/src/whisker/tapetum_llm/adjudicate.py:237-240` (`if suggested_verdict != VERDICT_PASS and not grounded` — empty `grounded` is falsy but the guard only fires for non-pass); `research/llm-readability/00-baseline.md:71-76` (#277 blocking condition 1 still open). Impact: rerun variance plus this gap means an advisory "pass" may not be anchored to verifiable markdown spans; humans cannot trust repeatability of clears.
- [HIGH] Oversized-paper chunking sits near the long-context non-deterministic retrieval zone documented for DeepSeek-V4-Pro. Evidence: `packages/whisker/src/whisker/tapetum_llm/constants.py:44` (`MAX_PAPER_MD_CHARS = 500_000`); `packages/whisker/src/whisker/tapetum_llm/chunking.py:57-92` (H2 split, serial triage, aggregate); `research/llm-readability/00-baseline.md:100` ("long-context degradation past 128K non-deterministic"). Impact: ~6 corpus papers above the budget get per-chunk LLM calls where within-chunk retrieval misses can vary randomly across reruns, then fold through `aggregate_adjudications` (`chunking.py:154-220`).
- [MED] Table facts use first-match-wins cell location, so duplicate normalized cell text always resolves to the top-left occurrence regardless of author intent. Evidence: `packages/whisker/src/whisker/facts.py:313-323`; `research/llm-readability/00-baseline.md:49` ("First-match-wins cell location"). Impact: verdict is deterministic for a fixed markdown string but can be reproducibly wrong when duplicate cells exist; olmOCR's bench also uses first-match semantics (https://github.com/allenai/olmocr/tree/main/olmocr/bench) but the risk is real for merged/nested tables absent from the 2-paper corpus.
- [MED] Fuzzy `present`/`order`/`math` facts delegate window location to `rapidfuzz.partial_ratio_alignment` before the exact substring DP, so tie or near-tie alignments depend on library tie-breaking (pinned but not re-goldened on corpus). Evidence: `packages/whisker/src/whisker/facts.py:214-236`; `packages/whisker/research/persona/00-EVIDENCE-BASELINE.md:136` (`rapidfuzz>=3.14.5,<4`). Impact: Lane 3 stays deterministic at a fixed lockfile, but a rapidfuzz minor release could shift fuzzy fact outcomes without a comprehension-corpus canary catching it unless parity tests extend to `_best_match`.
- [MED] Chunked papers skip tier-2 escalation entirely, so ambiguous tier-1 confidence never gets a second model pass unlike single-chunk papers. Evidence: `packages/whisker/src/whisker/tapetum_llm/adjudicate.py:203-204` (`if state.chunked: return`); `packages/whisker/src/whisker/tapetum_llm/adjudicate.py:206-208` (tier-2 only inside `[CONFIDENCE_AMBIGUOUS_LO, CONFIDENCE_AMBIGUOUS_HI]`). Impact: structural ordering variance — same paper class can follow different adjudication paths based on size alone, not content quality.
- [LOW] Deterministic lanes sort or fix iteration order before output and avoid RNG/network/LLM. Evidence: `packages/whisker/src/whisker/score.py:111-112,219` (sorted flags, regions by `token_start`); `packages/whisker/src/whisker/facts.py:452-453` (neighbor directions sorted at load); `packages/whisker/src/whisker/tapetum_llm/chunking.py:184,192` (sorted axis keys on aggregate); `packages/whisker/tests/test_metrics.py:244-249`, `packages/whisker/tests/test_match.py:95-100`. Impact: the CI comprehension gate and whisker sidecar JSON are reproducible artifacts; this matches olmOCR's "strictly deterministic pass/fail" design (https://olmocr.allenai.org/papers/olmocr.pdf).
- [LOW] Per-paper tapetum cascade defaults to serial in-flight LLM requests (`default_concurrency=1`), matching D11; batch CLI concurrency only parallelizes independent papers. Evidence: `packages/whisker/src/whisker/tapetum_llm/adjudicate.py:409`; `packages/whisker/src/whisker/tapetum_llm/cli.py:39-45`. Impact: eliminates cross-request ordering variance on our side; does not fix MoE routing inside vLLM.

## False-pass hypothesis
A pipe table with two cells both normalizing to `"foo"` after `_norm_cell`: a `table` fact targeting the second `"foo"` and its `right` neighbor is evaluated against the first occurrence (`facts.py:313-323`), passes neighbor checks on the wrong row, and Lane 3 reports pass deterministically while the downstream LLM reads the other cell.

## False-fail hypothesis
None found in the deterministic lanes for identical inputs. In tapetum, a pass-tier paper with high `unigram_coverage` could receive `review` on rerun because MoE routing or long-context indexer misses flip axis findings (`00-baseline.md:100`, SYNTHESIS item 6) even though whisker core verdict and markdown are unchanged.

## What would change my mind
Ten consecutive `adjudicate_paper` runs on the same PID against a dedicated single-tenant pod (no foreign batch traffic), with bit-identical `TapetumResult.to_dict()` including `suggested_verdict`, sorted `axis_findings`, and grounded evidence lists — would downgrade tapetum from "intrinsically variable" to "serving-config dependent" and could flip the overall verdict to `usable` if the grounding gap at `adjudicate.py:237` were fixed first.
