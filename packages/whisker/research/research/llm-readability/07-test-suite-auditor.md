**Confidence:** high

## Findings
- [CRITICAL] The #277 blocking grounding gap at `tapetum_llm/adjudicate.py:237` has zero test coverage. Evidence: baseline finding 1; `adjudicate.py:237-238` only demotes when `suggested_verdict != VERDICT_PASS and not grounded`; `test_tapetum_llm.py:305-340` (`test_decide_grounds_and_builds_result`) uses axis verdict `"review"` with mixed evidence, and `test_tapetum_llm.py:72-85` (`test_hallucinated_quote_dropped`) tests `ground_spans` in isolation, never a confident overall `pass` whose evidence spans are all dropped. Impact: the suite can stay green while a hallucination-backed `pass` ships, exactly the advisory-lane false-pass baseline finding 1 flags.
- [HIGH] No test exercises merged, nested, or multi-row-header pipe tables against `_check_table`. Evidence: baseline finding 2; `facts.py:261-295` (`_parse_pipe_tables`) assumes a flat header row + body grid; `test_facts.py:17-28` and `test_facts.py:121-179` use one 3×3 toy table only; olmOCR table accuracy requires HTML for rowspan/colspan (https://github.com/allenai/olmocr/tree/main/olmocr/bench, 05-web.md Q1). Impact: table corruption classes TabVerse shows collapsing (cell lookup ~9.9%, 05-web.md Q2) can pass all 685 collected tests while Lane 3 cannot express or detect them.
- [HIGH] `max_diffs` boundary behavior of the free-start/free-end substring DP is not directly tested. Evidence: `facts.py:191-236` (`_substring_edit_distance`, `_best_match` with rapidfuzz window widen); `test_facts.py:51-63` checks present fuzzy at budgets 1 vs 2 on synthetic `_MD` but never calls `_substring_edit_distance`, never probes the rapidfuzz Indel window trim documented at `facts.py:219-220`, and has no `max_diffs>0` cases for `order`, `absent`, or `math` (grep: no matches in `packages/whisker/tests/`). `test_edit_distance_parity.py:25-48` covers full-string Levenshtein only, not substring DP. Impact: off-by-one at the budget boundary or alignment-window miss can fail readable markdown or pass corrupt text without a failing test.
- [MED] The CI corpus gate’s deliberate negative-path coverage is exactly two canaries on two papers. Evidence: baseline corpus size (2 members); `test_comprehension_corpus.py:77-116` (`test_canary_scrambled_table_cell_fails`, `test_canary_scrambled_formula_fails`) are the only tests that assert `report.failed` on corrupted committed snapshots; the parametrized positive at `test_comprehension_corpus.py:60-74` never injects defects. Negative engine cases live in `test_facts.py` on synthetic `_MD`, not in the corpus gate. Impact: a broken gate that always passes would be caught only for one table neighbor and one math relation on P4182R0/P4185R0; absent/order/present scramble paths and other fact ids are un-canaried.
- [MED] Canary strength is minimal: they assert `report.failed` plus one failing fact id, not selective failure. Evidence: `test_comprehension_corpus.py:94-95,115-116` stop after `any(c.id == ...)`; they do not assert other verified facts still pass on the scrambled substrate. Impact: an over-aggressive gate that fails everything (or mis-attributes failure) could still satisfy the canary if the targeted fact id appears in `failures()`.
- [MED] `test_invariants.py` and `test_claude_invariants.py` do not guard comprehension or tapetum adjudicate semantics. Evidence: `test_invariants.py:8-16` scopes to metric identity/symmetry on `teds`/`mhs`/`text_nid`; `test_claude_invariants.py:8-18` scopes to AST/front-matter/`print()` bans. Neither imports `check_facts` or `_custom_decide`. Impact: large refactors to `facts.py` or `adjudicate.py` can pass 685 tests while breaking the LLM-readability claims those modules enforce.
- [LOW] First-match-wins cell location in `_check_table` has no adversarial duplicate-cell test. - [LOW] Opt-in tapetum behavioral eval does not close the grounding gap and never runs in CI. Impact: pod-gated eval may catch axis blindness but cannot regress-fix baseline finding 1.

## False-pass hypothesis
A WG21 paper whose pipe table repeats a cell value (e.g. `"Yes"`) in two tables: a verified table fact targets the second occurrence’s neighbor graph, but `_check_table` first-match-wins at `facts.py:317-318` binds the first table; all tests pass because `test_facts.py` never places duplicate cell text in multiple grids and the corpus canaries scramble a unique GPU row string (`test_comprehension_corpus.py:87-88`).

## False-fail hypothesis
A present fact with `max_diffs=1` where rapidfuzz’s partial alignment window drops a boundary character that the free-start/free-end DP at `facts.py:191-211` would recover inside the widened window: `_best_match` returns `-1`, the fact fails, and no test catches it because `test_facts.py:51-63` uses a clean in-vocabulary typo (`polymorfic`) that does not exercise the Indel-trim path documented at `facts.py:219-220`.
