# 12 - False-Negative-Hunter

**Verdict:** usable-with-conditions — the hard gate catches gross truncation and structural breakage, but ~198/200 papers have zero Lane 3 facts, the 0.85 unigram floor is order-blind and unfitted, and tapetum_llm never gates and skips most clean passes; token-preserving semantic corruption (cell swaps, xref drift, math structure collapse, alt-text rot) can reach `pass` with no automated objection.
**Confidence:** high

## Findings

- [CRITICAL] **~198 converted papers have no comprehension coverage; Lane 3 vacuously passes when no verified facts exist.** Evidence: corpus **2 members** vs **~200 converted papers** (sighting run scored **196**) (`00-baseline.md:53-57`, `00-baseline.md:77-78`); `FactReport.passed` returns True when the enforced list is empty (`facts.py:129-130`). Impact: the CI comprehension gate (`test_comprehension_corpus.py`) exercises only P4182R0/P4185R0; every other paper ships on structural gates + unigram floor alone, with no deterministic fact check in the default path.

- [CRITICAL] **The hard gate is a multiset-presence test: reordering, cell swaps, and xref renumbering survive at full unigram score.** Evidence: `_decide` hard-fails only on gate failures and `unigram_coverage < UNIGRAM_COVERAGE_FAIL_EDGE` (`score.py:152-160`, `constants.py:37-38`); shingle `coverage` is explicitly never a verdict flag (`score.py:136-137`); reordered prose yields `unigram_coverage == 1.0` while shingle coverage collapses (`test_check_content.py:479-489`). Impact: a table whose cells are permuted but whose cell strings still appear somewhere in the document, or a `[P1234R5]` rendered as `[P1234R6]`, keeps the same token multiset and can remain `pass` at `uni >= 0.95`; downstream dissect/agora read wrong associations while whisker certifies content present.

- [CRITICAL] **`select_candidates` never samples pass-tier papers lacking its four risk signals, so tapetum_llm is blind to the cleanest false passes.** Evidence: PRIMARY population requires `lossy_table_count > 0`, `table_parse_errors > 0`, `mojibake_count > 0`, or `(unigram_coverage - coverage) > COV_UNIGRAM_GAP_TRIGGER` (`adjudicate.py:82-84`, `adjudicate.py:97-109`, `tapetum_llm/constants.py:59`); tapetum_llm is opt-in and **never gates** (`00-baseline.md:35-37`, `CLAUDE.md` tapetum section). Impact: a pass paper with a well-formed pipe table, zero mojibake, and a modest reflow gap (<15 pp) carrying a row/cell swap or garbled code block never enters the advisory lane; the sighting run found only **4** `pass -> review` rescues among **196** adjudicated papers (`tapetum-sighting-run-2026-07-01.md:73`), consistent with most false passes never being forwarded.

- [HIGH] **Token-preserving corruptions with no whisker risk signal and no tapetum PRIMARY trigger include: cell swap, xref revision drift, in-fence code reflow, math-surface collapse, and stable-name bracket damage.** Evidence: tapetum prompt names row/cell swap as "deterministic token gate is blind to this" (`tapetum_llm/tapetum_llm.md:76`); fact schema has **no `code`, `xref`, or `image-ref` type** (`00-baseline.md:80-81`, `facts.py:59-64`); `_math_surface` preserves `^ _ =` for Lane 3 math facts but the hard gate uses `normalized_text`, which strips math operators (`facts.py:173-181`, `score.py:227`). Impact: code indentation garbling inside a non-empty fence passes `gates.py:115-129`; bracket-label corruption and wrong paper revision letters are invisible to `_has_pass_risk_signals`; math exponent drops that leave tokens elsewhere can pass unigram while destroying recoverable structure.

- [HIGH] **`UNIGRAM_COVERAGE_FAIL_EDGE = 0.85` is provisional and mis-calibrated for semantic corruption detection.** Evidence: constants comment states edges are "PROVISIONAL, pre-calibration" and "not yet a value fitted on a labeled corpus" (`constants.py:11-15`); baseline finding #5 and `CLAUDE.md` Calibration status confirm borrowed DP-Bench/Docling norms with no measured TPR/FPR on WG21 output. Impact: up to **15%** token multiset loss is required before hard fail; the pass band (`>= 0.95`, no soft flags) still permits ~**5%** token loss (`constants.py:37-38`, `score.py:161-162`); olmOCR-Bench uses **7,010** deterministic assertions including table neighbors and KaTeX layout (`05-web.md` Q1, https://github.com/allenai/olmocr/tree/main/olmocr/bench), while whisker's reference-free path gates on a single borrowed scalar with no corpus fit.

- [HIGH] **Images and alt-text corruption are invisible to the gate chain; the judge reads markdown text only.** Evidence: tapetum adjudicates seven text axes including images only as `` `![alt](path)` `` syntax (`tapetum_llm/tapetum_llm.md:42`, `tapetum_llm.md:49-52`); no image or alt-text fact type exists (`00-baseline.md:80-81`); structural gates check fences/tables/headings only (`gates.py:153-161`). Impact: swapped, truncated, or hallucinated alt text while the path token survives passes every whisker check; ViTaB-A reports Markdown evidence-cell attribution **~13-42%** vs images **~33-53%** (`05-web.md` Q2, https://arxiv.org/pdf/2602.15769), so text-only QA cannot certify figure semantics for vision-less downstream readers.

- [MED] **Even when tapetum_llm runs, a confident `pass` with fully ungrounded evidence still stands (#277 blocking condition 1 open).** Evidence: `_custom_decide` demotes to `review` only when `suggested_verdict != VERDICT_PASS and not grounded` (`adjudicate.py:237-238`); baseline load-bearing finding #1 documents this as CRITICAL/blocking and unchanged (`00-baseline.md:71-76`). Impact: the advisory lane can affirm a false pass the gate already issued; because tapetum never gates CI, a human treating an unaudited advisory clear as permission to ship (`00-baseline.md:84-85`, **72** review->pass clears) compounds the false-negative risk.

- [LOW] **Lane 3 table facts use first-match cell location, weakening the only deterministic table check when it does exist.** Evidence: `_check_table` stops at the first normalized cell match (`facts.py:313-323`). Impact: duplicate cell strings in one paper can bind the wrong grid coordinates and pass a neighbor check against an unrelated table; irrelevant for the ~198 factless papers but shows the comprehension model's narrow expressiveness even on the 2-member corpus.

## False-pass hypothesis

A code-heavy WG21 paper (no facts file, never in tapetum PRIMARY because `lossy_table_count=0`, `table_parse_errors=0`, `mojibake_count=0`, and `unigram_coverage - coverage <= 0.15`) converts with two defects: (1) a wide pipe table where column B and column C values are swapped row-wise but every cell string still appears in the markdown, and (2) a fenced ` ```cpp ` block whose lines were reflow-wrapped so statement order and indentation no longer match the source, while identifiers and keywords remain in the token multiset. Whisker returns `pass` (`gates.py:115-129` sees a non-empty fence; `score.py:156-184` sees `unigram_coverage >= 0.95`; no risk signal in `adjudicate.py:97-109`). tapetum_llm is never invoked. dissect reads scrambled table associations and broken code structure as ground truth. TabVerse cell-lookup accuracy mean **9.9%** (`05-web.md` Q2, https://arxiv.org/html/2606.09578v1) illustrates why multiset gates miss exactly this failure class.

## False-fail hypothesis

A faithful multi-column reflow where heading levels jump H2→H4 once (WG21 PDFs often flatten nested outline levels) fails `heading_monotone` (`gates.py:96-112`) despite `unigram_coverage >= 0.95` and intact prose; this is a false fail, not a false pass, and is partially addressed by tapetum RESCUE population (`adjudicate.py:90-92`) but still blocks `--gate pass` CI.

## What would change my mind

A committed `calibrate` run on **30-50 human-labeled WG21 conversions** (including table-swap, code-garble, xref, math, and alt-text corruption injectors) that fits `UNIGRAM_COVERAGE_FAIL_EDGE` to max recall at FPR ≤ 10%, expands the comprehension corpus to cover the major paper classes baseline lists as missing (`00-baseline.md:78-79`), and shows tapetum PRIMARY selection forwarding ≥90% of injected token-preserving corruptions with audited precision on the **72** review->pass clears — demonstrating measured false-negative rate, not borrowed constants.
