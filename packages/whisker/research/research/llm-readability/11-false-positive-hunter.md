# 11 - False-Positive-Hunter

**Verdict:** usable-with-conditions — Lane 3’s olmOCR-style fact model is the right comprehension gate, but table cell matching, grid-neighbor coupling, absent substring checks, and the default oracle display layer still reject or over-review faithful conversions that downstream LLMs read correctly.
**Confidence:** high (code-path and P4182R0 anchor); medium on fleet-wide advisory rates (sighting-run counts in baseline are unaudited)

## Findings
- [HIGH] Table facts require an **exact** normalized match on the target cell; `max_diffs` applies only to neighbors, not to `fact.cell`. Evidence: `facts.py:311-317` (equality on `_norm_cell`) vs `facts.py:333-334` (Levenshtein budget for neighbors only). Impact: legitimate tomd cell polish (`**No**`, footnote markers like `[1]`, trailing punctuation) hard-fails verified `table` facts while semantics stay intact — the failure class the P4182R0 read-back was meant to prevent (`00-baseline.md:61-64`, `comprehension-poc-report.md:182-183`).
- [HIGH] `table` facts assert **pipe-grid geometry** (`left`/`right`/`heading`), not semantic column identity; column reorder that preserves row meaning still breaks neighbor checks. Evidence: `facts.py:328-334`; olmOCR allows HTML rowspan/colspan while whisker is pipe-only (`00-baseline.md:46-48`; olmOCR-Bench README https://github.com/allenai/olmocr/tree/main/olmocr/bench). TabVerse reports structural cell lookup near 10% even when QA stays moderate (https://arxiv.org/html/2606.09578v1). Impact: a correct, LLM-readable table reflow fails Lane 3 and `whisker guard` conjunctively (`anchors.py`/`facts.py` gate docs in `CLAUDE.md:47-48`).
- [HIGH] Cell location is **first-match-wins** across all pipe tables with no disambiguation. Evidence: `facts.py:313-323`; baseline notes first-match behavior (`00-baseline.md:49`). P4182R0 carries duplicate cell text `GPU device code (CUDA, SYCL)` at `P4182R0.expected.md:55` and `:81`. Impact: inserting a summary table or reordering tables can bind the fact to the wrong grid and fail neighbor assertions on an otherwise correct conversion.
- [MED] `absent` facts remain **substring presence** on `normalized_text` with no token boundary; residual over-strictness after the two calibration fixes called out in `CLAUDE.md:311-314` (ref_nid hard gate and shingle `coverage` gate) did not relax absent semantics. Evidence: `facts.py:345-348`; P4182R0 forbids `Document Number` (`P4182R0.facts.jsonl` / `facts.py:345-348`). Impact: prose that legitimately quotes or discusses the stripped PDF furniture label (`…the Document Number header was removed…`) collapses to a contiguous `documentnumber` hit via `metrics.py:118-126` / `facts.py:343` and fails — a correct conversion wrongly rejected.
- [MED] Default oracle overlay still trains operators on **`ovr=` noise** on clean papers: `ref_overall` averages `ref_nid` with oracle-noise `ref_teds`/`ref_mhs` (`score.py:213-215`) and the terminal line leads with `ovr=` (`report.py:72-76`) even though only `ref_nid` can soft-flag (`score.py:175-178`, `REF_NID_ADVISORY_EDGE` `constants.py:87`). P4182R0 (3× 8/8 read-back, `00-baseline.md:61-64`) still prints `ovr=0.308`, `nid=0.872`, `teds=0.029`, `mhs=0.024` with `uni=0.954`, `qa=100` (`comprehension-poc-report.md:167-183`; `CLAUDE.md:353-354` says trust `uni`, not `ovr`). Impact: review fatigue at ~200 papers — alarming headline metrics on conversions the stack itself documents as clean; sighting run added 72 unaudited review→pass clears (`00-baseline.md:65-66`).
- [MED] `order` facts use **document-global first-match** positions, not section-scoped reading order. Evidence: `facts.py:353-365`. P4182R0’s verified chain (`P4182R0.facts.jsonl`, phrases at `P4182R0.expected.md:13`, `:31`, `:43`, `:250`, `:387`) passes today, but an early forward-reference or TOC mention of a later anchor phrase inverts positions (`pos <= prev_pos` at `facts.py:361-362`). Impact: legitimate heading normalization or front-loaded cross-refs fail order facts on readable markdown.
- [LOW] `heading_monotone` hard-gates level skips (`gates.py:96-112`) independent of comprehension facts; tomd may flatten skipped PDF levels into a cleaner H2/H3 ladder (HiChunk validates heading-aware structure as LLM-friendly — https://aclanthology.org/2026.acl-long.1372/). Impact: cosmetic hierarchy normalization forces `fail` via `score.py:152-154` even when Lane 3 facts and LLM read-back would pass.
- [LOW] `anchors.py` `must_not_contain` duplicates the absent-fact substring class with **zero** edit budget (`anchors.py:143-147`), amplifying false fails when guard runs anchors conjunctively (`CLAUDE.md:47-48`). Impact: same quoted-label false fail as `facts.py`, but without `max_diffs` relief.

## False-pass hypothesis
none found

## False-fail hypothesis
tomd wraps a table cell as `**No**` (or appends a footnote `[1]` inside the cell) while keeping the correct row/column semantics; `_check_table` requires exact `_norm_cell` equality on the target (`facts.py:317`) with `max_diffs=0` on the cell itself, so `tableA-gpu-coro-no` hard-fails in `whisker guard` even though a blind LLM read-back still answers “No” for that row/column (the P4182R0 validation methodology in `00-baseline.md:61-64`).

## What would change my mind
A labeled sweep of the ~200 converted papers (`00-baseline.md:77-78`: 2 corpus members vs ~200 in paperstore) showing verified-fact false-fail rate <2% after applying olmOCR-style table normalization (NFC, markdown stripping — olmOCR paper https://olmocr.allenai.org/papers/olmocr.pdf) to `_norm_cell`, or fleet data proving `ovr=` sorting/leading display was removed and advisory `ref_nid` flags correlate ≥50% with human-needed fixes on holdout labels.
