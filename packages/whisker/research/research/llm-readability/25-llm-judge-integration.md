# 25 - LLM-Judge-Integration

**Verdict:** usable-with-conditions — the tapetum_llm cascade has sound demotion machinery for fails/reviews, but three #277 blocking conditions remain open four days later; the headline failure class (a confident advisory clear that tells a human not to look) has no code path that catches it.
**Confidence:** high

## Findings

- [CRITICAL] Blocking condition 1 (confident-pass grounding gap) is still unfixed. Evidence: `adjudicate.py:237-238` demotes only when `suggested_verdict != VERDICT_PASS and not grounded`; a `pass` whose every `evidence_span` was dropped by `ground_spans` still exits as `pass`. Baseline load-bearing finding #1 (`00-baseline.md:71-76`). Impact: hallucinated evidence is silently discarded while the advisory channel affirms clearance — indistinguishable from the prompt-sanctioned "pass with high confidence and empty evidence" (`tapetum_llm.md:99`), so operators cannot tell a verified faithful conversion from a guess that invented then lost its quotes.

- [CRITICAL] Blocking condition 2 (ground-truth the sighting run) has no completion artifact in-repo. Evidence: `tapetum-sighting-run-2026-07-01.md:27-28,69-73` lists 72 `review -> pass` clears as "suggested review targets" and "potential golds" only; baseline finding #4 (`00-baseline.md:84-85`); repo search finds no labeled mini-eval, no human-audit results file, no committed PID list with adjudicated labels under `research/` or `packages/whisker/research/`. Per-paper sidecars live in gitignored `data/whisker/` (`tapetum-sighting-run-2026-07-01.md:77-80`). Impact: the lane's primary advertised value — 72 human-review waivers — is prevalence, not measured precision; any false clear in that set is an unaudited "do not look" instruction.

- [CRITICAL] Blocking condition 3 (vLLM version/flags verification) is undocumented at the service declaration. Evidence: `SERVICES.toml:64-74` (`alliance-pod`) carries endpoint, model name, and context window only; grep finds no `v0.24`, `reasoning-parser`, `tokenizer-mode`, or `tool-call-parser` comments; no deployment manifest in the repo. #277 synthesis specifies target v0.24.0 with `--tokenizer-mode deepseek_v4 --reasoning-parser deepseek_v4 --tool-call-parser deepseek_v4` (`packages/whisker/research/deepseek-v4-pro/SYNTHESIS.md:21,35`). Impact: structured-output reliability (5 JSON failures in the sighting run, `tapetum-sighting-run-2026-07-01.md:52-56`) and thinking-block handling cannot be attributed to a verified serving config.

- [HIGH] No code path catches a confidently wrong `pass`. Evidence: demotion guards at `adjudicate.py:237-240` exempt passes from ungrounded demotion and only demote sub-`CONFIDENCE_DECISION_FLOOR` (0.50, `constants.py:28`); tier-2 never ran in the sighting run (0/196 escalations, `tapetum-sighting-run-2026-07-01.md:21-22`) because every tier-1 confidence landed outside `[0.35, 0.65]` (`constants.py:22-23`). Baseline abstention failure: V4-Pro 94% non-abstention (`00-baseline.md:99`). Q4 AbstentionBench: models issue definitive answers even when uncertain (https://arxiv.org/abs/2506.09038). Impact: the model's dominant failure mode (guess instead of abstain) lands in the one verdict slot with zero post-hoc audit.

- [HIGH] `CONFIDENCE_DECISION_FLOOR` is a weak guard against overconfidence. Evidence: floor at 0.50 (`constants.py:25-28`); sighting run produced 0 tier-2 escalations (`tapetum-sighting-run-2026-07-01.md:21-22`), implying nearly all confidences ≥ 0.65. Q4 Overconfidence in LLM-as-a-Judge: judges systematically overstate correctness; confidence-driven routing is the mitigation, not a scalar floor (https://arxiv.org/html/2508.06225v3). Impact: the floor fires only on under-confidence; combined with 94% non-abstention, wrong passes arrive at high self-reported confidence and sail through.

- [HIGH] Grounding is not strict verbatim matching and is vulnerable to both over-flag and false-ground. Evidence: `grounding.py:39-54` normalizes via `normalized_text` (OmniDocBench `clean_string(textblock2unicode(...))`, `metrics.py:338-340`) then accepts exact substring OR `partial_ratio >= EVIDENCE_FUZZY_FLOOR` (0.90, `constants.py:50`) against the **entire** document. Q4 span-level judge study: zero-shot judges localize poorly (best 0.22 span-F1, over-flag correct content; https://arxiv.org/html/2607.00895). Impact: invented short quotes can fuzzy-match unrelated regions (false grounding keeps a fail/review); real defects cited with paraphrased quotes are dropped (pass stands via the CRITICAL asymmetry); the inspect sidecar reports drop counts but not char intervals (`grounding.py:56` returns `(grounded, dropped)` only).

- [MED] Blast radius of the 72 `review -> pass` clears intersects the grounding gap but is not fully explained by it. Evidence: baseline counts 72 unaudited clears (`00-baseline.md:65-66`); prompt explicitly allows "pass with high confidence and empty evidence" (`tapetum_llm.md:99`), and decide-step docs codify the pass exemption (`tapetum_llm.md:156`). #277 synthesis estimates 25-45% of emitted evidence quotes fail grounding (`SYNTHESIS.md:12`). Impact: some fraction of the 72 clears may be legitimate empty-evidence passes; an unknown subset may be confident passes that lost all hallucinated spans — structurally identical in the sidecar schema (`models.py:106-124`, no `evidence_was_emitted` flag).

- [MED] Exact fix for blocking condition 1 is one branch in `_custom_decide`, plus a regression test. Evidence: #277 synthesis proposes (`SYNTHESIS.md:32`): after `ground_spans`, if `suggested_verdict == VERDICT_PASS and working.evidence_spans and not grounded: suggested_verdict = VERDICT_REVIEW`. Test gap confirmed: `test_tapetum_llm.py:305-340` exercises demotion on a `review` verdict only; no test covers confident `pass` with all spans dropped (`00-baseline.md` persona 07 cross-ref). Impact: implementable in minutes; without it the advisory lane cannot defend its pass channel against the documented hallucination rate.

## False-pass hypothesis

Whisker flags `review` on a table-risk signal (`select_candidates` PRIMARY population, `adjudicate.py:97-108`). DeepSeek-V4-Pro triages the paper, emits `pass` at confidence 0.91 with an evidence span quoting a paraphrased table cell that does not exist verbatim; `ground_spans` drops it (`grounding.py:54`), but `adjudicate.py:237` exempts `pass`. Sidecar reads `suggested_verdict: pass`, `ungrounded_dropped: 1`, `grounded_evidence: []`. Operator treats the 72-style clear as permission to skip human review. Downstream dissect reads the swapped cell. No lane — deterministic or advisory — catches it.

## False-fail hypothesis

A faithful conversion with minor whitespace or LaTeX folding differences causes the judge to emit a `fail` on the `tables` axis with a paraphrased quote. `ground_spans` drops the quote; `adjudicate.py:237-238` demotes the fail to `review`. Operator must review a clean paper. Separately, a short generic quote ("the following table") fuzzy-matches at `partial_ratio >= 0.90` (`grounding.py:51`) against unrelated prose, keeping a spurious fail grounded and blocking demotion — human chases a phantom defect (Q4 over-flagging, https://arxiv.org/html/2607.00895).

## What would change my mind

A ground-truth audit of 30 randomly sampled PIDs from the 72 `review -> pass` clears (human labels against source PDF/HTML, blind to tapetum reasoning) showing false-clear rate ≤ 5%, **after** blocking condition 1 is applied — would flip the verdict to `usable` for the advisory pass channel.
