# 30 - The Steelman

**Verdict:** usable-with-conditions — whisker is fit for purpose as deterministic, conservative CI triage for tomd conversions when the reference-free hard gate (`--no-reference`, default `--gate review`) is treated as "block broken artifacts, never silently ship missing content," not as an autonomous correctness oracle; the documented gaps (uncalibrated edges, review-heavy triage, empty in-repo GT lanes) are real but explicitly scoped, not hidden.
**Confidence:** high

## Findings

- [HIGH] **The hard gate is structurally conservative: only two ways to fail, and both are defensible.** Evidence: `_decide` hard-fails exclusively on structural gate failure or `unigram_coverage < UNIGRAM_COVERAGE_FAIL_EDGE` (`score.py:152-160`, `constants.py:37`); cross-converter `ref_nid` adds review only and "NEVER hard-fails" (`score.py:175-178`, `constants.py:74-79`). Runtime ref-free on 382 papers: **14 failed (3.7%), 205 review (53.7%), 163 passed (42.7%)** (`00-EVIDENCE-BASELINE.md` §3a). Impact: whisker errs toward human review over false pass on the verdict axis that matters for shipping — the design choice "review beats a false pass" (`CLAUDE.md:320`) is implemented in code, not marketing.

- [HIGH] **Deterministic, no-LLM scoring makes verdicts reproducible and auditable.** Evidence: `CLAUDE.md:278-280` (pure functions, sorted collections, no LLM/network/randomness); `WhiskerResult.to_dict()` sorts flags and rounds to 4dp (`score.py:86-112`); Persona 04 verified byte-identical re-runs on real papers. Test suite: **353 passed in 1.62s** (`00` §2). Impact: CI can re-run whisker on the same staged inputs and get the same sidecar JSON — a prerequisite for trustworthy QA that cloud-LLM pipelines cannot offer; 353 tests validate the *implementation*, and determinism validates the *contract*.

- [HIGH] **Lane 2 metrics are benchmark-faithful, not ad-hoc heuristics.** Evidence: `metrics.py:18-25` documents verbatim PubTabNet/OmniDocBench TEDS (lxml DOM → APTED, xpath-descendant denominator); `normalized_text` = `clean_string(textblock2unicode(text))` ported from OmniDocBench (`metrics.py:88-96`, `338-340`); `rapidfuzz` Levenshtein with frozen GPL parity vectors (`metrics.py:67-72`, `CHANGELOG.md` 0.5.0). Impact: when labeled `<pid>.gt.md` exists, `whisker bench` scores are comparable to published table/text leaderboards — whisker is wired into the same metrology ecosystem as OmniDocBench/DP-Bench, not inventing a private ruler.

- [HIGH] **Content gating separates "missing words" from "reflowed order," matching every major benchmark.** Evidence: shingle `coverage` is reported but never flags (`score.py:136-140`, `CLAUDE.md:219-229`); the hard gate runs on order-invariant `unigram_coverage` (`score.py:156-162`); prior design that hard-gated shingle coverage failed 43 correctly-reflowed papers (`CLAUDE.md:312-314`). Runtime: mean `unigram_coverage=0.966`, only **3/382** ref-free hard fails on content floor vs **9/382** on `heading_monotone` (`00` §3a–3c). Impact: the rare content-floor fails are the signal worth stopping the line for; multi-column reflow no longer masquerades as content loss — a principled fix that increases trust in the 3 genuine missing-content fails.

- [MED] **Epistemic humility is documented in code, not buried in footnotes.** Evidence: `constants.py:11-15` ("PROVISIONAL … not yet a value fitted on a labeled corpus"); `CLAUDE.md:37-44` ("Fidelity is not comprehension"); oracle overlay explicitly "agreement != correctness" (`score.py:142-147`, `constants.py:74-77`); `calibrate` workflow documented but never run (`00` §5). Impact: operators know what whisker can and cannot claim — a QA tool that admits "review beats false pass until labels exist" is more trustworthy than one that presents borrowed thresholds as calibrated precision.

- [MED] **A prior 28-agent red-team already hardened the regression guard and calibrator.** Evidence: `notes/redteam-synthesis.md` Tier 1 — seven real bugs fixed (baseline floors now authoritative, NaN/inf → `STATUS_INVALID`, inverted-band guard, schema/kind validation, duplicate-pid `ValueError`, `target_fpr` range check, symmetric 4dp rounding); CHANGELOG 0.5.0 adds `content_recall`, null-axis eligibility, facts lane, GPL→MIT swap. Impact: the per-paper regression path (`whisker guard`) inherited adversarial review from 28 external-repo audits — not greenfield optimism.

- [MED] **Three-lane architecture is the honest answer to "no perfect oracle."** Evidence: Lane 1 stability (`golden.py`), Lane 2 fidelity (`bench`/`guard`), Lane 3 comprehension (`facts.py`) explicitly non-interchangeable (`CLAUDE.md:21-44`, `CHANGELOG.md` 0.5.0); conjunctive anchors + verified facts hard-fail in guard when GT exists (`CLAUDE.md:46-48`). Impact: whisker does not pretend one score subsumes correctness — it partitions regression (diff), resemblance (TEDS/NID), and comprehension (human facts), which is architecturally sound even though `00` §4 shows the in-repo corpus is still empty.

- [LOW] **The fail tier is small and mostly actionable structural breakage.** Evidence: ref-free hard rollup — `heading_monotone` 9, unigram `< 0.85` 3, `no_empty_table` 2 (`00` §3a); gates catch truncated files, bad front matter, empty code fences, headless tables (`gates.py:8-14`, `153-161`). Impact: 3.7% hard-fail rate is a reasonable CI noise floor for catching broken artifacts; operators can `--gate review` (exit 0 on review) and treat only `fail` as merge-blocking (`CLAUDE.md:302-303`).

## False-pass hypothesis

A conversion that **drops one non-repeated paragraph or permutes a single table cell** while keeping `unigram_coverage >= 0.85` and passing all structural gates would **pass** the reference-free hard gate — plausible given only **3/382** content-floor fails and mean `unigram_coverage=0.966` (`00` §3a–3b, `score.py:156-160`). This is a real blind spot, but it is **scoped and acknowledged**: Lane 3 `facts` (`facts.py`, `CLAUDE.md:194-202`) and labeled `bench`/`guard` exist precisely because fidelity metrics cannot catch "row 3, column 2" errors (`CLAUDE.md:37-39`). For CI without GT, whisker's role is conservative triage, not exhaustive semantic proof — and the default review tier (54%) still routes most papers to human eyes.

## False-fail hypothesis

**P3941R2/R3/R4** fail ref-free with `uni=0.999`, `drift=0.001` **solely** on `heading_monotone` H2→H4 jumps (`00` §3c, `gates.py:105-109`) — almost certainly good conversions wrongly hard-failed on heading pedantry. Separately, any clean paper with **one** furniture-stripped region hits review via `REGION_SOFT_COUNT=1` (`score.py:164-166`, **186** occurrences `00` §3a) despite spec declaring regions "expected on clean papers" (`CLAUDE.md:233-236`). These are real false-burden costs, but they reinforce conservatism: whisker would rather send a good paper to review (or fail on structure) than pass a broken one — the operational fix is `--gate review` plus human triage discipline, not abandoning the gate.

## What would change my mind

A labeled holdout set (30–50 papers with human `{pass,fail}` verdicts) showing the reference-free hard gate's **false-pass rate exceeds 10%** on conversions humans would reject — i.e., `calibrate --labels` runs and the fitted edges still cannot meet a stated FPR budget (`00` §5, `calibrate.py:10-11`). That would flip this to **garbage** as an autonomous ship/no-ship gate. Conversely, one committed labels file plus a `calibrate` run recording TPR/FPR/precision, with ref-free hard fails correlating with human "broken" labels on the 3 unigram-floor cases and the 2 empty-table cases, would flip to **usable** unconditionally.
