# 20 - The Math / LaTeX Fidelity Expert

**Verdict:** usable-with-conditions — the text-axis normalizer deliberately erases superscript and operator structure (OmniDocBench fidelity, not comprehension); Lane 3 `math` facts are the designed fix but run on **0/382** papers, and runtime probes confirm several exponent-preserving corruptions score as identical on `normalized_text` / `ref_nid`.
**Confidence:** high

## Findings

- [CRITICAL] **`normalized_text` silently destroys superscript and most operator structure before any text-axis compare.** Pipeline is `clean_string(textblock2unicode(text))` (`metrics.py:338-340`). `textblock2unicode` folds only `$...$` and `\(...\)` when the inner fragment contains `\`, `^`, or `_` (`metrics.py:140`, `322-330`); `clean_string` then keeps `\w` + CJK only (`metrics.py:115-126`), stripping `^`, `=`, `/`, `$`, etc. Runtime: `$E = mc^2$` → `Emc2`; `$x^2$` → `x2`; `row 3 col 2 in A^T` → `row3col2inAT` vs `row3col2inA`. Impact: Lane 2 `text_nid` / oracle `ref_nid` (`score.py:208-212`) and block matching (`match.py:144`) measure alphanumeric skeleton agreement, not whether an LLM reads `mc²` vs `mc` or `A^T` vs `A`. Spec acknowledges this split (`CLAUDE.md:37-40`).

- [CRITICAL] **Lane 3 `math` facts are built but not operational on real data.** Corpus has only `EXAMPLE.facts.jsonl` (one template `math` row: `E = mc^2`, `00` §4); `whisker facts --corpus` errors with no staged candidates. `FactReport.passed` is vacuously true with zero verified facts (`facts.py:128-130`). Impact: the only surface that keeps `^`/`_`/`=` after pylatexenc fold (`facts.py:173-181`) never gates **382** converted papers; math fidelity is **0%** enforced in production.

- [HIGH] **Confirmed false-pass vectors on the text axis (runtime, 2026-06-25).** After symmetric `normalized_text`, these semantically distinct pairs collapse to **identical** strings: `$\sqrt{x}$` vs `$x$` → both `x`; `$\frac{a}{b}$` vs `$a/b$` → both `ab`; `$\begin{matrix}a\\b\end{matrix}$` (skipped by `_should_skip_inline_textblock_formula`, `metrics.py:299-311`) → both `beginmatrixabendmatrix`. `text_nid` = **1.000** on the matrix pair; sqrt/fraction **SAME** norm with nid **0.300–0.308** (length padding, not semantic signal). Impact: a conversion that drops `\sqrt{}` or `\frac{}{}` wrappers can still show green `ref_nid` / bench `nid` when both sides make the same collapse.

- [HIGH] **Display math and plain `$...$` without `\^\_` bypass pylatexenc entirely.** `_INLINE_REG` matches only `$...$` and `\(...\)` (`metrics.py:140`); `\[E=mc^2\]` is untouched by `textblock2unicode` (runtime: stays `\ [E=mc^2\]` until `clean_string` → `Emc2`). Inline `$E = mc$` (no caret/backslash in body) also skips the fold gate (`metrics.py:322`) and keeps dollar delimiters until punctuation strip. Impact: inconsistent folding across delimiter styles; cross-converter agreement can hide missing `\(...\)` vs `$...$` wrapping while both normalize to the same alnum blob.

- [HIGH] **`content_recall` / hard-gate `unigram_coverage` use a different path but still miss structural math.** `content_tokens` runs `textblock2unicode` then `\w+` split (`metrics.py:358-369`); superscripts become separate tokens (`$x^2$` → `['x','2']`, runtime). That catches *some* exponent drops (`['e','mc','2']` vs `['e','mc']`) but not sqrt (`['x']` vs `['x']`, **same**). Hard gate `unigram_coverage` comes from tomd `check_content.py` (`score.py:227-228`), which lowercases and `_PUNCT_RE`-strips `[^\w\s]+` (`check_content.py:219-227`) — also removing `^`/`=` — so source PDF `E=mc²` and markdown `E=mc` can share tokens `e`, `mc` if the exponent was never tokenized separately. Impact: **163/382** ref-free passes (`00` §3a) are not proof that formulas survived; corpus mean `unigram_coverage` **0.966** (`00` §3b) leaves headroom for token-preserving math corruption.

- [MED] **Lane 3 `present` facts share the text-axis blind spot; only `math` type uses `_math_surface`.** `present`/`absent`/`order` call `normalized_text` (`facts.py:343-358`); `math` calls `_math_surface`, which keeps `^`/`_`/`=` (`facts.py:350-352`, `173-181`). Runtime: `_math_surface('$E=mc^2$')` = `e = mc^2` vs `_math_surface('$E=mc$')` = `$e = mc$` → **DIFF** (would fail `test_math_missing_exponent_fails`, `test_facts.py:82-84`); but `normalized_text` on the same pair → `Emc2` vs `Emc` (also DIFF, nid **0.800**). Conversely, `present` cannot distinguish sqrt vs bare `x` (both normalize away structure). Impact: authors must use `type: math`, not `present`, for formulas; mis-typed facts inherit the fidelity axis limitations.

- [MED] **Unicode vs LaTeX superscript forms disagree on every axis.** Runtime: `$x^2$` → norm `x2`, unicode literal `x²` → norm `x²` (**DIFF**, nid **0.200**); `_math_surface` → `x^2` vs `x²` (**DIFF**); `content_tokens` → `['x','2']` vs `['x²']`. Impact: a correct pylatexenc fold to unicode superscript can trip advisory `ref_nid` / review against a `$x^2$` reference even when both are faithful — formatting divergence, not content loss.

- [LOW] **Unit tests prove the math fact primitive works in isolation, not corpus math coverage.** `test_textblock2unicode_folds_inline_latex` (`test_metrics.py:212-217`) and `test_math_structural_pass` / `test_math_missing_exponent_fails` (`test_facts.py:77-84`) cover `$E=mc^2$` and exponent typos on synthetic `_MD`. **353** passing tests (`00` §2) do not exercise WG21 papers with verified `math` facts.

## False-pass hypothesis

A WG21 paper defines `requirement: $\sqrt{n}$ is constexpr`. tomd converts to `requirement: $n$ is constexpr` (radicand dropped, common OCR/converter failure). markitdown oracle emits the same broken form. **`normalized_text` both sides → `requirementnisconstexpr` with sqrt tokens collapsed to `n`** (runtime sqrt probe); **`text_nid` / `ref_nid` = 1.0**; **`unigram_coverage` unchanged** (token `n` still present). Structural gates pass; **`verdict == pass`**. A verified `math` fact `{ "type": "math", "text": "√(n) is constexpr", "checked": "verified" }` would fail on `_math_surface` (`facts.py:350-352`); with **0** production math facts (`00` §4), whisker cannot catch it.

## False-fail hypothesis

tomd emits `$x^2$`; markitdown emits unicode `x²` in prose (pylatexenc-faithful). **`normalized_text` strings differ** (`x2` vs `x²`, runtime nid **0.200**); with oracle on, **`ref_nid < 0.85`** raises advisory review (`score.py:176-178`, mean ref_nid **0.836**, `00` §3b). Content is correct; whisker steers a human to a delimiter/unicode disagreement, not a missing exponent.
