# 10 - olmocr-bench-analyst

**Verdict:** usable — olmOCR-bench is the strongest open-source prior art for per-page, deterministic fact assertions (no LLM in the eval loop); its `(pdf, page, id)` fact unit, page-scoped MD input, and macro-average rollup map directly onto whisker's planned text-lane per-page judge rebuild.
**Confidence:** high

## Findings

- [CRITICAL] **Unit of scoping is a JSONL "fact" bound to `(pdf, page, id)`, evaluated against one page's markdown output.** `BasePDFTest` carries `pdf`, `page`, `id`, `type`, `max_diffs` (`olmocr/bench/tests.py:83-112`). The harness loads candidate files matching `{pdf_stem}_pg{page}_repeat*.md` and passes only that file's full text to `test.run(md_content)` (`olmocr/bench/benchmark.py:91-116`). Corpus closure requires every `(pdf, page)` pair to have at least one test or the benchmark exits (`benchmark.py:246-251`). README states facts are "very simple, unambiguous, and machine-checkable" at page level (`olmocr/bench/README.md:7-8`). Impact: the boundary is **page**, not whole document; multiple independent facts per page are first-class. Whisker already has per-page text via `extract_textlayer()` (`00-baseline.md:29-30`) but judges monolithically (`pdf_judge.py:222-327`); olmOCR proves the smaller unit.

- [CRITICAL] **Presence tests use normalized substring fuzzy match, not exact equality.** `TextPresenceTest.run()` normalizes both reference and candidate via `normalize_text()` (`tests.py:47-80, 150-154`), optionally lowercases (`tests.py:156-158`), optionally restricts to header/footer zones via `first_n` / `last_n` char slices (`tests.py:139-140, 160-165`), then computes `threshold = 1.0 - (max_diffs / len(reference_query))` (`tests.py:168`) and `best_ratio = fuzz.partial_ratio(reference_query, md_content) / 100.0` (`tests.py:169`). Pass when `best_ratio >= threshold` for `type=present` (`tests.py:171-173`). Default `max_diffs=0` on `BasePDFTest` (`tests.py:100`) means exact match after normalization unless JSONL overrides (e.g. `max_diffs: 2` in `sample_data/dataset.jsonl:3`). Impact: presence is **fuzzy partial substring**, length-relative tolerance; directly addresses our p0957r8 failure mode (exhaustive absence over 40k tokens) by shrinking the haystack to one page and one anchor string per fact.

- [HIGH] **Absence tests are the same class with inverted inequality.** `TestType.ABSENT` dispatches to `TextPresenceTest` (`tests.py:28, 789-790`). In the `else` branch, pass when `best_ratio < threshold` (`tests.py:177-179`); fail when fuzzy partial match meets or exceeds threshold (`tests.py:180-182`). Same `normalize_text`, zone scoping, and `fuzz.partial_ratio` as presence. Sample: header/footer strip assertion in `sample_data/dataset.jsonl:5` (`type: absent`). Impact: absence is **not** a separate algorithm; it is presence with flipped comparison. Safer than monolithic LLM "missing_content: []" because each forbidden string is an isolated binary check on one page.

- [HIGH] **Order tests use fuzzysearch near-match positions, not ratio scores.** `TextOrderTest.run()` normalizes content (`tests.py:212`), finds `before_matches = find_near_matches(self.before, md_content, max_l_dist=self.max_diffs)` and same for `after` (`tests.py:214-215`). Pass if any pair satisfies `before_match.start < after_match.start` (`tests.py:222-225`). `max_diffs` capped at 50% of each search string at construction (`tests.py:208-209`). Impact: order is **positional fuzzy substring**, not LLM reasoning about document structure; one fact = one before/after pair on one page.

- [HIGH] **Per-test → corpus aggregation is majority-over-repeats, then macro-average over JSONL strata.** Per stochastic OCR repeat: `test.run(md_content)` → binary pass (`benchmark.py:116-120`). Per test: `test_avg = repeat_passes / num_repeats`; final pass if `test_avg > 0.5` (majority) (`benchmark.py:125-126`). Per JSONL stratum: `pass_rate = passed / total` (`benchmark.py:346, 384`). **Corpus score:** `new_overall_score = sum(jsonl_pass_rates) / len(jsonl_pass_rates)` — mean of per-JSONL pass rates, **not** micro-average over all ~7k tests (`benchmark.py:380-388`; comment at `benchmark.py:44-45`). Bootstrap CI resamples within each JSONL category independently then averages category means (`utils.py:47-60`, `benchmark.py:328-330`). RLVR training reuses `test.run()` with micro reward `passed/total` or macro-average over `TestType` categories when `macro_average=True` (`grpo_train.py:638-656, 1153-1161`). Impact: whisker should adopt **worst-fact or macro-stratum** rollup, not unweighted mean over pages; precedent exists in `aggregate_adjudications()` (`00-baseline.md:34-35`).

- [MED] **Anti-hallucination is deterministic: no LLM in eval, schema gates, baseline degeneration checks, render-time math validation.** Eval loop is pure Python + `rapidfuzz` + optional headless KaTeX (`tests.py:10-11, 16-17`; README confirms no soft edit-distance primary metric at `README.md:10-11`). Load-time: `ValidationError` on empty pdf/id, invalid `max_diffs`, unknown `type` (`tests.py:104-112`); duplicate IDs rejected (`tests.py:860-865`). Missing page MD is hard fail `(test, False, "Missing MD files")` (`benchmark.py:95-101`). `BaselineTest` auto-injected per PDF lacking explicit baseline (`benchmark.py:241-244`): non-empty alnum (`tests.py:514-515`), blank-page `max_length` cap (`tests.py:503-512`), tail n-gram repeat via `RepeatDetector` with `max_repeats=30` default (`tests.py:520-526`), CJK/emoji rejection when `check_disallowed_characters` (`tests.py:528-543`). `MathTest.__post_init__` fails construction if `render_equation(self.math)` returns None (`tests.py:561-564`); runtime exact-string short-circuit then KaTeX geometric `compare_rendered_equations` (`tests.py:594-608`, `katex/render.py:414-549`). `TableTest` enforces `threshold = max(0.5, 1.0 - max_diffs/len(cell))` (`tests.py:395-396, 442`). **Gap:** `checked: verified` is stored (`tests.py:36-38, 101`) but **not** enforced at score time — all loaded tests run regardless (`benchmark.py:241-251`). Impact: strong per-unit grounding for whisker text-lane; human provenance gate is curation discipline, not runtime (contrast whisker `facts.py:484-489` intent).

- [LOW] **Sub-page region scoping exists only for presence/absence via char zones, not bounding boxes.** `first_n` / `last_n` slice normalized page text to header/footer windows (`tests.py:160-165`). Table/math/order/format/footnote facts operate on full page MD (or extracted table/math regions within it). No block-level PDF coordinates in bench tests. Impact: olmOCR scopes smaller than document but not smaller than page except header/footer char windows; block-level scoping would be novel on top of this pattern.

- [LOW] **148 engine meta-tests exercise the assertion layer** (`tests/test_tests.py`, 148 `def test_` methods at scan time). Impact: the fact engine is regression-gated independently of corpus size; whisker should match this depth for ported matchers.

## False-pass hypothesis

`TextPresenceTest` with `max_diffs > 0` on a long page: `fuzz.partial_ratio` can match a decoy substring in the wrong section (e.g. repeated boilerplate) while the intended context (Table 2 caption on page 13) is absent — same class of error as our p0957r8 monolithic pass, shrunk but not eliminated without tighter anchors or zone scoping (`tests.py:168-173`). `TableTest` with `threshold = max(0.5, ...)` can accept a near-miss cell in the wrong table when neighbor relations happen to align on a fuzzy 0.5 floor (`tests.py:395-396, 442-443`).

## False-fail hypothesis

Default `max_diffs=0` rejects present facts when `normalize_text` strips formatting the author expected to matter (bold/italic removed at `tests.py:54-65`) or when smart-quote folding (`tests.py:74-78`) diverges from converter output. `MathTest` construction raises `ValidationError` if KaTeX cannot render the reference equation (`tests.py:563-564`), rejecting the entire test definition before any candidate is evaluated — structurally correct TeX in markdown that `pylatexenc` accepts may still false-fail if Playwright/KaTeX render fails.

## What would change my mind

Discovering that `benchmark.py` runs any test against **whole-document** concatenated markdown rather than `{pdf}_pg{N}_repeat*.md` page files — a direct read of `process_test` (`benchmark.py:93-116`) refutes that; the page filter is explicit.
