# 15 - nougat-surya-analyst

**Verdict:** usable-with-conditions — both repos scope quality checks to the page (nougat) or page/block (surya) and persist per-unit failure explicitly, but neither performs LLM verification ("does X match Y"); adopt their deterministic degeneration guards and in-band failure markers for whisker's per-page judge, not their transcription-only prompt shape or surya's non-deterministic parallel inference.
**Confidence:** high

## Findings

- [CRITICAL] **Nougat unit = one PDF page image → one autoregressive decode.** Pages are rasterized in order (`nougat/dataset/rasterize.py:44-51`), fed through `LazyDataset` one index at a time (`nougat/utils/dataset.py:94-98`), batched with `shuffle=False` (`predict.py:156-160`), and each batch element calls `model.inference(image_tensors=sample, early_stopping=args.skipping)` (`predict.py:167-168`). Default `--skipping` is ON (`predict.py:74-77`: `--no-skipping` is the opt-out). Impact: direct precedent for whisker v1 page-scoped judge calls; the unit boundary is already drawn at the page raster, matching our `extract_textlayer()` per-page list (`00-baseline.md:28-31`).

- [CRITICAL] **Nougat per-page degeneration detection is logit-variance arithmetic, not n-gram scan.** Two mechanisms: (1) live `StoppingCriteriaScores` monitors max-logit variance-of-variance during decode; flatlines below `threshold=0.015` over `window_size=200` tokens trigger early stop (`nougat/model.py:442-474`, wired at `:606-608`). (2) post-decode check stacks per-step max logits (`:614`), computes sliding `varvar` over reversed per-token variance (`:621-627`), flags repetition when `varvar < 0.045` in consecutive windows (`:635-637`), truncates at computed `idx` and pads tail with pad tokens (`:638-647`). If degeneracy starts before token 30 (`small_var[0] < 30`), `idx=0` → whole-page out-of-domain reject (`:642-643`). Generation is greedy (`do_sample=False`, `:605`). A secondary string guard runs in postprocess: `truncate_repetitions` scans longest repeating tail (`nougat/postprocessing.py:102-165`, invoked at `:361`). Impact: portable pattern for tapetum — deterministic signal on generation statistics vetoes trust before any judge score; no second model required.

- [CRITICAL] **Nougat [MISSING_PAGE] markers are written into the output artifact, not dropped silently.** Three marker kinds: `[MISSING_PAGE_FAIL:n]` when `repeats[j] > 0` (truncated repetition, `:182-185`); `[MISSING_PAGE_EMPTY:n]` when `repeats[j] == 0` (out-of-domain/cover page, `:186-190`) or when postprocess emits bare `[MISSING_PAGE_POST]` (`:178-180`, produced by `remove_hallucinated_references` at `postprocessing.py:322-323`). Final document is `"".join(predictions)` written to `.mmd` (`predict.py:196-202`). API variant keeps partial output in `+++ ==WARNING: Truncated because of repetitions==` blocks instead of markers (`app.py:132-148`). Note: out-of-domain path uses inconsistent page index `i*args.batchsize+j+1` (`predict.py:190`) vs `page_num` elsewhere (`:180,185`). Impact: answers baseline C5 — failed units are visible in-band; whisker per-page judge should emit explicit page-level `status: error|missing` records into the sidecar, not absence.

- [HIGH] **Surya per-unit confidence is `mean_token_prob` from response logprobs; no accept/reject threshold in code.** Schema: "Mean of exp(logprob) across response tokens" (`surya/inference/schema.py:32-35`). Computed in `_mean_token_prob` (`surya/inference/backends/openai_client.py:52-67`), requested by default (`settings.py:70`, passed at `openai_client.py:85-96,118-128`). Propagation: layout assigns one page-level `confidence` to every `LayoutBox` (`surya/layout/__init__.py:97-125`); OCR block mode sets per-block `confidence=mean_token_prob` or degenerate sentinels — `error=True, confidence=0.0` (`recognition/__init__.py:226-237`), `skipped=True, confidence=1.0` (`:213-222`), success at `:241-252`; full-page mode copies page-level confidence to all parsed blocks (`:325-345`). CLI persists to `results.json` with `confidence`, `skipped`, `error` per block (`surya/scripts/ocr_text.py:33-42`, schema documented `README.md:155-167`). Impact: model for whisker sidecar fields; consumers are expected to threshold externally — surya never gates on confidence internally.

- [HIGH] **Surya text-line detection confidence is per-bbox heatmap score, dynamically thresholded.** Named constants `DETECTOR_TEXT_THRESHOLD=0.6`, `DETECTOR_BLANK_THRESHOLD=0.35` (`settings.py:112-113`). Per-image scaling via `get_dynamic_thresholds` (`surya/detection/heatmap.py:13-23`); boxes below scaled `text_threshold` are dropped (`:71-72`); surviving boxes get `confidence = line_max / max_confidence` (page-max normalization, `:103-109`). Impact: detection confidence is relative within a page — a uniformly weak page still shows a 1.0 top line; never normalize whisker lane confidence against the same document.

- [HIGH] **Surya per-page failure chain: deterministic guards veto then reroute, never silent accept.** Full-page OCR path (`recognition/__init__.py:260-376`): server error → per-page fallback (`:292-294`); empty output on blank page (`is_blank_region`, `common/blank.py:40-64`) → accept empty (`:300-301`); empty on non-blank → fallback (`:303-307`); `_detect_repeat_loop` on raw output (`:81-108`) → fallback (`:309-314`); parse exception → fallback (`:316-323`). Fallback = layout + block-mode OCR for affected pages only (`:350-366`). Inference retry ladder also re-calls on `detect_repeat_token` with bumped temperature up to 0.8 (`openai_client.py:141-202`). Layout drops text blocks over blank crops (`layout/__init__.py:103-115`). OCR-error classifier is raw `argmax`, no confidence (`ocr_error/__init__.py:47`). Impact: veto/reroute pattern matches whisker fidelity — deterministic checks cap the model lane; no weighted fusion.

- [MED] **Neither repo folds page-level quality into a document-level pass/fail gate during conversion.** Nougat inference concatenates all page strings (including markers) with no document abort (`predict.py:196-202`); eval-only aggregation computes per-metric corpus means over eligible pages (`test.py:79-84`, `metrics.py:27-44` minlen gate, stratum split at `:104-117`). Surya CLI writes per-file lists of per-page dicts to `results.json` with no composite verdict (`ocr_text.py:33-42`, `detect_layout.py:45-56`). Impact: document-level fold is entirely consumer responsibility; whisker must supply `aggregate_adjudications()`-style worst-unit policy ourselves (`00-baseline.md:34-36`).

- [MED] **Batch order is deterministic in nougat; surya preserves input order but parallel decode is not bit-identical.** Nougat: `shuffle=False` dataloader (`predict.py:159`), greedy decode (`model.py:605`), serial page counter (`predict.py:165-177`), PDF pages rasterized in `page_indices` order (`rasterize.py:44-51`). Surya: `page_range` deduplicated and sorted (`scripts/config.py:95-97`), images loaded in page-index order (`input/load.py:22-31`), but `chat_completions_batch` uses `ThreadPoolExecutor` with `max_workers=SURYA_INFERENCE_PARALLEL` (default 8, `settings.py:58`, `vllm.py:205`) and retries with increasing `temperature` (`openai_client.py:190-191`); `executor.map` returns outputs in batch input order (`:212-213`) so page ordering in results is stable, but token-level output can vary across runs. Impact: nougat aligns with whisker D5/D11 serial determinism; surya's parallel+retry path is a cautionary counterexample for tapetum per-page judge dispatch.

## False-pass hypothesis

A 33-page paper where page 13 degenerates into a tail-repetition loop but the loop text is mostly valid words from earlier pages. Nougat's logit-varvar check fires only when variance flatlines (`model.py:635`); if repetition starts late enough that `idx/N <= 0.9` (`:639-640`), `repeats` stays `None` and the page ships truncated markdown with no `[MISSING_PAGE_FAIL]` marker. Whisker per-page judge comparing only that page's text-layer chunk to its markdown chunk could false-pass because repeated content is "present" in both sides. Surya would catch the same failure via `_detect_repeat_loop` and reroute (`recognition/__init__.py:309-315`).

## False-fail hypothesis

A valid cover page or publisher front matter that is visually unlike arXiv training pages. Nougat's out-of-domain branch (`small_var[0] < 30` → `idx=0`, `model.py:642-643`) maps to `[MISSING_PAGE_EMPTY:n]` (`predict.py:186-190`), replacing the entire page with a marker even if partial output was usable. Whisker per-page judge treating any `MISSING_PAGE_*` marker or empty page as automatic `fail` would false-fail an otherwise faithful conversion where only the cover page is unrepresentative — surya's analog is accepting empty output when `is_blank_region` is true (`recognition/__init__.py:300-301`) rather than failing the document.

## What would change my mind

Evidence that nougat's logit-varvar guard false-negates on our vllm_thinking tapetum backend (no `output_scores` / per-step logits exposed through pydantic-ai), leaving only the weaker `truncate_repetitions` string guard — that would downgrade nougat's contribution to marker-persistence only and shift the per-page judge design toward surya-style output-text repeat detection (`recognition/__init__.py:81-108`) as the primary degeneration axis.
