# 20 - False-fail hunter

**Verdict:** usable-with-conditions — per-page judging fixes the monolithic false-pass (p0957r8) but worst-page-wins plus verbatim presence checking will inflate advisory review/fail on faithful conversions unless each page call inherits the full conversion contract, olmOCR-style length-relative fuzzy floors, and aggregation demotion (empty-page skip, benign-page fold, document-level recall gate only).
**Confidence:** high

## Findings

- [CRITICAL] **Worst-page-wins multiplies per-page noise into document-level review at WG21 page counts.** Evidence: planned aggregation mirrors `aggregate_adjudications()` worst-axis / min-confidence fold (`chunking.py:226-259`); p0957r8 is 33 pages (`pdf_judge.py:369`, `00-baseline.md:9`). Math: if each page independently false-flags review with rate `p`, document false-review rate is `1 - (1-p)^n`. For `n=33`: `p=0.02` → **48.6%** doc review; `p=0.01` → **28.1%**; to cap doc review at **10%** need `p ≤ 0.0032` (~0.32%/page); at **5%** need `p ≤ 0.0016`. Impact: a design that fixes one 3% false-pass on 33-page papers can trade it for ~28% false-review if per-page precision is only 99%.

- [CRITICAL] **Page 1 title-block → YAML front matter is the highest-density false-fail unless the per-page prompt re-sanctions it.** Evidence: monolithic `JUDGE_SYSTEM_PROMPT` explicitly maps title block to YAML keys and forbids flagging (`pdf_judge.py:117-123`, `151`); tomd contract: page-0 metadata → front matter (`tomd/CLAUDE.md:234`). Per-page scope exposes only page-1 raw text (`Document Number: P3556R0`, dates, reply-to) against full markdown where those strings live under `---` not in body. Lane 3 encodes the same invariant as an `absent` fact: label `"Document Number"` must NOT leak into body (`comprehension-poc-report.md:99`). **p3556r0 does NOT prove the det missing_region pattern:** golden review records det **pass**, zero missing regions, fusion agree (`tapetum-golden-review-findings-2026-07-14.md:129,147-149`) — the risk is architectural, not observed on that paper. Impact: without per-page prompt inheritance, page 1 false-fails **every** paper on every run.

- [HIGH] **TOC-only pages false-fail presence checks because tomd deliberately removes the TOC.** Evidence: sanctioned in `JUDGE_SYSTEM_PROMPT` (`pdf_judge.py:124-126`); tomd strips TOC via exact + fuzzy heading match (`tomd/CLAUDE.md:16`, `lib/toc.py`). Raw text layer on a TOC page still lists dotted entries and page numbers; converted markdown has body headings only. A page-scoped judge comparing page `k` raw TOC lines to full markdown will quote `"2.1 General .............. 3"` as missing. Impact: multi-page TOCs (common on 20+ page wording papers) add guaranteed false-review pages under worst-page-wins.

- [HIGH] **Reflow/dehyphenation/LaTeX folding defeat verbatim presence unless fuzzy matching matches olmOCR bench semantics.** Evidence: contract allows unwrapped prose and dehyphenation (`pdf_judge.py:141-143`); judge requires missing quotes **verbatim from RAW PDF TEXT** (`pdf_judge.py:148-151`) with grounding against raw layer (`pdf_judge.py:326-332`). olmOCR bench normalizes both sides (NFC, hyphen/quote fold, markdown strip, whitespace collapse) then uses length-relative tolerance `threshold = 1.0 - (max_diffs / len(reference_query))`, default `max_diffs=0`, table floor `max(0.5, threshold)` (`research/redteam/olmocr.md:27-28,39,264-265`; `research/llm-readability/05-web.md:21-29`). Our tapetum grounding uses whole-document `partial_ratio >= 0.90` (`grounding.py:39-52`, `constants.py:67`) — wrong shape for page-local presence. Lane 3 `facts.py` uses rapidfuzz alignment + bounded edit budget `_present_within(..., max_diffs)` (`facts.py:299-326`) — closer portable precedent. Impact: faithful conversions flag `"implementa-"` / `"tion"` splits, `$x^2$` vs folded unicode, pipe-table vs raw column gaps.

- [HIGH] **Cross-page paragraph joins leave truncated raw tails on page N that look like missing content.** Evidence: tomd joins pages when last block lacks terminal punctuation and next starts lowercase (`tomd/CLAUDE.md:231-232`); p3556r0 shows the pattern: raw-style break `"listed in"` / `"Table 1 to try..."` across the page boundary (`snapshots/p3556r0.md:442-444`). Page-scoped raw for page N ends mid-sentence; full markdown contains the joined sentence once. Judge asked "is this page's content in markdown?" may quote the dangling tail. Impact: every cross-page join site is a false-fail candidate; WG21 papers routinely join (`cleanup.py` cross-page join in pipeline).

- [HIGH] **Figure/diagram text in the raw layer is legitimately imaged — the inverse of p0957r8 page 13.** Evidence: p0957r8 false-pass was captions/tables **present in raw, absent from md** (`00-baseline.md:11-13`, `tapetum-golden-review-findings-2026-07-14.md:9-14`); golden md **does** carry `![Figure 1...](p0957r8-fig13-1.png)` plus caption prose (`snapshots/p0957r8.md:452-456`). Reverse case: vector/raster figures embed axis labels, code tokens, `(a)/(b)` sub-labels in PDF text layer; tomd renders `![alt](path)` and drops in-diagram text (`tomd/CLAUDE.md:94-104`, p3556r0 flow diagram → `> **[Figure: Flow Diagram]**` placeholder at `snapshots/p3556r0.md:46-49`). Per-page judge sees diagram fragments in raw, no verbatim match in md. **Caption vs dropped-caption distinction** requires sanctioning "text inside rendered figure" or checking alt/caption band — not naive presence. Impact: papers with vector figures (`--extract-vector-images`) accumulate false missing-content quotes on figure pages.

- [MED] **Header/footer stripping is skipped on short papers (<3 pages), leaving page furniture that per-page checks treat as content loss.** Evidence: `_MIN_PAGES_FOR_HEADER_DETECTION = 3` — normalization skips repeated-line detection below that (`textlayer.py:60-62`, `144-160`); monolithic prompt says furniture is expected noise (`pdf_judge.py:109-110`, `127-128`). Administrative 1–2 page papers (N5034-class, `00-baseline.md:81`) keep running titles in per-page raw; markdown drops them by design. Impact: low page count does not reduce worst-page-wins exponent, but increases per-page false-flag rate on cover pages.

- [MED] **Full-markdown injection + page-local raw asymmetry flags content that moved globally (caption dedup, section reorder within md).** Evidence: plan is one call per page with **full** md (`00-baseline.md` research question); tomd drops duplicate caption sections when alt already captured (`tomd/CLAUDE.md:103-104`); table prose may move from raw page to HTML `<table>` elsewhere. Page judge still hunts verbatim page-N strings globally — finds relocated content but may mis-classify as "reordered" (`pdf_judge.py:116`). Impact: review noise on figure/table pages even when content exists; cheaper fix than fuzzy: prompt clause "content anywhere in markdown satisfies page-N presence."

## False-pass hypothesis

Per-page judging with full markdown injected may **false-pass** p0957r8-style defects when the dropped content physically lives on page 13 but the model checks page 12 and 14 thoroughly while page 13's call under-attends (same attention lottery, smaller raw window). Mitigation already planned: worst-page-wins + deterministic `content_recall` demotion (`pdf_judge.py:340-345`) — but recall was 0.9806 on p0957r8 (above 0.85 floor), so document-level recall alone does not catch localized drops; need page-attributed recall or det `missing_region_count` fusion block (`fusion.py:174`, `tapetum-golden-review-findings-2026-07-14.md:28-29`).

## False-fail hypothesis

**N5036-class 13-page paper, page 1:** raw text layer contains `Document Number: N5036`, date lines, and audience; markdown has YAML front matter only. Per-page judge (without inherited YAML sanction) returns `review`, quotes `"Document Number: N5036"` in `missing_content`; worst-page-wins forces document `review` despite faithful conversion. Same run: page 2 TOC lines false-flag; page with vector figure false-flags axis labels; aggregation never demotes because each page carries grounded quotes (`ground_spans` verifies against raw, not against sanction list).

## What would change my mind

A labeled replay on ≥30 golden PDFs (including p3556r0, p0957r8, p1068r11, short admin papers) measuring **per-page false-review rate** with the planned prompt+aggregation, showing **≤0.3%/page** (so 33-page doc stays ≤10% doc-level review) while still catching p0957r8 page-13 gaps. That would flip verdict to **usable** without the fuzzy/aggregation caveats.
