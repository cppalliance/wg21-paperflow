# 18 - aggregation-statistician

**Verdict:** usable — surveyed repos confirm no single dominant LLM-judge aggregation standard; the closest prior art to our planned per-page fold is our own `aggregate_adjudications()` (worst-unit + min-confidence + union evidence), with docling's axis-specific reducers (especially `parse_score` = 10th-percentile over pages) as the best cross-repo numeric-confidence analogue.
**Confidence:** high

## Findings

- [CRITICAL] **Planned whisker per-page fold (baseline intent): worst page, conservative confidence on failing pages only, union missing_content with page provenance.** Baseline cites existing chunk precedent: `aggregate_adjudications()` folds worst axis (severity-aware via `worst_axis_verdict`), `confidence = min(a.confidence for a in parts)` over **all** parts, and deduped union of `evidence_spans` (`packages/whisker/src/whisker/tapetum_llm/chunking.py:226-292`, `:106-123`). Per-page rebuild extends sibling reports: **overall = worst page verdict** (worst-page-wins, `research/per-page-judging/20-false-fail-hunter.md:8`, `11-olmocr-pipeline-v2.md:18`); **confidence = min over non-pass pages only** (variant: current chunk fold poisons confidence from a single shaky pass-chunk at `:259`); **missing_content = union across pages with page index on each quote** (provenance contract in `research/vlm-pdf-qa/opus-C-engineering.md:110`). Impact: this is stricter than docling mean grades and olmocr error-rate tolerance, aligned with fidelity (one localized absence fails the paper).

- [CRITICAL] **olmocr production: error-rate threshold on fallback pages, not worst-page-wins; single bad page rarely fails the document.** After parallel per-page VLM (`pipeline.py:548-554`), `num_fallback_pages = sum(page_result.is_fallback ...)` (`:557`). Document discarded only if `num_fallback_pages / num_pages > args.max_page_error_rate` (`:559-563`); default **`max_page_error_rate = 0.004`** (1/250, `:1222`). Otherwise concatenates all page `natural_text` via `build_dolma_document` (`:602-651`) with char-span provenance `pdf_page_spans` (`:605-617`, `:643`). Exhausted retries → `make_fallback_result` (pdftotext) with `is_fallback=True`, `is_valid=True` (`:233-249`, `:371-375`). **Confidence:** none at page or doc level (only `is_valid`, `is_fallback`, token counts in metadata `:628-630`). **Single bad page:** one fallback page in a 33-page doc passes (0.03 > 0.004 fails only at ≥9 fallbacks/250 pages). **Provenance:** per-page spans and attribute lists (`is_table`, `is_diagram`, etc.) survive in Dolma output (`:642-649`). Impact: opposite of whisker fidelity; copying olmocr yield policy would false-pass VLM failures (`research/vlm-pdf-qa/20-olmocr-pipeline-analyst.md:18`).

- [HIGH] **olmocr-bench: binary per-fact pass, majority-over-repeats, macro-average over JSONL strata (not micro-average over all tests).** Each `(pdf, page, id)` fact runs against one page MD file (`benchmark.py:91-116`). Per repeat: binary pass (`:116-120`). Per test: `test_avg = repeat_passes / num_repeats`; **pass if `test_avg > 0.5`** (majority, `:125-126`). Per JSONL file: pass rate = passed/total (`:346`, `:384`). **Corpus score:** `new_overall_score = sum(jsonl_pass_rates) / len(jsonl_pass_rates)` — mean of stratum pass rates, not fraction of all ~7k tests (`:380-388`, docstring `:11`). **Single bad unit:** one failed fact lowers its stratum rate; does not veto the whole PDF unless all facts on that page fail. **Confidence:** bootstrap CI only (`utils.py:6-60`), not folded into pass/fail. **Provenance:** `test_results[pdf_name][test.page].append((test, final_passed, explanation))` (`:130`). Impact: portable pattern for Lane 3 facts; for LLM judge use worst-fact/page fold, not olmocr macro mean (`research/per-page-judging/10-olmocr-bench-analyst.md:16`).

- [HIGH] **docling: axis-specific document reducers; parse uses 10th-percentile (worst-tail), layout/OCR/table use mean; grades advisory only.** **Page-level:** `parse_score` = `np.nanquantile(text_scores, q=0.10)` over PDF text cells (`page_preprocessing_model.py:85-88`); `layout_score` = `np.mean([c.confidence for c in processed_clusters])` (`layout_model.py:233-235`); `ocr_score` = mean OCR cell confidences (`:237-239`). Page `low_score` = `np.nanquantile([ocr, table, layout, parse], q=0.05)` (`base_models.py:595-605`). **Document-level** after all pages (`standard_pdf_pipeline.py:1068-1087`): `layout_score`/`table_score`/`ocr_score` = **`np.nanmean`** over pages; **`parse_score` = `np.nanquantile(..., q=0.1)`** with comment "worst 10% of pages" (`:1073-1077`). Doc `mean_score` = mean of page `mean_score`; doc `low_score` = mean of page `low_score` (`base_models.py:657-673`). **Grade constants:** POOR `<0.5`, FAIR `<0.8`, GOOD `<0.9`, EXCELLENT `>=0.9` (`:557-565`). **Single bad page:** one terrible parse page enters the 10th-percentile tail (1/33 ≈ 3rd percentile) but conversion **status never gates on grades** (`research/per-page-judging/13-docling-analyst.md:16`). **Provenance:** `ConfidenceReport.pages[page_no]` retained; exported to `confidence.json` (`document.py:382`, `:466`). Impact: adopt **parse-style tail reducer** for absence-sensitive LLM axis; do not adopt mean-only doc grades for pass/fail.

- [HIGH] **marker block-level: per-unit accept/reject with keep-original; no document verdict fold.** Each LLM processor compares block image + extraction; on failure increments `llm_error_count` and **returns without mutating** (`llm_table.py:201-203`, `:227-238`; pattern across `llm_form.py:98-110`, `llm_equation.py:110-125`, `llm_complex.py:73-85`). **Accept gates:** `"no corrections needed"` → no-op (`llm_table.py:207-209`); table self-score **`score < 4`** triggers retry up to **`max_table_iterations=2`** (`:215-218`, `:218`). Structural rejects: `len(parsed_cells) <= 1`, missing `</table>` (`:228-237`). **Page metadata fold:** `aggregate_block_metadata()` **sums** `llm_request_count`, `llm_error_count`, `llm_tokens_used` across blocks (`page.py:360-367`, `base.py:24-29`); exposed in `generate_page_stats` (`renderers/__init__.py:106-113`). **Document:** conversion always completes; no worst-block veto (`research/per-page-judging/12-marker-analyst.md:20`). **Benchmark `LLMScorer`:** page 0 only, 96 DPI (`llm.py:101-102`), returns `response["overall"]` 0-5 (`:131-133`); empty markdown → score 1 (`:109-115`); no multi-page aggregation. Impact: portable **reject-and-keep** unit gates; not a document adjudication policy.

- [HIGH] **nougat: inline `[MISSING_PAGE_*]` markers per failed page; document = ordered concat, no numeric verdict fold.** On failure: `[MISSING_PAGE_FAIL:{page_num}]` when `repeats[j] > 0` (`predict.py:182-185`); `[MISSING_PAGE_EMPTY:{page_num}]` on early-stop/domain mismatch (`:180`, `:188-190`); postprocess `[MISSING_PAGE_POST]` (`postprocessing.py:323`). Successful pages append raw transcription (`predict.py:192-195`); doc output `"".join(predictions)` (`:197`). **Constants:** repetition guard `varvar < 0.015` (generation), `varvar < 0.045` (post-decode) (`model.py:443`, `:635` per prior research). **Single bad page:** marker embedded in output; does not abort other pages. **Confidence:** none (logits heuristics only). **Provenance:** page number in marker string survives in `.mmd`. Impact: provenance-preserving failure markers portable to sidecar; not a pass/review/fail reducer.

- [MED] **MinerU / Dolphin: append-all-pages assembly, no worst-page veto, partial fail-forward.** MinerU: per-page results appended to `middle_json["pdf_info"]`, then `union_make` concatenates with `'\n\n'.join(output_content)` (`vlm_middle_json_mkcontent.py:929`; empty pages skipped `:979-980` per `14-mineru-dolphin-analyst.md:18`). Dolphin: `all_page_results` list → combined JSON `{pages: all_page_results}` (`utils.py:109-118`) and markdown via element concat with `---` separators (`:126-134`). **Single bad page:** degrades output silently; whole document still emitted. **Confidence:** local vLLM clients expose `ScoredOutput`/perplexity (`mineru-vl-utils`); **http-client has none**. **Provenance:** page index in JSON structure. Impact: concat-only pattern insufficient for QA; need explicit fold layer.

- [MED] **Existing whisker `aggregate_adjudications()` is the closest implemented policy to planned per-page judge.** Formula (`chunking.py:250-259`): max-severity finding **per axis** across parts → `worst_axis_verdict(axis_findings)`; **`confidence = min(a.confidence for a in parts)`** (all parts, including pass); **`evidence_spans`** union with dedup on `(axis, quote, reason)` (`:268-275`). Empty parts → `verdict=review`, `confidence=0.0` (`:239-248`). **Single bad unit:** one chunk with `fail/major` on any axis forces document fail (via `worst_axis_verdict`); one low-confidence chunk poisons entire confidence. **Provenance:** reasoning prefixed `[aggregated over N chunks]` (`:285`); evidence quotes lack page field today. Planned per-page delta: fold **page verdict** not axis bundle; min confidence over **non-pass pages only**; tag each `missing_content` quote with `page`.

- [LOW] **Deterministic bench aggregators (whisker bench, opendataloader-bench) use means, not worst-unit.** Whisker per-paper `overall = sum(eligible_axes) / len(parts)` (`bench.py:197-205`); corpus `aggregate()` = eligibility-weighted **means** (`:214-245`). OpenDataLoader-bench: `overall_average = _safe_mean(overall_components)` (`evaluator.py:107-116`); corpus `_aggregate_document_scores` = mean of doc overalls (`:128-151`). **Single bad paper** lowers corpus mean; does not fail batch. Impact: leaderboard math only; not templates for fidelity judge.

## False-pass hypothesis

Adopt **olmocr `max_page_error_rate=0.004`** for the PDF text judge: one page with missing Table 2 (p0957r8 page 13) times out after 8 retries, falls back to pdftotext that still matches token multiset on surrounding prose, counts as 1/33 fallbacks (3% > 0.4% threshold fails only at ≥2 fallback pages in 33 — actually 1/33 = 0.03 > 0.004 **would discard** the doc; wait: 1/33 ≈ 0.0303 > 0.004, so **one fallback in 33 pages discards the document**). Recalculate: 1/33 = 0.0303 > 0.004 → document discarded. For 250-page doc, 1 fallback = 0.004 exactly at boundary. For 33-page WG21 paper, **one fallback page discards** (`pipeline.py:559`). False-pass case instead: **sub-threshold** fallback (1 page in 500-page corpus doc) ships with pdftotext substitution while VLM missed visual table structure — olmocr optimizes yield over pixel fidelity.

## False-fail hypothesis

Adopt **docling doc `low_grade`** (mean of page 5th-percentile tails) as LLM pass gate: one page with cosmetic header/footer parse penalty (`page_preprocessing_model.py:136-138`) drags `low_grade` to FAIR/POOR while layout is excellent; document flagged for human review despite faithful conversion (`research/per-page-judging/13-docling-analyst.md:30`). Mapped to whisker: using mean-of-page-low-scores instead of worst-page-only on the absence axis would multiply false-review from furniture/TOC pages (`20-false-fail-hunter.md:12`).

## What would change my mind

Finding a surveyed repo whose **production QA path** (not eval-only bench) aggregates per-page LLM verdicts with explicit worst-page-wins **and** ships a structured pass/fail that gates output — with provenance per page. As of this clone: none do; marker `LLMScorer` is eval-only (`llm.py:94-134`); docling grades are advisory (`standard_pdf_pipeline.py:1060-1088` with no status gate); olmocr discards or concatenates without LLM fidelity verdict. Closest is whisker `aggregate_adjudications()` itself (`chunking.py:226-292`).

**Gain/loss snapshots:**
- **olmocr error-rate:** gain corpus yield on huge docs; **loss** silent pdftotext substitution and no LLM verdict (anti-fidelity).
- **docling mixed reducers:** gain axis-appropriate telemetry (tail for parse, mean for layout); **loss** no hard fail, mean grades false-pass localized defects on long docs (`13-docling-analyst.md:26`).
- **marker reject-and-keep:** gain unit-level sanity gates; **loss** no document-level adjudication.
- **nougat markers:** gain visible page-level failure provenance; **loss** no structured verdict/confidence for fusion.
- **Planned worst-page + non-pass min-conf:** gain catches p0957r8-class localized absence; **loss** false-review inflation if per-page precision < ~99% on 33-page papers (`20-false-fail-hunter.md:8`, math `1-(1-p)^n`).
