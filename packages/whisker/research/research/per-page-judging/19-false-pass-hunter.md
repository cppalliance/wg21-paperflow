# 19 - False-Pass-Hunter

**Verdict:** usable-with-conditions — per-page presence judging fixes the monolithic p0957r8 class (whole-page omission) but remains blind to cross-page order, duplication, token-preserving corruption, and asymmetric haystack search; ship only with deterministic adjuncts (page-level recall, order gap, table neighbors) and anti-rubber-stamp gates.
**Confidence:** high

## Findings

- [CRITICAL] **Cross-page reordering false-passes when every page's tokens appear somewhere in the markdown.** Evidence: planned unit is "is THIS page's content present?" with full markdown injected each call (`00-baseline.md:11-16`); per-page presence is order-blind by construction. olmOCR-Bench has a dedicated `order` type (`TextOrderTest`, `tests.py:29,186-226`) requiring `before_match.start < after_match.start` via `fuzzysearch.find_near_matches`. whisker already separates content from order: `unigram_coverage` gates, shingle `coverage` is advisory-only (`score.py:149-155`, `constants.py:79-82`); large `unigram_coverage - coverage` gap flags scramble (`COV_UNIGRAM_GAP_TRIGGER=0.15`). Impact: a 33/33 per-page pass stack still ships P3844R4-class papers (`coverage=0.507`, `unigram_coverage=0.979`, hybrid `19-false-pass-hunter.md:8`). **Countermeasure (cheap):** document-level `coverage` demotion or 2–3 olmOCR-style `order` facts per paper (`facts.py:68`, `tests.py:214-226`); no extra LLM calls.

- [CRITICAL] **Asymmetric haystack: small page source vs full markdown each call recreates attention failure in reverse.** Evidence: baseline root cause is exhaustive enumeration over two ~20k-token blocks (`00-baseline.md:13-16`); per-page shrinks source to ~1k tokens but keeps entire `tomd_md` in every prompt (`pdf_judge.py:306-309`, planned 33× repeat). olmOCR binds tests to per-page `(pdf, page)` output, not "locate this page inside a whole document" (`tests.py:83-112`). p0957r8 had `content_recall=0.9806` document-wide (`tapetum-golden-review-findings-2026-07-14.md:24-25`) — multiset recall did not catch a whole-page hole because other pages' tokens dominate the denominator (`metrics.py:372-389`). Impact: within-page partial loss (one table row on page 13) may still satisfice when the model finds the caption block and stops. **Countermeasure (cheap):** deterministic `content_recall(normalized_text(page_k), md)` per page before LLM; LLM only on pages below a floor; inject a precomputed md window (rapidfuzz anchor ±N chars) instead of full md when page recall is borderline.

- [HIGH] **Within-page sub-unit loss (one table row/cell) survives page-scoped presence checks.** Evidence: p0957r8 failure was Figure captions + Table 2 on page 13 partially absent (`00-baseline.md:10-12`, `tapetum-golden-review-findings-2026-07-14.md:9-14`); presence prompt caps `missing_content` at 5 quotes × 20 words (`pdf_judge.py:70-71,148-159`). olmOCR `TableTest` checks cell match plus directional neighbors with fuzzy floor 0.5 (`tests.py:342-480,395-418`); whisker `facts.py` `table` type does the same deterministically (`facts.py:374-384`). marker rejects table LLM merges yielding `<=1` cells or missing `</table>` (`llm_table.py:228-238`, `research/hybrid-llm-scoring/02-marker-hybrid.md:10`). Impact: page-level "mostly there" passes mask row-level garble the text lane's `tables` axis catches on P2583R0/P4003R0 (`hybrid-llm-scoring/19-false-pass-hunter.md:10`). **Countermeasure (cheap):** for pages containing pipe/HTML tables, run deterministic table-neighbor probes on extracted page text vs md (port `facts.py:_check_table` scoped to page); marker-style reject if parsed cell count collapses.

- [HIGH] **Duplicated content is rewarded, not penalized, by presence-only checks.** Evidence: `content_recall` explicitly ignores extra/duplicated candidate tokens (`metrics.py:380-381`); per-page prompt shape "is content present?" has no duplicate penalty. Concrete scenario: page 7 prose copied twice in markdown (converter stuck in a loop); each page-7 call finds the text, returns `pass 0.98, missing_content: []`. olmOCR `BaselineTest` flags repeating n-grams above `max_repeats` (default 30) in output (`tests.py:520-526`). Impact: degeneration and double-insertion defects pass both per-page LLM and document-level multiset recall. **Countermeasure (cheap):** document-level `unigram_drift` (precision complement, already computed in `score.py`) or olmOCR-style tail n-gram repeat scan on markdown (`tests.py:520-526`); demote pass when drift/repeat triggers.

- [HIGH] **`normalize_textlayer` header/footer strip can hide real repeated boilerplate from the judge.** Evidence: lines on ≥30% of pages and `<120` chars are stripped (`textlayer.py:56-58,153-160`); shortcut comment names wording-paper standard boilerplate as the intended keep (`textlayer.py:157-159`). Scenario: a 95-char normative sentence repeated on 40% of pages (WG21 wording papers) is classified as furniture and never reaches the per-page prompt or `ground_spans` verifier (`pdf_judge.py:326-332`). olmOCR uses zone-scoped `first_n`/`last_n` on presence tests to assert headers/footers without stripping them from the corpus (`tests.py:139-140,160-165`). Impact: false pass when converter drops repeated boilerplate the judge never saw. **Countermeasure (cheap):** split `clean_pages()` from join (`00-baseline.md:31-32`); log stripped lines; olmOCR-style optional `present` facts with `first_n`/`last_n` on raw page text for papers flagged as wording; or raise char cap for lines matching normative patterns.

- [HIGH] **Token-preserving semantic corruption (cell swaps, column permute) passes presence checks.** Evidence: whisker tapetum lane documents this as the core false-pass class (`whisker/CLAUDE.md` tapetum section); HQH ~60% OCR-category hallucination when unchecked (`research/vlm-pdf-qa/34-fidelity-failure-analyst.md:12`). Per-page presence asks existence, not correctness. olmOCR `TableTest` validates `up`/`down`/`left`/`right`/`heading` neighbors after cell locate (`tests.py:357-358,415-418`); marker table processor retries when self-score `<4` (`llm_table.py:214-225`). Impact: straw-poll table with permuted headers passes 33/33 page calls if all tokens appear. **Countermeasure (medium):** hand-author 1–2 `table` facts per table-heavy paper (`facts.py:374+`); or prompt addendum "flag cell values attached to wrong row/column headers" with required neighbor quote — still LLM, but olmOCR-proven shape.

- [CRITICAL] **Rubber-stamping: 33 serial near-identical prompts with no cross-page validation.** Evidence: production sidecars show confidence min 0.90, median 0.95, 18/18 fails at ≥0.95, escalation band hit 0/198 (`tapetum-golden-review-findings-2026-07-14.md:86-89`); empty-evidence pass is sanctioned (`tapetum_llm.md` L108, `adjudicate.py:293-306`). On `pass`, `missing_content: []` triggers zero grounding work (`pdf_judge.py:326-333`, F2 in golden-review). olmOCR uses repeat-majority voting when outputs are stochastic (`benchmark.py:103-126`); marker rejects empty/invalid LLM JSON and keeps deterministic output (`llm_table.py:201-209`, `gemini.py:131`). No planned check rejects uniform `(pass, 0.98, [])` × N. Impact: model fatigue / template completion yields document pass identical to monolithic false pass, just 33× cost. **Countermeasure (cheap):** (1) reject page pass when `confidence ≥ 0.95` AND `missing_content == []` AND page deterministic recall `< 1.0`; (2) document-level variance gate: if ≥90% pages share identical confidence ±0.02, demote to `review`; (3) require at least one grounded spot-check quote on pages with tables/code (marker schema-validation pattern, `02-marker-hybrid.md:10`).

- [MED] **Cross-page bleed: page K content present under page K±1 section still passes page K.** Evidence: full-md injection lets the model match page-13 table text under page-12's heading without verifying page boundaries; per-page unit does not include markdown page markers (tomd drops page furniture by contract, `pdf_judge.py:127-128`). docling aggregates per-page scores but uses separate layout/parse signals (`research/hybrid-llm-scoring/05-docling-vlm.md:9-10`). Impact: boundary-slipped content passes both source page and wrong-page presence. **Countermeasure (cheap):** deterministic anchor: locate page text in md via ordered fuzzy windows (`match.py` block-matching pattern); fail page if best match position falls outside expected doc fraction `(page_num/total)` ± slack.

## False-pass hypothesis

**33-page proposal, pages 4–6 swapped in markdown:** Converter emits section C before B before A; every page's text layer content appears verbatim somewhere in the 25k-token markdown. Per-page judge runs 33 calls, each with ~800-token page source + full markdown; all return `pass, confidence 0.97–0.99, missing_content: []` (rubber-stamp pattern). Worst-page-wins aggregation yields document `pass`. Deterministic whisker sidecar shows `unigram_coverage=0.98`, `coverage=0.52`, 18 misaligned regions — but fusion `llm_clear_soft_review` or LLM-only advisory still reads pass. olmOCR `TextOrderTest` would fail a single `before`/`after` pair (`tests.py:214-226`); whisker shingle `coverage` already signals it (`score.py:149-155`).

## False-fail hypothesis

**Wording paper with sanctioned `<ins>`/`<del>` markup:** Per-page prompt lists wording constructs as present content (`pdf_judge.py:131-140`). Raw text layer lacks color; model flags "suspicious markup placement" and caps at `review` on 12/33 pages. Worst-page-wins aggregation yields document `review` despite faithful conversion (inverse of F2 rubric-bleed — overcautious structure axis). olmOCR has no markup-color check; marker benchmark LLM scorer says "minor mistakes okay" (`llm.py:47-48`). Mitigation: aggregate with severity-aware fold (non-major per-page `review` → document `review`, not fail) matching `chunking.py:106-123`; do not treat markup suspicion as fail.

## What would change my mind

A held-out replay of p0957r8 + P3844R4 + one table cell-swap golden through the implemented per-page judge **with only** deterministic adjuncts disabled/enabled ablation: if per-page LLM alone catches all three without false-failing the wording paper, downgrade cross-page and haystack findings to MED; if p0957r8 still passes with per-page LLM only, haystack asymmetry is confirmed CRITICAL.
