# 11 - olmocr-pipeline-v2

**Verdict:** usable-with-conditions — olmOCR's production hot path is a clean per-page unit boundary (one PNG + static extraction prompt, no cross-page context), with char-span provenance in the Dolma artifact; port the unit scoping and span bookkeeping for whisker's text-lane judge, but reject its soft validation gates, blank-page pass-through, and metadata flags that never gate acceptance.
**Confidence:** high

## Findings

- [CRITICAL] **Per-page request = static extraction prompt + single page image only; zero anchor or cross-page context.** `build_page_query` renders page `N` via `render_pdf_to_base64png` (`pipeline.py:111-112`, `renderpdf.py:39-60`), optionally PIL-transposes the PNG when `image_rotation != 0` (`pipeline.py:114-131`), then returns a chat payload whose sole `user` message has `content[0]` = `build_no_anchoring_v4_yaml_prompt()` and `content[1]` = `data:image/png;base64,...` (`pipeline.py:133-146`). The prompt text is five fixed sentences instructing natural-text transcription, LaTeX equations, HTML tables, figure markdown syntax, and YAML front matter for `primary_language`, `is_rotation_valid`, `rotation_correction`, `is_table`, `is_diagram` (`prompts.py:164-170`). No `pdftotext`, no `RAW_TEXT_START/END`, no page-width injection, no neighboring-page text; `--target_anchor_text_len` is explicitly unused (`pipeline.py:1230`). Impact: whisker per-page judge should mirror **image + one page's markdown slice** with no whole-document context; do not copy olmOCR's extraction prompt verbatim.

- [HIGH] **Per-page acceptance is a three-gate AND on HTTP parse success, soft token/finish flags, and rotation metadata — not on content fidelity.** `try_single_page` rejects non-200 HTTP (`pipeline.py:187-191`). On 200, it sets `is_valid=False` when `usage.total_tokens > MODEL_MAX_CONTEXT` (16384) or `finish_reason != "stop"` (`pipeline.py:162,200-206`), but still parses YAML unless an exception fires (`pipeline.py:208-212`). `FrontMatterParser` requires all `PageResponse` front-matter fields except `natural_text` (body text); missing fields or extras raise `ValueError` (`front_matter.py:71-98`), caught by `try_single_page`'s broad `except` → `None` → retry (`pipeline.py:228-230`). `process_page` returns only when `result is not None and result.is_valid and result.response.is_rotation_valid` (`pipeline.py:302-303,314-315,338-339`); rotation-invalid pages enter a sequential retry loop using cumulative `rotation_correction` (`pipeline.py:307-320`). Soft escape hatches: if retries exhaust but `result.is_valid`, accept with `is_rotation_valid=False` (`pipeline.py:322-326,365-369`). Optional `--guided_decoding` adds a regex over the YAML header (`pipeline.py:179-182`). **`is_table` / `is_diagram` / `primary_language` never gate acceptance.** Impact: whisker must hard-fail on any schema/parse error and treat token overrun as fidelity failure; olmOCR's `is_valid=False` soft flag is not adoptable for our fail-not-partial invariant.

- [HIGH] **Provenance: `build_dolma_document` records char spans `[start, end, page_num]` per page in document order.** Loop at `pipeline.py:608-617`: for each `PageResult`, if `natural_text` is not `None`, append text plus `\n` (except last page); else append `""`. Record `start_pos = current_char_pos` before append, `current_char_pos = len(document_text)` after, push `[start_pos, current_char_pos, page_result.page_num]`. Document id = `sha1(document_text)` (`pipeline.py:633`). `attributes.pdf_page_numbers` holds the span list; parallel per-page arrays store `primary_language`, `is_rotation_valid`, `rotation_correction`, `is_table`, `is_diagram` (`pipeline.py:642-649`). `metadata` carries `Source-File`, `pdf-total-pages`, token totals, `total-fallback-pages` (`pipeline.py:624-631`). Downstream `dolmaviewer` slices `text[start:end]` per span to render page-aligned HTML (`dolmaviewer.py:104-106`); `prepare_workspace` re-splits on the same boundaries for per-page `.md`/`.pdf` training pairs (`prepare_workspace.py:123-138,232-269`). Impact: direct precedent for whisker storing per-page verdict spans over concatenated markdown; span math is simple half-open `[start, end)` with inter-page newlines.

- [HIGH] **No blank/trivial-page skip in the inference pipeline; empty pages still burn a VLM call.** `process_single_pdf` dispatches `process_page` for every page `1..num_pages` via `TaskGroup` with no pre-filter (`pipeline.py:548-551`). There is no `pdftotext` length check, no whitespace heuristic, no bench-style `max_length` gate in `pipeline.py`. The model contract allows `primary_language: null` when there is no readable text (`prompts.py:105-106` in schema; silver prompts say "output null" at `prompts.py:14,29,44,60`). At merge time, `natural_text is None` becomes empty string content but the page still gets a span entry (`pipeline.py:609-617`). Document is discarded only when **all** pages concatenate to empty text (`pipeline.py:619-621`). Blank-page mining exists only in `bench/miners/mine_blank_pages_gpt.py` and `bench/tests.py:502-510`, not production inference. Impact: whisker should add an explicit trivial-page skip (deterministic text-layer empty + no figures) to save tokens; olmOCR's always-call policy is wasteful for WG21 papers with blank separator pages.

- [MED] **`is_table` / `is_diagram` are model-emitted YAML booleans stored as per-page attribute lists but not used in inference routing.** Prompt instructs the model to set them in front matter (`prompts.py:169`). Parsed into `PageResponse` (`prompts.py:71-72`, `front_matter.py:66-100`). Written to Dolma `attributes.is_table` / `is_diagram` as page-ordered lists (`pipeline.py:647-648`). Fallback hardcodes both `False` (`pipeline.py:243-244`). **Production pipeline never branches on these flags** (no table-specific retry, no alternate prompt). Downstream use is dataset-oriented: `prepare_workspace.py:32-38,247-269` rewrites them into per-page training markdown front matter; `print_stats` aggregates on `primary_language` only, not table/diagram (`pipeline.py:1144-1147`); synth training infers them from HTML area ratios (`synth/mine_html_templates.py:287-297`). Impact: for whisker QA, table/diagram flags are optional metadata for triage (e.g. stricter recall floor on `is_table` pages), not something olmOCR demonstrates as an acceptance gate.

- [MED] **Unit boundary is strictly one PDF page; aggregation is ordered concat + document-level fallback-rate gate (extends prior report with span detail).** Page unit drawn at `process_single_pdf` `for page_num in range(1, num_pages + 1)` (`pipeline.py:549-551`). Results preserve task-creation order (page 1..N). Per prior report: fallback pages count toward `max_page_error_rate` (default 0.004) (`pipeline.py:557-563,1222`); `assert all(page_result.is_valid)` means even fallback pages carry `is_valid=True` (`pipeline.py:555`). Impact: whisker's `aggregate_adjudications` should use worst-page-over-pages with explicit per-page provenance spans, not olmOCR's silent pdftotext substitution.

## False-pass hypothesis

A blank separator page where the VLM returns `natural_text: null` (or empty body after YAML) still produces a `PageResult` with `is_valid=True` and a zero-width char span (`pipeline.py:609-617`). The document ships as long as at least one other page has text (`pipeline.py:619-621`). Mapped to whisker: if we only judge "content" pages and auto-pass blank pages without checking that the markdown slice is also empty, a page where the text layer is blank but the conversion erroneously inserted boilerplate would **false-pass** (same class as p0957r8 whole-doc attention failure, but inverted: trivial unit masked).

## False-fail hypothesis

A page with a dense HTML table where the model sets `is_rotation_valid=False` on every attempt but `is_valid=True` with parseable YAML gets accepted after retry exhaustion (`pipeline.py:322-326`). If whisker ported rotation as a hard QA gate, correctly converted table pages photographed at a skew would **false-fail**; olmOCR itself soft-accepts this path. Conversely, a page where `finish_reason != "stop"` sets `is_valid=False` triggers up to 8 retries then pdftotext fallback (`pipeline.py:205-206,371-375`) — table structure is lost but the page is marked valid, which is a false-pass for structure, not a false-fail.

## What would change my mind

Evidence of a `pipeline.py` code path that skips the VLM call when `get_anchor_text(..., pdf_engine="pdftotext")` returns whitespace-only text (or below N chars) before `build_page_query`. Current production always renders and POSTs for every page (`pipeline.py:548-551`); blank handling is deferred to the model's `null` output and merge-time empty-string coercion.
