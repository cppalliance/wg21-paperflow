# 47 - Quality-Equivalence-Methodologist

**Verdict:** usable-with-conditions — the program can ship speed levers only through a two-tier gate (same-config noise floor on 381 papers + non-regressing dev-replay recall + holdout read-only acceptance); without a fresh A-vs-A calibration run, exact-match gates will false-reject every lever.
**Confidence:** high

## Findings

- [CRITICAL] **Per-paper equivalence vector (381-paper fleet gate).** For each PID, extract from `whisker/llm/<pid>.whisker.tapetum.json` after deterministic `--fuse-only` refresh: (1) `suggested_verdict`; (2) `fusion.combined_verdict` (requires paired `whisker/det/<pid>.whisker.json`, pure function in `fusion.py:59-95`); (3) defect-group multiset keyed by `defect_type` only (ignore example quotes and LLM `affected_count` when `verified_count` is null, per `CLAUDE.md:876-883`); (4) coverage tuple `(unit_coverage.coverage_complete, sorted(unit_coverage.unchecked_unit_ids), sorted(unit_coverage.failed_unit_ids), len(unit_coverage.checked_unit_ids), unit_coverage.mode, all_pages_requested)`. A paper is **equivalent** between runs when all four components match. Fleet **flip rate** = fraction of PIDs where equivalence fails. Evidence: sidecar fields at `pdf_judge.py:503-549`; fusion contract at `fusion.py:15-29`. Impact: this is the primary metric for every candidate config B vs baseline A on the full 381-paper cold fleet (`00-baseline.md:17-18`). Quality risk if skipped: any lever that silently drops defect types or clears coverage caps passes wall-time tests while degrading advisory recall.

- [CRITICAL] **Baseline noise floor = same-config rerun variance, not exact match.** Identical reruns already flip verdicts on >=25% of papers (`packages/whisker/src/whisker/CLAUDE.md:556-558`). Primary measurement: two back-to-back `--force` cold runs at config A, c=32, same `_LANE_VERSION`, produced **5/20 = 25%** pass↔review flips on a borderline PID set with fail count constant (`packages/whisker/research/llm-batching/20-sweep-results.md:31-40`). Hosted MoE decode is batch-non-invariant (`tapetum_llm.md:31`; `MODELS.md:69-70`, `MODELS.md:77-78`). **Adoption rule:** compute `flip_AA` on the full 381 corpus (two A runs, `--force`, no fingerprint skip). Candidate B **passes** iff `flip_AB <= flip_AA + margin`, where `flip_AB` is the fraction of PIDs not equivalent to A-run-1 (tie-break with A-run-2: flag only if B differs from **both** A runs). Default **margin = max(0.02, 1.96 * sqrt(flip_AA * (1 - flip_AA) / 381))** (~±4 pp at flip_AA=0.25). Secondary guard: McNemar on paired verdict flips (A1 vs A2 discordant count should not be statistically smaller than A1 vs B). Impact: without this floor, a 16/381 (~4%) B-vs-A diff looks like regression but sits inside MoE noise (`00-baseline.md:29-30`: only 16/381 merged verdicts changed by LLM findings today). Quality risk: treating noise as signal blocks all levers; ignoring noise ships real regressions.

- [CRITICAL] **Dev-replay findings recall gate (9 papers, tunable).** Labels: `packages/whisker/corpus/dev-replay/labels.json` (9 golden PRs, `CLAUDE.md:851-853`). For each labeled `defect_groups[]` entry with `type` T on paper P, **hit** iff config sidecar multiset contains T with severity >= label severity (or `verified_count >= label.affected_count` when countable). **Recall** = hits / total labeled groups (29 groups across 9 papers as of 2026-07-17). Config B passes iff `recall_B >= recall_A - 0.05` (one missed group max on the dev set) AND every `expected_llm_verdict` still matches on clean papers (`expected_llm_verdict == pass` when `defect_groups` empty, enforced in `test_dev_replay_acceptance.py:44-58`). This set is for **development tuning**; never optimize thresholds against holdout. Impact: catches call-elimination levers that preserve verdict histogram but drop localized findings (metadata short-circuit strips unit quotes on 19 review papers per `17-metadata-short-circuit.md:14`). Quality risk: recall-only gate misses false-pass verdict inflation; pair with verdict flip ceiling above.

- [HIGH] **Holdout protocol (48 anchors, read-only acceptance).** Active manifest: `packages/whisker/corpus/holdout/manifest.json` — 3 papers (`p1112r4`, `p3714r0`, `p4182r0`), **48** source-page-verified anchors across 7 strata (`holdout/README.md:48-50`). `p0533r9` quarantined, excluded from every holdout metric (`manifest.json:31-33`; `CLAUDE.md:856-858`). Locked source+candidate SHA-256; drift fails the gate, not silent relabel (`holdout/README.md:16-20`). **Rules:** (1) never tune router thresholds, short-circuit predicates, or prompt caps using holdout outcomes; (2) run holdout only after dev-replay passes, at most **once per lever bundle** before fleet merge; (3) metric = anchor-level recall on `expected_candidate_status` via `classify_candidate_evidence` (`holdout/README.md:40-41`; exercised in `test_dev_replay_schema.py`). Holdout failure blocks merge even if 381-flip rate passes. Impact: final false-pass backstop for evidence-grounding regressions. Quality risk: 48 anchors cannot estimate 381-paper flip variance; do not substitute holdout for fleet A/A calibration.

- [HIGH] **Cost of one A/B round and shared validation.** Today: one cold fleet run = **3003 s (~50 min)** (`00-baseline.md:17-18`). Minimum statistically usable round: **A1 + A2 + B1 = ~150 min** wall (3 × 50 min); operational shortcut accepted by program: **A1 + B1 = ~100 min** if A2 is refreshed weekly and stored as `research/tapetum-llm-speedup/_scratch/aa-baseline/`. Post-lever projected cost drops with fingerprint skip (warm **64.8 s**, `00-baseline.md:19-20`) but equivalence measurement requires `--force` on unchanged markdown. **Share one B run** when levers compose without interaction: e.g. server APC + FP8 KV + retention env (all server-side, no client diff); longest-job-first paper ordering + HTTP client tuning (same LLM inputs); dual-pod shard of identical model (same prompts, partition PIDs deterministically). **Require isolated B runs** when levers touch call graph or payloads: metadata short-circuit, router precision, model swap, multi-unit batching, in-paper parallel, prompt reorder/tag move, output-token/schema changes. Impact: bundling incompatible levers wastes a 50-min run and confounds failure attribution.

- [MED] **Levers needing NO full 381 A/B (provably output-identical LLM inputs).** (1) **Server-only prefix caching / FP8 KV / retention interval** — same token stream in, same decode path; prefill-only (`05-web.md Q1/Q4`; `tapetum_llm.md:309`). (3) **Cross-paper scheduling order** (longest-job-first queue) — same calls, same per-paper serial chain (`00-baseline.md:36-42`); verify with wall time + optional 20-PID spot subset. (4) **Dual-pod shard, same model+weights** — logically identical requests; **conditional** one 20-PID spot flip check recommended because MoE batch composition differs per pod (`21-dual-pod-sharder.md`; `MODELS.md:69-70`). **NOT exempt:** guard-tag placement, user-block reorder, skipping calls, model family change, in-paper parallel bursts, schema/prompt edits — all change inputs or call multiset and require full protocol.

For these, also report **call-count delta** and **defect-group recall delta** on the 16/381 papers whose merged verdict changed in baseline (`00-baseline.md:29-30`).

(2) If full: run A1 (or reuse weekly A2), run B with `_LANE_VERSION` bump only when sidecar shape changes (`cli.py:110-116`). (3) Compute equivalence + flip rates; dump discordant PID list. Impact: turns persona proposals into a single program gate; expected **~100-150 min** validation tax per non-exempt lever, amortized by bundling server-only wins first.

## False-pass hypothesis

Metadata-fail short-circuit skips 1047 unit calls (`17-metadata-short-circuit.md:8`): `flip_AB` stays inside the >=25% A/A band because `suggested_verdict` and fusion were already capped by metadata (`fusion.py:410-423`), but dev-replay recall on `page_content_omission` and `table_corruption` groups drops when unit checks no longer emit matching `defect_type`s — fleet flip gate passes, human inspect loses the only page-scoped quotes, and a localized omission looks "equivalent" on verdict-only vectors.

## False-fail hypothesis

Prompt user-block reorder for APC (`15-prefix-cache-enabler.md:10-11`) causes 18/381 papers to flip `suggested_verdict` pass↔review while defect multisets unchanged — above a naïve 0% exact-match bar but **inside** the measured A/A floor (>=25%, `CLAUDE.md:556-558`; `20-sweep-results.md:31-33`). Rejecting the lever as quality regression forfeits 500-900 s wall savings when verdict churn is indistinguishable from same-config MoE noise.

## What would change my mind

A fresh July 2026 **full 381-paper double-A run** showing `flip_AA < 5%` on the equivalence vector (not just `suggested_verdict`) under current v10 `_LANE_VERSION` would tighten the margin to near-exact match and obsolete the >=25% noise floor — but would contradict the documented MoE non-invariance at c=32 (`tapetum_llm.md:31`, `20-sweep-results.md:31-40`) unless batch-invariant kernels are deployed first.
