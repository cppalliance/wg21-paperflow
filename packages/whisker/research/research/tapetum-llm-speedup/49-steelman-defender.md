# 49 - Steelman-Defender

**Verdict:** usable-with-conditions (+ the 3003 s cold run is near-optimal for the stated quality bar; the 5–10 min target is not achievable without verdict-semantics tradeoffs, but output-identical server and fail-only client levers should still ship)
**Confidence:** high

## Findings

- [CRITICAL] **The 50-min problem is overstated for steady-state operation: warm runs are 65 s and cold runs are rare.** Measured v10 fleet: cold **3003.4 s** vs warm **64.8 s** with **375/381 skipped** via per-paper fingerprint (`00-baseline.md:17-20`, `cli.py:565+`). Incremental skip fires on unchanged markdown, source, prompt, schema, model, and `_LANE_VERSION` (`tapetum_llm.md:318`, `cli.py:601`). `_LANE_VERSION` log runs v2 (2026-07-08) through v10 today (`tapetum_llm.md:326-333`, `cli.py:117`): **9 bumps in 15 calendar days ≈ 1 cold fleet per 1.7 days during active lane development**, matching the user's ~1.5-day cadence. Between bumps, operators pay **~65 s**, not 50 min. Billing is hourly pod uptime, not per token (`whisker/CLAUDE.md:683-687`), so a monthly cold run is cheap; optimizing cold path ROI only matters during burst lane churn. Impact: speedup program urgency is **development-velocity**, not production steady-state. Quality risk of ignoring this: teams ship risky levers to fix a pain point that warm skip already solved.

- [CRITICAL] **Wall time closes to the linear slot model; the architecture is slot-saturated, not client-idle.** ~**2284 calls × ~20 s / 16 slots ≈ 2855 s** vs measured **3003 s** (`00-baseline.md:22-25`). Per-paper cascade is **serial** (monolith → metadata → escalations → units, `pdf_judge.py:753`, `unit_judge.py:389`; `00-baseline.md:36-42`); fleet concurrency **32 papers** already overfills `--max-num-seqs 16` (`cli.py:119-127`, `00-baseline.md:33-35`). Raising server seqs to 32 regressed **+60% wall** (`00-baseline.md:81-82`). Impact: without **call elimination** or **more identical-model slots**, physics caps savings; prefix/decode tweaks shave percent, not order-of-magnitude. Quality risk: none for accepting the model; **HIGH** for pretending concurrency headroom exists.

- [CRITICAL] **Output-identical levers floor at ~37 min, not 5–10 min.** Free stack (verdict-semantics unchanged on merged fusion): (1) **fail-only metadata short-circuit** — 141 calls, **~179 s**, **0/32** metadata-fail papers change `suggested_verdict` if units skipped (`17-metadata-short-circuit.md:10`, `pdf_judge.py:711-712`); (2) **server APC + DeepSeek V4 retention fix** — **60–180 s**, bitwise-identical KV replay (`15-prefix-cache-enabler.md:20`, `05-web.md:6-12`); (3) **v10 empty-packet pre-filter** — already shipped, zero extra calls (`cli.py:115-117`, `tapetum_llm.md:333`). Arithmetic: **(2284 − 141) × 20 / 16 = 2679 s**; minus ~120 s APC mid → **~2560 s**; FP8 KV **+14.9% throughput** at ≤2 pt accuracy loss (`05-web.md:23-27`) → **~2230 s (~37 min)**. Still **3.7–7.5× above** the 300–600 s target. Reaching 600 s at 16 slots requires **≤480 calls** (600×16/20) — an **79% call cut** — or **32 effective slots plus ~55% call cut**. Impact: **5–10 min at unchanged verdict semantics is arithmetically impossible** with measured call volume. Quality risk: declaring victory on a sub-10-min run that required silent coverage cuts.

- [HIGH] **Every high-yield call-cut lever reopens documented false-clear and false-pass history.** The lane exists because deterministic gates miss token-preserving corruption (`whisker/CLAUDE.md:534-535`, PR #286 `p1068r11`: nine `heading_drift` signals consumed five `MAX_UNIT_CHECKS` slots, pages 7/10 never checked — `11-router-precision-auditor.md:8`, `PR286-LLM-FALSE-CLEAR.md`). **PR #282 `p4020r0`**: model returned **pass at confidence 1.00** on a known H2→H3 heading defect (`whisker/CLAUDE.md:559-561`, `corpus/dev-replay/labels.json:6-21`). **≥25% advisory verdict-flip** on identical reruns (`whisker/CLAUDE.md:556-558`); **96/96 clear firings at ≥0.95 confidence** including known false-clears (`whisker/CLAUDE.md:559-561`). Lever→risk map: **router tightening** misses **6/47** defect-group papers (`11-router-precision-auditor.md:16`); **unit batching** predicts **10–20%+ detection loss** (RuVerBench, `05-web.md:96-98`, `12-unit-batching-architect.md:10`); **cascade pre-gate** strict-clean population is **1/381** — widening reopens monolith-blind P0533R9/P0957R8/PR286 classes (`24-cascade-designer.md:8-12`); **in-paper parallel units** adds MoE batch-composition variance (`00-baseline.md:96`, `20-in-paper-parallelist.md`); **smaller dense judge / cascade** trades sovereignty-calibrated recall for speed (`05-web.md:88-90`, `00-baseline.md:100-101`). Impact: the **1510 unit checks (66% of calls)** are expensive because **16/381 papers** had merged verdict changed by LLM findings (~**143 calls per flip**, `00-baseline.md:29-30`) — cutting calls without holdout proof trades rare catastrophic misses for frequent minutes saved. Quality risk: **HIGH** on any lever skipping scoped verification on router-flagged units.

- [HIGH] **The revalidation treadmill can exceed lever savings during active development.** Each non-trivial lever demands a **381-paper cold run (~3003 s)** or **48-paper holdout A/B** before fleet deploy (`15-prefix-cache-enabler.md:34`, `whisker/CLAUDE.md:848-853` holdout manifest). At **~1 cold run per 1.5–1.7 days** from `_LANE_VERSION` alone (`tapetum_llm.md:326-333`), validating **5 levers sequentially** costs **~4.2 h of cold fleet time** in one week — **>5× the ~50 min saved per bump** if only one lever ships. Personas already disagree on safe cut sizes (metadata short-circuit **1047 vs 141 calls**, `17-metadata-short-circuit.md:8` vs Tier A). Impact: parallel lever experiments multiply cold runs; **stop-ship until A/B** is correct process but **negative ROI** during lane churn unless levers are batched. Quality risk: **MED** — shipping without replay repeats PR #282-class false-clears; **MED** — analysis paralysis if every 3% lever needs full fleet.

- [MED] **Dual-pod sharding and full metadata short-circuit are high-yield but NOT output-identical; treat as conditional, not "free."** Dual-pod: **3003 → ~1600 s** modeled (`21-dual-pod-sharder.md:8`, `00-baseline.md:67-68` twin `deepseek-v4-pro` pods in `SERVICES.toml`), but adds a **second MoE scheduler variance axis** within the existing **≥25% flip budget** (`21-dual-pod-sharder.md:16`, `whisker/CLAUDE.md:556-558`) — exceeds **production quality-stability** if read as bit-identical verdicts (`00-baseline.md:77-78`). Full metadata fail+review unit skip: **~1331 s** (`17-metadata-short-circuit.md:8`) with **merged verdict unchanged** but **35 defect groups** lost from inspect sidecars (`17-metadata-short-circuit.md:8`). Combined with dual-pod: **(2284−1047)×20/32 ≈ 773 s (~13 min)** — first path under 15 min, still above 5–10 min without prefix reorder. Impact: defensible **speed-with-conditions** stack, not **same finding quality** by strict sidecar/inspect completeness. Quality risk: **MED** triage noise; **LOW** on fusion hard-fail (advisory-only, `fusion.py:76-77`).

- [MED] **Defend adoption of genuinely free levers even if they do not hit 5–10 min.** Ship without holdout gate: **(1)** vLLM build with DeepSeek V4 selective retention + `VLLM_PREFIX_CACHE_RETENTION_INTERVAL=32768` + `--enable-prefix-caching` (`05-web.md:6-12`); **(2)** `--kv-cache-dtype fp8` where sliding-window skip flag applies (`05-web.md:23-27`); **(3)** **fail-only** metadata unit skip (`pdf_judge.py:870` guard when `metadata_check.verdict == "fail"`, `17-metadata-short-circuit.md:10-11`); **(4)** v10 empty-packet pre-filter (done). Defer until holdout: per-paper guard tag + unit user reorder (`15-prefix-cache-enabler.md:10-11`, security tradeoff `15-prefix-cache-enabler.md:18-19`), router combo filters (`11-router-precision-auditor.md:16`), unit batching (`12-unit-batching-architect.md:3`). Impact: **~200–350 s** cold savings at **near-zero verdict risk** — worth doing despite not solving the headline target. Quality risk: **LOW**.

- [LOW] **70% zero-defect unit checks prove spend, not waste-by-design-error.** **1057/1510** unit checks returned zero defect groups (`00-baseline.md:29-30`); only **16/381** papers had merged verdict changed by LLM findings. That ratio is the **price of fail-closed coverage** after PR #286 routing miss: blind elimination is **46% wall** (`10-call-graph-accountant.md:18`) but **HIGH false-pass risk** (`10-call-graph-accountant.md:29-30`). Impact: the cold run is "slow" because the lane **refuses to trust monolith pass** on router-flagged regions — correct for stated quality bar. Quality risk of treating zero-yield checks as bugs: **HIGH**.

## False-pass hypothesis

**Combined "safe" router filter** (`11-router-precision-auditor.md:16`): drop redundant `table_presence`, cap `heading_drift`, relax section recall — saves **~238 s** but simulation misses **6/47** defect-group papers including multi-table HTML defects (`P4025R1`/`P4025R2`). Fleet wall drops; a **poll-table or multi-table swap** survives as monolith `pass` + empty unit `defect_groups`, repeating the PR #286 architecture false-clear class (`PR286-LLM-FALSE-CLEAR.md:433-437`) at advisory `pass` while deterministic fusion still looks acceptable.

## False-fail hypothesis

**Unconditional `table_presence` on all 1478 PDF table pages** (`11-router-precision-auditor.md:30`): saturates `MAX_UNIT_CHECKS=5` on **256/376** checked papers, leaving high-severity units in `unchecked_unit_ids` (`unit_judge.py:370-372`), forcing fusion `review` via incomplete coverage (`fusion.py:192-195`) on **clean conversions** — router over-fire causes advisory false-fail without finding defects. Speedup by **adding** router precision (fewer spurious signals) fixes false-fail; speedup by **skipping units** without router retune amplifies it.

## What would change my mind

A single cold fleet run at `_LANE_VERSION` fixed, using **only** levers classified output-identical (server APC/retention, FP8 KV, fail-only metadata skip, v10 pre-filter), showing wall **≤600 s** with **0 merged-verdict diffs** vs v10 control on all 381 sidecars — would falsify the floor arithmetic and flip verdict to **garbage** (current architecture not near-optimal). No such run exists in the evidence set.
