# 24 - Cascade-Designer

**Verdict:** usable-with-conditions (+ a strict deterministic pre-gate is the right shape and already partially exists, but on the measured 381-paper fleet it skips unit checks for **1 paper only** with **0 marginal call savings** until the risk router is retuned; monolith alone does **not** cover token-preserving corruption for skipped papers)
**Confidence:** high

## Findings

- [CRITICAL] **Strict all-clean pre-gate population: 1 / 381 papers (0.26%).** Counted over `data/whisker/llm/*.whisker.tapetum.json` (381 files): a paper qualifies only when `len(risk_signals)==0`, every `page_screen[].flagged==false`, and `textlayer_diff.text_nid >= PDF_JUDGE_NID_FLOOR (0.80)` plus `textlayer_diff.content_recall >= PDF_JUDGE_RECALL_FLOOR (0.85)` (`constants.py:164-165`, persisted at `pdf_judge.py:534-537`). Exactly **one** successful PDF (`p4008r0`) meets all four; **zero** HTML papers. Four error tombstones also have empty `risk_signals` but no usable cascade. Impact: deploying the user-specified AND gate today saves **0 unit calls** on the cold run: that paper already runs **2 calls** (monolith + metadata, `pdf_judge.py:880-890` skips units when `risk_signals` empty; `unit_judge.py:340-341`).

- [CRITICAL] **The risk router, not the page screen, blocks the gate: 376 / 381 papers have non-empty `risk_signals`; only 5 have zero (1 ok + 4 errors).** Among **167 / 181** PDFs with zero flagged pages, **166 still carry router signals** (dominant types on zero-flag papers with unit findings: `table_presence` 295 occurrences, `heading_drift` 270 — aggregated signal counts across 31 such papers). Page screen rarely fires (`screen_flagged=0` on **168 / 181** PDF log lines per `12-false-economy-hunter.md:16`) while router mean **15.2** signals/paper. Impact: a pre-gate that requires **both** zero flag and zero router hits **1 paper**; a screen-only gate would reach **167 PDFs** but violates the stated spec and drops unit checks on **31 PDFs** that produced `defect_groups` despite clean screens (**17** with high/critical severity).

- [CRITICAL] **Monolith alone does not cover the LLM lane's residual risk class for skipped papers.** Documented ceilings: P0533R9's 151 missing `constexpr` qualifiers exceed monolith's 5-quote cap (`tapetum_llm.md:93`, `pdf_judge.py:197-198`); P0957R8 page-13 omission survived monolith pass until per-page screen (`tapetum_llm.md:93`). PR #286 poll-table corruption: screen **0 / 15** flagged, monolith pass — token-preserving semantic damage (`c06-grounding-asymmetry.md`). Measured: **31 / 167** zero-flag PDFs have non-empty `defect_groups` found only via unit checks; monolith `grounded_evidence` empty on the sole strict-clean paper. Impact: skipping unit checks on any population wider than the n=1 strict set **reopens the blind spot** the lane exists to catch; keeping monolith+metadata for all papers does **not** substitute for scoped unit verification on router-flagged regions.

- [HIGH] **Proposed PDF-lane cascade (mirror text lane + Q5 pre-gate).** Text lane: tier-1 triage on every paper, tier-2 only when `_escalation_signals` non-empty (`adjudicate.py:256-299`, `tapetum_llm.md:263`). PDF lane today: monolith → mandatory metadata → page escalations (screen-gated, `pdf_judge.py:733-833`) → **up to 5 unit checks whenever `risk_signals` non-empty** (`pdf_judge.py:880-890`, `MAX_UNIT_CHECKS=5` at `constants.py:223`). Design: insert deterministic **Tier-0 pre-gate** after metadata, before `run_unit_checks`:
  1. **CLEAN (skip units):** `flagged_pages==0` AND `risk_signals==[]` AND doc `text_nid/recall` above floors AND `metadata_outline_check.verdict==pass`.
  2. **UNCERTAIN (full routed units):** any hard router signal (`low_recall`, `token_delta` with `deficit >= TOKEN_DELTA_THRESHOLD`, `missing_code`) OR any flagged page OR doc floors fail.
  3. **SOFT-ONLY (cheap confirmation):** zero flagged pages, doc floors pass, metadata pass, but only soft signals (`heading_drift`, `table_presence`) — one batched "any conversion defect on these N unit_ids?" call instead of up to 5 full-contract checks (spinov/futureagi pattern from `05-web.md:93-103`: deterministic floor first, expensive judge only on UNCERTAIN).
  Hook: branch at `pdf_judge.py:880` before `run_unit_checks`; reuse existing vacuous-complete path (`pdf_judge.py:842-849`). Impact: Tier-0 CLEAN matches today's behavior (n=1). Tier-3 SOFT-ONLY is where wall-clock lives **if** router soft-noise is decoupled from hard signals — not measurable until router retune.

- [HIGH] **Looser screen+floor gate (ignoring router) saves ~171 s but buys 10 false economies.** Hypothesis counted on sidecars: **34 PDFs** with zero flagged pages, doc floors pass, metadata pass — would skip **137** of **~830** PDF unit calls (~**171 s** at 20 s/call, 16 slots, `00-baseline.md:24-25`). **10 / 34** of those papers have non-empty `defect_groups` (**4** high/critical) that unit checks supplied; monolith did not ground them. Impact: ~4.5% fleet wall reduction at quality risk on table/heading defects the router saw but the screen cleared — unacceptable without a labeled holdout.

- [MED] **179 / 180 PDFs already saturate the 5-check cap** (`01-call-count-accountant.md:30`). Pre-gate that only removes checks on the 1 strict-clean paper cannot move the 3003 s needle; retuning `route_pdf_units` (`source_router.py:167-220`) to suppress soft signals when per-page recall ≥ `PAGE_RECALL_FLOOR (0.90)` and page not flagged is the prerequisite for a spinov-style UNCERTAIN band larger than n=1. Impact: router precision, not gate boolean, is the lever.

- [LOW] **Page escalations are already a deterministic→LLM cascade and stay for all flagged pages.** 16 escalations / 13 papers on the fleet (`09-escalation-cost-auditor.md:8`); 11 refuted. Pre-gate does not remove them; zero-flag strict-clean papers pay 0 escalation calls. Impact: marginal.

## False-pass hypothesis

**P0876-class / PR #286-class:** Poll-table cell truncation (`SF`→`S`) with document `content_recall` 0.994, screen 0/15 flagged, monolith pass 0.98 (`c06-grounding-asymmetry.md`). Router emits `table_presence` / `heading_drift` soft signals; unit checks catch cell-level defects. A pre-gate that skips units when the page screen is clean but soft router signals remain — or a retuned router that silences soft signals on high-recall pages — would merge monolith `pass` while six table errors survive, exactly the token-preserving corruption class the LLM lane exists to surface.

## False-fail hypothesis

**Heading-drift noise on otherwise faithful PDFs:** 270 `heading_drift` router hits on zero-flag papers with unit findings include cosmetic H-level jumps that metadata already caps at `review` (`pdf_judge.py:711-714`, fusion `source_aware_review_cap` on 321/381 papers per `12-false-economy-hunter.md:10`). Running five full unit checks on every soft-signal paper when metadata already failed fusion is fusion-dead spend (~1043 calls, `12-false-economy-hunter.md:14`) — not a false fail, but wasted serial wall that a SOFT-ONLY confirmation tier or metadata-fail short-circuit would remove without touching strict-clean semantics.

## What would change my mind

A holdout replay (dev-replay 9 PRs + 48 holdout anchors, never tune on holdout) showing that reclassifying `heading_drift`/`table_presence` as non-routing when `page_screen.flagged==false` and per-page recall ≥ 0.90 **does not** drop any labeled PR #286 / P0533R9 / P0957R8-class defect, while expanding the strict-clean population from **1 → ≥50** papers with measured unit-call reduction ≥500, would flip to **usable** without conditions.
