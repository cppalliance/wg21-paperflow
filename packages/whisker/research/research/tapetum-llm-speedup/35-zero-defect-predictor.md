# 35 - Zero-Defect-Predictor

**Verdict:** usable-with-conditions — router features can skip ~45% of unit checks but no single deterministic rule reaches SAJA's 99.6% precision on verified defects; `coverage_complete` must be extended to admit `predicted-clean` or skipped units force review caps.
**Confidence:** high

## Findings

- [CRITICAL] **70% zero-defect baseline confirmed on raw LLM output, not on verified groups.** From 381 sidecars (`data/whisker/llm/*.tapetum.json`), 1570 executed unit checks: 1077/1570 (68.6%) returned zero raw defects in `unit_checks[].defects`; 00-baseline.md reports 1057/1510 (70.0%) on the same fleet run. Only 72/1570 (4.6%) checks produced verified `candidate_not_found` + `ground_exact` defects; 50 checks map to 52 merged `defect_groups` across 47 papers. Impact: the skip pool is ~70% of calls, but the *quality-critical* tail is 4.6%; predictors must be judged on verified-defect false-skip rate, not raw empty output. Quality risk: optimizing for 70% empty-LLM skips over-predicts safety.

- [CRITICAL] **No deterministic rule matches SAJA Q5 (44% skip @ 99.6%).** Best volume rule: `heading_drift` as the sole router signal → skip 701/1570 (44.7%), precision 98.58% on verified defects (10 false-skips / 72 total verified-defect checks). Closest to SAJA volume (`05-web.md` Q5: 44% @ 99.6%) but 1.42% false-skip rate on skipped checks, missing 10/72 (13.9%) of all verified-defect findings including P4014R0 `page:5`, P4093R0/R1, P4099R0/R1. At ≥99.6% precision, greedy OR over all rules yields only 50 skips (3.2%): `missing_code` ONLY (45) + `low_recall` ONLY (5), zero false-skips. Impact: SAJA-class automation saves ~31 s on the 3003 s cold run (50×20 s / 32 concurrent papers); the 44.7% rule saves ~422 s (~14% wall) but drops 10 verified defects. Quality risk: medium heading_drift-only units with `page_recall=1.0` still hide real table/content loss on adjacent signals.

- [HIGH] **`table_presence` is the non-skippable signal class.** Verified-defect rate by router signal on checked units: `table_presence` 55/511 (10.76%), `low_recall` 13/279 (4.66%), `heading_drift` 51/1284 (3.97%), `missing_code` 1/147 (0.68%). Rule `NOT table_presence in signals` skips 1060/1570 (67.5%) but precision is only 72.14% on zero-raw-defect (295 false-skips). Any gate that skips `table_presence`-routed units is unsafe. Impact: safe skip rules are confined to heading-only / missing_code / low_recall subsets. Quality risk: table corruption is the dominant verified-defect channel.

- [HIGH] **Per-page `page_screen` recall is necessary but insufficient for PDF skips.** 782 `page:N` checks; verified-defect rate by screen recall bucket: `<0.85` 83.3% (5/6), `[0.85,0.90)` 16.7%, `[0.90,0.95)` 32.0%, `[0.95,0.98)` 11.5%, `≥0.98` 6.52% (41/629). Rules `page_recall>=0.98` and `page not flagged` skip 40–45% at 92–93% precision on verified defects (41–55 false-skips). Many verified defects sit on `page_recall=1.0` and `page_flagged=False` (e.g. P3181R1 `page:2`, P3427R3 `page:2/5`). Screen is computed at `pdf_judge.py:296-304` (`PAGE_RECALL_FLOOR`); it catches escalations but cannot safely pre-empt unit checks. Impact: page recall alone cannot reach SAJA precision. Quality risk: false confidence on high-recall pages with localized table defects.

- [MED] **Paper-level nid/recall is a weak unit-level predictor.** `paper_recall>=0.95` skips 722/1570 (46.0%) at 93.49% verified-defect precision; `paper_recall>=0.98` skips 357/1570 (22.7%) at 93.54%. Paper metrics live in sidecar `textlayer_diff` (`pdf_judge.py:534-537`); only 181/381 papers carry `page_screen`/`textlayer_diff` (PDF lane). HTML section checks (788/1570) have no page recall or paper recall features. Impact: paper-level gates are PDF-only and still miss ~6% of verified defects at best. Quality risk: HTML lane has no equivalent deterministic gate.

- [MED] **Feature table summary (1570 checked units).** Signal types present on checked units: `heading_drift` 1284, `table_presence` 511, `low_recall` 279, `missing_code` 147. Severity on routed units is overwhelmingly `medium`/`high` (zero units with sole `low` severity in corpus). Page token count from `page_screen[].tokens` median 270 (3657 page entries). Unit-id split: `section:*` 788 (HTML), `page:*` 782 (PDF). All checks carry router signals (0 no-signal checks). Impact: feature space is discrete and low-dimensional; no continuous confidence score like SAJA's calibration head exists in our stack.

- [LOW] **`predicted-clean` sidecar recording requires `coverage_complete` semantic change.** Today `coverage_complete` is true only when `checked_unit_ids == routable_coverage ∪ required` with no unchecked/failed (`unit_judge.py:460-464`). Fusion fail-closed review cap requires `coverage_complete is True` (`fusion.py:192-195`); unchecked units cap verdict at `review` (`tapetum_llm.md:122-124`). Recording a skip as `predicted-clean` without counting it toward coverage forces `coverage_complete=false` and a review cap on otherwise-clean papers — same as silent omission. Unroutable units already show the pattern: excluded from coverage set (`tapetum_llm.md:124`). **Recommendation:** add `predicted_clean_unit_ids` and treat them as covered in `coverage_complete` with `unit_selection[].status: "predicted-clean"` and deterministic rule id — mirrors unroutable precedent but needs `_LANE_VERSION` bump and fusion test updates. Impact: without this, any skip rule degrades advisory verdicts even when defects would have been zero. Quality risk: false review inflation, not false pass.

## False-pass hypothesis

Skip rule `heading_drift` ONLY at 44.7% volume: would never run LLM on P4014R0 `page:5` (medium `heading_drift`, `page_recall=1.0`, verified structural defect) and 9 other verified-defect checks, silently removing them from `defect_groups` while monolith/metadata may still pass — a classic false-pass on localized content the monolith missed.

## False-fail hypothesis

Implementing skips without `coverage_complete` extension: a paper whose 5 routed units are all truly clean but 3 are `predicted-clean` skipped would record `coverage_complete=false`, capping LLM verdict at `review` (`unit_judge.py:474-477`) despite zero defects — false-fail via coverage semantics, not conversion quality.

## What would change my mind

A holdout-validated rule achieving ≥40% unit-check skip at ≥99.6% verified-defect precision (≤0.4% false-skip on skipped checks) on the 48-anchor dev-replay/holdout set — measured the same way as SAJA Q5, not on raw empty-LLM rate.
