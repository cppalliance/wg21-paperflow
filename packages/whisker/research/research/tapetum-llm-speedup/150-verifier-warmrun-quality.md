## False-pass hypothesis

Applying the 25% `flip_AA` floor fleet-wide would **accept** levers that add ~4% real regressions (16/381 changers today) as "within noise," because 25% is ~6× the observed full-corpus LLM-impact rate — but it would also **reject** levers whose borderline pass↔review churn matches measured MoE noise on the 20-PID set even when defect multisets are unchanged (`47-quality-equivalence.md:28-30` APC reorder case). Using p=0.04 from baseline changers without a 381 A/A run risks **false-pass on real regressions**; using p=0.25 risks **false-fail on noise-identical levers**.

## False-fail hypothesis

Treating exact-match gating on 381 papers without any A/A floor would false-reject every lever that touches prompts or batch composition, because **5/20 identical c=32 reruns** already flip without any lever — exact match is incompatible with MoE non-invariance on the shared pod.
