# 13 - Payload-Scoper

**Verdict:** usable-with-conditions — payload scoping can preserve ANYWHERE semantics only with a mechanical full-document presence layer plus post-hoc grounding (already full-doc), but prefill savings are ~7–14% fleet wall at best; prefix-cache prompt reorder (stable tag, shared candidate block last) is the higher-ROI lever and may make scoping unnecessary for the 3003 s target.
**Confidence:** high (measured `data/paperstore/*.md` sizes; file:line anchors on prompts, grounding, and inject order); medium (scoped-window false-fail rate without A/B replay)

## Findings

- [CRITICAL] **Full candidate markdown is sent on every unit check and page escalation by construction.** Evidence: `unit_judge.py:769-776` (`inject_untrusted(candidate_md, tag)` in `_check_one_unit`); `pdf_judge.py:389-395` (same in `_escalate_page`); monolith also embeds full md once (`pdf_judge.py:640-643`). A median routed PDF paper (~5 unit checks, ~0 page esc) prefills the full document **~6×** (1 monolith + ~5 units; metadata is already scoped to front matter + headings at `unit_judge.py:220-256`). Impact: at P50 md size (below), **~51K chars (~13K tok) of duplicated md input per unit call**; fleet **1510 unit calls** (`00-baseline.md:22-23`). Quality risk: none from duplication itself; waste is prefill-time only.

- [CRITICAL] **The ANYWHERE rule is the root cause: unit/page judges must not false-fail cross-page reflow.** Evidence: prompt binding at `unit_judge.py:137-139` and `pdf_judge.py:224-226` ("Content from this unit/page counts as present if it appears ANYWHERE in the candidate markdown, in any order"); tomd cross-page join when prior block lacks terminal punctuation (`packages/tomd/src/tomd/CLAUDE.md:231-232`). Post-hoc refutation already searches the **full** on-disk candidate (`unit_judge.py:728-729` → `grounding.py:419-438`; grounding uses `raw_tomd_md` while LLM gets `strip_binary_payloads` output per `pdf_judge.py:612-613,872`). Impact: a naive "local section only" payload **will** false-fail join tails unless the LLM receives either the full doc or a presence oracle. Quality risk: **HIGH** for section-only scoping without oracle.

- [HIGH] **Measured candidate markdown sizes (`data/paperstore/*.md`, n=583, 2026-07-23):** min **1059** chars; P10 **6623**; P25 **15751**; **P50 34336**; P75 **73685**; P90 **139148**; P95 **220688**; max **4890371**; mean **94438**. Token estimate (chars/4): P50 **~8584 tok**, P90 **~34787 tok**, mean **~23610 tok**. Impact: at `@4000 tok/s` prefill (`research/tapetum-llm-throughput/02-prompt-token-auditor.md:10`), one unit call pays **~2.1 s** prefill for md alone at P50, **~8.7 s** at P90; decode still dominates (~93% of per-call wall, `02-prompt-token-auditor.md:20`).

- [HIGH] **Prefill savings from scoping are real but insufficient alone for 5–10 min.** Model: replace full md with **~8K-char section window** + **~1K-char presence index** (hashed normalized phrases / n-grams for mechanical ANYWHERE lookup) → user payload drops from P50 **~9259 tok** to **~2675 tok** (**−6584 tok/call**, measured from P50 file sizes + typical **2500-char** page source per `02-prompt-token-auditor.md:16`). At **4000 tok/s**, **−1.65 s prefill/call**; fleet **1510 unit calls** → **~2485 s aggregate prefill**, **~198 s wall** at **16 slots** (`00-baseline.md:24-25`). Page escalations (**16 calls**, `10-call-graph-accountant.md:24`) add **~2 s** wall. **~7% of 3003 s** — not the 80–85% cut required. Quality risk: **MEDIUM** if presence index misses fuzzy/dehyphenated/w wording-markup matches that `classify_candidate_evidence` handles on full text (`grounding.py:466-489`).

- [HIGH] **Prefix caching may supersede scoping: current prompt layout defeats APC today.** Evidence: per-call random guard tag breaks system-prompt suffix (`00-baseline.md:48-52`, `pipeline/tools.py:55-62`); `inject_untrusted` wraps **both** source and candidate with **fresh** `SRC{secrets.token_hex(4)}` tags per call (`unit_judge.py:767-776`), and **source precedes candidate**, so even identical md cannot share a leading prefix across unit calls (optimal pattern is shared doc then unique query last: `05-web.md:69-73`). DeepSeek-V4-Pro at concurrency 16: APC fix raised prefix hits **0% → 74.3%**, throughput **44 → 196 tok/s** (`05-web.md:6-12`). Reordering to `[stable system + stable paper tag] + [shared candidate md block] + [unique source/risk tail]` on a **paper-stable tag** could make **4/5 unit prefills cache hits** on median papers without shrinking payload. Impact: est. **~236 s wall** saved (377 papers × 4 redundant md prefills × **2.5 s**/16 slots) — comparable to scoping, **zero semantic risk**. Quality risk: **LOW** if guard tag stays per-paper (not per-call) and injection defense holds (`pipeline/tools.py:49-52` escapes forged delimiters).

- [MED] **A hybrid scoped payload can preserve ANYWHERE semantics if designed as LLM window + deterministic oracle.** Pattern: (1) send **H2-bounded section window** for the unit's page (±1 neighbor for join tails) plus **compact presence index** (sorted normalized 5-gram hashes or token-set sketch of full md); (2) prompt clause: "if index contains normalized(source phrase), treat as present regardless of window"; (3) keep **`verify_unit_evidence` / `classify_candidate_evidence` on full `raw_tomd_md`** unchanged (`unit_judge.py:425,728-729`). Mechanical keyword counts already use full doc (`unit_judge.py:634`). Metadata call proves partial-candidate pattern works (`unit_judge.py:220-256`). Impact: captures most prefill win on long papers (P90 **139K chars**) where window ≪ full doc. Quality risk: **MEDIUM** — index must include dehyphenation-normalized forms or join-site false-fails recur (`research/all-pages-llm-coverage/21-false-fail-review-mode.md:22`).

- [MED] **Scoping does not reduce decode time; fleet bottleneck stays call-count × decode.** Evidence: `pdf_judge.py:27-28` (~**70 tok/s** decode); unit output cap **1536 tok** (`00-baseline.md:27-28`); **70% zero-defect unit checks** (`00-baseline.md:29-30`). Shrinking input saves prefill only; each call still pays **~17–27 s decode** (`02-prompt-token-auditor.md:16,20`). Impact: even **100% prefill elimination** on unit calls saves **~≤14% wall** (prefill share); reaching **3003 s → 300–600 s** still requires call elimination / dual-pod / parallelization levers from `00-baseline.md:88-103`. Quality risk: none from prefill-only optimization.

- [LOW] **APC with no shared prefixes adds overhead; fix share ratio first.** Evidence: `05-web.md:81-82` (~**36.7% throughput overhead** when prefixes never match). Current per-call random tags guarantee **zero md sharing** until prompt reorder. Impact: enabling APC before fixing prompt structure may **hurt** more than help; reorder first, then tune `VLLM_PREFIX_CACHE_RETENTION_INTERVAL` (`05-web.md:6-9`). Quality risk: none.

## False-pass hypothesis

Section-window scoping without a full-doc presence index: on a **cross-page join** (`tomd/CLAUDE.md:231-232`), page-13 tail text lives under page-12's markdown heading; the LLM sees only page-13's window, reports `content_omission`, but post-hoc grounding refutes only if the model emits a verbatim `source_quote` — a **pass** verdict with silent missed join corruption would slip through if the model rubber-stamps (`research/all-pages-llm-coverage/SYNTHESIS.md:13`).

## False-fail hypothesis

Full presence index + unchanged grounding: model flags a dangling `"listed in"` join fragment as missing; index/hash set shows the phrase exists document-wide; model caps at **pass/review** per ANYWHERE rule — but if index normalization is too strict (exact alnum fold only), dehyphenated or wording-markup-wrapped matches stay invisible and verified defects inflate (`grounding.py:487-489`, fuzzy abstains to `ambiguous`).

## What would change my mind

A `--debug` sidecar replay logging vLLM `prompt_tokens` and APC hit rate per call type showing **≥50% fleet wall** is prefill (not decode) on unit checks — that would elevate payload scoping above call elimination and flip the "insufficient alone" finding.
