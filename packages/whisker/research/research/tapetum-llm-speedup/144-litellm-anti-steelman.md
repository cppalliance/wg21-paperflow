## Findings

- [CRITICAL] **Dependency weight dwarfs `pipeline` and pulls cloud/proxy surface we do not need.** Core SDK declares **12 direct deps** (`pyproject.toml:17-28`: httpx, openai, pydantic, aiohttp, tiktoken, tokenizers, jinja2, …). Frozen workspace lockfile counts **435 packages** (`uv.lock`, 435 `[[package]]` entries; comment at `pyproject.toml:38-39` says reproducibility comes from this lock). Optional `[proxy]` alone adds FastAPI, Granian, boto3, Azure SDK, Prisma, cryptography, MCP, etc. (`pyproject.toml:43-75`). Code mass: **2149** Python files under `litellm/`, **132** provider directories under `litellm/llms/`, **10278** lines in `router.py` alone. Contrast: `pipeline` ships **5 direct deps** (`packages/pipeline/pyproject.toml:8-14`) and four family backends in one module (`model_backends.py:15-19`, `pipeline/CLAUDE.md:7`). Impact: **0 s** wall savings on 3003 s run; adds supply-chain audit surface, install time, and version-pin conflict risk with our pydantic-ai stack. Quality risk: **LOW** for speed; **MED** for security/maintenance drag.

- [CRITICAL] **Abstraction mismatch: generic OpenAI-shaped adapter vs one-`ModelBackend`-per-family mechanical workarounds.** LiteLLM's entry is `completion(...)` with optional `response_format: Union[dict, Type[BaseModel]]` (`main.py:4811-4834`, `428-453`) — a provider-agnostic dispatch layer. Our contract requires each backend to own BPE cleanup, `<think>` stripping, schema-in-prompt, JSON extraction, sampling pins, and bounded retries internally (`model_backends.py:9-19`, `46-54`, `310-337`; `pipeline/CLAUDE.md:46-54`, D2). LiteLLM's 132 provider trees implement *translation*, not tapetum's *workaround inventory* (`MODELS.md`). Dropping `VllmThinkingBackend` behind `litellm.completion(model="openai/deepseek-v4-pro", …)` would lose family-specific retry-on-truncation (`model_backends.py:64-73`) and pydantic-ai `UsageLimits.request_limit` wiring (`agents.py:110-136`, D9/D10). Impact: **negative** for structured-output reliability (55 BPE retries ≈ 100 s today, `00-baseline.md:60-61`); refactoring cost >> persona 21/140's ~40-line whisker shims. Quality risk: **HIGH** (schema/BPE regressions).

- [CRITICAL] **Importing LiteLLM strains CLAUDE.md invariants D1, D5, D6, and "no global state."** D1: every LLM call must go through `run_agent` / `run_task` (`CLAUDE.md` Determinism). LiteLLM is a parallel `completion()` / `Router.acompletion()` API (`main.py:4811+`, `router.py:6483-6570`). D5/D2: backends pin `temperature=0.0`, `seed=0`, `top_k=1` (`model_backends.py:310-336`, `631-636`); LiteLLM forwards caller kwargs and provider defaults — no project-wide sampling floor. D6: structured output via Pydantic `output_type` on every step; LiteLLM optional `response_format` is not wired to our `StepHooks` / `ModelRetry` validators. Global mutable module state: `litellm.cache`, `client_session` / `aclient_session`, `model_cost_map_url` fetching GitHub JSON (`__init__.py:374-377`, `396-402`) — violates `pipeline/CLAUDE.md` "No global state" and offline-first posture. Impact: **0 s** speedup; **HIGH** determinism/fidelity audit cost. Quality risk: **HIGH**.

- [HIGH] **Hidden retry stacks inflate tail latency and can reroute mid-chain.** Router defaults `num_retries` to `openai.DEFAULT_MAX_RETRIES` when unset (`router.py:559-564`). `async_function_with_retries` re-invokes `make_call`, refreshes healthy deployments each attempt, sleeps via `_time_to_sleep_before_retry`, and mutates response headers (`router.py:6486-6570`, `6565-6568`; `router_utils/add_retry_fallback_headers.py:205-219`). A second router retry layer on top of 2284 calls adds opaque duplicate attempts; cross-deployment retry breaks paper-local pod pinning (persona 140/22). Impact: **+0–200 s** tail (duplicate 429/5xx paths); **quality risk: MED-HIGH** (MoE batch composition + prefix-cache locality loss, `05-web.md:69-77`).

- [HIGH] **Default caching and routing opacities fight quality-stability.** Global `litellm.cache = None` by default (`__init__.py:376`), but Router with `cache_responses=True` sets module-global `litellm.cache = litellm.Cache(...)` (`router.py:483-487`) — side effect on import path.
