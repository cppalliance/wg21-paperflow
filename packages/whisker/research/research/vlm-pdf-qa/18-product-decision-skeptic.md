# 18 - Product-Decision-Skeptic

**Verdict:** usable-with-conditions — the operator need (verify conversion against the source, not the artifact chain) is real, but the plan as stated oversells "independence" while the portable repo pattern is image-plus-markdown comparison or a second converter plus deterministic diff; zero-shot VLM-as-judge without a finetuned 7B cannot deliver the claimed value on a corpus where det already passes 43% outright and fusion only moves advisory verdicts in narrow branches.
**Confidence:** high

## Findings

- [CRITICAL] **Claim: "LLM judges independently of the deterministic lane." Delivered design in prior art is not independent.** coarse (the closest open-source verifier) renders page PNGs and sends them **with** the corresponding markdown chunk to a vision LLM (`05-web.md` Q5 → https://github.com/Davidvandijcke/coarse/blob/dev/src/coarse/extraction_qa.py). Today's tapetum_llm is worse: it injects whisker verdict, flags, and metrics into every triage header before the markdown (`adjudicate.py:379-392`), so the model sees the det lane's opinion, not a blind second read. Impact: pairing page images with the same markdown the det lane already scored is **correlated evidence**, not independence; marketing this as "LLM prüft unabhängig" misstates what fusion compares.

- [CRITICAL] **True independence is already partially implemented on the det side, and olmocr-as-second-converter is the cleaner architectural alternative.** `score_paper` runs markitdown as a second deterministic converter and scores text agreement (`score.py:289-301`, `reference.py:45-65`). Swapping the oracle engine to olmocr (PDF-native VLM conversion, `00-baseline.md:13-19`) and diffing with existing `text_nid` / `table_score` / TEDS yields **two independent extraction paths fused deterministically**, with no ~60% OCR-category hallucination budget from a zero-shot judge (`05-web.md` Q4 → https://arxiv.org/html/2406.17115v1). Impact: for the user requirement "unabhängig prüfen, dann vergleichen," VLM-as-second-converter + det diff matches the requirement; VLM-as-judge-with-markdown-sidecar does not.

- [HIGH] **Many "PDF-only" error classes are already caught or soft-flagged by det + extract; the incremental PDF-only surface is narrow.** `check_paper_content` compares PyMuPDF `page.get_text()` to markdown and surfaces missing/extra regions with page numbers (`check_content.py:260`, `score.py:243-277`); its own matrix lists dropped paragraphs, dropped figure **captions**, and lossy tables as **yes**, while heading skips and unfenced code as **no** (`check_content_arch.md:331-343`). Whisker folds `qa_score`, `lossy_table_count`, `table_parse_errors`, and `uncertain_count` from `tomd` QA into soft review (`score.py:170-173`, `qa.py:102-103`). Impact: dropped text-rich pages and broken table parses are largely det-lane problems already; the plan's value concentrates on **token-preserving semantic corruption** (cell swap, section permutation, visual-only wording), not on generic "seeing the PDF."

- [HIGH] **PDF-only blind spots vs det: a concrete inventory.** (1) **Table cell transposition** with all tokens present: det miss by design (`packages/whisker/research/persona/18-wg21-domain-expert.md` cited in `19-steelman.md:9`; `unigram_coverage` gate at `score.py:156-160`). (2) **Reading-order / section permutation**: shingle `coverage`/`drift` reported but **never hard- or soft-gates** (`score.py:136-138`, `constants.py:21-33`). (3) **Visual-only ins/del markup** (raster color, no text layer): whisker pass on matching tokens (`13-adversary-evasion.md:27`, `score.py:130-131`). (4) **Low-text / figure-only dropped page**: both lanes can false-pass when omitted page contributes little to `unigram_coverage` (`13-adversary-evasion.md:21`, `check_content_arch.md:334` catches caption **text** loss, not wrong figure content). (5) **Caption vs image semantic mismatch** (alt from regex, wrong diagram): not in check-content matrix (`check_content_arch.md:331-343`). (6) **Glyph-layer / CMap shared blind spot**: explicitly "no" for both paths (`check_content_arch.md:343`). Impact: VLM-on-PDF helps classes (1)-(5) **in principle**; class (6) needs a second **text** extractor (Poppler/pdftotext), not pixels alone (`check_content_arch.md:361-364`).

- [HIGH] **Surveyed-repo evidence supports VLM-as-judge only with task-specific finetuning, not zero-shot deployment.** DOCR-Inspector (closest academic match) uses page/element images plus parsed output with a **DOCR-Inspector-7B finetuned** model and 28-type checklist (`05-web.md` Q5 → https://arxiv.org/abs/2512.10619). Zero-shot judges face HQH **~60% average OCR-category hallucination** and MTabVQA **37.0% EM / 61.7% F1** for GPT-4.1 on rendered tables, open-source **2.1-11.8% EM** (`05-web.md` Q4 → https://arxiv.org/html/2406.17115v1, https://aclanthology.org/2025.findings-emnlp.1083). Hot repos in `00-baseline.md` with real page-image paths (olmocr, marker, MinerU, Dolphin, docling) are **CONVERSION** pipelines, not conversion-QA judges (`00-baseline.md:26-45`). olmOCR itself is "built for PDF->Markdown conversion, not open-ended QA" (`05-web.md` Q1). Impact: porting olmocr rasterization without DOCR-Inspector-7B (or equivalent finetune) ships the **conversion** stack while selling **QA**; the evidence base does not support zero-shot VLM-as-judge at production FPR.

- [MED] **Marginal verdict impact is low given det pass rate and asymmetric fusion.** Ref-free det on 382 papers: **163 pass (42.7%), 205 review, 14 fail (3.7%)** (`packages/whisker/research/persona/00-EVIDENCE-BASELINE.md:59`). Fusion only changes merged advisory verdict in narrow branches: det=pass + LLM fail(major) → merged **review only**, never fail (`fusion.py:203-215`); det=review + LLM pass → merged pass (`fusion.py:166-201`, clearing **101/232** reviews = 44% of the **review queue** for the existing **markdown** LLM, `research/hybrid-llm-scoring/SYNTHESIS.md:13-14`). Pass-tier papers without risk signals never reach tapetum at all (`adjudicate.py:99-101`, `114-126`; selection gap in `research/hybrid-llm-scoring/SYNTHESIS.md:48`). Impact: on the **163 det-pass** cohort, a new VLM lane can only **escalate** advisory review via major fail, not save failures; incremental **merged** verdict changes across the full corpus plausibly sit in the **low single-digit percent** (escalations minus clears on a candidate subset), while full-page VLM cost scales with **189 PDFs × 3-13 pages** (`00-baseline.md:80-81`) and requires a **new multimodal pipeline** (`00-baseline.md:72-73`, no vision service in `SERVICES.toml:73-74`).

- [LOW] **Implementation cost is front-loaded; delivered value is back-loaded and unmeasured.** End-to-end multimodal support is absent today: `run_agent` / `ModelBackend.run` accept `user_message: str` only (`00-baseline.md:72-73`), `StepContext.inject_untrusted` is text-only (`runner.py:119-121`). A VLM service (e.g. Qwen2.5-VL / olmOCR-2) needs new backend class, pinned `mm-processor-kwargs`, serial per-page loop (D11, `11-determinism-auditor.md:20`), and labeled holdout calibration that **does not exist** (`00-EVIDENCE-BASELINE.md:93-96`, zero real corpus members). Impact: the plan spends engineering on plumbing before proving incremental recall over markdown tapetum on the false-pass population the lane was built for (`tapetum_llm` purpose in `score.py` header comment block via `CLAUDE.md`).

## False-pass hypothesis

**P3844-class token-preserving corruption** (coverage 0.507, shipped at tapetum conf 0.95 per `research/hybrid-llm-scoring/SYNTHESIS.md:35`): det **pass** or soft **review**, coarse-style VLM judge at 150 DPI (`05-web.md` Q5 coarse card) hallucinates agreement with the markdown (HQH OCR-category ~60% error, `05-web.md` Q4), returns **pass** with empty evidence (`tapetum_llm.md:106`, `adjudicate.py:295-298` demotes ungrounded non-pass only). Fusion applies `llm_clear_soft_review` (`fusion.py:166-201`) → combined advisory **pass** while `whisker --gate` still reads det alone (`fusion.py:12-13`). Operator trusts merged sidecar; semantic table corruption ships.

## False-fail hypothesis

Faithful wording paper with ins/del visible only as red/green raster strokes: VLM at marker highres 192 DPI (`00-baseline.md:22`) flags missing ins/del as tables/wording **fail+major**, whisker **pass** on text-layer tokens (`13-adversary-evasion.md:27`). Fusion: det=pass + major → merged **review** only (`fusion.py:204-215`), inflating human queue without blocking ship — noise sold as safety.

## What would change my mind

A labeled holdout (≥30 WG21 PDFs, human-adjudicated conversion defects) showing **(A)** page-aligned VLM-as-judge with DOCR-Inspector-7B-class finetune catches **>80%** of token-preserving false passes that det **pass** and markdown tapetum miss, at **≤10%** incremental false merged-pass rate under `fuse_verdicts`, **or (B)** olmocr-as-second-converter deterministic diff catches the same class with **zero** sampling hallucination and measurably lower ops cost than per-page zero-shot judging — would flip the verdict to **usable** and pick the winning architecture explicitly.
