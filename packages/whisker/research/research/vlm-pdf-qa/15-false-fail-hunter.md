# 15 - False-Fail-Hunter

**Verdict:** usable-with-conditions — a naive page-image-vs-markdown VLM judge will flood the advisory review queue by flagging intentional tomd normalization and hallucinated OCR diffs; the plan is adoptable only with an explicit conversion-contract prompt, DOCR-style checklist gating, and major-only fusion escalation, otherwise it inverts the lane's purpose.
**Confidence:** high

## Findings

- [CRITICAL] **Page furniture stripped by tomd is a deliberate contract, but a visual VLM judge has no equivalent sanction list and will flag every omission as missing content.** Evidence: tomd step 6 strips repeating headers/footers, page numbers, and running doc numbers before extraction (`packages/tomd/src/tomd/CLAUDE.md:17,215-224`); whisker already treats furniture-only region mismatches as benign when `unigram_coverage >= 0.95` (`packages/whisker/src/whisker/score.py:183-190`, `REGION_BENIGN_UNIGRAM_FLOOR` at `tapetum_llm/constants.py:93`). Impact: on the current corpus, **47/181 det-pass** rows carry misaligned-region soft flags (`data/whisker/llm/report-merged.json`); a VLM comparing page raster to markdown will see footer lines ("Document #: P4182R0", page *N* of *M*) absent from md and emit `segment_lost` / wording-axis fails — the exact false-fail class persona 14 hypothesized (`14-false-pass-hunter.md:28`). DOCR-Inspector's 28-type taxonomy includes text-level `segment_lost` without a "sanctioned chrome" class (`05-web.md` Q5 DOCR-Inspector card); coarse returns a 3-tier `good/acceptable/poor` rating rather than hard reject (`05-web.md` Q5 coarse card); marker's `--use_llm` refines already-parsed blocks and does not independently judge whole-page omissions (`00-baseline.md:26`).

- [CRITICAL] **Fusion escalates det-pass papers to review on any LLM/VLM fail+major, so false-fail volume directly floods the human queue even though it never hard-fails.** Evidence: `fuse_verdicts` maps `det=pass` + `llm=fail` + `_has_major_axis_fail` → `combined_verdict=review`, rule `llm_escalate_major` (`packages/whisker/src/whisker/tapetum_llm/fusion.py:204-215`); tapetum is advisory-only and the lane's stated goal is reducing review load (`packages/whisker/src/whisker/CLAUDE.md` tapetum_llm section). Impact: today **0** rows hit `llm_escalate_major` while **171/181 det-pass** rows have no LLM verdict at all (`report-merged.json`); the baseline plan expands from selective candidates (`adjudicate.py:83-111`) to **ALWAYS** feeding the PDF (`00-baseline.md:5`), exposing the full pass tier. HQH reports **>40% overall hallucination** for most evaluated LVLMs and **~60% average OCR-category hallucination** (`05-web.md` Q4 HQH card). A conservative **30% false-major rate** on the pass tier yields **~54 new escalations** (181×0.30); scaled to the **189-PDF** corpus (`00-baseline.md:80`) that is **~27 papers**, on top of the current **99/381 merged-review** rows (**~49** at 189-PDF scale) — a **55–70% review-queue increase** if mitigations are absent.

- [HIGH] **Figures, pipe tables, and syntax-highlighting colors are intentional representation changes invisible to a naive visual diff.** Evidence: tomd emits raster figures as `![alt](path)` with caption-derived alt text (`packages/tomd/src/tomd/CLAUDE.md:67-68,48`); tables reflow to pipe syntax (`packages/whisker/src/whisker/CLAUDE.md:150` — normalized_text strips pipe formatting for comparison because layout is not the signal); syntax-highlighted code blocks lose chromatic spans — non-green/red/blue color triggers a block-level skip as "syntax-highlighted code" (`packages/tomd/src/tomd/lib/pdf/wording.py:197-204`). Impact: a VLM sees colored C++ on the page and monochrome fenced code in md → `code` axis fail; sees a rendered table grid vs `| col |` pipes → `tables` axis fail; sees inline figure pixels vs `![Figure 1: ...](p1234-fig2-0.png)` → `structure` or `wording` fail. olmOCR-Bench scores **96.1% on headers/footers** and **84.9% on tables** as a *conversion* model (`05-web.md` Q1 olmOCR card), not as proof it will ignore those diffs when asked to *judge* fidelity; marker LLM processors (`llm_table`, `llm_equation`, `llm_page_correction`) *repair* parsed blocks rather than reject normalization (`00-baseline.md:26`).

- [HIGH] **LaTeX/math is an inherent visual-vs-text mismatch: PDF shows rendered glyphs, markdown carries source notation.** Evidence: tapetum's `math` axis explicitly flags `\frac{a}{b}` collapsed to `a/b` as a defect (`packages/whisker/src/whisker/tapetum_llm/tapetum_llm.md:59`); whisker's cross-converter `normalized_text` folds inline LaTeX to unicode via `pylatexenc` specifically so text axes compare *content* not *notation* (`packages/whisker/src/whisker/CLAUDE.md:145-150`). Impact: a VLM page image shows ∫, ∑, and stacked fractions while md may show `$...$`, `\(...\)`, or unicode escapes — the judge will report `math`/`wording` major fails on faithful conversions. DOCR-Inspector's equation types (`05-web.md` Q5) target parsing errors in extracted output, not "rendered-vs-source notation equivalence"; coarse pairs image+markdown chunk and asks for a quality tier (`05-web.md` Q5 coarse card), which is closer to lenient grading than our axis-level `fail`.

- [HIGH] **Multi-column reflow is correct when `unigram_coverage` is high but looks "wrong" in reading order on the page image — repeating a known whisker false-fail history.** Evidence: shingle `coverage` hard-gating falsely failed **43 papers** where tomd correctly reflowed multi-column text (95% words present, 66% sequential); fix moved the content gate to order-invariant `unigram_coverage` (`packages/whisker/src/whisker/CLAUDE.md:318-320`). `report-merged.json` shows **250/381** rows with `unigram >= 0.95` and `overall < 0.7` (reflow signature); **126** of those are already det-pass. Impact: a VLM judging visual reading order against linear markdown will flag column-major vs row-major permutations as `structure` fails even though whisker passes them — the same defect class the deterministic lane was calibrated to stop failing on. M3DocDep shows naive page chunking costs **4.5–15.3 ANLS points** vs dependency-aware chunking (`05-web.md` Q4 M3DocDep card), implying order judgments without layout-aware pairing are unreliable.

- [MED] **VLM hallucination fabricates differences that do not exist, turning clean det-pass papers into escalated review.** Evidence: HQH — GPT-4o lowest at **13.6%** hallucination, still >10%; **>40%** for most models; OCR hardest at **~60%** average (`05-web.md` Q4 HQH card). DocVAL's post-hoc OCR-region grounding validator adds **+12.4 mAP** by filtering hallucinated traces (`05-web.md` Q4 DocVAL card). Impact: without bbox-grounded cross-check, a VLM can "read" footer text, phantom table cells, or math symbols from the page image, emit `fail+major` on the `wording`/`tables` axis, and trigger `llm_escalate_major` on papers whisker already passed — pure queue noise. The current text-only tapetum lane at least grounds evidence quotes in markdown (`tapetum_llm.md:106`); image hallucination is a new failure mode with no mitigation in the baseline plan (`00-baseline.md:73` — no multimodal pipeline yet).

- [MED] **A VLM lane that false-fails review-tier papers can undo the lane's clearest win: `llm_clear_soft_review`.** Evidence: fusion rule `llm_clear_soft_review` promoted **95** det-review papers to merged-pass when LLM confidently passed soft-flag-only whisker results (`fusion.py:168-201`; `report-merged.json` — all 95 had `det=review`, `merged=pass`). Impact: re-running with a harsher VLM judge on the same population risks reversing those 95 clears back to review (or worse, if VLM `fail+major` meets a det-review paper, default fusion keeps det-review — `fusion.py:217-227` — but the inspect burden returns). Net effect: false-fails do not only add pass-tier escalations; they can erase the **25%** review reduction the text lane already achieved on this corpus.

- [LOW] **Prior art that handles normalization best uses lenient tiers or reconstruction checks, not binary page-vs-md rejection.** Evidence: coarse `extraction_qa.py` returns `good/acceptable/poor` plus find-replace corrections (`05-web.md` Q5 coarse card); RaV-IDP scores *reconstructed* entity renders against source crops and triggers fallback only on low fidelity (`05-web.md` Q5 RaV-IDP card); olmOCR is finetuned for PDF→markdown conversion (headers/footers **96.1%** on olmOCR-Bench) not open-ended rejection (`05-web.md` Q1). Impact: porting coarse's binary "poor = fail" without its tier semantics, or DOCR's taxonomy without sanctioned-diff classes, will be stricter than our whisker+tapetum contract and misaligned with the queue-reduction goal.

## False-pass hypothesis

None found for this persona's scope (over-strict judging is the failure class under review). The complementary risk — VLM falsely *accepting* semantic defects on det-pass papers — is persona 14's charter (`14-false-pass-hunter.md`).

## False-fail hypothesis

**P3100R6-class administrative paper, det-pass with benign furniture strip:** PDF page footer shows `WG21 / P3100R6 / 2024-01` and a page number; markdown omits both by design (`tomd/CLAUDE.md:215-224`). Whisker passes with `(benign) misaligned region(s)` and `unigram_coverage >= 0.95` (`score.py:183-190`). VLM page image judge reports `wording` axis `fail`, severity `major`, evidence "footer line missing from markdown." Fusion: `det=pass` + `llm=fail` + major → `llm_escalate_major` → merged **review** (`fusion.py:204-215`). Human inspects a correct conversion.

## What would change my mind

A held-out evaluation on the **181-paper det-pass tier** (or **~90** at 189-PDF scale) running the proposed VLM prompt with an explicit sanctioned-diff appendix (furniture, image refs, pipe tables, syntax-color loss, math notation) plus DOCR-style Chain-of-Checklist, showing **≤5% false-major rate** (≤9 papers) while preserving persona-14's false-pass catch rate on injected defects — measured against `report-merged.json` baselines, not synthetic-only.
