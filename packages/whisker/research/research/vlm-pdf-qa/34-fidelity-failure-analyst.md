# 34 - fidelity-failure-mode-analyst

**Verdict:** usable-with-conditions — a per-page VLM QA lane is fidelity-viable only if it rejects olmocr-style page fallbacks and tapetum-style partial-review aggregation; every uncovered page or ungrounded claim must surface as `status=error`, never as a complete-looking sidecar.
**Confidence:** high

## Findings

- [CRITICAL] **PyMuPDF rasterization failures must fail the paper before any VLM call; olmocr instead substitutes pdftotext and may still emit the document.** Evidence: `fitz.open()` raises `fitz.FileDataError` (subclass `RuntimeError`; also `fitz.EmptyFileError` for zero-byte files) on corrupt xref / unreadable PDF; no separate `PasswordError` class in PyMuPDF 1.27.2.3 — encrypted PDFs surface as `FileDataError` / unreadable text at open or first `page.get_pixmap` (`packages/tomd/src/tomd/lib/pdf/pipeline.py:1407-1411`, runtime `import fitz` check). olmocr rasterization shells out to `pdftoppm` and raises `ValueError` on nonzero exit (`renderpdf.py:39-60`, GitHub `allenai/olmocr`); per-page VLM exhaustion calls `make_fallback_result()` which fills `PageResponse.natural_text` from `pdftotext` anchor text, **not blank** (`pipeline.py:229-246`, `:323-326`, `:365-369`); document is discarded only when `num_fallback_pages / num_pages > max_page_error_rate` (default **0.004**, ~1/250) (`pipeline.py:547-553`, `:1200`). Impact: olmocr's default is **pragmatic partial output** with silent quality degradation; under root `CLAUDE.md` fidelity ("fail not partial") a VLM QA lane must treat any raster failure on page *k* as **paper-level error**, not anchor-text fallback.

- [CRITICAL] **Schema-invalid output on one page of thirteen must be `status=error`, not "review with missing pages annotated."** Evidence: pydantic-ai backends pin `retries=3` on `Agent(...)` (`packages/pipeline/src/pipeline/model_backends.py:455-460`, D10 analogue); exhausted retries raise through `run_agent` → `StepError` (`packages/pipeline/src/pipeline/runner.py:265-274`, `:385-391`). Current tapetum chunk loop has **no per-chunk firewall**: one failed `run_agent` aborts the whole paper (`adjudicate.py:218-223`); only **hard-split oversize** sets `state.partial` and demotes pass→review (`chunking.py:136-136`, `:148-150`; `adjudicate.py:300-304`). When dispatch completes without `_result`, `adjudicate_paper` returns `TapetumResult(status="error", suggested_verdict=review, confidence=0.0)` (`adjudicate.py:507-518`); fusion treats `status=="error"` as unusable and keeps deterministic verdict only (`fusion.py:85-93`, `:17`). Impact: fidelity-pure policy for a **per-page** lane: 12/13 successful page verdicts is a **partial result mistakable for complete**; correct verdict is **`error`** with `pages_completed=12`, `pages_failed=[k]`, `failure_reason=schema_exhausted`, sidecar explicitly **not** aggregating pass/fail across pages.

- [CRITICAL] **VLM hallucination is a silent false-pass unless every finding is quote-grounded and verified against deterministic text.** Evidence: HQH benchmark — OCR hardest category, **~60% average hallucination** across models (`05-web.md` Q4 HQH card, `https://arxiv.org/html/2406.17115v1`). DocVAL post-hoc grounding (answer + OCR-region presence + bbox geometry) yields **+12.4 mAP** from filtering hallucinated traces alone (`05-web.md` Q4 DocVAL card, `https://arxiv.org/html/2511.22521v2`). Tapetum already grounds evidence quotes against **markdown** via `ground_spans()` and drops ungrounded spans (`grounding.py:170-240`; `adjudicate.py:279-296`); a VLM lane must extend this to **dual grounding**: (1) `quote_md` ⊆ converted markdown (existing), (2) `quote_pdf` ⊆ `page.get_text()` from PyMuPDF on page *k* (deterministic text layer, same path as `check_content.py:259-260`). If the VLM claims "missing table row" but `quote_pdf` is absent from the PDF text layer, downgrade finding to `unverified` and force paper **`error`** if any major-axis claim fails dual grounding. **Nougat-style repetition guard** (variance threshold in `StoppingCriteriaScores`, varvar `< 0.045` post-decode — `research/llm-readability/repo-scan/nougat.md:23-25`) catches degenerate VLM loops before they become confident per-page passes.

- [HIGH] **Page-count mismatch (PDF `page_count` ≠ markdown section cardinality) is a hard structural error, not an advisory finding.** Evidence: tomd records `result.page_count` from `doc.page_count` (`pipeline.py:1408-1436`); body contract is H2-per-section (`chunking.py:131-133`, `00-baseline.md:69-70`). olmocr aborts document when `PdfReader` cannot count pages (`pipeline.py:521-526`). A VLM lane comparing page *k* image to markdown chunk *k* requires **`assert pdf_page_count == len(page_verdict_slots)`** before aggregation; mismatch → `status=error`, `failure_reason=page_count_mismatch`, no per-page verdict fold. Impact: treating mismatch as `review` would let an operator ship a conversion missing an entire page while 12/13 pages say pass — violates fidelity contract.

- [HIGH] **Timeout or pod-unreachable mid-paper must leave no partial sidecar; resume requires page-level checkpoints and atomic final write.** Evidence: tapetum CLI uses `_PAPER_TIMEOUT_SECONDS = 900` and on exception writes **no** tapetum artifact (`cli.py:63-67`, `:532-549`); sidecar persistence is direct `out_path.write_text(...)` without temp+rename (`cli.py:262-265`) — contrast `paperstore._atomic_write_bytes` (`.partial` then rename, `sqlite_backend.py:618-637`) and `write_qa_json_atomic` / `write_content_check_json_atomic` (`qa.py:582-587`, `check_content.py:953-973`). olmocr connection exhaustion calls `sys.exit(1)` after backoff (`pipeline.py:272-273`). Impact: mid-paper crash today can leave truncated JSON (research `21-error-handling.md:14-15`); VLM QA lane should persist **checkpoint JSON** per completed page via atomic replace, and only emit `<pid>.vlm-qa.json` when `pages_completed == pdf_page_count` OR atomically write `status=error` with checkpoint pointer for operator rerun.

- [MED] **olmocr emits non-blank fallback pages and proceeds; our lane must invert that policy.** Evidence: `PageResult.is_fallback=True` with `is_valid=True` (`pipeline.py:94-102`, `:229-246`); warning path when `0 < num_fallback_pages ≤ threshold` still builds Dolma doc (`pipeline.py:554-557`). Impact: porting olmocr's per-page loop without rewriting failure policy recreates exactly the "partial result mistakable for complete" failure mode the fidelity contract forbids.

- [MED] **Failure-policy table (failure mode → verdict/status → sidecar content → operator action).**

| Failure mode | Verdict / `status` | Sidecar content (minimum) | Operator action |
|---|---|---|---|
| Rasterization fails page *k* (`FileDataError`, `EmptyFileError`, pixmap OOM) | **`error`** — no aggregate pass/fail | `failure_reason=raster_failed`, `pages_failed=[k]`, `pages_completed` count, PDF path + page_count | Fix/replace PDF; rerun from page *k* after checkpoint |
| Encrypted / password-required PDF | **`error`** at open (before page loop) | `failure_reason=encrypted_pdf`, no page array | Obtain decrypted source; restage via paperstore |
| VLM schema invalid on page *k* after retry budget (D10 / `retries=3`) | **`error`** — do **not** emit 12-page aggregate | `failure_reason=schema_exhausted`, `pages_failed=[k]`, debug/trace refs for page *k* | Inspect debug transcript; adjust prompt/schema or service; rerun page *k* |
| VLM returns pass but dual grounding fails (quote not in PDF text layer or markdown) | **`error`** (major claim) or demote finding to `unverified` + **`review`** only if lane stays advisory | `grounding_failures[]` with `{page, axis, quote_pdf, quote_md, check}` | Human verifies page image vs source; fix conversion or grounding rules |
| VLM repetition / degenerate output (nougat varvar guard) | **`error`** for that page | `failure_reason=degenerate_output`, `pages_failed=[k]` | Rerun page; check model health / temperature pins |
| Page-count mismatch (PDF pages ≠ markdown page slots / H2 map) | **`error`** before aggregation | `failure_reason=page_count_mismatch`, `pdf_pages=N`, `md_sections=M` | Reconvert (`paperflow convert`); fix tomd section emit |
| Timeout / pod unreachable mid-paper | **`error`**; no final sidecar unless checkpoint complete | Checkpoint file with `pages_completed`, `last_good_page`; final sidecar absent or explicit `incomplete=true` | `--service` health probe (`cli.py:367-407`); rerun with resume from checkpoint |
| Crash during sidecar write (non-atomic) | **`unreadable`** (merge layer) | Truncated JSON — treat as no result | Delete corrupt sidecar; rerun paper |
| All pages adjudicated + grounded | **`ok`** + per-page + rolled advisory verdict | Full `page_verdicts[]`, dual-grounded quotes, `pdf_page_count`, paper.md hash | Normal fusion (`fusion.py:117-227`) |

## False-pass hypothesis

13-page WG21 paper (`n5036.pdf`, 13 pages per `00-baseline.md:81`): VLM returns confident **pass** on every page for a table row-swap defect (same tokens, wrong cells — det already passes at `unigram_coverage` ≈ 1.0, `score.py:156-160`). Without **DocVAL-style dual grounding**, the VLM invents a plausible `quote` that grounds in markdown (`ground_spans` fuzzy tier, `grounding.py:229-236`) but **does not appear** in `page.get_text()` for that page. Sidecar aggregates 13× pass → looks complete; fusion escalates nothing because tapetum advisory demotes only major axis fail on det=pass (`fusion.py:203-215`). Operator ships semantic corruption.

## False-fail hypothesis

Clean conversion where tomd strips page furniture (headers/footers) by design (`packages/whisker/src/whisker/CLAUDE.md` verdict model): VLM claims `segment_lost` because footer text visible in page image is absent from markdown. Strict **PDF-text-layer grounding** rejects the finding (footer was never in `get_text()` extraction path used for comparison) → correct **pass** if grounding gate requires quote in **both** markdown and body-relevant PDF text, with an explicit `furniture_excluded` allowlist for known edge bands (mirrors `cleanup.py` repeating-edge detection).

## What would change my mind

A holdout run on ≥20 real WG21 PDFs showing page-level VLM QA with **dual grounding + zero olmocr-style fallbacks** achieves ≤2% silent false-pass on defects that survive det `pass`, while marking ≥95% of induced single-page failures (raster kill, schema kill, timeout) as explicit `status=error` sidecars — with atomic writes and checkpoint resume demonstrated on an injected mid-paper pod kill.
