# 24 - nougat-vision-analyst

**Verdict:** usable-with-conditions — Nougat is a strong reference for logits-based degeneration detection and `[MISSING_PAGE_*]` failure markers portable to whisker, but as an encoder-decoder it is a second-converter (not a chat judge), runs at low fixed-resolution rasterization, and carries CC-BY-NC weights plus stale maintenance that make it a poor primary VLM QA lane versus olmOCR or instruction-tuned Qwen-VL judges.
**Confidence:** high

## Findings
- [HIGH] Rasterization uses **pypdfium2** at default **96 DPI** via `scale=dpi/72` (1.333×), not PyMuPDF/poppler; `LazyDataset` calls `rasterize_paper(pdf, pages=pages)` with no DPI override — `nougat/dataset/rasterize.py:18-49`, `nougat/utils/dataset.py:87-88`. In-memory pages are saved as **BMP** bytes before PIL open — `rasterize.py:52-55`. CLI/dataset tooling exposes `--dpi` default 96 — `rasterize.py:68-69`, `README.md:128`.
  Impact: WG21 pages at 96 DPI (~816×1056 px letter) are well below olmocr's 1288–2048 px longest-side default (`00-baseline.md:14-15`); fine math/code glyphs and dense two-column text lose detail before the encoder ever sees them.

- [HIGH] Swin encoder enforces a **fixed canvas** `[896, 672]` (height × width): margin crop → optional long-axis rotate (`align_long_axis` default **False**) → resize shorter side to `min(input_size)=672` → `thumbnail` to fit → symmetric pad to 896×672 → ImageNet normalize — `nougat/model.py:387-388`, `nougat/model.py:148-188`, `nougat/transforms.py:166-172`. Pretrained backbone init is `swin_base_patch4_window12_384` but `img_size` is overridden to the Nougat canvas — `model.py:72-85`.
  Impact: Aspect ratio is preserved with letterboxing, not distorted, but the entire page is downscaled into a single 672×896 viewport; multi-column academic layouts and small inline math share one resolution budget with no per-region crop (contrast marker block-crops at 192 DPI — `00-baseline.md:22-23`).

- [HIGH] **Logits-based repetition guard (portable QA signal)** operates at two layers during inference. (1) **Generation early-stop:** `StoppingCriteriaScores` tracks per-step max-logit variance in a sliding window (`L=15`, normalized), then variance-of-variance over 200 steps; when `varvar < 0.015` it schedules a stop index — `model.py:418-474`, `model.py:606-608`. (2) **Post-decode truncation:** stacks `decoder_output.scores`, takes per-step max logits, computes sliding-window variance `var`, then variance-of-variance `varvar` on reversed subsequences; if `varvar < 0.045` for consecutive windows and no early EOS, truncates sequence at computed index and logs a warning — `model.py:614-647`. (3) **CLI failure taxonomy:** `repeats[j] > 0` → `[MISSING_PAGE_FAIL:n]`; `repeats[j] == 0` with early-stop → `[MISSING_PAGE_EMPTY:n]`; postprocess-only → `[MISSING_PAGE_POST]` — `predict.py:178-191`. `--no-skipping` disables layer (1)+(2) gate — `predict.py:74-77`, `README.md:71-72`.
  Impact: This is a **reference-free self-consistency signal** (degenerate generation ⇒ unreliable page) directly portable to any autoregressive VLM QA lane; thresholds are hand-tuned (`0.015`, `0.045`, `minlen=120`) — `model.py:443`, `model.py:628`, `model.py:635` — and README documents false positives on CPU/older GPUs ([#11](https://github.com/facebookresearch/nougat/issues/11), [#67](https://github.com/facebookresearch/nougat/issues/67) — `README.md:83-84`).

- [HIGH] **Post-decode string guards** complement logits checks: `truncate_repetitions()` removes continuous tail repeats ≥30 chars — `postprocessing.py:102-165`, invoked at `postprocessing.py:361`; `remove_hallucinated_references()` detects near-duplicate reference lines (rapidfuzz ratio >0.9, slice length >15) and replaces with `[MISSING_PAGE_POST]` — `postprocessing.py:190-329`, `postprocessing.py:363`; absurd table rows dropped when `\begin{tabular}` >15 or `\multicolumn` >60 per line — `postprocessing.py:451-457`.
  Impact: Useful patterns for whisker to flag hallucinated bibliography blocks and runaway LaTeX, but regex/heuristic — not grounded in PDF coordinates (contrast DocVAL grounding in `05-web.md` Q4).

- [MED] **Math handling** is conversion-target LaTeX (inline `\(...\)`, display `\[...\]`, `tabular`), not QA. Eval splits predictions into Text / Math / Tables strata via regex before char-NED and set-F1 — `metrics.py:22-24`, `metrics.py:63-83`, `metrics.py:104-117`. Postprocessing applies math-specific fixes (`\mathbf`, `\tag`, subscript artifacts) — `postprocessing.py:37-55`, `postprocessing.py:369-377`.
  Impact: Confirms Nougat was built to **emit** math, not **verify** tomd math; a diff lane must normalize LaTeX delimiters heavily or false-fail on formatting-only drift (whisker already lacks math stratum on guard path — `packages/whisker/research/redteam/nougat.md:256-258`).

- [MED] **Multi-column / layout failure modes** are implicit, not documented as a feature. Training domain is arXiv + PMC scientific PDFs; FAQ states non-Latin scripts (Chinese, Russian, Japanese) **will not work**, and `[MISSING_PAGE]` often means domain mismatch or failure-detection false positives — `README.md:184-188`. No prompt or layout pass: Donut-style `model.inference(image_tensors=...)` with `do_sample=False`, no user text — `model.py:592-605`, `predict.py:167-168`. Fixed-canvas downscale (finding 2) is the main structural limiter for dense WG21 two-column prose + code blocks.
  Impact: WG21 papers are English and academic-shaped (favorable), but committee-specific layouts (narrow margins, code in small font, numbered proposal sections) are out-of-distribution versus arXiv preprints; expect elevated `[MISSING_PAGE_*]` rates without `--no-skipping`.

- [MED] **Not a JUDGE; fits second-converter + diff only.** Output is always a transcription (`.mmd` markup), never a fidelity verdict or structured QA schema — `predict.py:193-202`, `README.md:81`. Architecture: SwinEncoder + mBART decoder, no instruction channel — `model.py:37-114`, `model.py:504-519`. Proposed pattern: rasterize PDF → Nougat `.mmd` → deterministic diff vs tomd `.md` → treat large divergences + `[MISSING_PAGE_*]` as LLM-lane prior.
  Impact: **Strengths:** independent vision path (meets independence-purist requirement in `00-baseline.md:113`), built-in unreliability markers, `do_sample=False` generation — `model.py:605`. **Weaknesses vs chat-VLM judge (olmOCR, DOCR-Inspector, coarse `extraction_qa.py` — `05-web.md` Q5):** no "compare this markdown to the page" prompt; diff is format-sensitive (both sides are transcriptions); correlated errors if both miss the same table; double full-page inference cost; cannot catch semantic errors both converters agree on; CC-BY-NC model license blocks commercial production deploy — `LICENSE-MODEL.md:1-3`, `README.md:215`.

- [LOW] **Maintenance status:** not GitHub-archived; last upstream push **2025-02-21** (`remove levenshtein dependency #255`, clone `git log -1`). Model weights last released **2023-08-22** (`0.1.0-small` / `0.1.0-base` — `README.md:76-77`, GitHub releases). Open maintenance thread [#242](https://github.com/facebookresearch/nougat/issues/242) (Sep 2024, updated Jul 2025) cites unfixed blocking bugs and community migration to Marker/MinerU; ~140 open issues, no committed regression CI in upstream (Nougat eval is corpus-mean JSON only — `test.py` cited in `packages/whisker/research/redteam/nougat.md:15-17`).
  Impact: Port **algorithms** (repetition heuristic, failure markers, stratum metrics), not the repo as a maintained dependency; olmOCR-2 (Apache 2.0, Qwen2.5-VL, `05-web.md` Q2) is the better self-hosted second-converter baseline.

## False-pass hypothesis
Nougat and tomd both omit a complex inline equation in the same WG21 table cell (vision blind spot at 96 DPI + 672 px canvas). A deterministic diff shows high agreement on surrounding prose and no `[MISSING_PAGE_*]` markers (`predict.py:178-191`), so the fusion lane false-passes conversion fidelity even though math content is missing from both transcriptions.

## False-fail hypothesis
Failure-detection false positives on CPU (`README.md:83-84`) emit `[MISSING_PAGE_FAIL:n]` for valid WG21 pages with repetitive boilerplate (standard "Revision history" blocks or numbered clause lists triggering `varvar < 0.045` — `model.py:635-645`). A diff lane treats the page as failed/unconverted even when tomd captured the content correctly.

## What would change my mind
A controlled run on ≥20 WG21 `data/paperstore/*.pdf` pages showing Nougat second-pass `.mmd` vs tomd `.md` diffs (with failure markers disabled via `--no-skipping`) catch ≥80% of deliberately injected conversion errors (dropped table row, mangled `\verbatim` block) at ≤10% false-alarm rate — demonstrating the dual-converter pattern beats a single chat-VLM judge on our corpus without `[MISSING_PAGE]` noise.
