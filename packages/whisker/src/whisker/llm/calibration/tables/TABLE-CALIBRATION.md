loosen, merge, rename, or “simplify” an existing heuristic if a row below
or `TestNewFlagsControlPapers` goes red. If a new branch is too loud, narrow
*that* branch.

`table_probes._classify_unit` (dumps). Contract rules stay in
`deepseek-v4/tables/rules.toml`. No new rule IDs for these classes.
